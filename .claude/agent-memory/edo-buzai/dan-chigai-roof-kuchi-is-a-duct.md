2026-09-20 松江松平の雨押え(`build_matsudaira_dewa_buzai.py -- amaosae`)で踏んだ三つ。

- ⛔⛔ **段違いの「口」は管。**渡廊下が段を折ると下屋の上下の葺き面のあいだに口が開くが、
  抜けるのは①走り方向だけでなく **②幅方向(廊下の一方の軒先 ↔ 反対の軒先)**。
  **②が本体** — 横から覗くと 3.7m の隙間が素通しになる。⛔ 口の丈ぶんの板を1枚立てても
  板の脇に管が残る。⭕ **断面を埋める**。素通しの検査は**両方向へ**投げる。
- ⛔⛔ **瓦の上に載る部材の底は「谷」で取る。**谷は流れ方向の水路なので、山に載せると
  谷が全長の管になる(谷は山より 0.104m 深い)。⚠ ただし軒先では軒瓦・裏甲が名目面より
  0.11 下にあり、素直に最小を取ると軒の下へ 5cm 垂れて**鰭**になる ⇒ 名目面からの落ちに頭打ちを入れる。
- ⛔⛔ **`V.rotate_z(90)` を「枠を回す」用途に使わない。**cos が 6.1e-17 残り、
  端数が `round()` の .5 の刃(実例 −0.09295 = −929.5)に乗ると**幅の正負で切り上がりが逆**になり、
  左右対称の検算が落ちる。⭕ **整数だけの行列** (x,y,z)→(−y,x,z)。
- ⛔ 高い屋根の「裏」を max で1本に決めない。破風板と瓦場の継ぎ目に**幅 6mm の裏の無い一枚**が
  挟まって値が 0.12 跳ね、全区間が破風板と判定されて区画が空になる。⭕ 端から走査して段で割る。
- ⛔ 検証レンダで在庫部材を継ぐときは `hook_textures()` を**読み込みの後**に呼ぶ(先だと板が写らない)。
  画角も**部材そのものの外形**から組む(継いだ床板を含めると框が画面の隅へ落ちる)。

**Why:** 屋根どうしの取り合いは「見えている面」ではなく**空間のつながり**で決まる。
**How to apply:** 二つの屋根の隙を塞ぐ部材を作るときは、まず**どの向きに光が通るか**を数えてから形を決める。
