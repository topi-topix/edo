- 段の継ぎ目(直線・妻を見せる段)で両棟とも素の妻だと、低い方のけらば・袖瓦・破風が躯体の端から 0.322 高い棟の中へ入り、軒の出 0.63 の分だけ高い棟の壁の前に「欠けた屋根の止め+黒い破風」が出る(辺16 の写真)。⇒ 低い方の端を `--miter-cut 0.01 …`(msuf は 0 に丸めるので留めの名は不変・素の版は `--name`)+ `--seal --cut-kera lo` で焼く。高い方は素の妻のまま。札は jamb・passage 不変、eave.x0 が躯体の端へ・二端とも切ると height 7.183→7.118(既存の両端の留めと同じ)。
- 岡部の段の継ぎ目は 8 か所で、低い方は全部その駒の −X 端だった(roster の端点を突き合わせて機械で拾える)。片端の留めの版を両端切りにすると割付が据え置き(anchor C)に変わり窓の位置が動く ── 留めの継ぎ目の光線は 0/0 のまま。
- 頂点18 の屋根の黒い裂け目は同じ座の浅い入隅(−10°)の谷の流れで、切り面が丸瓦の筋とほぼ平行に走り、相手より高い丸瓦の脇(+X 向き)と断面の板が帯に見える。瓦の位相は窓割りの切り貼りに縛られ揃えられない ⇒ 谷の納め(谷瓦)が要るが意匠なので所見で返した。
- 写真の持ち主: scratchpad の scene.py(prefab の TRS で FBX を組み、Unity のカメラで撮る・`--probe x,y` で画素の持ち主と材と法線・`--cull` で Unity と同じ裏面の扱い)。P40 の青白い妻 = D_Corner_Masu(天 14.025・隣の溝 13.808)── 据えの側。

**How to apply:** 座の違う直線の継ぎ目の版を焼くときは低い端を切る版にする。新しい長さを焼くときも同じ引数で。関連 [[cut-kera-step-roof-and-naname-roof-back]] [[same-seat-miter-hip-and-short-standin]] [[nagaya-body-length-and-goten-root-offset]]
