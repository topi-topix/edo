- 壁の浅い版は同じ乱数で底・段鼻・水叩きを共有し、壁の丈だけ替え、踏面ごとの天端で _Ago の板を張った(縁の潜り 0.03 = 野面石の面取り 0.028 を覆う)。丈 < 0.36 は 1 段積み。.meta は A_Ago の写し。
- 検めの模型地形を駒の並びの座標と世界の座標(−0.5 ずらし)で取り違え、段の所で地形の三角形が溝に被さって「欠陥」に見えた ⇒ bed() は並びの座標で引き、溝の中の節点は前後 1 升の低い方の底へ。
