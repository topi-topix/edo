- 局所 +Z = 外のとき **+X は外から見て左 = 走りの進む向き**。走りの**始め**を切る駒は逆手(`--R`・切る端 −X)。
  849_L を辺0 の始めに据えて区画の外へ 3.07 出た(1 枚分ずれて反対へ伸びた)。逆手は素を鏡にせず組を −x へ置いて切る(巻きが裏返らない)。
