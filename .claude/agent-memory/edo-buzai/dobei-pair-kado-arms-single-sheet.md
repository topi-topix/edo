2026-10-12 施主の指摘(岡部の南の塀が内から透ける・冠瓦が二筋・棟止めが無い)を受けた監査(EDO-0502)で測った。

**事実:** `Dobei_Kado_*`(build_kado.py の PAIR)は裏の板(s_hei の b)が**折れ点の 1 駒分だけ**で、腕は表の板 1 枚 ⇒ 内から光線の 73% が抜ける(00/12M/90 とも)。施主の写真の「柱と縦の線だけが見えて向こうが透ける」はこれ。組の裏の寄せは load_pair が obj 単位で 0.2(×1.818 = 0.364)、直線の DobeiRun は世界 0.20 ⇒ 隅と直線で裏の板・棟の位置が 0.16 ずれる。直線の組も棟が 0.20 離れて二筋・小口は 0.36 の中空・端に鬼が無い(在庫の s_hei_l/r に鬼と袖瓦があるのに未使用)。
**Why:** s_hei_center は「表から見る片面 1 枚 + 屋根は芯の上」の模型で、2 枚重ねは厚みの偽装にしかならない。
**How to apply:** s_hei の組で新しい駒を焼かない。直すなら屋根を 1 組だけ使い、壁の表を鏡で裏へ写して厚み t で閉じた一つの断面(直線・切り・端・留めの隅)に作り直す。透けの検査は Light Path の Is Camera Ray で背景だけマゼンタにして(照明は灰)、表を向いた面だけ当たる光線で数える。[[magenta-background-finds-holes]] [[dobei-kado-short-arms]]
