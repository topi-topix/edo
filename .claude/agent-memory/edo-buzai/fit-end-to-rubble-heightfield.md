平面で切れない相手(乱積み)には「端を 0.01 升で刻み、光線の当たりへ頂点を詰め、食い込みは標本で退かす」で焼く(`Tools/Blender/build_sanno_sando_fit.py`)。

- `build_sanno_buzai.dan` の石は **Blender x = −Unity X** ⇒ `cuts` の先頭の石が Unity **+X** 端。取り違えると何も詰まらず「測った隙が小口のまま」になる。
- 頂点の値を窓の最小(侵食)で取ると、急な石の面で 傾き×窓 の隙が一面に出る(>0.01 が 4 割)。**石の段(隣の当たりと 0.02 以上違う所)の周りだけ**窓の最小へ下げ、残りの食い込みは 0.00125 升の標本+相手の三角形の頂点・辺の上の点で退かす(升の標本だけだと石の角が標本の間に隠れて 0.014 食い込む)。相手の目地(幅 0.04 未満)は開き(最小→最大)で跨ぐ。
- 袖(乱積み)を詰めると、坂上の個体の頂点が坂下へ寄って**天端の斜めの線を越え**、平面の背が痩せ切る高さより下では**坂下の端 Z=+踏面/2 を越える**。⇒ 当たりの帯より下は旧来の平面で切り、帯から上は先に平行面で余りを落としてから詰める。詰めた頂点は天端の線の下へ。当たりが今の背の面より 0.45 以上奥の所(E の袖の下半)もあるので届く幅は 0.80。

- r11(2026-09-27): **検査は Unity と同じ測り**(駒の点が相手の閉じた体積の中か・8方向の偶奇・見える地表より上)で回す。X に沿った隙の測りだけだと地表近く・横から入る石を見落とし Unity で 0.03〜0.07 出た。相手は閉じたメッシュ全体で受け取る。
- 袖は石を刻むと天端が欠片に割れる(施主指摘)⇒ 列ごとの走りの一次の写し(高さも勾配ぶん)で石を塊のまま伸縮。**多角形は測る前に三角形へ**(割り方の食い違いで 0.002 残る)。
- 出隅 Kado90 は稜線を回る横目地が腕から腕へ透けた ⇒ x=z の留めの板(両面・面から 0.03〜0.30)。見つけ方は「点を通る直線が両向きとも何にも当たらない」の探針。

**Why:** EDO-0437 参道の階で、隅石を退けると段の端に隙 0.12〜0.24、袖の背に口 0.04〜0.11 が残り、据えでは 0 にできなかった。
**How to apply:** 野面の相手へ突き付ける部材を焼くとき。形は据えの従属値 — 据えを変えたら棟梁に相手の三角形(局所)を書き出させて焼き直す。関連 [[sode-knee-vs-kado-arm]] [[nori-cut-step-and-sode]]
