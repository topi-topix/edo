- 天端を地盤と面一にした石の桝(Doi_Masu_G0)は、外の上の面取りと地形の穴の縁の間を内から斜めに抜けた光線が地中の空へ出た(マゼンタ)。⭕ build_doi_haisui.ring_skirt: 石の外面 −0.015 で +0.003 → 外へ 0.25 で −0.03 の土の輪+内の縁から石の中へ 0.03 潜る垂れ(芯向き)。垂れが無いと皮と石の 3mm の間から抜ける。
- 写した .meta は材の名簿も写す。土の皮を足したら Soil の externalObjects を足す(G1 の写しには無い)。
- 「高さ 1.2 級の隅」でも PlaceRunKado は両脇の直線材の実メッシュの丈(倍率 0.75 の Castle Wall = 3.00)で引く ⇒ 名は H0400_S075。見付で H0160 を焼かない(build_kado の --h は 4 未満を作れない)。
