松平出羽守邸の屋根 8 点(平入り+庇 5・渡廊下の下屋 3)を `build_goten_roof.make_hirairi` /
`make_rokageya` として起こしたときに踏んだもの。型は他邸でも使える。

**Why:** 指図の勾配(本6寸・庇4寸5分・下屋4寸)はどれも瓦モジュールの素の 5.5寸ではなく、
ピボットも既存の二系統(軒先 / 床)のどちらでもない「頭」が要った。

**How to apply:**
- **勾配を変えるときは瓦モジュールごと軒先の線まわりに回す**(`_tile_field_k`)。⛔ z を縮めない
  — 4寸なら起伏が 27% 潰れて実ジオメトリの瓦を使う意味が消える。送りの**平面上の**進みは
  `step.x` に縮むので格子の枚数はそちらで数える(`STEP_RUN` で数えると足りない)。
- ⛔⛔ **検証レンダの地面を z=0 に置かない。** 下屋はピボットが**頭**で本体が z<0 に在るため、
  z=0 の板が屋根を切って**大棟しか写らない**。「瓦場が焼けていない」と誤診しかけた(実際は 447 面)。
  地面は `mn.z − 0.05`、画角も**部材の実測から**取る(軒高の引数で組まない)。
- ⛔ **三方庇(`hisashiOmit`)は bbox で検算できない** — 庇を断った辺は本屋根の軒が 0.9 出るので
  **外形が四方庇と対称のまま**。⇒ 辺ごとに**軒先手前 0.3m の天端**を測る(庇 1.601 / 本屋根 2.313)。
  瓦は位相しだいで名目平面から −0.15〜+0.15 うねるので許容は下 0.16・上 0.30。
- 辺の綴り ↔ Blender 軸: **格子 +u = Blender −X / +v = Blender +Y**
  (u0=+X端 / u1=−X端 / v0=−Y端 / v1=+Y端)。→ [[fbx-name-mm-floor-float]] と同じ「軸と綴り」の系。
- **`当たり` は軒桁ではなく軒先の下端**(庇のある辺 = 軒桁 −(庇間数×1.818+軒の出)×庇勾配)。
  軒桁で読むと下屋が相手の軒を突き抜ける。下屋の頭 = 当たり − `roka.clear`。
- ⭐⭐ **下屋の頭を「軒先の下端」から取ると頭上が足りない**(2026-09-20 棟梁の実測 1.662 <
  `roka.zujoMin` 1.727)。指図の取り合いは**庇の軒桁の天端**(`_roka` ④)で、そこから取れば 1.742。
  ⇒ **庇の軒先を廊下の幅 1間だけ切り欠いた版**を別に焼く(`make_hirairi(notches=...)`)。
  受け面の実測はピボットから **z +1.926**(軒桁 2.744 の4棟)/ **+1.592**(厩)。
  ⚠ 切り欠きの位置は `links[]`×`munes[]` から解く(この邸は奥向4棟に6か所)。
  ⚠ 脇板は `V.box` で作らない(矩形だと軒下へ垂れる)。⚠ 検算は**真上からの光線** —
  受け板は箱なので頂点では測れず、nan を「焼けていない」と誤診しかけた。
- ⛔⛔ **切り欠きの受け面は「板」で、下端が厚のぶん下にある。** 当たりを**最小交点**で採る実機は
  その下端を拾うので、**板厚がそのまま頭上の余裕を食う** — 厚 0.08 で `roka.zujoMin` を 65mm 割り、
  「切り欠きが効いていない(切らないのと同じ数値)」と読まれた(2026-09-20 棟梁の実測)。
  ⭕ **3分(0.0091)**まで薄くして解決(頭上 1.7332・余裕 6mm)。⛔ 0 厚にはしない。
  ⇒ **面を出す部材は、面の高さだけでなく「その板の下端」も申し送る。**
- ⚠ **焼いた FBX へ光線を当てるときは二重の罠** — 取り込んだ物は **scale 0.01 + Y-up→Z-up の回転**を
  object 変換に持つ。①光線は `matrix_world.inverted()` で局所へ ②`distance` は**局所の単位**
  (世界 60m = 局所 6000)。短い距離だと届かず「交点なし」= 板が無い、と誤診する。
- 渡廊下の床 `Goten_FloorBoard_1ken`(キット `floor.fbx`)は**厚 0.0636** で、
  縁の下 0.34 − 0.0636 = 0.276 < `roka.ennoshitaMin` 0.303。⇒ **`Goten_RokaEnita_1ken`
  (厚 1寸 0.0303・縁の下 0.3097)を別部材で焼いた**(2026-09-20 普請奉行の発注。1寸2分 0.0364 が限界)。
  ⚠⚠ **その縁板だけピボットの z=0 が「板の天端」**(既存の床板は z=0 が**底**)— 床は面で落縁へ継ぐため。
  ⚠ 焼いた FBX を読み直して測るときは `o.matrix_world @ v.co` が**世界座標**(ピボットは FBX ノードの
  平行移動)。ピボット基準で見るには translation を外す。⛔ 複製を並べるときも `o.location` を
  **上書きしない**(加算する)— 上書きして 30mm ずれた絵を「板が二重」と読みかけた。
