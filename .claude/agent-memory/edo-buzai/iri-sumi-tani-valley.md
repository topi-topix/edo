- 入隅(θ<0)の同じ座の留めは切る面が丸瓦の筋とほぼ平行で、瓦の位相が揃わず片方が 5〜10cm 高く出る ⇒ `build_nagaya_omote.cut_tani`(入隅の端は既定で `tani`):瓦の層(丸瓦の山の線から −0.19 まで)を切り口から 0.15 切り戻し、谷の板を切り口の線に跨がせ切る面で半分ずつ。上から一本の溝・光線の穴 0。
