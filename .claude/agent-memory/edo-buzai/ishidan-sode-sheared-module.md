2026-09-23 EDO-0415(`build_sanno_buzai.py -- sode`・`Own.IshidanSode(keri,fumi,i)`)。

- ⭕ 段ごとの駒は蹴上ぶん上がるので、**横目地を水平にすると段の境で食い違う**。横目地も勾配に平行にし、箱を面取りしてから鉛直に剪断する(竪目地と側面は平面のまま)。
- ⛔ UV を駒の局所座標や面ごとの乱数で貼ると、目地の無い段の境で柄が切れて**細い偽の目地**が立つ(近景で実見)。⭕ 剪断の前に周期座標 s と天端からの下がりで貼り、位相は「周期の中の石の番号」で決める。
- ⭕ 段石の材差し替えの回帰は頂点の多重集合で 0/0 を示した([[rebake-regression-by-vertex-multiset]])。関連 [[kirishi-tile-and-shu-material]]

**Why:** 施主が城の CastleWall の段々の袖を「石段と物が違う」と退けた。
**How to apply:** 勾配に沿って連続させる駒は、剪断・UV を周期で考えてから作る。

**留め(`sode_miter`・同日):** 平面で折れる勾配の壁は、天端を勾配のまま伸ばすと留めで**段差 2·腕·tan h·勾配**(女坂 0.07m)。⭕ 端の頂点は Z だけ動かし高さは芯のまま据え置く(奉行の判断・ねじれ可)。組み絵の符号は一度逆に振った — 留めの面からの最遠を数で刷って捕まえる。⚠ 面取りのある端は面上に2段の高さが乗るので、段差を最大と最小の交差で測ると偽の 0.02 が出る。段を折る石段は差し込みを外端の楔(w/2·sinΔ)より長く。

**両端切り(`sode_miter_list`・同日の続き):** 段石を弦で据えると一つの折れが前後二つの継ぎ目に分かれ、真ん中の段は両端を切る。端ごとに同じ切りを2回かけるだけで済む(F と B の帯は 1.2m 離れて干渉しない)。組み絵は「回転 = 一覧の 2|h|」で組むと口・段差・目違いとも 1e-7 の桁 — 実際の据えの角は 0.01° 丸めなので残差は (X−xc)·0.005° ≈ 0.3mm が上限。⚠ 一覧が scratchpad にしか無いと焼き直せない。
