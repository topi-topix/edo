EDO-0437 案A(板を石の天端・地面まで下ろす)で `build_itabei_jifuku.py` → `Own.ItabeiJifuku` / `Own.ItabeiHashiraHk` を焼いた。

- 下端の形は据えた場所の従属値 ⇒ 場所ごとに焼かない。代(y −0.60)つきの直材を焼き、削る頂点 = 局所 y ≤ −0.599、`uv2` = d(uv)/dy(削ったら `uv += uv2·Δy`・後で消す)。
- 削り方: 列ごとに床の線(厚みの窓の最大・隣の標本で膨らませる)→ 格子点 = 床の点 → 間の線が床を割る所は近い端を上げる(上限 = 隣の格子点までの窓の最大)。窓の最大だけで上げると隙 p90 0.046、この手で 0.019・食い込み 0。
- ⚠ Blender はデータ名の末尾 `.60` を複製番号と読み `Hk0.001` に化ける ⇒ 名で部材を拾わない(接頭辞で拾う)。

- ⚠ 側面を縦に割った後で「向きの揃う帯」を一本拾って距離で外挿すると u が帯の外(アトラスの白 u 0.25..0.27)へ出て足元に白い四角(2026-09-27)。点を含む帯で内挿する。検算は FBX を読み直し代の側面の uv を画像で標本(白 0)。

**Why:** 板の下端 0.117 のままでは目地で 0.35 透け、接地 ±0.01(oki-kata §4)を守れない。
**How to apply:** 凹凸の相手に木部を接地させる部材はこの型(代+光付け)で。関連 [[fit-end-to-rubble-heightfield]] [[itabei-split-and-obj-subasset-material]]
- ⭐ **2026-09-27 夕 施主裁定: 据えの基本は根入れ(埋めて隠す)、違和感が見える所だけ光付け。** 光付けは石の段の足の楔(高さ 1.5cm)が点を足しても縮まず 1 駒 50〜100 秒 ⇒ 山王の板塀は `EdoBuild.RootToBed`(形を変えず代 −0.60 を石・地面へ埋める)へ切り替えた。下端は粗く(地覆 8 頂点・柱 12 頂点)焼き直し済み。代つきの部材は「埋める前提の長い足」として起こせばよい。
