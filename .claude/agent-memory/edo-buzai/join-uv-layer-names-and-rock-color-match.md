土井の庭の部材(EDO-0533・build_doi_niwa.py)で踏んだ。
- 丸太・岩は UV 層 `UVmap_0`+`LightMapUV`、bmesh 自作は `UVMap`。そのまま join すると自作の面の第1層が (0,0) で土・切石が無地の一色になる(Unity も第1層を読む)。⭕ join 前に各部品を1層・同名へ(`_finish`)。
- 苔の無い FJG Soil の茶の矩形(u0.008..0.122×v0.900..0.995)を土橋の 3.4m に当てるなら 16m 周期。1枚の四角(芯に頂点が無い面)で u を |x| で折り返すと面全体が一色の縞になる。
- 切り口に ROCK_PLAIN_UV(青灰)を貼る石は、元石も平均色 R−B≈0 の個体から(Rock_05_cut・Rock_07)。m_rock_02/03 は淡桃で継ぎはぎに見えた。
- 岩の切り口の n角形を inset すると棘の三角が出る。⭕ 蓋を消し内接円の輪を置いて輪郭とジッパーで綴じ、下へすぼめる。底の開いた岩に符号付き体積の向き直しを掛けない(面ごとに向きを決める)。
**Why:** 3回の検証レンダで一つずつ見えた。**How to apply:** 在庫メッシュ+自作の面を一体に焼く部材すべて。
