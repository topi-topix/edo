⭕ **決着した(2026-09-20)**。回廊 `Sanno_Kairo_{8x2ken_20650x4200, 7x2ken_17550x4200}` を
**軒先 2.100**(床 = 基壇の座 29.0 から)で焼いた。桁の天端 2.405・大棟の上端 3.942 は従属値
(勾配は瓦モジュールの素の 5.5寸)。

**Why:** 丈は上下二つの実測に挟まれて、**取れる帯が狭い**。
- **下** 袖塀 `Sanno_Sodebei_4200_d1560-700` の屋根の天端は門の敷居 28.3 から 2.505
  (`bom[袖塀…].outlineM`「全体(瓦を含む)」)= 回廊の床からは **1.805**。軒先がこれを下回ると
  「低い屋根付きの袖塀」が回廊の軒の上へ出る。
- **上** 楼門の軒高 **4.80**(丸桁の上端・`bom[楼門…].ruikei`)= 絶対 33.10。
- ⛔⛔ **楼門の軒先(敷居+4.07 = 絶対 32.37)より下には納まらない** — そこまで下げると
  梁間 4.2 の切妻の軒先が 1.48 になり、袖塀のほうが高くなる。⇒ **「棟は楼門の軒先より高く、
  丸桁より低い」がこの三者の寸法が許す唯一の帯**。⛔「回廊を門の軒の下へ納める」案は成り立たない。

**How to apply:** 楼門・袖塀・基壇の座のどれかが動いたら測り直す(生成器 `build_sanno_kairo.py` の
`report` が焼くたびに上下の余裕を刷る: 現行 下 0.295 / 上 0.158)。
⚠ 第二稿で**翼は楼門から 4.2 m 離れた**ので、屋根どうしの当たりはもう無い(離れは袖塀が埋める)。
⇒ 旧の「屋根を門の軒先の外で切る」手当ては**不要になった**。関連 [[kumimono-eave-gap-and-slat-window]]
