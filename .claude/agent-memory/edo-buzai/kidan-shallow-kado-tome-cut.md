build_kidan_saka.py `--tome <P|M> <折れ°>` / `--okabe-tome`(岡部 10 か所 18 本)。名は元の駒の名 + `_T<P|M><折れ×5 の 3 桁>`・C# は staging の `Own.IshigakiChokuTome`。

- 切り口の錨は**足元の前の角**(X=−2.40)を枠の端に残す ⇒ はみ出さず、据え手の「走りの端を実メッシュの射影で合わせる」とも食い違わない。天端の前の縁で錨を取ると枠の外へ 1.0·tan c 伸ばす継ぎが要る。
- 一様な倍率では切り角が変わらない ⇒ 倍率は名に入れない。両脇で倍率が違っても天端の前の縁の線と天端が同じなら面は一致する(大きい方の切り口の余りは背の土と地中)。
- 浅い切り角(1.7°)は素の小口が足元の角で面に接して欠片が残り開いた辺が出た ⇒ 面の上に載り切った面を消してから張る。L41 × 11.1° は切り口が背で端の小口まで届き道のりが二値 ⇒ 素の剪断に落とす。

- 2026-10-16 追: 端の駒が交点 Q の手前で止まる角(P35)は、局所の走り = (据えた走り + 頂点まで)/倍率 で伸ばした版(OKABE_TOME の P35x → _L175/_L77)。数は r149/base_ends.txt。C# は端の駒の len で版を引くので伸ばした len を渡す側の手当てが要る。
- コミットの道具: macOS の bash 3 に mapfile は無い ⇒ 配列が空のまま `git commit -- ` に落ちると index の全部を巻き込む。件数を数えて 0 なら止める。
