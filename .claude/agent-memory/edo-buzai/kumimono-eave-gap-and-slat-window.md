`build_sanno_shaden` の `kumimono`(丸桁は頭貫上端 +0.95 固定)と `irimoya`(反りで壁通りに z(d) 上がる)を楼門へ流用したら、**kumi 1.10 で垂木の下端が丸桁の 0.61 上を通り、立面で組物と屋根の間に空が抜けた**(2026-09-13 `build_sanno_romon.py`)。軒の出と反りで決まるので kumi ≈ 0.95 − z(eave−0.30) + 0.105 で詰める(楼門 0.47)。組物の帯の隙も素通しになるので**軒小壁の板**を壁通りに足すこと。

**Why:** 丸桁の高さは kumi に依らず、屋根だけが kumi で動く。社殿は棟が大きく目立たなかった。
**How to apply:** 社殿の道具で別寸の建物を起こすときは、正面立面を先に1枚焼いて帯の空を見る。検算で「窓の中の頂点を数える」ときは、箱の部材(連子子など)は**上下端にしか頂点が無い**ので窓に両端を含める(0 対 0 で落ちた)。関連 [[neishi-plan-skew-gap]]
