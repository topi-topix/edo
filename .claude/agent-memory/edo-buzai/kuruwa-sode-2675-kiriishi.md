2026-10-10 EDO-0502。棟梁の PlaceKaidanSodes(EdoOkabeYashikiBuilder)は sode の文の最後の「追記」節(無ければ全文)に「切石の袖」があれば `IshidanSode`、無ければ `IshidanSodeUchikomi` を引く。今の文は切石 ⇒ `sode 0.2675 0.450 3.636 --depth=…` で 6 本焼いた。
蹴上は yTop−yBot を float で割った 0.26750001 ⇒ Mono の F3 で "0.268"(cs_f3 も同じ)。meta は 0.283 の版を guid だけ替えて写す。

**Why:** 依頼文に「打込接ぎ」とも「切石」とも無く、在庫は両方の版がある。
**How to apply:** 袖の型は焼く前に指図の文と使い手の分岐を読む。関連 [[sode-uchikomi-texture-lattice-cycle]] [[ishidan-sode-sheared-module]]
