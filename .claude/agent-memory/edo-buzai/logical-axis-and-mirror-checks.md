2026-09-20 に**実測で押さえた**(⛔ 註から推論しない — 一度 `SH.q` の合成を読み違えた)。

- **`SH.box3(M, u0,u1, v0,v1, h0,h1, …)` → Unity (X = u, Y = h, Z = v) の恒等写像。**
  ⇒ 「見え面 +Z」は論理 +v。社殿・御供所・透塀・回廊・鳥居はすべてこの系で組める。
- **`VM.Mesh.box(x, y, z)`(走り・高さ・厚み)→ Unity (X = −x, Y = y, Z = z)。**
  ⛔ **走りが反転する**ので、左右非対称な部材をこちらで組むと立面でも数値QAでも素通りして俯瞰で露見する
  (EDO-0161)。⇒ 新しい部材は `SH.box3` / `SH.q` + `M.quad_uvs` の系で組む。
- 確かめ方: 論理 u[1,2] v[3,4] h[0,1] の箱を1個焼いて `SH.unity_verts` で読むだけ(10秒)。

**Why:** 二つの道具が同じ「論理座標」を名乗りながら走りの符号が違う。
**How to apply:** 部材を起こす前にどちらの系で組むかを決め、**焼いた直後に鏡像の検算**を入れる。
⚠⚠ その検算は **`set` で比べる**(⛔ `sorted(list)` で比べない)── 同じ座標の頂点の重複数が
左右で違うので、**対称なのに「非対称」と出る**。2026-09-20 に回廊でそう読んで原因究明に時間を使った。
