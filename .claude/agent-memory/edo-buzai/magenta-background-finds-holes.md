**部材の穴は、背景をマゼンタにして刷るまで見えない。**⛔ 既定の灰青の空で穴を探さない。

**Why:** 漆喰も瓦も灰色なので、抜けていても**影になった面**に見える。裏面カリングを全材に
掛けても背景の色が変わらないので判別できない。2026-09-22(EDO-0354)に庫裏の棟の穴を
⑥まで刷って見落とし、マゼンタにして初めて出た。さらに EEVEE は既定で**裏面も描く**ので、
カリングを掛け忘れると裏返った面が普通に見える(→ [[mesh-box-inward-normals-and-ray-checks]])。

**How to apply:**
- `V.studio` のあと `world.node_tree.nodes["Background"].inputs[0].default_value = (1,0,1,1)`。
  **地の面が1画素でもマゼンタなら、そこは Unity で空が抜ける。**
- 目だけに頼らず**光線で数える**(`build_typ_kuri._sukashi_audit`)。
- ⛔⛔ **「当たらなかった」だけでは穴にならない。**部材の幅の外は**空**なので、素直に数えると
  完全に塞がっていても数百本が「抜け」と出る(±0.30m を一律に撃って 263/868 と刷り、
  直っているのに ⛔ に見えた)。⭕ **その (y,z) が中ほどで皮より下にあるか**を先に上から
  撃って確かめ、**中に入っている格子だけ**を数える。

⛔ **`_skin_audit` の類で局所座標と世界 bbox を混ぜない。** 棟モジュールを含む駒は行列に
**鏡**が残っていることがあり(→ [[ridge-module-mirrored-and-koguchi-arc]])、混ぜると裏表が
まるごと反転して**直っている物が ⛔ と出る**。⭕ 測る前に `transform_apply` で鏡を焼く。
