- 外形を溝の外の壁の線(芯から 0.27)に収めるには、芯から ±0.27 の線を二等分線で留めた六角形にする。留めの点は 0.27/sin(β)(β=内の角/2)。凹の側の壁が潰れないよう口の面は芯の交点から max(0.30, 0.27/tanβ+0.12)。
- 口を底まで開けると、溝の玉砂利の面の下が口から素通しになる ⇒ 口の面は敷居の石で受ける溝の底の高さまで塞ぐ。二つの溝の底が違うので敷居の深さを名に入れる(Doi_Masu_GK<角>_D<深さ>_A<敷居>_B<敷居>)。形は二等分線に対称なので、鏡像の角は A と B を入れ替えた名で焼く(反転しない)。
- 検めのレンダは型 A の駒を両腕に突き付け、地面は triangle_fill で折れた帯の穴を開ける。型 A の単独の駒の縁石の目地からマゼンタが見えるのは溝の駒の既存の性質(地面の穴が溝の帯の全幅のため)で、桝の欠陥ではない。
