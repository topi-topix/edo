**Why:** `VM.Mesh` 系の躯体は論理座標が右手系のまま Blender へ写るので、**区間の順序が
そのまま法線の向き**になる。Blender の EEVEE は裏面も描くため、**検証レンダでは絶対に
気づけない**(Unity へ入れて初めて壁が消える)。

**How to apply:**
- ⛔ `m.box(x0,x1, y0,y1, z0,z1, …)` に **z0 > z1 を渡さない**。昇順に直す小関数を通す。
- ⚠⚠ **`build_obi_nagaya.shitami` は `out < 0` のとき意図して逆順で呼ぶ**(`hboard(…, t1, t0, …)`)。
  裏面・盲面・妻を張るとそこが内向きで焼ける。⇒ **躯体を `to_object` した直後に
  `bmesh.ops.recalc_face_normals` を通す**(箱と角柱の集まりなので外向きに揃う)。
  ⛔ 屋根には通さない — キットの瓦は元から正しい。
- 同じ理由で **`OB.section` の妻の三角は ±X で巻きが反転する**。recalc がまとめて直す。

**光線で閉じを数えるときの偽陽性**(2026-09-21 に3度踏んだ):
- ⛔ **決め打ちの高さで撃たない** — 屋根の外の点は当たらなくて当然。**先に真上から屋根の高さを
  採り、その比で撃つ**。
- ⛔ 高さを採る点を**けらばに置かない** — 袖瓦の天端(屋根面 +0.40)を拾う。**壁の通りの内側**で採る。
- ⛔⛔ **最初の当たりで済ませない。**段違いの屋根では上の棟の軒が下の屋根の上へ出ているので、
  上から順に拾って**床より上の最後の1つ(= 一番低い屋根)**を天井とする。
- 撃つ範囲は**部材の寸法から出す**(店先の柱通り・裏壁)。決め打ちの ±3.6 は狭い間数で壁の外へ出る。
