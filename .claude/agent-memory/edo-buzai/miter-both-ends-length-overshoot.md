- 棟梁は両端を留める棟を lo の Q へ据えるので、0.01 の刻みで切り上げた札の余り(17.630−17.628)がそのまま hi の端の越えになる。越えた切り口の土台の表(壁の外面 +0.005)が相手の外面より外へ出、座の違い(19.20/19.00)で相手の土台の箱の頂点が同じ高さの桶に無いので、MiterOverrun が +0.005 と数えた。版の切り口そのものは面の上で正しい。
- 直し: 両端を留める棟は札を「待ちの要る長さ −0.0002」に焼く(名は切り上げの 0.01 のまま・PickMiterCut の −0.001 の内)⇒ 相手の側に頂点が無い。scratchpad の sim.py(MiterOverrun の写し・全頂点)で +0.0048 を再現してから焼いた。
- seal の板の下の縁を SEAL_RELIEF(0.035)のまま土台の底まで下ろすと土台の前に 3cm の鰭 ⇒ 土台の帯は土台の表へ段を付けた(build_nagaya_omote.seal_cut)。
- 長屋の土台に kit の継ぎ目の毛筋(マゼンタで見える)が駒の中にある ── 旧い版にもある既存の物。

**How to apply:** 両端 --miter-cut の版は待ちの長さを F3 で受けて −0.0002 で焼く。片端の版は切り上げのままでよい(据えが留めた端を Q に合わせる)。関連 [[nagaya-miter-cut-signed-anchor-seal]] [[nagaya-miter-cut-convex-corner]]
