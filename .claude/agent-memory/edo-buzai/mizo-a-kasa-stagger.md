- 片側の壁にだけ載る駒でも左右どちらに据えられるか判らない ⇒ 継ぎ目は A の縁石の継ぎ目(r 0.35/0.75)の中間 r 0.55 に取ると両側で 0.2 ずれる。2段目は半駒ずらし(r 0.05)。
- 検めは単体でなく相手(A D0.15)の縁石に載せて並べ焼き(kasa_shots)。道の側の地面を天端 −0.02 に張ると「道から見える姿」が出る。
