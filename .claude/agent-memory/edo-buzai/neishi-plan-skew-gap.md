根石 `Neishi_Tamaishi_L*` は土台 `s_rock_0X` の平面形が走りに対して斜めの楕円のまま残る。地盤線の差し渡し(x の最小〜最大)で突き付けても、**斜めの石の隣では上から見て三角の空**が出る(2026-09-13 焼き直しの `neishi_ue.png` / `neishi_run.png` の 3〜4 個目の間)。

**Why:** 差し渡しは断面の x の外接なので、平面の傾きは詰めに効かない。2026-09-10 版から同じ形で、見え高を上げて(第33次 showMul 0.45)目に付きやすくなった。

**How to apply:** 棟梁への申し送りに「隙が目立つなら yaw 180° 反転を混ぜる/斜めの個体(L0.54, L0.58)を隣り合わせない」と書く。部材で直すなら土台の主軸を走りへ回してから `_fit` する(形は保てる)。関連 [[neishi-show-converge]]
