2026-09-26 EDO-0437(山王 前庭の縁)で踏んだ。

- 勾配の刻みは「1間(伸縮 1.2 まで)の端で 天端の線 − 駒の天端 ≤ 頭の不揃い」から逆算する。天端の勾配 0.03〜0.18 なら 0 と ±0.12 だけで最悪 0.065(±0.08 の内)── 3 段・4 段に刻む必要は無かった。剪断は鉛直なので勾配の違う駒どうしも切り口は天端から測って同じ(継げる)。
- ⚠ `EdoBuildNozura.PlaceNozuraRun` は直線の駒に勾配 0 を渡している(2026-09-26 時点)⇒ 焼いただけでは据わらない。据える側が駒の +X への天端の勾配を渡す手当てが別に要る。

**Why:** 施主の求めは「必要最小の組」。駒の数(本数×4個体×±)がそのまま LFS の重さになる。
**How to apply:** 勾配の駒を足すときは impl の profile から駒ごとの勾配と見付を先に数え(scratchpad の簡易割付で十分)、刻みを誤差の予算から決める。関連 [[nozura-back-crest-flush]] [[nozura-kado-sigma-fold]]
