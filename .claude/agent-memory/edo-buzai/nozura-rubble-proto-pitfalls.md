2026-09-24 山王の前庭の縁の土留めの試作(`Tools/Blender/proto_sanno_dodome.py`・FBX なし)で踏んだもの。

- ⛔ Voronoi の石の天端を**直線で切ると頭が平らな縁石の列**に見える(根石1段で顕著)。⭕ 半径 0.12〜0.32 の円弧(5本の接線)で切る。
- ⛔ 芝の肩を石の頭の線より下から立ち上げると、石が**墓石の列のように芝から突き出る**。⭕ 肩は頭+2cm・面より5cm前から 1/4 楕円で立て、裾を頭の裏へ 0.3 潜らせる(裾が無いと肩の下から空が抜ける)。
- ⚠ Blender 4.5 の hair は `hair_length` が効かず 1m の草むらになった ⇒ 三角の札を bmesh で撒く。札は明るく出るので暗めの色に。MixRGB は Fac=0 が入力1(逆に繋いで前庭が一面赤土になった)。

**Why:** 施主が選ぶための見比べの絵なので、石の頭と芝の納まりの嘘がそのまま案の評価を曲げる。
**How to apply:** 本番のモジュールでも天端の石は円弧で切り、芝の肩は頭より上から被せる。関連 [[garden-stone-edges-rounded]] [[magenta-background-finds-holes]]

**本番(2026-09-24・`build_sanno_nozura.py`・`Own.SannoNozura`)で足した三つ:**
- ⭕ どの駒どうしでも継ぐには、継ぎ目に跨る「端の石」を**端の種 + 番人の種だけ**の Voronoi で決め、中の種は番人より外に置く。端の石を手で矩形に作ると中の石との間に空が開き、裏板が平らに見えた。割りは**天端から下へ**測る(段の違う駒も天端で継げる)。`-- check` が切り口の頂点集合を 12 駒で比べる。
- ⚠ bisect の `use_fill` で塞いだ小口は UV が縞になる ⇒ 切った面だけ平面投影し直す。
- ⚠ 勾配 0.4 の袖に頭 ±8cm・R0.3 の円弧を使うと天端が鋸の歯に見えた ⇒ 袖は ±2.5cm・R1.2〜2.0。
