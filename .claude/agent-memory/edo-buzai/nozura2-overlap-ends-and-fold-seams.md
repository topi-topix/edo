岡部の施主の写真「石垣の部材の境目の隙間および段差」。依頼は「小口が平らで端の石の角を落としてあるので継ぎ目ごとに 2 倍の溝」と見立てていたが、
**まっすぐ継いだ旧の駒は Blender で並べると継ぎ目が見えない**(端の石は継ぎ目を跨ぐ一石を半分ずつ持つ・光線で幅 p90 0.02・抜ける行 0)。
隙は**継ぎ目で走りが折れる所だけ**: 凸の側で法 0.3×深さ の分だけ楔に開き、平らな小口と縦一直線の隙(折れ 5.5° の H4.8 で 74% の行が抜け・幅 0.12)。
据えの規則は折れ 20° 未満を直線の駒で継ぐ。段差は勾配の駒の不足(線 0.69/m に最大 0.45)と、駒の中心を線に載せる据え。

- ⭕ `--family=2` で `Nozura2_*`(Models/Nozura2): 両端を 0.02 + 0.026·深さ だけ延ばす(斜めの切り口・`overlap_planes`)。延ばした所は隣と同じ石 ⇒ まっすぐなら消える。
  H≤2.4 は折れ 15°・H4.8 は 10° まで抜け 0。重ねの所の板は 6mm 奥(z-fight しない)。端の石の列は旧と同じ ⇒ 旧の隅・法切り・積み止めと継げる。
- ⚠ **据え手が実メッシュの射影の端(span)で連ねると重ねの分だけ駒が離れる** ⇒ `Own.Nozura2OverlapMax(h)` を引くか、伸縮×1.818 の間で連ねる。
- 坂に乗る隅の駒は作らなかった: σ 空間で剪断すると腕の先の切り口が深さで食い違う(g·tan(φ/2)·z ── 52° G0.66 で足元 0.48)⇒ 直線の駒と継げない。
- 測りの罠: zsh は `set -- $spec` で割れない(`${=spec}`)・Blender の出力は `grep -a`。

**How to apply:** 野面の継ぎ目の隙を言われたら、まず折れ・天端の段・見付の違いを分けて Blender で並べて測る。[[nozura-end-caps-per-stone]] [[kado103-and-grade-per-meter]]
