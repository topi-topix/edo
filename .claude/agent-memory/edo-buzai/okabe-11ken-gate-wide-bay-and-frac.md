- `--body` の窓は妻の外面から常に 1.381 に端の窓があり、δ は「端の窓 〜 最初の中の窓」の間を伸縮する ⇒ 隣どうしは妻を挟んで 2.762 で続く。端数を片端へ寄せるのは `--frac <m> <L|R>`(名は素の _kutai と同じ・向きは局所 +X = s 増の前提)。
- 「部屋3・番所1.5・口2・番所1.5・部屋3」は 1.5間の格子では閉じない ⇒ `--wide 0.909` で真ん中の窓割りだけ 2間にし、口をそこへ抜く。一階の天端 3.895 なので口 3.30+冠木 0.42 は棟を上げずに収まる。
- 通用門の袖は `build_munamon.py --sode 0.30`(札の jamb が方立の外の面へ移る)。岡部の出隅 P41(38.6°)は N40_3 と座が 0.30 違い、留めの切りは屋根が合わない ── 未決。
**How to apply:** 門長屋・区切りの長さ違いを焼くときは窓の芯の print を見て、継ぎ目の側が 2.762 で続くかを確かめる。関連 [[nagayamon-bansho-beside-gate]] [[nagaya-miter-cut-convex-corner]]
