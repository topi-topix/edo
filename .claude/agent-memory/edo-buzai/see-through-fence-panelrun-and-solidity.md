## ① `EdoBuild.PanelRun` は**片面ポリゴンの塀**専用

`PanelRun` は `Place(..., new Vector3(sx, ES, ES))` で **1スパンに2枚**(`side` 0/1、裏は
`latOff = -0.12`、yaw +180°)置く。穂垣 `Eg.Hogaki5` も板塀も **片面ポリゴン1枚もの**なので
表裏の対で初めて1枚の塀になる、という前提。

⛔ **実ジオメトリの両面もの(丸材の格子・柵・透塀)をここへ差さない。**2枚置くと格子が
0.12m ずれて二重になり、**透けが潰れて藪に見える**。⭕ 1スパン1枚で置く。

⛔ **`ES` 倍にも注意。**`Eg.*`(edogoyomi の obj)は **ES=1.818 単位**なので `(sx, ES, ES)` が正しいが、
`Assets/Edo/Models/` へ自分で焼いた FBX は **実寸**。`(sx, 1f, 1f)` にしないと 1.8 倍に育つ。
⇒ 新しい部材を `PanelRun` に載せるときは **`pair` と `unitScale` の2つを呼び手が選べる**ように
してもらうこと(2026-09-22 に提案した形)。

## ② 透けの合否は数値と「並べ比べ」の両方で出す

- **見付の充実率**を光線で数える(`build_typ_yarai.solidity`)— 厚み方向へ格子状に撃って
  当たった割合。竹矢来 **30.4%**(= 69.6% が抜け)/ 板塀・穂垣は **100%**。
- ⛔ **それだけでは足りない。**在庫方の差し戻しは「**20m 離れると板塀と区別が付かない**」だった。
  ⭕ **後ろに色分けした的を並べ、手前に新造・9m 奥に在庫を置いて、目の高さ 1.60m・20m から
  1枚**(`build_typ_yarai.narabe`)。透けている物の向こうに的が見え、塞いでいる物は真っ黒の帯に
  なる — これが一目で読める唯一の絵。関連 [[narabe-check-and-fbx-byte-noise]]
- ⛔ `check_seethrough.py`(囲まれた透明を数える)は**この手の部材には効かない** — 抜けが意匠なので。

## ③ run に並べるモジュールは「ピッチの整数倍」で組む

幅 3.636 = 格子ピッチ 0.606 × 6 ちょうど。⇒ 突き付けても格子が継ぎ目を跨いで通る。
**親柱は各1間の中心(x = 0.909 / 2.727)**に置く — 継ぎ目(x=0 / 幅)に置くと隣と二重になる。
⚠ その代わり **run の両端と隅に柱が無い**(0.909m ぶん格子だけが残る)。
