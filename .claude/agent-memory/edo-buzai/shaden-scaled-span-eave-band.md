`build_sanno_shaden` の軒の出 = 半スパン × EAVE_RATIO(0.63)は、梁間 9.2m の本殿・拝殿で **2.90m** になり、丸桁(頭貫上端 +0.95)と垂木の下端の間に**約 1.5m の帯**が開いて、向拝の近景で組物の奥に瓦場の裏(緑)が縞に透けた(2026-09-14)。kumi を丸桁へ詰めると軒先が頭貫より下がり、向拝の庇(拝殿の軒からの従属値)まで崩れるので、**高さは動かさず壁通りに軒小壁を立てて塞いだ**(`noki_kokabe`、柱間 1間の旧名の棟には足さない)。

楼門(奥行 5.75m)は「軒高 = 丸桁の上端 4.75」で kumi を従属値にすると、共通の反り(`Sori`)のままでは**大棟の上端 7.61 / 鬼の頂 7.87**で、考証の類型「棟高 約 9.0」に届かない(軒の出を 1.6→2.6m に振っても 0.07m しか動かない)。

⭕ 2026-09-14 追記: 「棟高 約 9.0」は**出典なしの目安として考証が撤回**。楼門の棟高は勾配規則の従属値(7.6)のまま・入母屋【S】で確定。
⚠ 「軒の出 2.90」は本殿・拝殿(半スパン 4.6)の値。楼門は側柱芯から**中央 1.81 / 隅(軒反り込み・bbox)1.97**。軒の出を返すときは測った位置(中央か隅か)を必ず添える。

**Why:** 反りは半スパンの比で決まり、棟高は奥行でほぼ決まる。類型の棟高は勾配を指定していない。
**How to apply:** 別寸へ流用したら近景で組物の帯を先に見る。類型の棟高と食い違ったら勾配を黙って急にせず、`Sori(mean=…)` の案として普請奉行へ返す。関連 [[kumimono-eave-gap-and-slat-window]] [[kairo-romon-eave-level]]
