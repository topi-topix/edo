2026-10-04 EDO-0533 土井 boundaryPlinth.back(EdoBuild.PlaceCastleBack / CutAlongBack / BackBedGap)。

1. Castle Wall は底の奥行 2.4 だが**天端の奥行は 1.4**(見え面 局所 −X が法・背 X=0 が鉛直)。外と背の二列では奥行 3.09 の長屋の下に
   幅 0.89 の鉛直な溝が残り、妻の小口と口の脇で地表が見える。⇒ 背の駒の背の面を天端の前の縁にした「埋め」の列を足す(長屋の下で隠れる)。
2. 犬走り 0.3 の切り(丙)は 2m 格子に描けない ── 線の際の節点だけ下げても奥の節点との一次で帯の上に地山が残り見付が −0.23。
   ⇒ 帯の中の点で升の四隅の最大を見て、超える升の四隅を座 −0.05 へ下げる(切りが一升の幅に緩む・体積は膨らむ)。線の端の外は切らない
   (隣の棟の背の低い座で切って 0.64 掘った)。
3. 斜めの辺(土井 辺13)で駒の**世界の外接箱**を「下に在る石」の判定に使うと、継ぎ目の頂点が高い隣の箱に入り偽の −0.6 を出す。
   ⇒ 走りの座標(s, t)で駒の箱を取り、継ぎ目の頂点は端で接する低い方を採る。

**How to apply:** 基壇の上の棟の背を石で立てる邸(岡部の表長屋・家臣長屋)へ移すときも同じ。入隅は交点で切らず相手の天端の奥行(1.4+犬走り)まで延ばす。
