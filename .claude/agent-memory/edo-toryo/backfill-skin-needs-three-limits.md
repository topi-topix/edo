2026-09-25 山王 EDO-0430 で「部材の底まで皮を盛る」(`EdoBuildHifu.cs` の 2d 裏込め)を起こしたときの罠。

1. **底 = 天端の駒がある。** 土留めの駒は背・小口・底の面が無い殻で、縁の内の「最も低い面」が天端になる。
   その底を種に max で伝えると、回廊の基壇の背の 29.0 が壁を越えて表の斜面へ流れ、4m の石垣が丸ごと土に埋まった。
   対処: ① 外形の中は伝えない(chamfer の障害)② 外形の中の点はその点の駒の底(BotL)より上げない
   ③ 天井 = 「外が開いた地面で地面が底より低い辺」だけを種に 1:n で**上る**最小(辺の外側だけに種を撒く。薄い駒で抜ける)
   ④ 皮の縁(地形のまま残す点)から 1:n で上る最小。
2. **面の中で盛ると突き合わせが増える。** 底が面より高い駒の脇(縁から 0.5m 以内)では「隙 0」と「面 ±0.30」が両立しない。
   面の中は面 + (tol − 0.02) で止め、部材から 0.5m 以内だけ許した(隙 3467→776 / 面の不合格 1→5 件の取引)。
3. **地形の木の升は穴を開けずに皮を被せる。** 盛る側は穴が要らない。盛らない点は地形の下 0.05 へ沈め、芝は残す。
   `Drawn().At` は穴の外でも皮が地形より高ければ皮を返す(被せた皮を描かれた地表として測る)。
4. 試しの度に地形の資産を scratchpad の退避から戻して打つ(芝の削除が積もる)。Stage9 は 10 秒台に収まる。

**How to apply:** 裏込めを他邸へ広げるときは四つの枷を外さない。残る隙は駒の側(隅の欠け・小口の開き)の話として報告する。
