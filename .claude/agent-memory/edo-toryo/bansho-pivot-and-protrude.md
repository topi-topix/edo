`Matsudaira_Bansho_W*.fbx` の**ピボットは走りの芯・奥行の芯・基壇の下端**
(`build_matsudaira_bansho.py` の `z0,z1 = -D/2, D/2`)。

1. **`protrude` は「躯体の外面が外周線を越える量」**(指図 `parcelOut._`)。
   芯を `線 + protrude/2` へ置くと外面は `protrude/2 + d/2` = **2.8m** へ出る(d=3.6)。
   正しくは芯を **`線 + (protrude − d/2)`**、あるいは `EdoBuild.Face`(帯 `MatsudairaBanshoBodyBand`
   + **走りの窓 ±w/2+0.02** で切石基壇の角 ±0.18 を外す)で測って `線 + protrude` へ寄せる。
2. **部材は片手**(局所 X: 基壇 −0.18 / 側面の出格子の受け **+0.22**)。2棟を同じ yaw で据えると
   出格子が片方は門柱・片方は袖塀を向き、**袖塀へ 0.22m めり込む**。
   ⇒ 置いた実メッシュで「躯体の面より大きく出るのがどちら側か」を測り、
   **門の開口を向いていなければ `localScale.x` を反転**する(Unity は負スケールで裏返らない)。
3. `outAdd`(部材の最外の出)は **0.55m = 向唐破風の軒**。旧 0.30 は基壇 0.18・出格子 0.22 しか
   数えていなかった。⇒ 街路への張り出しは **2.0 + 0.55 = 2.55m**(実測一致)。

**Why:** 1+3 で普請検査の実測 3.350m と宣言 2.3m が 1.05m 食い違っていた(0.80 が据え方・0.25 が欄)。
**How to apply:** 番所・櫓のように「線を跨いで据える棟」は、**線からの張り出しを直接測って寄せる**。
芯の座標を計算しない。→ [[measure-dont-nudge]]
