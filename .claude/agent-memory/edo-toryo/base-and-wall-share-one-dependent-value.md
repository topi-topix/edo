**症状**(2026-09-21 松江松平): 隅櫓を内へ寄せて袖塀が伸びたのに、**足元の石垣基壇だけが指図の旧
`s1` で止まり 1.38m 短い**。囲い自体は閉じているので閉じの検査では出ず、走り方向の端の検査
(`RunEndQA`)だけが ★ を出した。

**原因**: 塀を建てる Stage2 は `YaguraKeepout`(櫓の実メッシュが塀の回廊を塞ぐ所)で端を解くのに、
基壇を建てる Stage3 は **指図の `runs[].s0/s1` をそのまま読んでいた**。指図の値は「実測の控え」なので、
部材や据えが動くたびに古くなる。

**対処**: **従属値を解く関数は一つ**にし、塀・基壇・検査の三つが同じものを呼ぶ
(`Stage3_Ishigaki` からも `YaguraKeepout` を呼び、`RunEndQA` の期待値にも同じ clamp を当てた)。
⛔ 差(1.38m)を定数で足さない。⛔ 長屋の run には当てない — 一体部材で端が動かせないので、
基壇も動かさない。

**あわせて**: 隅の駒(櫓)が**回廊を塞がなくなった**ときは、塀を**頂点まで通す**のが指図どおりの
従属値(開口 = 0)。旧 `s0` で止めると頂点に 0.24m の口が開く。閉じは**三角形が帯の高さを跨ぐか**で
測ること — 頂点の帯や最寄り頂点の距離で測ると、箱の部材が消えて嘘の穴・嘘の閉じが出る。
