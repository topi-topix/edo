2026-09-25 山王 EDO-0430 v18(回廊の基壇の北の犬走り・東の北端)。

症状: 見え面の足元から 0.3m 以内に +0.1〜0.56 の土の縁(写真で緑の塊)。依頼は「石の底が床 25.05 より高い → 根入れを直せ」だったが、
**実測で駒の底は 25.00(床の 0.05 下で根入れ済み)**。前提を測らずに据えを直していたら無駄な作業になっていた。
原因: 殻の駒(底の面が無い城の石垣)は法の途中の点の Bottom が法の面そのもの。皮の sealFace と床(隣 ±0.25m の底の**最大**を採る)が
足元の 0.25m 奥の法の高さ(25.5〜25.8)を底と読んで皮を持ち上げた。WallBottom は |ny|≤0.2 の鉛直な面しか数えず、法(ny≈0.24)を落としていた。
直し: TopIndex.WallBottom は上を向いた面(UP_NY)以外を全て数える ── 法の足(根入れ)を下の縁として拾う。塞ぎ 1116→817・床 32→6、隙 0 のまま。

**How to apply:** 「皮が盛り上がる」と言われたら、先に Stage9 を CutEdgeSkin の段ごとの値(h0/cap/seal/floor/dig)で追う ── どの規則が上げたか 1 回で分かる。
残り(v18): 男坂の北の袖 051 は下り側の端で底が設計面とほぼ同じで塞ぎが +0.2 / 楼門の北の腰の隅(天端 25.94 で全部埋まる駒)の外形の中は OutsideY の法の頭打ちで −0.33 /
女坂の北の袖の背は設計面が袖の天端より 0.4〜0.9 高く、±0.1 は被り 0 と両立しない(指図の話)。
