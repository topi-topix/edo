症状(岡部 第57巡 sideFace): 返しの天端の線を石段の端の線に引くと、野面の法 1:0.30(H4800 の実測)で下の段ほど見え面が段の内へ出る(K_Dan1 で 0.6m 差)。
対処: 天端の線を「端の線 + 法 ×(天端 − 踏面)」へ退けて引く = 平面で斜めの線(EdoBuild.StairSideCrestLines・法は FaceBatterOf で測る)。
罠1: 本線の残りが 0.5m 未満だと区間割りが捨て、返しが本線と継がらず出隅の駒が立たない(始まり 打ち切り)→ 出隅に触れる残りは捨てない(_sideCorner)。
罠2: 返しの駒の丈を地表で測ると踏面の上に口が開く(面なし)→ NozuraSeg.footAt に踏面を渡す。同じ坂の上の石段(K_Dan2)まで返しを延ばすこと。
残り: 野面の石の出入りで見え面 − 端の線が ±0.1〜0.27 残る(硬 ±0.05 は野面では届かない恐れ ── 普請方へ)。
