2026-10-12 EDO-0502 第117巡(岡部 角 P0 の南・辺4・5)。

1. **症状**: 写真 minami_hei_uchi_roji の「土手と割れ目」は、依頼では練塀と野面石の間とされたが、画素から光線で名指すと
   **野面石 TW_Higashi_Minami の背の小段(13.30)と TW_Higashi_Se の隅 kado6 の前**だった。練塀と野面石の間の床は 12.40〜12.53 で平ら。
   **原因 1**: 小段の溝 D_MinamiHei_kodan の天端の線を LayMizoOnTopLine が「外の縁石の外 0.30」で引く ⇒ 辺4・辺5 の東は線が練塀へ寄り、
   その点が造成の面の段(小段 13.30 → 床 12.30)を越えて床を読んだ ⇒ 溝が小段より 0.7〜1.06 低く据わり、溝の下げで小段に筋、北に小段がそのまま土手に残った。
   **対処**: `MizoTopSpec.surfaceOnLine`(線の上で引く)を小段の溝に。
   **原因 2**: `SinkGroundUnderParts` は法の見え面の下の節点を「面 − 0.05」へ下げる ⇒ 見え面の足が前の地表(小段の法 12.7〜13.3)に埋まる所で
   見え面と前の地表の間に 10.5〜11.8 の溝。**対処**: 下げの下限 = 面の法線の水平の向きへ、どの駒の下でもない最初の節点の高さ(見え面の前の地表)。
2. 地表の欠陥を写真で見たら、まず画素の光線で何に当たっているか(駒/地形・座標)を出し、DesignY(造成の面)と今の地形の差の表を刷る ── 差の符号で誰が書いたか分かる。

**How to apply:** 溝を小段・天端の上に切る所・法の駒の下の地面を下げる所は、他邸(土井・松江松平を細かい地形へ移すとき)でも同じ型。

3. **溝の両脇の帯が下がらない**(第117巡の2回目): `FlushGroundToMizoTop` に `outAt`(区画の線の外向き)を渡すと、線の内の側を「上げるだけ」にする(台の石垣の根の型)。
   南の練塀の内の溝は内の側が小段・斜面で高く、板の外の縁より 0.07〜0.18(西の足元の溝は 0.4〜1.1)高い土が残った。**対処**: D_MinamiHei の型A は `outAt = null` で別に流す
   (帯は板の外の縁 ±0.02 に全数入った)。⚠ 同じ Stage の中で「上げるだけ」の型と両側の型が同じ一覧に混ざっていないかを見る。
4. 板付きの段落ち(Doi_DanOchi_Ago_*)の壁の丈は `EdoBuild.MizoWallRise`(板を除いた石の天端 − 底)。MizoPieceOf.top は板の内の縁(+0.003)を読む。
