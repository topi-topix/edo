**症状**: 社叢の低木5本が埋没 1.0〜1.8m(山王 2026-09-23)。「地表へ上げれば消える」と見えるが、
据え直すと**浮き 1.85〜3.38m** になる。直っていない。

**原因**: 埋没も浮きも一つの量の裏表 —**駒の足あとの下の起伏**。実測で 1.9m 幅の低木の下が
2.4〜3.4m 落ちていた(地表の勾配 150%・山王の崖。1m 刻みで滑らかに下がるので造成の瑕疵でも
2m/px の量子化でもない)。起伏 > 許容の和(埋没 1.0 + 浮き 0.7 = 1.7m)なら、どこへ据えても
どちらかが鳴る。他の 479 本の 0.05〜0.4m の埋没も同じ勾配由来で、緩い所ほど小さい。

**How to apply**: 「埋没しているから上げる」の前に **埋没 + 浮き(= 起伏)** を同じ物差しで測る。
和が許容の和より小さければ据え直しで両方入る(SeatOnGround)。超えていれば据え方の話ではなく
**駒の大きさか点の位置**の話なので、動かさずに数値を添えて差し戻す(呼び出し元の裁定)。
物差しは普請検査と揃える — 山王の表は「最下面から 0.15m 以内の実メッシュ頂点 × 描かれた地表」で、
`EdoBuild.Contact`(格子ごとの最下点・全高)より 0.3m ほど厳しく出る。
