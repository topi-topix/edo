- 症状: S_Hei_04 1.22・S_Hei_01c 0.685・N13_0 1.085 と c が見込みの倍。原因: PlaceCastleRun の「中ほどの駒」(端から 3m)が無い短い組は全駒を
  InsetRunToPoly(区画の多角形)へ渡し、隣の辺を跨ぐ端の駒の都合で組ごと控えていた。対処: 中ほどの駒が無ければ辺の線への出で取る ⇒ 全 run が見込みどおり。
- c を正すと、足元が低く丈の高い頭の駒(S_Hei_02 の 4 駒・S_Hei_16 の 4 駒)が 0.02〜0.33・S_Hei_04 の尻 0.72 区画の外。並びが一次で減る(0.164/0.115/0.066/0.017)
  のは端の納めでなく駒の丈(法の足が深いほど外へ出る)。走りに沿って駒の実長まで引いても収まらない。退けると隅に口 ⇒ 駒ひとつだけ内へ(天端の前の縁が段【柔】)。
- 出隅 < 40° は交点で閉じると根石の端が頂点の手前 c·tan(φ/2) で止まり足元に口 ⇒ 端を頂点の走りへ(kadoMinTurn)。浅い折れで c が違う辺の交点は数 m 先へ飛ぶ ⇒ 二等分の面。

**How to apply:** 基壇の ★「引いても収まらない」が並びで一次に減るなら端でなく丈を疑う。[[castle-run-along-parcel-edge-traps]] [[nozura-need-h-under-batter-and-kidan-koh]]
