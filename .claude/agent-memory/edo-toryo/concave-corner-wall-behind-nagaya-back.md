2026-10-12 EDO-0502 第113巡(岡部 角 P0 案A)。

1. **症状**: S_Hei_01.join0「北の端は長屋 N41_5 の妻の面へ突き込み 隙0【硬】」で、端から長屋へ打つ光線が 21 本とも当たらない。
   **原因**: 練塀の外面 = 線から c+0.3【硬】で、c は据えた基壇の実測(S_Hei_01 は倍率 0.5 ⇒ 0.50)。外面は線から 0.80 内(x −380.0)、
   長屋 N41_5 の背の面は線から 0.32 内(x −379.52)⇒ 塀の厚み全体が長屋の背の裏(路地の側)にあり、妻の面と重ならない。外から路地へ 0.34 の口。
   指図の innerFace の見込み 0.42 は c ≈ 0 を前提にしていた。**対処**: 測って返す(face【硬】と join0【硬】が両立しない ⇒ 普請奉行へ)。
2. **症状**: 通用門の前に敷居 12.2 へ向けた土の塊。**原因**: 造成の面(okabe_graded.bin)の TsuyoTamari の面が区画の線まで 12.2。
   **対処**: Stage3d の PlaceKomonFront が門の札の前の面 +0.05 〜 線を道の地表(線から 0.7 外)へ切り下げる(EdoBuild.GroundToPoly)。
3. 造成の面(python)は run の内の帯を seat0/seat1 で焼く ── runs[].seatRule(文)は読まない。C# で天端だけ変えると内の帯と天端が食い違う。

4. **症状**: 背の路地の南の延長を 12.2 へ盛っても、TW_Higashi_Se の南の端の隅 kado6 の下で地面が 10.8〜11.2 の穴。**原因**: kado6 は旧い地盤(10.1)まで
   足を下ろして据わり、Stage3d の SinkGroundUnderParts が駒の上向きの面(法の足 10.1)より下へ地面を下げる。SeRojiPlan.At を南へ延ばしても kado6 の据えは変わらなかった。
   **対処**: 未解決(隅の駒の足を路地の床で切る据えが要る)。5. Stage2b は細かい地形で 15〜24 分(swap 16GB 下では 50 分超で止まって見える)。
   進み具合は Temp へ一行ずつ書いて見る(野面の網 PlaceNozuraNet が 13 分)。

**How to apply:** 欄の「見込み」は c を仮定した値 ── 突き込み・面一の欄は据えた後の実面で両立を測ってから建てる。
