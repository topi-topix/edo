**症状**(2026-09-23・山王の井戸 EDO-0274): 井戸屋形を礎石へ `Contact(…, down)` 型で下ろすと 1.93m 沈んだ。
井桁も縁石から 0.05m 浮いた。どちらも「当たり 0」と返る。

**原因**: `Contact(a,b,dir)` は頂点を 0.25m の筋に割り、**両方の頂点がいる筋だけ**で測る。柱の根(0.12角)と
礎石の天端(0.45角)は頂点が隅にしか無く、筋が一度も重ならない。代わりに軒の隅と石敷の隅が同じ筋に入って
「当たり」になった。井桁の木口は隣の礎石の隅と同じ筋に入った(平面では 0.02m 離れている)。

**対処**: 鉛直の載せは `EdoBuild.RestOn` / `RestGap`(`EdoBuildSueru.cs`)を使う。頂点の真下の三角形の面で測り、
材(サブメッシュ)でも絞れる。天端を地表に揃えて埋める物は `SeatFlush`。⚠ 総当たりだと樹木で数分止まったので、
三角形は 0.5m 升に振り分けてある。同じ穴は横向きの `Contact` にもあり、柱と塀の当たりを見落とし得る
(→ [[run-end-at-opening]] の断面で測る話と同じ根)。

関連: 指図 json を別の窓が書きかけのとき、`EdoSannoShaRebuild.Impl` は指紋が合わず例外を出す。
算出物の欄が要らない段は `WKeidai`(指図の `grid.keidai`)で座標を引けば止まらない。
