**症状**(2026-09-21 松江松平): 丈 0.495m の段石が「埋 1.576m」と出る。**幾何として在り得ない桁**。
同じ巡で岩屋の天井石は「0.148m=合格」と出るのに、絵では宙に浮いていた。

**原因**: `EdoBuild.Contact(駒)` が真下の地面を **`GroundGrid`(最寄りの格子点)** で引いていた。
格子は **2.0 m/px** なので、最寄り点へ丸めると **±(1m × 勾配)** の誤差が乗る。滝見の斜面(1:2.5)では
±0.4m、段の足元の起伏と足して 1.5m 級になる。**嘘の不合格**(石段12駒・景石3駒・植栽101点)と
**嘘の合格**(天井石 浮き 1.083 が 0.148 に見える)が同時に出る。

**対処**: `Contact` は **`Ground`(描かれている面=SampleHeight)** で引く。
平らな所では格子と一致するので差は出ない。⛔ `GroundGrid` / `PadY` は**面の設計高**を決める道具で、
接地の道具ではない(役目が違う。`GroundGrid` の注記「面の高さは格子点で測る」は 面 の話)。

⚠ **効く範囲は全邸**。`SeatOnGround` / `SeatBuried` / `SeatOnCrest` と、それを使う検査すべて。
既に据えてある駒は**その Stage を流し直す**と正しい位置へ動く(松江松平は Stage3/6/6c/6d を流した)。
流していない邸は位置はそのまま・**測り値だけ**が正直になる。

⛔ 「数が減ったから直った」と読まない — 測り手を替えたときは**必ず旧と新を並べて刷る**
(植栽 1812 点: 旧 302 / 新 201。母集団が同じことを示してはじめて比較になる)。
