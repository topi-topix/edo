2026-10-09 EDO-0502 第63巡(岡部 const.nozuraCrestCover・EdoBuild.NozuraCrestCover・CutEdgeSkin の 3f)。

1. **設計の格子の hold で天端の上へ盛ると、3e の HoldY の双一次が表の石の上(0〜0.36)へ土を引き込む**(設計の格子と皮の格子は原点が揃っていない)。
   ⇒ 皮の節点ごとに盛る段(3f)を足した。検めは MeasureSkin に coverDesigned を渡して設計の帯を被りに数えない。
2. **隅の駒の二つの見え面を同じ頂点で帯に割ると、片腕の帯にもう一方の腕の石が入る**(表の石の上の地表 > 天端 693 点・最大 4.2 の偽)。
   ⇒ 頂点を近い方の見え面の腕へ分けてから帯を作る。
3. 0.25m の皮の格子では帯の縁(0.36)の手前の節点が石の下(天端−1m 等)に居て、一次の面が帯の頭 0.1〜0.15 を石の天端の下へ潜らせる
   (帯の上の土 −0.27)。⇒ 縁の手前 0.3 の節点を駒の天端 −0.003 まで上げる。指図の「0.03 を狙い・1/20 で背へ」は 0.74m で 0.037 下がり
   後端で天端を割る ⇒ 帯の頂を裏石の後端で ≥0.02 になる高さへ上げた(柔の 0.03 より硬い下限を先に)。
4. 石段の段石・踊り場の上へも盛っていた(被り 35 点)⇒ 野面でない部材の外形と縁 0.2 は盛らない(otherPart)。
