症状: 山王の石段(EDO-0415・2026-09-23)。段石の底の帯の頂点と描かれた地表の差を取ると、男坂 45 段で最大 0.434m・女坂 38 段で 0.175m・
参道の階 2 段で 0.140m が地表より上に出る。頂点は段石の幅の端(局所 x=±3.5)の底に集まっている。
原因: 段石は設計面 + 蹴上で据え、地表は石段の幅方向に傾いたまま。端の下の空洞は袖(底が地表の下まで入っている)が外から塞ぎ、
前は下の段の胴が塞ぐので、外からは見えない。
対処: 「浮き」は袖で塞がれない端の頂点だけで数える(今回 0)。空洞そのものを数えると嘘の不合格になる。
切通しで袖を建てない区間は地表が高いので空洞が出ない。
