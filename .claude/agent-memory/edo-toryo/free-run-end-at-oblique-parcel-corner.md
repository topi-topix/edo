2026-10-03 EDO-0502 第5巡。辺0 の SE_Hei_0b は隣の辺41 の線を 0.053m 越えるので `KeepInsidePoly` が走りに沿って引く(角 95°)。
辺41 の長屋 N41_5 は石垣基壇の上(y 14.6〜)で練塀(11.0〜13.65)とは高さが別、端の先 3m に駒は無い(GapAlong・全高さ 0.4 刻み)。
辺24 の終わりも同じ(辺25 は木柵が 25° 折れて離れる)。⇒ 練塀を伸ばすと辺41/辺25 の線を越える(硬い・区域)。閉じるなら端を隣の辺の線で斜めに切った駒
(留めの小口)か、隣の辺の囲いの側を寄せる ── 伸縮では解けない。

**How to apply:** 「辺の始め/終わりの口」を言われたら、まず端の先に相手が居るか光線で見る。居なければ口は区画の線と端の楔で、部材(斜めの小口)か設計の話として返す。
