2026-09-26 EDO-0428(山王 男坂の頭 × 楼門の腰。Stage5b 踏石・踏み止め と Stage9 の床を覆う部材を足した)。

- **面取りの口**: `StretchEnd` は外形の凸包の端で合わせるので、段石(Dan_*)の端の面取りの分、天端の帯で 0.007〜0.012m の口が残った。
  **対処**: 据えた後に天端の帯で `GapAlong`(駒の中から相手へ)を測り、口の分だけ `StretchEnd` を足す(最大3巡・`LayShikiishi`/`ExtendEndToFace`)。
  帯の下は相手へ 0.016〜0.017 入る(見えない)。脇(袖)も同じ ── 前後だけ閉じて脇に 0.010 残した巡があった。
- **門の床**: `FloorTris` の「面 ±0.5 の上向きの最高」は楼門で 28.69(脇間の床)を拾った。床の三角形は全頂点 ≤ 床の天端なので
  基壇の天端 28.30 も入り、皮は各点の真上の面 −0.15 へ納まった(基壇の中の皮 1374 点が全部 上の面より 0.02 以上下)。天端 28.30 の所の皮は脇間の床の下。
- **腰の隅の重なり(二巡目で解消)**: 普請奉行の決めで下の側を 0.01 ずつ下げる `EdoBuild.SinkCoplanarUnder`。楼門の基壇の天端は
  28.288〜28.294 の斜めの小面を持ち、0.01 では 19 点残った ⇒ 無くなるまで 0.01 ずつ(上限 0.03)。結局 0.03 下げた。
- **門の上向きの面の下の皮(二巡目)**: 床の帯だけ・最高の面の cap では、床 14.89 の下で地面の高さの面 14.50 と皮が重なった。
  直し: 門の屋根でない上向きの面(`OpenUpTris`)を皮の格子点の周り ±step・step/4 刻みで拾い、皮 +0.02〜−0.15 の面の 0.03 下へ。
  ⚠ 埋もれた面を拾う深さを 0.5 にしたら坂下の門の基壇の中の段まで拾って皮を掘り、隣の Dan_00 の底が 0.15 覗いた ⇒ 0.15。
  ⚠ 楼門の基壇の天端には幅 2〜4cm の割れ目があり、下の棚 28.10 が覗く ⇒ 隠れた面も数える(基壇の中の皮は下げても見えない)。
  残り: 楼門の西の縁に 1〜3cm 張り出した棚 28.00 の上を皮が渡る 2 点(基壇の足の根入れ・前から 0.2 埋まっていた)。
- **指紋**: 同じ敷地の別窓が指図を書くと(sashizu:sanno を自窓が押さえていても書ける)Stage の Impl が指紋違いで例外。焼き手の dry-run で
  食い違いが相手の区域だけなら `bake_impl.py sanno --write` して流す(相手は刷り待ちだった)。
