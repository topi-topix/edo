**症状** 成満寺(820 m²・`daichikita_jm`)と社僧坊 2 筆(`sannojubo_parcels_6/7`)で庫裏だけ「境内に収まらず未建」。
棟どうしの離れを 2.0 → 1.0 → 0.3m へ緩めても入らない(_6/_7 は置けた棟の最小離れが 8〜10m も空いているのに未建)。

**原因** 庫裏の駒 `EdoAssets.VK.SmallHouse` の実メッシュが **14.49×10.49m**。本堂 7x6 間(屋根込み 14.70×12.85m)と
ほぼ同じ大きさで、「小屋」ではない。820 m² の境内に 本堂189 + 墓地79 + 鐘楼34 m² を置いた後、
縁 2.0m を残して 152 m² を足す余地は**どこにも無い**(格子を総当たりしても最良で −5.74m のめり込み)。
加えてこの駒は `EdoBuild.Body(withRoof:false/true)` が同じ矩形を返す = 軒が壁体と分かれないので、
軒にも縁 2.0m が効いて更に不利になる。

**対処** 離れの手を増やしても直らない。直すなら**部材の側**(庫裏に見合う 4〜5 間の駒を起こす / 小さい境内では
庫裏を建てない、を表で決める)。⛔ 非等方に縮めて合わせない。

**Why:** 置き方の緩めを幾ら足しても入らない物を、ビルダー側の局所修正で追いかけるのを止めるため。
**How to apply:** 「◯◯は境内に収まらず未建」を見たら、まず駒の実寸を測る([[measure-dont-nudge]] と同じ作法)。
