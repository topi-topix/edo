**症状** `JishaOmoya` の前庭 `JISHA_FRONT`(6.0m)の起点を辺の中点 `gateC` から**門の駒の実面**へ移した(2026-09-22・
EDO-0354 ③)ところ、成満寺 `daichikita_jm` が **3/4 → 2/4 棟**(墓地も未建)、`sannojubo_parcels_5` が **3/3 → 2/3** に減った。
前庭は 1.82 → 6.55m(成満寺)・3.32 → 6.30m(坊)で、狙いどおり伸びている。

**原因** 山門は奥行が深く敷地の内へ 0.75m 折り込むので、実面は中点より約 4.2m 奥。前庭の要求がそのぶん深くなり、
本堂が約 4.5m 奥へ寄る。本堂の点は `sc = 2|横ずれ| + vf` の最小で**許される一番手前**に座るが、
それでも奥の帯(墓地・蔵の居場所)を食う。⚠ 緩める三手は**棟ごと**に回るだけで、
後の棟が入らなくても**本堂は置き直されない**(全体の退きが無い)。

**手当ての候補**(施主裁定が要る): ① 門の実面からなら 6.0m は過大 — 起点を変えたぶん `JISHA_FRONT` を下げる。
② 後の棟が落ちたら本堂の巡から総当たりし直す(境内ぜんたいの退き)。⛔ 起点を中点へ戻すと門が本堂に貼り付く元の姿に戻る。

**Why:** 「取り合いを実面で測る」直しが、別の所で棟数を減らすことがあると知っておくため。
**How to apply:** 置き場所の制約を1つ厳しくしたら、必ず**棟数の増減**を前の巡と突き合わせて報告する。
