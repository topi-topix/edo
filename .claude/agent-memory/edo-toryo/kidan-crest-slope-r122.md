2026-10-13 EDO-0502 第122巡(EdoBuild.PlaceSlopeCrestPiece・CastleSec.grade・SlopeKado・HeiStretchSetback(breakAt)・HeiProfileRows の折れ点の外)。

1. **HeiProfileRows は出隅で折れ点の写しより先の辺の走りに、隣の辺の勾配を延ばしていた** ── P24(辺23 平ら → 辺24 3.03%)で辺23 の尻 1.1m が 11.134 になり、
   台の隅の駒の両腕の天端が 11.134/11.100 で据わらなかった(1.8m の段の時は高い方へ揃える規則が隠していた)。
   ⇒ 辺の走りの t を [tStart, tStart+sCend−sC](その辺の芯線の範囲)へ挟む・sC と sCend を区間の切れ目に足す。練塀の駒は隅の腕の外なので変わらない。
2. **平らな台の駒は見付が 4·s を越えると黙って下へ継いだ丈(Ishigaki_Choku_H0450〜)を引く**(PlaceCrestWall の 2 回目の測り)。坂なりも同じに丈を選ばないと
   倍率を指図が決めた run(S_Hei_02 s 0.25)で底が 0.08〜0.38 浮く ⇒ 坂の駒も H0450/H0500/H0600 を焼いた。
3. Stage2 は台を 3 回据え、2 回目と 3 回目で c → d → 芯線の道のり t が動き**勾配が 0.0004 ずつ違う**(GU0903 と GU0901)。焼く一覧は最後の据えの不足だけで
   (CrestWall.missingSlope は PlaceIshigaki ごとに空にする)。2 回目の ★ 焼いていない は読み捨てる。
4. 坂の隅の倍率は丈から(hReal/4)── 焼いた倍率の一覧の先頭で名を作ると S035 の H0857 という無い名になる。
5. d を一続きで一つにしても P35 の段(辺35 s0.36)は折れ点から 0.14 で隅の駒の中 ⇒ stepClear が +0.17 寄せる(⚠)。d では解けない。
6. seatOverGround: N の不足 0.283 @NW_Hei s14.89 ⇒ 決めた座を全部 +0.29(段の点と高さは据え置き)。外の地盤は base_dem の線上と外 0.5 の高い方。
7. **d は台の倍率で決まる不動点**(d = 一続きの c の最大 + 0.30・c ≈ 倍率)── 2 回目の台が焼いていない坂の駒を「据えない」で抜くと c が 0 に化け、N の d が 0.30 に落ちて
   練塀が台の法の上へ出た(足の隙 1.72)。⇒ 焼いていない坂の駒は素の駒を水平に代わりに据える(抜けにしない)。北も含め全部 d 1.05 に落ち着いた。
8. **焼き足しは 3 巡要る**: 台・塀の直線 → 隅の駒が据わって腕が決まる → 走りの切りの T が変わる。NeribeiLineRun は区間に一枚でも無いと区間ごと建てない
   (★ 駒が無い の行を全部拾う ── head で切って見落とし、N の 7 辺の塀が抜けたまま 2b〜3d を 15 分流した)。
9. d を 0.30→1.05 にすると細い台(倍率 0.25・天端の幅 0.35)の上に塀が載らず、足は台の裏の土の上 ⇒ FillUnderFoot が溝の**世界の外接の箱**で斜めの辺の足の下を除き 0.3〜1.4 浮いた
   ⇒ 溝・桝は駒の向きの外形(keepPieces)で除く。計測の「隙」は Bed.At が地表と同じ値なら石でなく土(bt > g + 0.02 だけを台の隙に数える ── 第121巡の表は土の浮きを混ぜていた)。
10. **土の楔の測りは Bed.At では 0 にしかならない**(Bed = 地表と駒の上面の高い方 ⇒ 地表 − Bed ≤ 0)。PartTops.Top(石の上面)と地表を比べ、塀の外の縁より前(犬走り)だけを数える。
   楔の正体は 0.25 格子: 塀の足の下の節点(座より高い内の地面)が天端の上の一升に掛かり外の縁の前 0.07 に 0.3〜0.8・段の所は上の踏み面の土 ⇒ EdoBuild.LowerSoilOnCrest(平らな天端の真上の節点だけ下げる)。
**How to apply:** 台の坂なりの駒の焼き足しは r122/wrap_kidan.py の形(build_kidan_saka を import して build_straight(g,h,L)/build_kado(角の実値,s,gi,go))。
