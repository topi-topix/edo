**① 偽の穴** — 「座+0.6〜1.4m の帯に入る**頂点**」で外周の閉じを測ると、
**柱のような単なる箱は頂点が上下の縁にしかない**ので帯に 1 点も入らず、**材があるのに穴**と出る。
松江松平の表門(2026-09-20): 帯では門柱が消えて 番所|門 に 0.200m の穴が左右に出たが、
**同じ高さを跨ぐ三角形**で測ると 番所W 117.300‥121.550 / 表門 **121.550‥126.050** / 番所E 126.050‥130.300 と
**完全に連続**していた。⇒ 閉じは**三角形が高さを跨ぐか**で測る(頂点ではなく面)。

**② 腕の測り方で 1m 変わる** — 隅部材の腕を「全頂点の射影の最大」で測ると**軒・反り**を拾い、
壁体で測るより 0.9m 長く出る。指図 `kado.parts[].armRaw` はその長い方で書かれており、
run の s0/s1 がそれを前提にしていたので外周に 0.85〜1.18m の口が残っていた
(`Dobei_Kado_88M` 宣言 4.134m / 壁体の実測 3.30m)。⇒ **隅を先に据えて壁体の腕を測り、
run の端をそこへ寄せる**(`KadoArmSpan`)。⛔ 辺の**端の run にだけ**効かせる — 全 run に効かせると
同じ辺の run が丸ごと重なる(一度そう建てた)。

**③ 事後に寄せる関数を持たない**(施主指示 2026-09-20・EDO-0286)。`AlignGateFace` /
`CloseKadoSeams` は削除した。据える時点で `EdoBuild.AlignFace` / `Abut` / `SeatOnCrest` / `PadY` で
**測って置く**。寄せる関数があるほど置き方の欠陥が隠れる。
