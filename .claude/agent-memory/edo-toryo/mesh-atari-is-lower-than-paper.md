渡廊下の下屋の頭を「その端の当たり − clear」で据えるとき、**当たりを実メッシュの
最下端(鉛直線で貫いた最も低い交点)で測ると、指図の従属値より 0.08m 低く出る**。
松江松平 2026-09-20 の実測: 奥向の庇の軒桁 名目 2.546 → 実測 2.465(−0.081)/
御殿の帯割り 名目 3.028 → 実測 2.943(−0.085)。

**Why:** 指図の「軒桁」は**構造の線**で、部材の葺き厚(垂木+野地+瓦)はその下に付く。
同じ差は軒先でも出る(名目 1.521 → bbox 最下端 1.399 = 軒先瓦の垂れ 0.122)。
⇒ 紙で余裕 15mm と出た頭上が、実メッシュでは 65mm の不足になる。

**How to apply:** 規則5どおり実メッシュで測る。ただし**測った値と指図の従属値を並べて報告する** —
差が一定(≈0.08)なら部材の葺き厚で、⛔ 指図の誤りでも据え付けの誤りでもない。
下限割れが出たら自分で逃がさず(軒高・床・幅・下限のどれを動かすかは設計判断)差し戻す。
瓦は名目面から ±0.15 うねるので、**幅を横切って 5 点測って中央値**を採る(1 点だと位相で振れる)。
→ [[checkscene-center-vs-seat]] と同じ「何を測っているか」の系。
