症状: 山王の女坂(EDO-0415・2026-09-23)。留めの継ぎ目16か所は口・重なりが全部1mm以内で ⚠ 0件。ところが継ぎ目の端面を
継ぎ目の線(二等分面の水平方向)に写すと、上下の駒が外面・内面とも同じ量ずれていた(16→17 と 7→8 で 0.036/0.032m、
小さい折れは 0.004m)。近景のレンダでも外面に小さな段が見える。
原因(推定): 平らな駒を段ごとの段石の小口へ据えた位置のまま差し替えている。2つの段石の小口の線は折れ点で一点に交わらないので、
留めの面では合っていても、面に沿う方向の位置が段ごとの芯の置き方でずれる。
対処: 継ぎ目は「口」と「継ぎ目の線に沿うずれ(天端の高さで外面・内面の端を比べる)」の2つで測る。直しは据え手の側
(EdoBuild.MiterIshidanSode)の話で、指図や部材の話ではない。

おまけ: 継ぎ目の数は「折れ11×2=22」にならない。袖が切通しで片側だけ抜ける折れは数えない(女坂は N 6 + S 10 = 16)。
真上からの抜けの検め(3cm格子で全域を三角形と総当たり)は MCP がタイムアウトする。両端 1.2m の帯・4cm・三角形の外接矩形で先に弾く。

関連: [[contact-cell-too-fine-on-sparse-meshes]] [[measure-dont-nudge]]

追記(2026-09-23 同日・弦で据え直した巡): 段石を段の境を結ぶ弦で据え、両端切りの駒にしたら目違いは最大 0.0007m・口 0.0003m に消えた。
新しい罠: 焼いた一覧は「両隣に袖がある」前提で、袖が切通しで途切れる隣の端(相手の居ない端)も切ってある。器は相手の居ない端を
+0.00 で引くので綴りが合わず平らのまま据わる(N_039f が F-0.09_B+0.00・S_007f が F+0.00_B+0.79 を探して無し → 口 0.043m)。
焼く一覧は器と同じ規則(相手の居ない端は切らない)で起こす。ログの「留めの駒を焼いていない」の綴りが焼き直しの一覧そのもの。
