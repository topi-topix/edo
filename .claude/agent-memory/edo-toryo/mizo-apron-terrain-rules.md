2026-10-12 EDO-0502 第112巡(岡部 台の前の溝を `DoiMizo(k, d, ago:true)` へ。EdoBuild.SinkGroundUnderMizo / FlushGroundToMizoTop / MizoApronOf)。

5 回流して分かった順(どれも 0.25m 格子の三角形の話):
1. 板の下を駒の最下点(= 板の下面 −0.34)まで下げると、板の外の縁の外に深さ ≈0.36 の三角形の溝が立つ ⇒ 板の下は **真上の駒の上面(光線)− 0.03**。
2. 帯(0.3)を縁石から測ると板の下に収まり道の節点が残る ⇒ 道(縁 +0.03〜0.06)と板の下の節点の三角形が**板の上へ鋸の歯に被る**。帯は**板の外の縁から**・高さは板の外の縁の天端。
3. 蓋の下の駒は天端を蓋の厚 0.15 下げてあり板が埋まる ⇒ 板の下は**蓋の天端 − 0.03** まで(板の上面まで下げると蓋の脇に沈んだ帯と歯)。
4. 板の下の縁石寄りの節点を浅くすると、溝の中の深い節点との三角形が内法の壁で底を越える(溝の中の土 第111巡 3033 → 一時 3538)⇒ 対角 hs·√2 で見積もった上限まで下げる(→ 88)。
5. 天端の線が地表より高い所(D_N40_Mae の頭・勾配 1/21)は板が浮き、板の下の低い節点と帯の節点で板の縁の前に歯 ⇒ **板の下だけの節点は上げてよい**(どの駒の溝の中にも当たらない節点だけ)。

測り方: 縁の外 0.04 刻みで「地面 − 縁の天端 < −0.05」= 歯、溝の芯 ±0.15 で「地面 − 底 > 0.01」= 溝の中の土。第111巡との比べは前の TerrainData の写しを Assets に一時 import して GetInterpolatedHeight で同じ標本を引く(終わったら DeleteAsset ── safety_checks=false が要る)。

**How to apply:** 張り出しの付いた溝・土の板の付いた部材を地形へ据える巡は、上の 5 つを先に入れてから流す。板の材(Soil)は道のスプラットと色が違い帯に見える ── 部材方の話。
