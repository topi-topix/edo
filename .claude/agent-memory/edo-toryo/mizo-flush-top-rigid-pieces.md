2026-10-11 EDO-0502 第111巡(岡部 台の前の溝を天端の線で据える `EdoBuild.LayMizoOnTopLine` / `FlushGroundToMizoTop`)。

1. **深さは下流へ減らない**: 駒は剛体で底が天端と平行。天端 = 地表なら継ぎ目で底が上らないためには版の深さが下流へ単調に増えるしかない
   ⇒ 頭の深さ(と途中の底の上限)が全長を決める。「吐き口へ浅く」「頭の底 ≤ 座 −0.15」「敷き ≥ 道 +0.02」は面一と同時に満たせない(差し戻した)。
   地表が流れの向きに上る区間(s44〜46 の分水)は天端を水平以下にするしかなく、地表と 0.03〜0.08 外れる。
2. **版の深さは外の側の縁石で測る**: 両側の縁石の天端は 0.4mm 違う。低い方で選び実の側で据えると、毎駒 0.4mm ずつ天端が沈み続け
   30 駒で版が一段深くなった。外の側は水平の向きで先に決め、その側で選ぶ。許しは 3mm まで・届かない分は天端を ≤0.01 下げる。
3. **傾いた駒の局所 z**: InverseTransformPoint を高さ 0 で打つと 勾配 × 13m だけ z がずれて端に張り付き、0.02〜0.03 の偽の段差を読んだ。縁石の高さで写す(MizoCurbTopAt)。
4. **0.25m 格子の歯**: 全幅 0.54 の溝は格子が 1〜2 列しか入らず、溝の中を下げた節点と帯の節点の三角形が外の縁石の見え面の前に歯(≤0.25)を立てる。
   斜めの辺(辺40)で目立つ。節点では直らない(下げを浅くすると溝の中に土)── 部材の側(外の縁石の外へ土の帯の輪・Masu G0 と同じ)で隠す。

**How to apply:** 面一の溝を据える巡は、頭の深さと底の上限を先に刷ってから版を選ぶ。歯は撮って見せ、部材の土の帯を部材方へ。
