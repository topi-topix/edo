2026-10-03 岡部 EDO-0502 第2巡。

1. **一本物の長屋(Own.NagayaOmote*)の呼び寸法は破風込みの全幅**。全幅で突き付けると妻壁は両端 0.322m 内なので継ぎ目が 0.644m 開く。平行移動で躯体を寄せると鎖の端に 0.644×継ぎ目数(辺41で 2.58m)が残る。⇒ `EdoBuild.FitBodyToSpan` で躯体を run の区間へ伸縮(≤8%)。隅の端は腰が隣の辺を跨ぐので 0.02m ずつ戻す。門長屋は伸縮しない。
2. **EdoGotenKit の御殿は地面に触れる部材を持たない**(最下点は濡縁 床−0.28 = 地盤+0.34)。浮き 0.341 は据えでは消えない ── 縁束・束石の部材の話。
3. **棟門を FaceOut(全頂点の最大の張り出し)で塀の面へ寄せると軒(札の eave 1.2m)を拾って柱が 1.4m 引っ込む**。札があれば `EdoBuild.PlaceGamae`。
4. **GradeSaka の法尻は線で測っても、2m 格子の盛りは隣の節点まで一次で描かれる**。描かれた法尻は節点の盛りから 8 方へ測る。路面の節点の盛りは締められない(R_UraZaka は路肩が線から 2.1m で描かれた盛りが 1.00m まで下りる)。

**How to apply:** 長屋・門・坂を据える巡ではこの4つを先に疑う。関連: [[nagaya-mon-gate-offset-axis]] [[measure-dont-nudge]]
