松江松平の平入り+庇の**切り欠き入り**屋根で、渡廊下の「当たり」を測ると**呼びより 80mm 低い**値が出る
(2026-09-20 実測)。切り欠きの中を鉛直に貫くと面は 2 枚:

- **上 = 受け面(庇の軒桁の天端)** local 2.5459(= 床 0.62 + ピボットから 1.9259)
- **下 = その板の下端** local 2.4659 — ちょうど **80.0mm** 下

`RoofPierceMinY` は**最も低い交点**を返す(軒先の下端を当たりに採るための規則)ので、切り欠きでは
下端 2.4659 を拾う。その結果 頭 = 当たり − `roka.clear` が 80mm 下がり、柱筋の頭上が
**1.662**(狙い 1.742・`roka.zujoMin` 1.727)になる。切り欠き無しの版と数値が変わらないので
「切り欠きが効いていない」と誤診しやすい。

**Why:** 部材は受け面を厚 80mm の板として焼いてあり、板の下端は実在の障害物。受け面を当たりに
採ると廊下の頭は板の下端から 19.5mm しか空かず、指図の `clear` 0.10 を下回る ⇒ **どちらを採るかは
設計判断**で、棟梁が決めてはいけない。

**How to apply:** 切り欠きのある取り付きで頭上が 80mm 足りないときは、測り方の取り違えではなく
**この二面のどちらを当たりに採るか**が未決。差し戻して裁定を仰ぐ(部材の板を薄くする / `clear` を
切り欠きでは緩める / 受け面を当たりに採る、の三択)。⛔ 自分で受け面へ寄せ替えない。

参考の実測(床上): 庇の軒先手前 0.3 の下端 = **1.520**(奥向4棟・軒桁 2.744)/ **1.186**(厩・2.410)。
庇を断った辺はそこより **+0.720** 高く出る ⇒ 三方庇の向きの検算に使える。

## 決着(2026-09-20)

二段で解けた。**どちらも「線の上で測る」ことが原因**だった。

1. 受け板が厚 80mm だったので、板の下端を当たりに拾って 80mm 低く出た
   ⇒ 部材方が **3分(9.1mm)** へ焼き直した(施主裁定A。`clear` も `zujoMin` も動かさない)。
2. それでもまだ低かった。棟の**外形線ちょうど**で測ると、切り欠き(線より外)ではなく
   **棟の内側の庇の裏**(local 2.4654)を拾う。線から 0.010間(18mm)外へ出ると 2.5368。
   しかも線上は数値的に際どく、**同じ納めでも端によって内と外を拾い分ける**
   (6端のうち1端だけ 2.537 が出て、切り欠きが効いていないように見えた)。
   ⇒ `RoofPierceMinY` に **outward**(棟から廊下へ向かう向き)を渡し、
   **頂点が1つも外側に無い三角形を落とす**。当たり = 廊下の上に張り出している物、という定義そのもの。
   帯割りの棟は軒の裏が線を跨いで続くので**跨ぐ三角形が残り、表向の値 2.943/2.903 は不変**。

結果: 奥向3本 当たり 2.537 / 頭 2.437 / **柱筋の頭上 1.733**(下限 1.727)。
