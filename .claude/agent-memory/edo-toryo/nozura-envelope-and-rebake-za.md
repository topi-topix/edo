2026-09-26 EDO-0437 第4巡(山王 参道の階)。

1. **中ほどの一本の中央値は野面の出入りを均す** — 段 3 の +X が「d 0・当たりが割れない」と読まれ切らずに置かれ、
   隅の石が 0.08〜0.11 段石へ入ったまま。段 0・段 4 は中ほどで当たらず測りもしなかった(入り 0.03〜0.07)。
   **対処**: CutStairEndsToBatter の envWall(野面の篩 `EdoAssets.Own.IsSannoNozura`)で、見える当たりの在る端は全部 EnvelopeCut。
2. **野面の駒を焼き直すと(cdbff6ec 背の尻すぼみ・脇の膨らみ)隅の駒のもう一面が動く** — 部材方が前の prefab で測った
   段 1 の za(0.014/0.024)は今の駒では −0.041/−0.005。焼いた組(za 0.024/0.034)は 0.015 の篩で引けない。
   **How to apply:** 野面を焼き直した巡は、跨ぐ端・包絡の切りの焼く一覧を棟梁が測り直してから部材方へ渡す(古い一覧で焼かせない)。
3. 包絡の za は 0.01 刻み × 欠く奥行 0.01 刻みで打つ(3 点では最も出た石を見落とし 0.06 甘い)。
