2026-09-26 EDO-0437(EdoBuildNozura.cs PlaceNozuraNet / PlaceNozuraRun、EdoSannoShaRebuild.Nozura)。

1. **見え面を描かれた地表で測ると隣の土留めの際で取り違える。** Tuck と皮が天端の下を下げているので、切り込みの東の返し 1.7m が前庭の側を向き、
   鎖が入隅を跨いで隅の駒を 3 つ置いた。→ 設計面(`SodeFootAt` = Gr.Bilinear)で測る。さらに離れを城の石垣の奥行 3m にすると
   区画の線の際で下がる地盤を拾い、E の南 5m が外を向いた → 離れは野面の駒の天端の列の控え(実メッシュ ~0.86)。
   継ぐかは**両側の見立てが揃ったときだけ**(片側が出隅・片側が入隅なら入隅)。
2. **算出物 profile の区間の端の行は口・石段の地表**(見付 0・受け 0)。区間の天端をそれで補間すると端で 1.7m 落ちる(SW 16.2→14.5)。
   見付と受けが共に 0 の行は、壁の在る行が一つでもあれば使わない。
3. **端の相手を光線で測る縦の範囲は「端の線の上の地表」まで下ろしてはいけない** ── 天端を高い側の地盤に揃えた壁はそこが天端と同じで
   光線が一本も立たず、黙って打ち切りになった。見え面の前(0.7m)の地表・足元の平場まで下ろす。
4. **打ち切りの駒(H0.15)は見付の要る端で 1.47m 浮いた**(SE の東の端 天端 16.4・足元 14.5)。端の見付が最小段を超えるなら直線の駒で終える。

**How to apply:** 野面の網を流したら `s3` の「入隅の通す側/可動側」「打ち切り」の行と、見え面の前の地表で測った浮きを先に見る。
見切り石(見え 0.6)は背の土が 0.6 を超える口では必ず埋まる(男坂の口 0.82/1.20)── 退けて相手へ直に突き付ける(硬い制約)。
