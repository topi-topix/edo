2026-09-26 EDO-0437 第2巡(EdoBuildNozura.cs PlaceNozuraRun ②' と ③ の端の突き付け)。

1. **斜めに交わる面の当たりを走りの向き(dOut)の筋で測ると嘘になる。** ContactPts の筋 0.25m の中で 43° の面は 0.25/tan43° ≈ 0.27 ずれ、
   触れていても めり込みと読む。→ 相手の面の法線(光線で引いた平面の法線を相手の中へ向けた物)で測り、寄せは走りに沿って c / (dOut·n)。
   普請の計測も同じ ── 候補の向き(芯の差・両駒の right/forward)のうち**最も離れる向き**の値を採ると斜めの嘘が消える(scratchpad meas2)。
2. **野面の駒の「天端の前の縁の端」は測れない。** 端の石の頭が天端の帯(最高 −0.12)の下に入り、斜め切りの駒で 0.7m 手前を端と読んだ
   (SW の東端が女坂の袖へ 2063 頂点・最大 0.30 入った)。見当に留め、切り口は相手の面で測って寄せる。
3. **入隅の可動側の鉛直な小口は、通す側の法の足(楔)へ縮めても入る。** 低い石ほど深く入り、何巡戻しても −0.05〜−0.09 が残る
   (前庭 W の南の区間 0.4m は伸縮 0.20 でも入った)。硬い制約なので退けた ⇒ 小口を相手の法で切った駒が要る(部材方)。
   参道の階の袖の背 × 切り込みの出隅の駒(−0.06/−0.13)も同じ形(野面の袖の背を法で切った駒が無い)。

**How to apply:** 斜めの相手・法の相手に突き付ける C# を書く前に、測る向きが相手の面の法線か確かめる。端のめり込みが巡を重ねても同じ値なら
縮めでは解けない形(楔か伸縮の下限)── 駒の伸縮(localScale.x)を先に見る。
