2026-10-12 EDO-0502 第118巡(練塀を一枚物 Neribei へ入れ替え)。
1. **症状**: Stage2 → Stage3d だけを流したら、地形の差が辺39(N39_0 の下)で −2.94m・辺23/24 で −2.3m。
   **原因**: 基壇(PlaceCastleRun)は今の地形で「全体が埋まり退けた」を決める ⇒ 3d の後の地形で S2 を流すと 576→584 駒・
   N41_1 の根石 +0.062 ★ に変わり、3d の SinkGroundUnderParts が増えた基壇の下を掘った。
   **対処**: 外周を触る巡は S1(graded へ上書き = 地面の初期化)→ S2 → S2b → S3d。S1+S2 は 1 分、**2b は 60〜90 分**、3d は 35 秒。
2. **症状**: 継ぎ目ごとに 0.042 の「隙」。**原因**: 低ポリの箱(shitami・hei)は帯(底+0.6〜1.4)の中に頂点が無く、小口の頂点だけ拾った。
   継ぎ目のちょうど上の光線は面に沿って縁で外れ「抜け」と出る。**対処**: 走りは全高の頂点で・光線は継ぎ目の ±0.004 で、各駒の底から。
3. 3d は練塀を床へ据えてから地面を下げる(垣の沈みを避けた順)⇒ 腰が厚くなった(0.69)一枚物の内の縁が、下げた内の地面の上で浮く
   (南 辺6〜11・隅 P2〜P10 で 0.15〜0.58)。据え直しは南の内(裁定待ち)の話になる。
**How to apply:** 岡部の外周の巡は S1 から流す。測りは m2/m3 の型(scratchpad r118)。関連 [[writeback-before-measuring]] [[lowpoly-vertex-window-empty]]
