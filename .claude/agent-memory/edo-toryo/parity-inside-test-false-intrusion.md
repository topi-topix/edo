2026-09-26 EDO-0437 第4巡(山王 女坂の北の袖 TW_Onna_N_001f × 前庭 SW の斜め切りの駒 TW_Zentei_SW_013f)。

**症状**: 普請の計測(scratchpad m2.cs の Depth)が「袖の角が隅の中へ 0.234(000f も 0.106)」と出し、前の巡の私は
「相手を 1.5m・400 点の標本で拾うので 001f が漏れた」と診た。実際は 001f も相手に入っていた(頂点の最小 1.31m)。

**原因**: 内外の判定が 3 方向の光線の偶奇の多数決。野面の駒は石が重なり開いた辺(46 本)もあるので、外の点でも
2 方向が奇数になる。その点から (0.6,0,−0.8)・±X・−Z・下へ打った光線は**一本も当たらない**(= 確実に外)。

**対処**: 内外は「8 方向とも当たりが 1 以上 かつ 奇数が過半」で読む(scratchpad robust_pair.cs)。これで 0.234/0.106 → 0.000。
**How to apply:** めり込みの申告を直しに行く前に、その点から数方向へ光線を打ち、当たり 0 の向きが在れば偽。
直す器(ContactTri を書いた)は要らなかったので戻した。関連: [[regression-claim-diff-prefab-first]] [[contact-cells-miss-flat-faces]]
