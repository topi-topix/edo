2026-10-15 EDO-0502 第139巡(普請方 r138 の M1 TW_Minami_Mizo・M2 腕の先の擦り付け・M3 木柵を水平に)。

1. **野面の線は天端の前の縁**(PlaceNozuraRun)── 法尻は線から 法(0.3)×見付 だけ見え面の側へ出る。溝の縁石 +c に法尻を置くなら、線は「縁石の外の縁 + c + 0.3×脚の最大の見付」。
   見付の小さい所は法尻が縁石から離れる(脚ごとに一直線)── 報告に離れの幅を刷る。
2. **型H の段落ち(Doi_DanOchi)は x ±1.00**(縁石は 0.57・その外は地際の板)、型A は ±0.67(縁石 0.26)。凸包・外接で「溝へ入る」を測ると板の上の駒を全部数える(33 駒の偽)
   ⇒ `EdoBuild.IntoMizoChannel`(局所で縁石の内・天端より上)。
3. 溝の芯の鎖から「3° 未満の一直線の点」を除くと、尻の型H → 床の溝の型A の変わり目が消えて離れが脚の最大(+0.31)に化けた ⇒ 除かない。離れの違うほぼ平行の脚は渡りの脚で継ぐ。
4. `OffsetPolylineLegs` でほぼ平行(0.01°)の脚の離れが 0.04 違うと交点が 6670m 先へ飛んだ ⇒ 3° 未満・交点が遠いときは中点で継ぐ。
5. 帯の記録(BandRecPath heiline/heifoot)の線から 3m を越える点(隅の法尻)は FootBandAlongAt が NaN ⇒ 縁石の天端は溝の駒の実メッシュ(CurbOuterPoint の top)で測る。
6. 「天端は地盤を通す」【硬】と「一駒の変わり ≤0.15」【硬】は辺6 の坂(1:4・溝も型H で下る)で両立しない ── LimitStep で守ると天端が地盤から 5m 離れ H2.4 を越える。地盤を一駒で均して通し、越えた所を ⛔ で刷った(普請方へ)。
7. `HoriSaku` の柱の根は局所 −0.12(板の下端 0.10)── 「柱 0.30 以上根入れ」と「下端 = 地盤 +0.03〜0.08」は部材で両立しない(部材方へ)。板の浮きは厚みの両面と芯の三筋で測る(岸の斜面で外の縁が浮く)。
8. **速い試し**: r138 の `hmc_S3.bin`(S3 の後・3d の前の地形)を SetHeights で戻し、PlaceMinamiHei → PlaceMinamiMizoWall を reflection で呼ぶと 20 秒(S2b 77 分を回さない)。
   Stage3d を丸ごと試すと新しい手の例外で 3d の記録を失った ⇒ 新しい手は try で包んで ⛔ を刷る。
**How to apply:** 溝・線に沿って土留めを立てる巡は、線の意味(天端の前の縁)と法尻の出を先に決める。当たりは駒の局所の筋で測る。
