2026-10-15 EDO-0502 第140巡(普請方 r139 N1〜N6・TW_Minami_Mizo の作り直し)。

1. **法尻の線を溝の駒の両端の縁石の外の縁で引く**(EdoBuild.CurbToeLine)── 鎖の折れの交点は「残した点」の離れで引く。捨てる前の点で引くと隣の区間が脚から振れ、
   隅の折れが 38.5 → 34.4° にずれて Kado38 が引けなかった。
2. 溝の筋へ入った駒の所だけ線を背へ足すとき、**段で足すと 15〜20° の折れが立ち、PlaceNozuraRun が偽の隅に Kado27 を据えた** ⇒ 0.8 全量・その先 2.5 で 0 へ。
   脚ごとに足すと(r139 の作り)脚全体の法尻 − 縁が +0.30 に化ける。
3. **継ぎ目の天端の段は「継ぎ目の帯の頂点の最高」で測らない** ── 法の足の石が走りの先へ出て帯を外し、坂の駒では中ほどの高い石を拾う(0.5〜3.5 の偽)。
   ⇒ 駒ごとに 0.1 の升の最高を中ほど 15〜85% で一次式に当て、継ぎ目へ延ばす(EdoBuild.NozuraJointStepReport)。
4. PlaceNozuraRun の第133巡の分岐(焼いた勾配 0 の駒の中ほどを線へ寄せ直す)は**継ぎ目に 勾配 × 走り の段**を作る ⇒ 段 ≤0.05【硬】の run は NozuraSeg.strictChain。
5. 隅の駒は水平 ⇒ 天端の線を腕 ±0.909 の内で隅の天端に揃える(坂のまま据えると腕の先に 0.2〜0.3 の段)。焼いた隅の折れは丸めで外れる ⇒ EdoBuild.KadoDegBaked(±2°)。
6. 背の天端 − 地盤は**節点で**測る(near の点の双一次は帯の外の節点を混ぜて −0.17 の偽)。天端は「near の内の地盤の最高 − (切りの上限 − 0.05)」を下回らせない ⇒ 切り ≤0.30 を守れる。
7. IntoMizoChannel の「溝の筋」は**両側の縁石の外の縁の内**(縁石の上も入る)。溝の頭の桝 G0 は溝より幅が広く、上の駒が入る(+0.27 足す)。
8. 速い試し: run2 の hmc_S3.bin を戻して PlaceMinamiHei → PlaceMinamiMizoWall → MinamiMizoBack を reflection で 2〜3 分(据えは解き直しごとに約 20 秒)。
9. 隅の際の足しは点ごとに足すと腕ごとに違う量で出て折れが 38 → 33° に化け、焼いた隅が引けない ⇒ 隅の際 2.5 は一つの値(近い隅どうしも同じ)。
   隅の天端が H2.4 を要すると Kado38(H2.1 まで)が無い ⇒ 隅の天端を焼いた最も高い H に収まる所まで下げる(背の切り ≤0.30 の内で)。
10. 返しの腕の先の切れ込みは「囲まれた塊」でなかった ── 北は駒の外形の中(h)・南は書いた小段、両端は外へ抜けた一〜二升の帯。
    ⇒ 書いた面を外形まで延ばす手と、向かい合う二方に挟まれた帯の手(EdoBuild.CloseEnclosedUnwritten)。候補は書いた節点の隣を一升広げる。
11. 木柵の帯を今の地盤で書くと、記録の節点が区画の線の崖(外は base_dem で 2m 低い)に接し、升目の段の検めが 352 → 1074 に増えた(崖そのものは前から在る)。
**How to apply:** 縁に沿う線を駒の継ぎ目で引く巡は、隅の折れが鎖の折れと一致するかを最初の試しで刷る。継ぎ目の段の検めは一次式で。
