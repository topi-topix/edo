2026-10-16 EDO-0502 第146巡。`EdoBuild.FaceStraight`(EdoBuildMizo.cs)の向きを主軸(PCA)から面そのものへ替えた。

1. **第145巡の案(凸包の面の側の最長辺)は土井で外れた**: E12_N03(留めの版 mc946x0)で凸包の最長辺は出入りの間を渡す斜めの辺 4.97m を拾った。
   **採った規則**: 候補 = 凸包の辺で外向きが r(凸包の最も近い点 → towardPoint)から 30° 内。選ぶ = その向きの支え線から 0.01 内に載る頂点の
   走りの広がりが最も長い辺。⟶ 対称な駒は不変(E13_N02〜08・N11 ±0.015°)、門・塀は格子の向き 20.604° に揃い(旧 PCA は 0.2〜2.2° 傾いていた)、
   E12_N03 は yaw と一致(旧 9.1° 外れ)、岡部 N12_0 は −93.536(yaw 183.536 と一致・P12 の斜めの駒 66.97° が据わった)。
2. **r を重心から取ると多駒の run で外れる**(呼び手は pcs[0] の中心から点を置く)。凸包の最も近い点からなら面の法線そのもの。
3. **留めで切った短い駒(土井 E13_N01 4.05m mc0x946)の背は面が 0.70m しか無く**、背の側は留めの切り口 −116.7° を返す(45° の窓では拾い・30° でも
   r がずれると拾う)。主軸の旧値も −121.7° で、どちらも「面」として当てにならない。⟶ 短い留めの駒の背を相手の面に使う欄は差し戻し候補。

**How to apply:** 面の向きを実メッシュで取るときは、凸包の辺 × 支え線の広がりで。最長辺も主軸も使わない。土井は流し直すと D2 の門の背 ≤0.05m・
D10 の塀 0.3°・E12_N03 との出合いが動く(第146巡では土井は流していない)。関連 [[r145-facestraight-pca-tilt-and-corner-road]]
