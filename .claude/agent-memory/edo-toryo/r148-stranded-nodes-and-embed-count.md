2026-10-16 EDO-0502 第148巡。

1. **取り残しの節点**: SinkGroundUnderParts / SinkGroundUnderMizo は真上(と 0.06 の四方)に駒の面が在る節点しか下げない。石の目地・継ぎ目の V・隅の駒と溝の間の隙の節点は
   S1 の造成の高さ(天端の高さ)のまま残り、周りの下げた節点との三角形が溝の床・見え面に土の楔を立てた(頂点40 D_N39_1_Mae_000 の脇 16.49 vs 床 14.23・TW_Hori_Kishi の継ぎ目 65 本)。
   「後から書き戻す手」ではなかった(bin を段ごとに比べると S1 の値がそのまま残っている)。さらに下げの手の「見え面の前の地表」の歩きがその取り残しを前の地表と読み、隣の見え面の節点まで
   天端の高さで止めていた。直し: 歩きで取り残し(隣 8 の 4 以上が駒の下)を飛ばす+ Stage3d の末尾に `EdoBuild.LowerStrandedNodes`(取り残しを隣の最も低い今の地表へ)。
   ⛔ 隣の駒の面の高さへ下げない ── 根入れの見え面の高さへ下げると前に窪みが開き、見え面の土の数えが 960→1017 に増えた(試し)。
2. **見え面の土 1891 の半分は根入れ**: SoilOverFacesReport が「地表 > 面」を数えていた。前の地表(法線の向きへ駒の外へ出た所 +0.15)以下は根入れ(893)・天端の帯の土(38)を外すと 960。
3. 台の石の浅い出隅(40° 未満 10 か所・P41 39°)は突き付け+口の裏の駒(IG_Slit_)── 端が互いの面より 0.12 前へ出る。留めの版(端を二等分の面で切った Castle Wall・倍率 0.5)が在庫に無い ⇒ MiterBaseWait で待ちへ。
4. P16 の丘は区画の外・隣 sannosha_prec の中(base_dem +1.5・x=−527 で 0.8 の段)── 岡部の流しは触っていない。
5. 重い測り(NearHulls を区画の全部の駒 + Planting で)を execute_code に直に書くと 30 秒を超え、再送で Unity が長く塞がる ── 印のファイル+txt で。

**How to apply:** 地面の歯・楔は「真上に何も無い節点」を先に疑う(光線で節点を名指し、駒に当たらなければ取り残し)。見え面の土の数えは前の地表で根入れを外してから読む。
