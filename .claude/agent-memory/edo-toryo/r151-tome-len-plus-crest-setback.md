2026-10-16 EDO-0502 第151巡(EdoBuild.SwapEndsToTome・EdoBuildShiroIshigaki.cs)。

1. **症状**: P35 の端の駒(1.39/0.41 の _L 駒)が Q の手前で止まり、伸ばした版 L175/L77 を部材方が焼いたのに「端の len + Q までの道のり ÷ 倍率」で引くと 1.557/0.578 になり L156/L58 を探して外れ、元の L139/L41 に落ちた(口 0.535 のまま)。
2. **原因**: 留めの版は切り口の錨を足元の前の角(X=−2.40)に置くので、天端の前の縁(X=−1.40)の角は端から 1.0·tan(折れ/2) 奥(spec の tomeCrestFrontCorner.z = 端 ∓0.196 @22.2°)。札の据えはこの角を Q へ寄せる ⇒ その奥行ぶんも走りに足す。
   Q で終わる角(P8 など)は ext = −tan·倍率 で足し 0 ⇒ 元の len の版のまま(式が両方に合う)。
3. **対処**: need = len + ext/倍率 + tan(折れ/2)。|need − len| > 0.005 なら need ±0.01 の版を引き、無ければ元の len。角の端が局所 Z=0 の側(_TP)で伸ばした版を元の位置に据えるときは奥の端を残すよう角の向きへ寄せる。footOf と継ぎ目の測りは版の走りで。P35 ⭕ 継ぎ目 −0.003・待ち 0。

**How to apply:** 部材方へ伸ばした版を頼むとき・引くときは同じ式で。tan の項を落とすと 0.36 足りない。関連 [[r150-kidan-tome-placement]]
