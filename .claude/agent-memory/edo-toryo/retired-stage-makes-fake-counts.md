**症状**(松江松平 2026-09-21): `NiwaQA` が「散布点 1278 点のうち **449 点は部材が解けず据えず**」。
ところが部材のパスは 1278 本とも実在し、流し直すと **1278/1278・解けず 0**。

**原因**: シーンに居た 829 駒は**退役した `Stage7`(庭の植栽)**の出力で、`Stage7'`(散布点を据える)の
出力 `Niwa/Planting` は**一駒も無かった**。検査は「`Planting` が無いなら `Niwa/G_*` を数える」と
直してあったので、**別の母集団**(旧 Stage7 の 829)を新 Stage7' の宣言(1278)から引いた。
449 も 829 も、どちらも「据わっていない数」ではない。

**How to apply:**
- 件数が合わないときは**まず「その数が数えている集合」**を突き止める。0 件も同じ(規則19)。
- 退役した Stage は**コードで塞ぐ**。松江松平は `Stage7_Niwa`/`Stage8_Shamen` の先頭で
  「7' を使え」と返して止めた(`EdoMatsudairaDewaBuilder.cs`)。放っておくと二重に植わり、
  旧 Stage7 の `Clear(Group("Niwa"))` は `_markers`・`Mizu`・`Ishigumi`・`Tenkei` まで消す。
- 旧 Stage が据えていた物のうち**指図が宣言していない物**(松江松平では景石18)は消してよい。
  指図が宣言する庭石は 6c 石組 / 6d 点景が持っている。消す前に**指図の宣言と突き合わせる**。
