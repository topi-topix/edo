松江松平の表向(26.70)⇔ 奥向(27.00)をつなぐ渡廊下 3 本(2026-09-20・施主裁定B = EDO-0288)。
指図 `links[].dan = {v:29, axis:"u", kind:"框"}` を**区間の割り**として読み、区間ごとに
地盤(`TerraceY`)・床・当たり・頭を解く。⛔ `links[].y` を一枚の床として読まない。

**① 段の柱通りは「低い側の区間」が持つ。** 高い側に立てると、**低い側の屋根のけらばの出**
(実測 0.17m)の下を通るので **0.34m 突き抜ける**(実測: 柱天端 29.440 / 下の屋根の下端 29.101)。
低い側に立てれば柱天端 29.180 に対し上の屋根の下端 29.362 で **0.182m の空き**。
⇒ 上の屋根は段を跨いで葺き下ろし、その下へ潜る柱は**低い側の屋根の線で止める**。

**② 折れ目に立ち上がりが開く。** 区間ごとに自分の端の当たりから頭を解くので、折れは
**0.26m**(両棟の軒が 0.04m 違うぶん 0.30 に満たない)。上下の駒は走り方向に 0.17+0.17 重なるが、
下の屋根の天端 29.245 と上の屋根の下端 29.433 の間に **0.188m の口**が残る。
**雨押え(立ち上がりの板)の部材が無い** ⇒ ⛔ 発明せず差し戻す(1.雨押えを新造 / 2.上の区間の頭を
下げて葺き面を通す=「葺き下ろす元は各区間が取り付く棟」に反する / 3.現状で可、の三択)。

**③ 框は上段框では作れない。** `Goten_JodanKamachi_1ken` は段 0.15 固定で**上の床板(奥行0.55)を
抱いている**ので廊下の床板と二重になる。桁材 `Goten_Beam_1ken`(成 `BeamH` 0.182)を段の高さへ
縮めて充てた(`EdoGotenKit.RokaKamachi`)。⚠ これも代用なので部材方への候補。

**④ 突き合わせ(`CheckScene`)は `Buildings` 直下に指図の名の物を探す。**区間に割るときは
**指図の名の親を1つ立てて区間をその子**にする(親の平面位置は指図のまま)。でないと
「廊下 L_x が実装に無い」+「孤児 L_x_a/_b」で 3 件鳴る。
