山王の勝手口(2026-09-22・EDO-0398)で続けて踏んだ二つ。どちらも**部材の原点と測る帯**の話。

## 1. 口の縁は「走りへの射影」で測る(帯を細くしない)

算出物の `segs` の口の幅(2.909m)と、そこに建つ門の走りへの投影(1.992m)の差が
**そのまま素通しの空隙**(南 0.457 / 北 0.460m)。門は走りに対して**傾いて・ずれて**据わる
(勝手口は 39°傾き・線から 0.446m 外)ので、⛔ **`monguchiKen` からの引き算で出せない**。

`EdoBuild.OpeningSpan`(= `BodyAt` + `CorridorSpan`)で測るが、**控えの帯に塀の半厚を渡すと壊れる** —
腰高の柵の半厚は 0.062m で、傾いた門の頂点が帯に**一つも入らず** `false`(= 塞いでいない)になり、
口がそのまま開いたまま建った。⇒ **その口の幅**を帯に渡して射影で測る(帯は「この口に建つ駒か」を
選ぶためだけの物)。実測: 口 2.909m → 塞ぐ [0.457, 2.449] → 残る素通し 0.000/0.000・接触 −0.013m。

## 2. 口の向こう側に柱を足さない

`Saku_Koshidaka_1.818` は**局所 −X 端に柱を持っている**(x∈[−0.909,+0.909])ので、口の向こう側の
縁には**もう柱が立っている**。足すと二重になり、しかも柱の部材 `Saku_Koshidaka_Post` は
**原点が +X の木口**(x∈[−0.115,0])なので、節点に置くと設計の線の**外へ 0.115m** はみ出す。
⇒ `Saku_SW` / `Saku_Sando` の芯が 0.04〜0.05m 鳴った(許容 0.02m)。一度そう建てて戻した。

⭕ 逆に、**部材にならない切れ端**(1スパンの 1/4 未満)は柱を1本だけ立てる — 据えないと run が
設計の線の端まで届かず、突き合わせが**芯のずれ**で出る(`Ita_Keidai` の 0.144m の切れ端で 0.48m)。
走りの先の端なら節点にそのまま置けば内へ収まる。始まりの端だけ柱長ぶん送る。

## 3. 射影 s は端ではない — 端は「極値をとった点の居場所」(2026-09-23)

`OpeningSpan` が返すのは**走りの線の上の s** だけ。門が走りに対して傾いて・横へずれて据わると、
その s の場所に門の実体は無い ⇒ 山王の勝手口(39°・線から 0.45m 外)で、射影で端を取った柵の柱と
門の間に **0.822m の口**(外接箱どうし)が残っていた。⭕ `EdoBuild.OpeningJambs` は**極値をとった
点そのもの**(門の脇柱の角)を返し、run はそこで折れて門に取り付く。`OpeningSpan` は退役・削除。

## 4. 柱で立つ門は「帯の頂点」では測れない — 断面で測る(同じ日に二度目)

箱で焼いた柱は**頂点が上下の端にしか無い**ので、腰の帯(28.3〜29.3)に入るのは貫と**礎石の天端**
だけ。礎石は柱より 0.105m 大きいので、帯から採った脇柱は実際の柱より外に出て、閉じが 0.085m
足りなかった(断面どうしの距離で実測)。⭕ `EdoBuild.SectionAt`(**三角形 × 水平面**の交わり)なら
頂点の無い高さでも柱の実形が出る。`OpeningJambs` は囲いの丈を **5 段**に割って各段の断面を採り、
**いちばん内へ引っ込む段**へ端を取る(= どの高さにも隙が残らない。礎石のように外へ張り出す物へは
そのぶん食い込む — めり込みは隙より良い)。実測: 断面どうしの距離 0.822 → **0.000**(28.45〜29.49m の
全段で交差)、bbox 距離 0.822 → 0.000、突き合わせの芯は鳴らず。

**How to apply:** 塀・柵・長屋の run を口で割る回は、①部材のどちらの端に柱があるか ②柱の原点が
木口か芯か を**資産から測って**から据える。門・鳥居・山門など**柱で立つ相手**を測る回は、帯ではなく
断面(`SectionAt`)。→ [[measure-dont-nudge]] / [[bansho-pivot-and-protrude]] / [[front-axis-differs-per-part]]
