2026-09-27 EDO-0437 山王 前庭の板塀(地覆の組)。

1. **症状**: 光付けした柱が法肩で一様に +0.016 浮き、石の天端の上の地覆が目地の際で 0.16 天端へ食い込んだ。
   **原因**: 旧 ScribeToBed は厚みの列(3 列・間隔 0.037)ごとに窓 [z−0.037, z+0.037] の床の最大で列を上げていた。
   厚みの向きの勾配 × 0.037 だけ浮き、目地が厚みの途中に掛かると隣の列の間の面が天端へ入る。
   **対処**: 下端の三角形の中に 0.0025 刻みの標本を取り、格子点を自分の床から始めて、面が床より下の標本があれば重みの大きい頂点から上げる(2次元)。
   食い込み 0・法肩 +0.009 以下になった。Stage4 は 8.5→60 秒。
   **残る物**: 目地(段の鉛直な面)の際は格子の目(走り 0.01・厚み 0.037)の分だけ水平に離れる(最短距離 0.017)。直すのは部材の下端の格子を細かく焼くこと。
   格子を 0.010×0.0093 に焼き直しても最短距離 0.013 が残った(= 格子の目の対角 0.0137)。0.0065×0.0062(対角 0.009)でも、目地の溝(幅 0.025)の際で 0.014 が残った ── 段の際の頂点は天端まで上がるので、その扇の分(約2目)離れる。上限は目の対角でなく約2目。標本を 0.01 間隔で取ると見落とすので、⚠ の近くは 2mm 間隔で測り直す。
   測るときは鉛直の差でなく床への最短距離で(鉛直だと目地の底との差 0.19 が出る)。
2. **症状**: `Itabei_Ita_1.410.fbx` の .meta に remap が在り、remap メニューも「済み」なのに Renderer の材が null(桃色)。
   **対処**: `AssetDatabase.ImportAsset(p, ForceUpdate)` で直った(取り込みが古いまま)。remap の後に材を LoadAssetAtPath で検める。

関連: [[measure-dont-nudge]] [[contact-must-use-drawn-surface]]

3. **症状**(同日・9列の柱): 柱の足元に白い四角。**原因**: 柱の「代」の側面の uv が u 0.068〜0.288 に張られ、
   材 itabei の地図の u 0.25〜0.27 が白い列(代の帯の標本の 9% が白)。地覆の帯(u 0.858〜0.975)は白 0。
   **対処**: 部材方の uv の置き場の話。光付けの後は足元を近接で撮り、白・桃色を目で見る(接地の数が合格でも出る)。
