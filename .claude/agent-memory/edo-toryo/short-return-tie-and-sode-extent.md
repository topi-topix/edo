2026-09-25 EDO-0430/0442 山王 前庭の切り込み `TW_Zentei_Kiri`。

- **症状1**: 東の返し(1.7m)の駒が前庭の側を向いた(Stage9「高い側を向く Zentei_Kiri 1/5」)。
  **原因**: 区間の票が2つで 1対1、`LowSide` は同票を右手へ倒す。**対処**: `EdoBuild.RunLowHand`(同じ run の区間の票の差で手を決める)を
  Stage3 が同票・無票の区間で使う。
- **症状2**: 参道の階の袖が段の全長(5段)に据わり、切り込みの返しと重なった。**原因**: Stage2 は袖の線からの脇の離れだけで段を選んでいた。
  **対処**: `EdoBuild.OverlapAlong`(袖の run を段の弦へ射影した重なり)で袖の run が走る段だけに据える。他の石段の袖の数は不変。
- **症状3**: Stage2・3 を皮(Stage9)の後に流し直すと、低い腰石垣(見付 0.1m)の駒が一つ逆へ向いた(`TW_Koshi_W_009f`)。
  **原因**: 前の巡の TuckUnderCrest が地形を下げた状態で駒ごとの LowSide を測る。**対処**: Stage1 から流し直す(S1→S2→S3→S9→S4→S5)。
- 症状4(解消 2026-09-25 v22): 返しの駒(2.0m)を 1.7m の区間の芯に置き、口の出隅で N の天端の線より 0.146m 北へ出た。
  **対処**: `EdoBuild.ShortSegConvexEnd` で出隅の端を決め、駒を出隅へ `FlushRunEnd`(天端の帯で測る)・余りは入隅の裏へ。
  ⚠ 寄せたら Stage3 の「駒ごとの見え面の測り直し」の窓(±1m)が入隅の先へ出て、東の返しが前庭の東の土留めの外の低い地盤を拾い裏返った
  ⇒ 窓は区間の中に切り、駒一つの区間(N=1)は測り直さない。当たる先: 楼門の腰石垣の返し 1.40m・御供所 EK 1.36m・前庭 W 1.95m も同じ据えに変わった。
- 症状5(2026-09-26 対処): 段石の小口(鉛直)× 返しの法 1:0.25。`EdoBuild.AbutStepEndsToWalls` が段ごとに蹴上の中ほどで光線を打ち
  段石の長さを詰める(上端の口・下端のめり込み 各 0.026)。⚠ 一つの端が二つの面(返しと袖)に跨る段(参道の階 Dan_01・女坂 Dan_00/01)は
  離れが 0.22〜0.36 割れるので動かさない ── 据えでは解けない。⚠ 片側だけ詰めると駒の原点が軸から外れ、突き合わせの「端点」が 0.1 ずれた
  ⇒ 子 `_axis` に据えた原点を残し、検めは `EdoBuild.StepAxis` で測る。
- 症状6: 袖の奥の暗い三角 = **北の土留めの鉛直な小口**(返しとの出隅に隅の駒が無かった)。別々の run の出隅を `PlaceRunKado` が駒の芯で
  測り、短い返し(1.7m)の芯が相手の控えの線より前に来て「入隅」と誤った(黙って飛ばす)。⇒ `PlaceRunCorners` で別 run も走り×FaceSide で凹凸を決める。
  当たる先: 御供所の郭 EK×SE にも隅が入った(EK は隅の駒だけになる ⇒ 突き合わせは `_x_…_kado` を両 run に数える)。
  袖の背は隅の駒の法へ中ほどで突き付け(−0.20)ても上端・下端に 0.07 残る ── 丈 0.6 の鉛直な小口では解けない(背を法に切った部材の話)。
