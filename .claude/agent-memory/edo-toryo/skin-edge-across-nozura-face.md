2026-09-26 EDO-0437 第5巡(山王 前庭の東の縁 TW_Zentei_E)。写真で「表の石が欠け奥の土が縦の帯で見える」「足元が地面に埋もれる」。

**測り方**: 見え面の前から水平の光線を 0.02 刻みで打ち、壁の駒(一時の MeshCollider)・皮の群 EdgeSkin・地形のどれに先に当たるかを数える。
駒の間の抜け(どれにも当たらない)は 0。皮が先に当たる帯が z≈854.8〜855.1 で 13.64〜14.32(= 写真の帯)。
皮の頂点を列挙すると、見え面の線(d≈0〜0.1)の点が天端の直下 14.35〜14.49、隣の外の点が足元 13.6 ── その辺が法 1:0.3 の見え面と
ほぼ重なって 0.1 奥に張り、石の出入り(±0.1〜0.2)で覗く。⚠ `EdoBuild.Ground` は穴の升の下の見えない地形を返す ── 皮の在る所は `EdoBuild.Drawn().At`。

**対処**: CutEdgeSkin の「3b 見え面の前へ皮を出さない」(天端の帯の駒の外形の中の点 → 見え面の側の低い隣への辺を 5 点で測り、
見え面の向きの水平の光線が 0.6m 内に部材へ当たらなければ 0.05 ずつ下げる・TopIndex.Ray)。

**How to apply:** 皮の在る敷地で見え面の「欠け」「埋もれ」を指摘されたら、駒を動かす前にこの光線の数え(駒/皮/地形の先着)を取る。
