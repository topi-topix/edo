2026-10-10 EDO-0502 第85巡(EdoBuildSkinSolve.cs・岡部 Stage3b だけ solve: true)。2回流して被り 32→370・隙 7→35・見え面の土 454→1356 と悪化。原因は測ってある:

1. **野面の駒は石の寄せ集め** ── 縦の線が 9〜13 枚の面を切り、中に下向きの面が何枚もある。出入りで区間を割ると石一つずつの底を「駒の底」と読む。⇒ 駒ごとに一番上と一番下の当たりだけで一つの塊(`SolidOf`)。一番上の当たりの法線も石の小面で、見え面の向き(WallFace)との内積は 0.09 等 ── 法線で見え面を判じない。全ての帯で篩う駒に `NozuraCrestCover.Add` で帯(天端の前の縁→法尻の平面)を作り FaceAt の d<0 で判じる。
2. **見え面の上限を「一番上の当たりの駒」だけで掛けると、下にある別の駒の見え面を逃す**(TW_Higashi_Tsuyo_Side0_0_050f の前で皮 15.8・石 14.2)。⇒ 縦の線に当たる全ての駒の帯で d<0 なら掛ける(未実装・次の手)。
3. **周り(0.125/0.25)の天端の上限は陰を飛ばす** ── 0.125 先に高い駒(上の段石)が在れば 0.25 先の低い踏面は引かない(旧 CAPR と同じ)。入れないと K_Kuruwa の2段目が平ら 16.50 を 16.20 へ引いた(矛盾の最多 166)。未実装。
4. **端の駒を埋める土 ≥ 天端 + buryMin は硬い lo**。狙い(hold)に入れただけでは隣の袖の見え面の上限に負けて −0.141(⛔)。SkinDesign に buryMin を通す。未実装。
5. **平らな面 Kadonouchi の輪郭は SideEnd 延長の石垣の背(天端 21)まで入る** ⇒ 「平らの y+e より高い天端の石垣の背(0〜back+skirt)」は平らに引かない(`behindHigherWall` ── 入れた)。逆に **SideEnd1_0_0_018f 等の天端 14.57 は平ら 16.50 の内に在る** ── 門の内の右下 1.95 の窪みは指図の値どうしの矛盾(延長の天端 < 平らの面)。皮では解けない。普請方へ。
