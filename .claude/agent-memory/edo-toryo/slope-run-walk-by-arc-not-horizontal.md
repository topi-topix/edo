**斜面に駒を連ねる走りは、水平の長さでなく地表の道のり(3次元の実長)で割る。継ぎ目は駒の足元でなく丈の中ほどで合わせる。**

**Why:** 2026-09-23・山王 `Saku_SW`(EDO-0398)。水平で割って駒を roll で傾けると、駒の水平の張り出しが
pitch·cosθ に縮むので**継ぎ目が毎回 pitch(1−cosθ) 開く**(30° の斜面で 0.19〜0.31m の素通しが 4 箇所)。
逆に地形の折れ目(法尻 6.7°→27.3°)では**頭どうしが 丈×Δsinθ 重なる**(実測 −0.31〜−0.40m)。
隙とめり込みが**同じ走りに同時に出たら、たいていこれ**。⛔ 継ぎ目を足元で合わせると折れ目の重なりが丈の全量に乗る。

**How to apply:** `EdoBuild.GroundPolyline(a, b, span, floatMax, buryMax)` で継ぎ目を採り、
`EdoBuild.PlaceOnChord(部材, j0, j1, 親, 名)` で弦に張る(`EdoBuildRun.cs`)。
均しの縛りは**部材の根入れ**(`EdoBuild.RunMeasureY(path).Root`)から渡す — 上=根入れ(足を地面から出さない)/
下=その倍。均しは 2 巡まで(増やすと縛りに当たった継ぎ目へ折れが集まって悪化する・実測)。
結果: 隙>0.10 が 4→0(最大 0.310→0.001)、めり込み 0.309→0.151、浮き 0、埋まり最大 0.45、走りの端は設計の線どおり。
天端(seat)のある run は水平割り・roll 0 で従前と同一(`Ita_Keidai` はバイト等価)。
⚠ 折れ目の食い違いは剛体の駒では消えない — 丈の中ほどで継いで**半分ずつ頭と足へ振り分ける**のが上限。
