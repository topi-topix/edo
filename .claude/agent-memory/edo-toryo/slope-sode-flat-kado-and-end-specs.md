2026-10-07 EDO-0502 第41巡(岡部 TW_Kado_Sode.sodeSlope・端の型)。

1. **坂の天端を「区間ごとの背の向き × 設計面」で引くと、出隅の節点で背の点が飛び天端が 0.43 落ちる**(勾配の寄せ 0.39 外れ)。
   ⇒ 0.1m おきの生の値を PAV(隣接の違反を均す回帰)で単調にしてから渡す(SodeSlopeSegs)。
2. **天端が坂の区間を鎖に継ぐと、継ぎ目ごとに「段の境」の駒(G−220)が立つ**(1m で 0.05 超の差を段と読む)。NozuraSeg.flow = true で止める。
3. **斜交の出隅の隅の駒(Kado52_H4800)は天端が平ら** ⇒ 勾配 0.35 の坂の上では腕の先で天端と背の差が 0.53 になる(硬 ≤0.3 を割る)。
   置き方では解けない ── 坂の隅の駒(部材)か線の折れの扱い(指図)。
4. 名指しの端(returnEnd・endKado・kadoReturnUniform)は EdoBuild.EndSpec に欄の文の値を入れて NozuraEndRule.spec で渡す。
   「延ばす向き 1.5m の内の実面」は平行に走る外周の石垣を拾う(距離 0.00)⇒ RunAxis で 30° 以内を除く。
5. 急な勾配(|g| ≥ 0.2)を低い見付で引くと ±0.12 へ寄る(±0.275/±0.45 は H0600 以上だけ)⇒ EdoAssets.Own.SannoNozura が一つ上の見付へ上げる。

## 第42巡の追記

2026-10-07 EDO-0502 第42巡(岡部 K_Dan1・TW_Kado_Sode)。

1. **皮の窪みの原因は推し量らず EdoBuild.SkinTrace で測る**(点を入れると CutEdgeSkin が格子の点の高さを段ごとに刷り、Stage3b の返りに「皮の追跡:」で出る)。
   execute_code で `EdoBuild.SkinTrace = new List<Vector2>{...}` を入れてから EdoBuildQueue で Stage3b を流す(同じドメインなら残る)。終わったら null に戻す。
2. 段石の背の 0.85 の窪みの正体は二つ: ① 外形の中(段石の下)の点を「面の外は駒の本当の底まで下げる」で積みの底 17.84 まで下げ、外の点 18.73 との
   三角形が背の縁で落ちた ② 外の点の cap(周り 2 格子 = 0.5m の天端の最小)が 0.45 先の下の段の踏面 18.47 を拾った。
   ⇒ StairBackRim(縁の点は天端 −0.02)と、2 格子先の天端が間の高い駒の陰なら引かない、で直した。隣の点が城の石垣の法の下(外形の中・上向きの面なし)なら外の点として地盤で見る。
3. 袖の坂の低い端(線の端から 0.6m 先)は**背の地盤が前の面 16.50 より低い 15.7〜16.4**。地表の票で見え面を決めると端の駒が背を向く(裏表)
   ⇒ NozuraSeg.face で名指した。小口の土(高さ 0.15)では背の側の小口 0.15〜0.39 が残る(普請方へ差し戻し)。
4. 突き付けの端の戻しは伸縮の段が変わると当たりが跳ぶ(−0.46 → −0.46 → +0.24)⇒ 入る位置と口の位置を覚えて割線で挟む(FILL_PASSES 12)。
5. H4800 は G000 しか焼けていない ⇒ 坂の袖の出隅の上手は平らな H4800 の段になる(天端と背の差 +0.47 ⛔ は部材の話)。
