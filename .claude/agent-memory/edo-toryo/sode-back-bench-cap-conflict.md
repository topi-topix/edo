2026-10-04 EDO-0502 第13巡 岡部 TW_Kado_Sode(EdoBuild.RunsByBackSlope/BackBenchAt)。見える背の口は 15 → 0。
天端と背の地盤の差(硬 ≤0.30)は最大 0.42〜0.45 で残る。外れ 16 点は全部 run の**下手の端 s≤0.3**(低い run との段の境の脇)。
試して効かなかった物: 皮の設計の格子 1m→0.5→0.25m(0.43→0.43→0.42)・盛りの上限 0.6→1.0(施主裁定A・0.42 のまま)。
⛔ 一度「上限との衝突」と報告して裁定を取らせたが外れだった ── 設計面の狙いと**描かれた地表**を同じ点で並べてから原因を名指すこと。

測り方の罠: `Drawn().At` は石の下の皮も返す。背の地盤は「上から光線を打って最初が皮・地形、0.15m 前が石」の点で測る。
外れた疑い(第13巡の後半): ① 低い run の駒の外形が背へ伸びて皮を押さえる ── 外れ 11 点のうち 9 点はどの外形にも入らず真上に駒の天端も無い ② 外形の縁で天端の下へ納める ── 0 点。
皮の頂点は狙いでなく**元の設計面**の高さ(例 狙い 19.89・皮 19.50・設計 19.50)。設計の格子には狙いが入っている(写した節点 727)⇒ 皮の中の後段が設計の値を使っていない。
次に測る所: CutEdgeSkin の「見え面の前へ出る皮の辺を下げた」(全邸で 1416 点・場所が刷られない)と OutsideY。点を名指して、どの段が高さを決めたかを刷る道具が要る。

**How to apply:** 段違いの天端の背を盛るときは、段の境の両脇 0.5m を別に測る。原因を名指す前に狙いと描画を同じ点で並べる。
