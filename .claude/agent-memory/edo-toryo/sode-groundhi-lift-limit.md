症状(2026-09-24 EDO-0430): `EdoBuild.PlaceIshidanSode(..., groundHi:true)` で袖を背の地表まで上げた。男坂6・女坂62・郭の階7・中門の内4 駒が上がり、
女坂の坂下 TW_Onna_S_000〜002 と坂上 TW_Onna_N_038〜040 は要る上げ 1.55〜2.08m が上限 1.41m(袖 2.20 − 笠 0.30 − 段石の底 0.48)を超えて据えなかった。
あわせて上げた駒の隣の留めの駒(F-1.86 / B+0.60)が未焼けになる ── 並びが変わると焼く一覧も変わる([[miter-joint-slides-along-cut]])。
⚠ 袖が建っても**踏面の端に地表が被る**(2m 格子の節点が段の外の高い地盤から踏面を跨いで張る。女坂 196/460 点・最大 1.19m)。
TuckUnderCrest は天端 + 0.05 より高い節点を触らない(掘ると連鎖する [[dig-to-unbury-cascades]])ので、これは袖の上げでは解けない。

**How to apply:** 切通しの石段は、上げの上限を超える所に丈の足りる袖(部材方)が要る。踏面の上の地表は段石の外形の中の節点を下げる別の手が要る
(EDO-0421)。上げの量・上限・背で地表より出る量は Stage2 の log に刷ってある。
