**症状**(2026-09-21 松江松平): 東小門の石段 3段(走り 1.35m・落差 0.9m)が、平場 27.00 の下に
**丸ごと埋まって**いた(天端 −0.601m)。表門の段も 0.28m ずれ。

**原因**: 段は指図の `pos`(literal)に置かれるが、**造成した段の落ち際は擦り付けで 2.4〜4.5m に広がる**
(地形は 2.0 m/px)。走り 1.35m の段はその中のどこにでも載り得るので、literal の位置は落ち際と一致しない。
⚠ `y0/y1`(敷居・面の設計高)は**意図なので正しい**。狂っているのは**走りに沿った位置**だけ。

**対処**: `EdoBuild.FitRunAlongAxis(foot, up, 各段の弧長, 各段の天端, 探索幅, 刻み, 許容)` —
剛体のまま走りに沿って滑らせ、**各段の天端とその下の地表**の差の最悪値が最小になる寄せ量を返す。
⛔ 段数・落差・幅・向きは動かさない(指図の意図)。実測 K_Komon −1.95m(0.601→0.073)/ K_Mon −0.45m(0.330→0.133)。

⛔ **許容(`accept`)に 0 を渡さない** — 「よりましな所」を求めて段が何 m でも歩き出す
(差 0.153m の一枚段が 1.10m 動いた)。許容は**その段自身の蹴上** — 一蹴上以内の沈み/浮きなら段は段として読める。
⛔ 逆に、**寄せると決めた後の同点崩しに許容を混ぜない** — 許容ぎりぎり 0.285m で止まり最下段がほとんど見えない。
同点崩しは「最良 +0.02m 以内でいちばん動かさずに済む所」。

⚠ 両端を地形から取っている段(`kind: 庭の段`)には要らない — すでに従属値で解けている。
