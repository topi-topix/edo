2026-09-25 EDO-0430 で測った(施主「ガタついています」の赤丸。この巡は施主が「段を無くす整地」に切り替えて止めた)。

- `EdoSannoShaRebuild.Sukibei` は run の両端を常に `c`(隅部材へ続く)にする。段の境 4 か所(NE|NE2・NW|NW2・SW2|SW・S|S2)は
  一直線の継ぎで `joints` に `kadoFrom` が無いので隅も立たない ⇒ 躯体は節点から ±0.09 で止まり **0.18m の口・柱なし**、
  屋根は設計で ±0.40 引っ込む。
- 段を残して納めるなら部材は既存の端の型で足りる: 高い側 = `h`(節点に柱・棟天端まで・笠・破風)、低い側 = `t`
  (柱なしで木口を柱の面へ突き付け。スパン − 0.09)。1767_nt は既存、他(1818_hn/nh・1923_hn/nh・1905_nt/tn・1532_tn)は未焼成。
  ⚠ 低い側も `h` にすると笠(±0.12)が高い側の柱(±0.09)から 0.03 出て透塀に食い込む。
  石垣の段の縦面は柱の低い側の面(節点 −0.09)に揃えると、h の基壇が宙に浮かない。

c でなく **n**(柱は +X の端)で閉じる。要った新造は 1818_nn の 1 点だけ(build_sanno_sukibei.py --span 1.818 --ends nn --no-kado)。
