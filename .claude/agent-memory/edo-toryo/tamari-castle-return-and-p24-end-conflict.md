2026-10-10 EDO-0502 第100巡。

1. **外周の基壇 IG_<棟>_* は Castle Wall × run の s(N41_0/1 は 1.25)** ── 丈 5.0・控え 3.0。PlaceRunKado は隅の駒を倍率 1 で据えるので、
   素の Kado90(控え 2.4)は見え面が 0.6 食い違い ⛔ で退く。隅の駒の返しの見え面は「控え(3.0)+ 腕」 ⇒ 最短でも約 2.95m(A200x-4)。
   溜り TsuyoTamari の脇は外の線から本線まで 5.43m しか無く、「隅の返しを一駒(定尺 1.8)」は焼いた駒では作れない ⇒ 部材方・普請方へ戻した。
   溜りの脇の線 = 基壇 IG_N41_0_434 の小口(z 1042.72)と一致している(測った)。
2. **辺24 の impl の線は北(P25 寄り・964.24)が始まり**。Kado_P24 は南の端(955.3)で、endKado の積み止め(辺24_1_0 端1)と同じ端。
   ends 10-10p の「始まり(Kado_P24 の側)は ②」と「終わりは tome1」は同じ端を名指す矛盾 ⇒ 当てずに戻した。

3. **溜りの脇を本線より先に(通す側)にすると、石段の口が本線の両端 0.28 しか残さないので、脇の通しの駒が石段の脇の返しと 0.28 離れて並ぶ** ──
   被り 220→494・継ぎ目の口から土 259→385。一度流して戻した。口の残りが控えより短い本線では入隅の順を入れ替えない。
4. **辺24 の「土の歯」(写真 qa06)は TW_Nishi_Kado でなく外周の基壇 IG_S_Hei_21_18x の外の見え面**。NozuraCrestCover.Add はこの駒の見え面を
   内向き f=(1.00,0.09) と読む ⇒ FaceAt が false で、足元の帯(前・背)も見え面の上限も掛からない。皮は線の外 0.03 の点 8.59 と線の内 0.22 の点 10.93(天端の下)を結び、
   三角が法の前を渡る。直すのは帯の見え面の向き(区画の線際の外周の基壇は外向き)── EdoBuild の型。

How to apply: 欄が端を「〜の側」と名指したら、impl の line の向きと Kakoi の Kado_P<n> の位置を先に刷ってから型を当てる。
外周の基壇に隅の駒を回す欄は、run の s と焼いた隅の駒の倍率を先に比べる。関連: [[run-corners-seams-and-tiers]] [[stepjoint-and-kado-return-traps]]
