EdoBuild.TrunkFootLocal(2026-09-25・EDO-0409・18ac81b4)は「LOD0 の最も低い 0.3m の帯の xz の外接矩形の中点」。
榎・欅・松・椋・梅・常緑は帯 = 16頂点の幹の輪で (0,0) に出る(ピボットが幹の芯)。**紅葉6本と蔓7本は帯が
地面近くの枝葉まで拾い**(帯の幅 1.0〜1.6m、n=256〜386)、中点が幹から外れる(Momiji_Small_03 で 0.39m)。
**Why:** 定義は SeatPlant の footBand に揃えよと指示された。紅葉の「幹の足」が真の幹かは未検め。
**How to apply:** 紅葉・蔓で道辺・芯々が外れたら、帯の定義(最大連結・最も密な輪)を疑う。目録の列 trunk_dx/dz で当たりを付ける。
目録を `Edo/アセット目録/目録を再生成` で流すと 09-21 以来の新部材 +346/-81 行が混じる(列だけ足したいなら木の行へ差し込む)。
MCP のメニュー呼び出しはタイムアウトするが走っている — tsv の mtime で待つ。
