2026-09-25 山王 EDO-0430 v17(回廊の基壇の東 TW_Kairo_E)。

症状: 見え面の足元に尖った山形が 2m おき(節点の間隔)。造成前の地盤にも設計面(graded)にも無い。
原因は三つ重なっていた:
1. 見え面の 0.1〜1m 奥(駒の外形の中)の地形の節点は、整地が設計面を双一次で写すので天端の側(28.1)を持つ。段の閾(2.83m)より低い土留め(1.1〜1.4m)は跨ぎの判定に掛からない。
2. 皮(CutEdgeSkin)は部材から NEAR(0.5m)以内と外形の中の点を**地形のまま**描いていた(設計の地盤は near==0 だけ)。外形の中は cap(法の面 − 0.15)まで持ち上がり、土が法を這い上がって見えた。DesignOut の欠けた隅も地形で埋めていた。
3. 整地の縁の節点(4 隅が欠ける)は最寄りのセルの**値**を 1m 外へ延ばしていた ── 斜面(0.3〜0.9m/m)で +0.3〜0.75。値でなく「設計面 − 造成前」の差を混ぜる。

直し: `SkinDesign.baseAt`(造成前の地盤)+ CleanAt(外形の中の節点を造成前に置き換える)/ 設計があれば near 1・2 も設計の地盤(外形の中は下げるだけ・底 ≤ 地盤+許容の駒だけ底で止める・殻の駒は底と見なさない)/ floored は orig と比べ WallBottom 0.2m を先に / Stage1 の NodeY は差を混ぜる・土留めの前 4m の設計面の外を造成前へ戻す。
帯 3m の 0.1 超え 1425/2836 → 93/2894 点。隙 0・被り 0・面の重なり 5(据え置き)。

**How to apply:** 見え面の前の検めで基準を引くとき、設計面のセルを見え面の奥から混ぜない・欠けた隅は値でなく差で混ぜる(物差しの方が +0.15 嘘をつく)。
⚠ 皮の Stage9 は 17 秒だが MCP の応答が切れて 6 回走る(冪等・約 2 分)。delayCall は Unity が裏にあると発火しない。
