2026-10-10 EDO-0502 第98巡(岡部 backOfN39_1 10-10o「背の台の石垣を背の全長に」)。

1. **Za_<棟> は EdoBuild.Body の凸包** ── 背の面(FaceOut の座+0.1〜1.2 の帯)より外へ 0.6〜1.0 出る(返しの溝の外 u 9〜17 で前 0.6 が座 14.00、前 1.2 で郭 13.10)。
   背に石垣を立てると前に 0.9 の土の棚が残る ⇒ FlatFaces で背の線の半平面で切った(EdoGeom.ClipHalfPlane)。どの面が点を取るかは FlatFaces を reflection で呼んで PIP で名指す。
2. **PlaceNozuraNet の鎖は nozSegs の順に組まれ・据わる**(依存の無い限り)。相手の区間の駒へ「近くの駒の実面へ」突き付けたい区間は、網の直前に**最後に足す**
   (据わった駒は pool に入る)。⚠ pool の近さの判定は Body(g, 400) の間引き ── 大きい長屋(4.9万頂点)を pool に入れても 1.5m 以内を拾えず ③ 積み止めへ落ちる。
   長屋が相手の端は実メッシュの全頂点で端を測って noAbut で打ち切る。
3. 端が別の区間の線の上(走りの 0.1〜Len−0.1・横 0.1 以内)なら端の納め(積み止め)を掛けない ── T 字の止めはこれで積み止めが消える。端点どうしが 5cm 以内だと Links が継ぐので離す。

How to apply: 区間を足す・端を相手に止める巡は 2b の log の「野面の乱積み(始まり … / 終わり …)」の行で相手の名を確かめる。関連: [[skin-solve-lo-hi-first-runs]] [[measure-dont-nudge]]
