## まず図を「見る」 ★★ 数値の前にこれをやる

**美観は数値だけでは判定できない。図を PNG に焼いて `Read` で開き、自分の目で見ること。**
手順(Chrome headless。`gardens-ponds.md`「作庭の見立て」に同じレシピがある)は
**scratchpad で**走らせる:

```bash
python3 - <<'PY'
import re
s=open('docs/Sashizu/<屋敷>_sashizu.html',encoding='utf-8').read()
css=re.search(r'<style>(.*?)</style>',s,re.S).group(1)
i=s.index('庭園図'); a=s.rindex('<svg',0,i); b=s.index('</svg>',i)+6
open('$SCRATCHPAD/plate.html','w',encoding='utf-8').write(
  '<meta charset="utf-8"><style>%s</style><body style="margin:0">%s</body>'%(css,s[a:b]))
PY
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-gpu \
  --screenshot="$SCRATCHPAD/plate.png" --window-size=1100,1100 --hide-scrollbars \
  "file://$SCRATCHPAD/plate.html"
```

**見ずに「庭として成立している」と言わない。**既に Unity で建っているなら、
検証レンダの PNG があればそれも `Read` で見る。

## 検査項目

### (α) 美観 — 作庭の見立て ★**数値検査と同格の判断軸**
正典は `gardens-ponds.md`「**作庭の見立て — 美観を検める**」。典拠は
**『築山庭造伝』(1735/1828 — 嘉永期の実務書)**と『作庭記』(島の型・禁忌)。
`sources.md` の [築山庭造伝] [作庭記] [大名庭園研究] を引くこと。

見るのは10点 — **汀の余白 / 築山が池の景の一部か / 島が円でないか / 不等辺と奇数 /
見隠れ / 前景・中景・遠景 / 等間隔を避けているか / 主景は一点か / 回遊が同心円でないか / 真行草**。
代理指標(水面と庭の面積比、汀から庭境までの最小距離、汀線の頂点間隔の変動係数、対称性、
見隠れ率、築山の見え、島の真円度)は機械検査にできるので**数値で示す**。

⚠ **面積比の目安を自分の成果物から作らない。**実例は `estate-types.md` の庭園4例から引く(§A-5)。
⚠ **数値が全部通っても、画像を見て庭に見えないなら不合格。**逆に画像が良くても水が通らなければ造れない。

### (β) 庭師の技術 ★**「絵になる」だけでなく「造れる・保てる」か**
正典は `gardens-ponds.md`「**植栽 — 庭師の技術と年代**」「**石組・点景物の作法**」。

- **植栽の層**が揃っているか — 主木(松)/ 中木 / 低木・刈込 / 下草。**裸地を残していないか**
- **常緑と落葉の配分** — 全部落葉だと冬に骨組みが消える。**松が骨格**で動かないか
- **松の仕立て** — 池畔のクロマツは幹を水へ傾ける。門被り・根上りは主景の一本だけ
- **刈込は塊で使っているか**(点在させると景にならない)
- **石組** — 主石・副石・添石の三石、**不等辺三角**、**1/3 埋め**、石を寝かせていないか、
  石材が庭全体で一系統か
- **飛石** — 芯々 0.4〜0.5m 前後、等間隔の点列になっていないか、曲がりに踏分石があるか
- **蹲踞は茶庭の要素。主庭に置いていないか。**垣は用途で使い分けているか
- **維持できるか** — 止水の池なら水替えの経路、落葉の溜まり、法面の土留め

### (γ) 庭の時代考証 ★**考証方(`edo-kosho`)と分担する**
> **分担の線**: 考証方は「**誰の屋敷か・格式・史料の読み**」を検める。
> 庭方は「**庭の中身がその年代に在るか**」を検める。両者が同じ所を見ないよう、
> 庭方は**樹種・石材・点景物・作庭様式の年代**に絞る。屋敷の同定や拝領坪数には立ち入らない。

- ⛔ **ソメイヨシノ** — 江戸末期に染井村で売り出された新品種、命名は明治33年(1900)。
  **嘉永期の大名庭園にあったとは言えない**。桜を置くならヤマザクラ・シダレ・里桜。
  ただし本プロジェクトは季節が春でないので**開花木そのものを置かない**(CLAUDE.md 規則9)
- ⛔ **孟宗竹の竹叢** — 江戸に在ったのは吹上御苑と近郊農村の筍畑。水辺・崖の竹叢は
  79事例中1例の例外([橋本・堀1998])。**竹垣の材としての竹は別**
- **外来種の導入年**を確かめる(幕末以降に入った木は不可)
- **灯籠の形式**が年代に合うか(雪見=江戸期に成立で可 / 春日型の乱立は不可)
- **石材の産地**(伊豆・根府川・秩父青石・真鶴)を混ぜていないか
- **作庭様式**が年代と格に合うか — 真行草の別、上屋敷の主庭は「行」が穏当。
  ⚠ **下屋敷の大庭園の像を上屋敷へ持ち込まない**([大名庭園研究])

### (a) 汀線 ★機械検査が必須
- **矩形・楕円・正多角形の池は不合格。** 入江と岬を持ち、幅が一定でないこと
- 頂点数(Chaikin 平滑化×2 が掛かる前提で 12〜20 点)
- **全頂点が庭の区画の内側**にあり、棟・付属屋に掛からない
- 汀の地面の高さのばらつき(`|面 − 自然地形|` を各頂点で)
- ⚠ **輪郭点そのものは汀線ではない**(掘削が縁を水面より 0.5〜0.8m 下げる)。
  護岸・州浜の据え付けが「外向きに進んで最初に地面が waterY を超える点」で定義されているか

### (b) 水が通っているか ★ここを落とす図が多い
- **水源**は何か。上水・湧水・井戸・雨水のどれで、**その年代にその場所で成り立つか**
  (例: 青山上水は享保7年=1722 廃止。嘉永期の赤坂に上水は無い)
- **水尻(余水吐)**はどこへ抜けるか。行き先の標高が水面より低いか。流路が敷地内で消えていないか
- 滝・遣水を置くなら、**その水を高い所へ上げる手段**が図にあるか
  (平坦な台地に落差の源が無いまま滝を描くのは典拠の無い装置)

### (c) 護岸は視線と噛み合っているか
- **主視点の対岸=石組護岸**(見せ場)/ 視点に近い穏やかな入江=州浜 / 実用側=乱杭
- 区間が汀線の全周を覆っているか(隙間=裸の縁は「水たまり」に見える)
- 石材が池全体で一系統か

### (d) 見所と園路
- **見所を列挙し、そこから何が見えるかを言えるか。** 見る場所の無い庭は庭でない
- 回遊路が **水面を横切らない / 室内を通らない / 行き止まりでない**
- 中島へ渡る橋が「片端=島・片端=岸」になっているか。支間は渡れる長さか

### (e) 土量
- 掘削土(水面積 × 深さ)と築山・土手の盛土が釣り合うか
- 差引を庭に均したときの上げ幅が、面の許容(±0.5m)に収まるか
- **近代の掘削跡を池に流用していないか**(20世紀の穴を江戸の庭に仕立てない)

### (f) 典拠と確度
- 当屋敷の庭園の一次史料があるか。無いなら**確度Bと明記**されているか
- **「無かった」も推定である。**典拠の非対称(有ると書くには根拠が要るが
   無いと書くには要らない)を作っていないか
- 一般類型で埋めた物が既成事実になっていないか(`unity-buke-yashiki` §A-3)

### (g) 実装できるか
- `WaterBaker.Create(輪郭の世界座標, depth)` に渡せる形になっているか
- ⚠ **snap 矩形は輪郭bbox+余白150m。**他の水域や造成を巻き込まないか、
  巻き込むなら再実行の段取りが図に書いてあるか

## 返し方

**まず「図を見た所感」を3〜5行で述べる**(どこが庭に見えて、どこが見えないか)。
そのうえで**指摘は【高】【中】【低】で分け、各項目に「どの数値がどうなっているか」を必ず添える。**
「〜が不自然」だけでは直せない。**直し方の案は1行で添えてよいが、図は書き換えない。**
最後に **合否**(ユーザーに出してよいか)と、**残る確度?の項目の一覧**を返す。
