---
description: 建築部材を用意する — 在庫を引き、無ければ Blender で新造する
argument-hint: "<部材名。例: 築地塀の端部 / 31.3度の隅石垣>"
---

対象: $1

1. **まず `edo-zaiko` で在庫を引く。** 使えるものがあればそれを使い、ここで終わる
2. 在庫に無い / 寸法や格式が合わないと確認できたら、`edo-buzai` を起動する。渡すもの:
   - 何の部材か、どこに使うか(屋敷・辺・向き)
   - 必要寸法(**間数**で。1間 = 1.818m)
   - 参考になる既存スクリプト(`Tools/Blender/` から近いものを名指しする)
   - 継ぐ相手の部材(端部の処理・小口が透けないか)
3. `edo-buzai` の完了条件が4つ揃っているか確認する:
   検証レンダを見た / FBX を規約パスへ出した / **EdoAssets.cs に登録した** / remap メニュー名を返した
4. Unity で **マテリアルを remap する**(やらないと真っ白)
5. 据えたら `/fushin-qa` を通す

**注意**: Blender は CLI スクリプト方式が正典。GUI で手を入れない(再現性と git 差分のため)。
