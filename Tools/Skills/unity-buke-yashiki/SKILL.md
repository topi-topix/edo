# 江戸武家屋敷の敷地内を作る

**この SKILL.md は原則と索引だけ。** 詳細は `references/` に分けてあるので、
作業に必要なものだけ読み込む(全部読む必要はない)。

まず **§B の設計三原則**を読む。過去の手戻りはすべて §B の違反から起きている。

---

## §A. 絶対規則

- **A-1 手組み canon に触らない** — `Ishigaki` / `Nagaya` / `Omotemon` グループはユーザーの手組み
  ([[ishigaki-canon-is-user-handbuilt]], [[never-regenerate-hand-edited-objects]])。作業は
  `Buildings` / `KachuNagaya` / `Garden` グループで行う。撤去は**削除でなく `SetActive(false)`**
  (判断が覆っても即戻せるように)。
- **A-2 破壊的作業の前に**: シーン保存 → `git add -A && git commit` → 地形は heightmap を
  scratchpad へ `.bin` バックアップ。ユーザーに言われなくてもやる。
- **A-3 復元物には典拠ラベルを付ける** — 一般類型で埋めた物を、後から一次史料のように扱わない。
  コミットに `【典拠: 一般類型/当屋敷の一次史料は未確認】` のように明示する。
  「作り直して」と言われた物こそ、まず**存在の典拠**を確認する(作り直しの依頼は形状への不満であって
  存在の追認ではない)。一次史料が非公開・未入手ならその到達点も記録する。
  典拠を問われたら**推論の鎖を分解して一番弱い環を名指しする**。確度の区分は `references/sources.md`。
- **A-4 建蔽率は「敷地全体ベース」のみで報告する**(ユーザー指示)。
  「可建平坦地ベース」「台地帯ベース」等の分母操作は禁止。低いなら分母をいじらず §B-1 の整地で
  可建地を作る。
- **A-5 目安を自分の成果物から作らない**。過去に「上屋敷=建蔽率20-30%」と書いたが、これは自分が
  前の屋敷で出した23.5%を基準にした自己参照で出典が無かった。
  数値は必ず `references/estate-types.md` の実測プラン・発掘値から引く。
- **A-6 地形の出自を疑う**。「なめらかだから自然地形」は循環論法
  (補間で復元した領域は、なめらかに見えるように作られている)。`references/site-grading.md`。

## §B. 設計の原則 — これが本体

### B-1 **まず地形を測る。面の高さは自然の平場から採る。切盛は最小にする** ★★

⚠ **2026-08-23 にユーザー指示で全面改定した。**
旧版は「まず整地する。建物を地形に合わせない」だったが、**これは撤回**。
その考えで土井邸は玄関棟を平均1.65mの盛土に載せ、自然の窪みを埋めて平らにし、二度差し戻された。

ユーザーの言葉:「**現在の地形をベースにまずは考えるべき**です」
「**窪みのところも切土、盛り土で形を変えるのではなく、その窪みを活かした配置**にしてください」
「**切土盛り土はできる限り減らす**こと」。

**順序**:

1. **地形を測る**(回転間グリッドで 0.5〜1間刻み。実測=確度P)
2. **矩形を総当たり走査して「起伏の小さい位置」を探す。** 面の高さはその矩形の
   `(max+min)/2` を丸めた値 — **探索が面の高さを教える。設計者が先に決めない**
3. **見つかったベンチに棟を割り当てる。** 棟が入らないベンチは面にしない。
   **段の数はベンチの数で決まる**(「4面にしよう」と先に決めない)
4. 合格の目安は **棟が載る所で |設計面 − 自然地形| ≤ 0.5m**

**窪み・鞍部・肩は埋めたり削ったりせず、そのまま使う。**
窪みは一段低い郭にして棟どうしを**階段廊下**でつなぐ。幅の足りない帯は**雁行の細長い翼**として組む。
肩の高まりは**築山**に使う。

造成そのものは史実にある([菊地2003] 江戸発掘67遺跡「土地改変は高さ1〜4m程のものが多い」/
[富山市埋文] の段切り)ので**してよいが、最小にする** — 1〜4mは*上限の目安*であって目標ではない。
**現代地形に従うのは街路・坂・水系・崖線などマクロ地形**([[terrain-follows-present-day]])。

⚠ **平場は「建物が載る大きな面」。斜面に細い段(雛壇リボン)を刻むことではない。**
細い段を何段も刻んで長屋を並べるのは §B-3 違反(実際にやって差し戻された)。
**平場にできない急斜面は庭・法面**であって、建物で埋める場所ではない。

**切土・盛土は必ず図にする**(§B-6)。文章の「1〜4mに収まる」だけでは、どこを動かすのか伝わらない。

→ 手順は `references/site-grading.md`、図の作り方は `references/sashizu.md` §3a/§3b

### B-6 指図には**現況図・切盛図・動線図**を必ず入れる ★★

ユーザー指示(2026-08-23、松江松平と土井で二度の是正):
「**自然地形を指図に載せること**」「**切土盛り土を図に反映すること**」「**動線図を足すこと**」。

| 図 | 何を示すか | 詳細 |
|---|---|---|
| **現況図** | 造成前の地形。段彩2m+等高線(10m太線)。隣の屋敷の区画も重ねる | `sashizu.md` §3a |
| **切盛図** | 造成後との差。暖色=盛土/寒色=切土/無彩=±0.3m/地の色=造成しない+段ごと土量表 | §3b |
| **断面** | 東西・南北の格子で通す。造成前を破線で重ね同じ配色で塗る。無造成の区間を明示 | §3c |
| **動線図** | 表向/役方/勝手/奥向。延長・昇り・越える石段の段数 | §3d |

**この4つが無い指図はユーザーに出さない。** `edo-kenzu` が完備検査で落とす。

⛔ **4つとも地盤の上に立つ図なので、地形は「造成を含まない参照面の正本」から採る。**
Unity の live terrain を `SampleHeight` で吐くと、**他家の造成を「自然地形」として取り込む**
(2026-08-24 に4屋敷で発生。土井の DEM は隣家の区画の68%が隣家の設計面の値になっていた)。
→ `sashizu.md` §3a「地形は正本から採る」。edo-unity の正本は `docs/Sashizu/base_dem.json`。

### B-2 レイアウトは「連続御殿複合 ＋ 外周長屋帯 ＋ 開放地は白洲と中庭だけ」

⚠ **この型を地形より優先しない。** 棟の割り付けは §B-1 で見つけたベンチの上で組む。
ベンチが細ければ雁行の細長い翼に、段が分かれれば階段廊下でつなぐ。

ユーザーの言葉:「**基本的には建屋がつながっており、大きい屋敷があり、周りに長屋がある**」。
[福井図](越前福井藩上屋敷)がその正典:

1. **御殿は一つの連続複合** — 玄関・大広間・黒書院・大台所・料理間・居間・御成風呂・舞台が別棟でなく、
   **廊下と中庭を抱いた一続きの輪郭**として敷地中央〜東半を埋める
2. **長屋は外周に連続した帯** — 西・南・東の三辺。隅に矢倉
3. **開放地は玄関前の白洲と中庭だけ** — 敷地の中に独立した建物がぽつんと置かれた箇所は**一つもない**

→ 型は `references/estate-types.md`、組み方は `references/buildings.md`

### B-3 建蔽率は目標値でなく「正しいレイアウトの結果」

**やってはいけないこと(繰り返し差し戻された実例)**:
- ❌ 空いている土地に長屋をぽんぽん建てて数字を上げる
- ❌ 敷地中央に浮いた長屋列を作る(境界から10〜34m内側に5組作って全廃した)
- ❌ 斜面に細い段を刻んで長屋リボンで埋める(34棟建てて差し戻された)
- ❌ 分母を可建地に替えて低い数字を正当化する
- ❌ 石高密度(坪/石)で「この藩は余裕があるから疎でよい」と正当化する
- ❌ **「まず整地する。建物を地形に合わせない」**(旧 B-1・2026-08-23 撤回)。
  面の高さを先に決めて地形をそれに合わせると、自然の窪みを埋め、平場の上にさらに盛る。
  土井邸で玄関棟を平均1.65mの盛土に載せ二度差し戻された。**いまは §B-1 のとおり地形が先。**

**正しい進め方**: §B-1 で平場を作る → §B-2 のレイアウトで組む → 出た数字を敷地全体ベースで報告する。
足りないと感じたら棟を足すのではなく、「**御殿複合が平場を使い切っているか**」
「**外周長屋が全周に回っているか**」を見直す。

### B-5 寸法を動かす変更は、直しでも「図が先」

**指図は新築のためだけの手続きではない。既にある屋敷の寸法を動かすときも、
先に図(平面＋断面/展開)を起こしてレビューを受ける。**

指図に**文章を追記するだけ**で Unity に入るのは違反。文章は寸法の整合を検査できないので、
取り合いのズレが図に出ず、実装してから初めて見つかる。

**実例(2026-08-15, 岡部邸)**: 郭をまたぐ動線を、図を描かずに直し続けて**5回作り直した** —
参道の屋根を撤去 → 石段の折返しを廃止 → 土留めの形を作り直し → 登廊の床を石段から木の階段廊下へ
→ 取り付きが階段の側面に付き当たっていたのを直す。
ユーザー指摘:「先に綺麗につなげるように指図を作り直したほうがよい気がします。指図更新してますか?」。
図を先に描いた回(其五)は**一発で通った**。

**⛔ 例外を作らない(ユーザー指示 2026-08-15)**:「すべて指図でしっかりと設計してから取り掛かる」。
「小さい直しだから」「一箇所だけだから」で図を飛ばさない。**飛ばした回はすべて作り直しになっている。**

**How to apply**:
- 「寸法を動かす」= 位置・高さ・幅・段数・部材寸法のどれかが変わる変更。見た目の微調整は除く
- **部材どうしが干渉している/隙間が空いている、という指摘も寸法の問題**。
  現物を実測して図に落とし、断面で当たりを取ってから直す(目分量で寄せると別の所が当たる)
- 図には**現状と提案を並べて**描く(撤回する形を消さずに残す)。何を捨てたかが後から追える
- 図の数値はそのまま実装の定数にする。図と実装で別々に数字を持たない
- 図で決めた不変条件は**機械検査**に落とす(廊下の連結検査・外周の天端検査)。
  目視でなく数字で押さえる。検査が無い不変条件は必ず壊れる

### B-4 撤回済みの誤った基準(再発防止)

| 誤り | なぜ誤りか |
|---|---|
| 上屋敷=建蔽率20-30% | 自分の成果物基準の自己参照。史料値は `estate-types.md` |
| 石高密度で建蔽率を割り引く | 石高=国元の生産力、敷地=幕府拝領(逓減的)。比に意味がない |
| 可建平坦地ベースで報告 | 分母操作。§A-4 |
| 造成ゼロ・地形追従が既定 | 敷地内には当てはまらない。§B-1 |
| 密度の本命は敷地内の家臣長屋列 | §B-2/§B-3 違反。長屋は外周に回すもの |
| 斜面は雛壇に刻んで長屋で埋める | §B-1/§B-3 違反。斜面は整地して平場にするか、庭にする |
| Village Kit のプレハブで御殿を作る | 壁で閉じた一軒家なので入側から壁が見える。御殿は廊下に面して障子・襖が並ぶ。`buildings.md` |
| 直しなら指図は文章の追記でよい | 文章は寸法の整合を検査できない。§B-5 |
| 外周は地形追従で置けばよい | 一本の run で天端が10m以上振れて棟が段々になる。`perimeter.md` |
| 長屋のピッチは 7.81m(屋根幅から) | **壁・海鼠・土台は 8.065m。屋根で測ると全継ぎ目が 0.252m 重なる**。なまこ紋の二重・瓦のずれ・窓の不揃いはこれ一つが原因。ピッチは決め打ちせず実行時に壁を測る。`perimeter.md` |
| 段の縁は一律の幅で摺り付ける | 段差の小さい縁では要らぬ土をいじり、大きい縁では崖が残る。**勾配で決め、「縁が盛土/cap以内/着地する」の三条件で打ち切る**。落とすと崖に9mの土手が生える。`sashizu.md` §3b |
| 長屋・塀は石垣の法肩と面一に据える | **犬走り 0.30m(≒1尺)を残す**。縁ぎりぎりは雨落ちが目地を洗い笠石が欠ける。造成も石垣の前に土を残す。`perimeter.md`「囲いは石垣の天端に犬走りを残して据える」[犬走り] |

石高が正当に効くのは **石高→軍役→江戸詰人数→必要長屋床面積の下限** まで。
「敷地をどれだけ空けてよいか」の根拠にはならない(拝領地は使うために与えられている)。

## このスキルの育て方

新しい知見は **`qa-and-pitfalls.md` の失敗事例集** か、該当する実装章に追記する。
