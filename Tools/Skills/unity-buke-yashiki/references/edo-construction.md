# 江戸の設計法・普請 — 寸法がどう決まるか

指図を起こす前に読む。**寸法は「決める」ものではなく「基準から比例で決まる」**のが近世の作法で、
これを知らないと図面の数字が現代の設計の癖(切りのよいメートル)になる。

## §1. 木割(きわり) — 部材の比例で建物が決まる

- 木造建築で、各部材の**比例**によって建物の寸法を表す方法。**柱の太さを基準**にすると、
  他の部材の寸法と間隔がどんな比率になるかが決まる。[木割]
- **『匠明』(1608, 平内政信)** = 日本最古の体系的・網羅的な木割書、全5巻。原本は東京大学蔵。
  多くの木割書が**垂木**を基準にするのに対し、匠明は**柱**を基準にするのが特徴。[匠明]
- 平内政信は紀州の大工。匠明は平内家の秘伝書となり、**江戸幕府の大棟梁**の家系につながる。
  平内家の木割書群は「四天王寺流系本」と総称。[匠明]

→ **含意**: 御殿の各部が比例で揃うので、棟が違っても軒高・柱間・屋根勾配が揃って見える。
   Unity で寸法の違うアセットを混ぜると、この「揃い」が壊れて村に見える。

## §2. 柱割と畳割 — 江戸間は柱割

| | 何を先に決めるか | 基準 |
|---|---|---|
| **畳割(京間)** | **畳**の寸法を先に決め、それに合わせて柱を置く | 柱の**内法** |
| **柱割(江戸間)** | **柱と柱の間隔**を先に決め、そこに畳を合わせる | 柱の**心々** |

- 江戸(関東)は**柱割**。**1間 = 6尺 = 1.818m は柱の心々間隔**。[江戸間]
- 帰結: 柱割では部屋の内法が柱の太さの分だけ小さくなり、**畳の実寸は部屋ごとに少しずつ変わる**。
  指図に書く畳数は「柱間の数×2」であって、畳の実寸から出した値ではない。

→ **含意**: 指図のグリッドは**柱心**で取る。**身舎の寸法は1間=1.818mの倍数**にする。
   22m や 36m のような切りのよいメートル値は近世の平面には出てこない
   (2026-08-14 の岡部の指図はこれを外していた)。

## §3. 地業(じぎょう) — 建物の足元

- **礎石基礎**: 大石(礎石)を地中に埋め、その上に柱を立てる。掘立柱より耐久性と通風がよい。
- **割栗石**: 戦国期以降、城郭・門・建物・社寺に使われ、明治〜昭和初期まで道路・塀・基礎に広く用いられた。
- **黒鍬(くろくわ)組**: 土工の専業集団。土を動かす技に長け、印旛沼の干拓などの土木に従事した。

→ **含意**: 建物は地面に直に載らず**礎石の上**にある。Unity では躯体底を地面より少し上げる
   (現行の sink 0.10〜0.12m はこの表現でもある)。

## §4. 土木 — 江戸そのものが普請でできている

- **天下普請**: 幕府が諸大名に課した公共土木。江戸城・堀・埋立が対象。
- 屋敷単位の造成も同じ文脈([site-grading.md] 菊地2003)。切土・盛土1〜4mが多く、
  紀伊家紀尾井町の盛土5.0m、長府毛利の切土10.0mが実測の上限側。
