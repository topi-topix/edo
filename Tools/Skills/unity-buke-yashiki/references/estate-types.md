## 上屋敷 — 越前福井藩上屋敷 (約6,600坪) [福井図]

**これが §B-2 のレイアウト原則の正典。** 迷ったらこの図の構成に戻る。

**規模**: 約130m / 約77m / 約113m / 約105m の不整形多角形。
図の注記「江戸城から近かったため規模は小さめ」= **城至近の上屋敷は30万石級でも1万坪未満がありうる**。

**外周 = 全周長屋 + 隅矢倉**。長屋には**江戸勤番の藩士が居住し「いざというとき藩主の盾になる」**。
表門のある辺も長屋(→ 「表門辺は築地塀」は絶対則ではない。`historical-layout.md` 参照)。

**門は1つの街路辺に格の3段構え+裏小門**:
- **御成門** = 将軍専用の出入り口。「江戸初期には将軍の御成が少なくなかった」。表門より上手に別置。
  御成対応をする家門・大藩の上屋敷のみが持つ。
  ⚠ **御成セット(御成門・能舞台・御成風呂)は御成最盛期(秀忠〜家光)に固有の装置。**
  [福井図]は寛永〜明暦期・龍ノ口屋敷の姿([福井図の年代])で、**幕末期の屋敷へ既定で持ち込まない**。
  御成を受けた加賀本郷邸ですら幕末の門構成に御成門は無い([加賀本郷邸の御成])。
  幕末の屋敷に置くなら当家への御成記録を確認してから(2026-08-23 松江松平で撤去した経緯)。
- **台所門(=表門)** = 大名の出入り口。**表門が「台所門」を兼ねる**名称に注意(表門=儀礼専用とは限らない)。
- **小門×2**(同じ辺)+**小門**(下辺) = 藩士の出入り口。複数・隅寄りに分散。

**内部 = 一つの連続御殿複合が敷地の大半を占める**(散在パビリオンではない):
- **表**: 玄関(表門から直進)→**大広間**(藩士が大名に謁見する場)→**黒書院**(同僚の大名など特別な
  訪問客を接待)。右筆部屋・トイレが黒書院の並びに付く。
  **謁見(家中向け)と接待(対外向け)は別室**なのが要点。
- **御成ゾーン**(図の上端〜右上): **舞台+楽屋**(上辺いっぱいに横たわる)・**御成風呂**。
  御成門から表を経由せず達せられる側にまとまる。**御成対応 = 能+風呂+専用門の3点セット**。
- **服務**(中央): **大台所が敷地のほぼ中心**。料理間・小姓部屋が隣接。
- **奥**(右下): 居間。**藩主一家は屋敷の中心部に居住し、藩士は中心部に入ることができない**
  → 外周長屋(藩士)→中間→中心(藩主)の同心円防御。
- **土蔵×2**は下側の空地に御殿から離して置く。
- **庭園は描かれない比重**(下と右の空地のみ)。城至近の上屋敷は儀礼建築で敷地を使い切り、
  回遊庭園を持たないことがある — 広庭は中屋敷・下屋敷の役割という分担の傍証。

**Unityでの棟リスト**: 表(玄関+大広間+黒書院) / 御成(能舞台+楽屋+御成風呂) / 中央(大台所+料理間) /
奥(居間) / 土蔵2+ / 外周(全周長屋+隅矢倉+御成門+表門+小門2〜3)。

## 中屋敷 (約1万7,870坪) [中屋敷図]

図の注記による定義: **中屋敷=世継ぎや隠居した大名の住まい。上屋敷の代わりに使われることもあった。**

- **外周**: 上屋敷と同じく**藩士が住む長屋が御殿を囲む構造**(図の注記ママ)。左辺・右辺(2区間)・
  上辺に長屋列。**隅矢倉のラベルは無い** → 矢倉は上屋敷格の装置と考えてよい。
- **門は2つ**: **表門**(下辺中央)+**裏門**(上辺の左隅)の前後貫通型。御成門・小門群は無い。
- **中軸線が明快**: 表門→**玄関**(直進)→**表御殿**(政務空間・藩士が勤務)→**奥向御殿**(藩主一家の
  生活空間・**上屋敷の御殿と機能は同じ**)が図の下→上へ一直線に連続。表御殿と奥向御殿は**別棟だが
  近接**し、間を小棟群が埋める。
- **厩・馬場は裏門側**(図の上端): 上辺の長屋の内側に 厩→馬場 が長屋と平行に並ぶ。
  ⚠ [西川1959]系の「厩は表門まわりの長屋列と同じ帯」(長州藩麻布屋敷)とは**逆の実例** —
  厩・馬場は表門側/裏門側どちらの類型もある。裏門側なら「馬の搬出入は裏から」の動線。
- **密度**: 御殿群は敷地中央に南北に長く固まり、周囲(特に左辺沿い・下辺の両脇)は広い空地。
  上屋敷より明確に疎。1.8万坪級は「中央の御殿クラスタ+外周長屋+広い余白」。

**Unityでの適用**: 上屋敷の棟リストから 御成ゾーン(能舞台・御成風呂・御成門)と隅矢倉を落とし、
表御殿+奥向御殿の2核+玄関を中軸に並べる。裏門(kabukimon〜h_mon級)を表門の対角辺に開け、
厩+馬場をその内側に付ける。長屋は全周でよい。

## 下屋敷 — 尾張藩戸山屋敷 (13万坪, 1751〜1764) [戸山図]

**下屋敷=御殿は端に小さく、敷地のほぼ全部が大名庭園**という類型の極端かつ正典的な実例。
図の注記: 13万坪(東京ドーム8個分以上)、**神社・堂塔38、茶亭107ヶ所**。

- **表御門と表御殿は同じ隅に寄せる**。御殿は敷地の1割未満で、門から即・御殿、残り全部が回遊庭園。
- **水系が骨格**: 上の御泉水(上池)→流れ→**御泉水**(中央の大池)の2池構成。大池の縁に**龍門の滝** —
  名物仕掛け: **水を堰き止めている間は渓流の飛び石を渡れて、堰の板を外すと飛び石が水中に没する**
  (可動堰による演出。プロジェクトの どんどん堰 [[edo-waterfall-dondon]] と同系の土木を庭園演出に転用した例)。
- **麻呂ヵ嶽**: 渦巻き等高線で描かれる大築山。**頂上に床机・毛氈を設え、将軍来訪時に江戸の眺望を
  楽しんだ** → 築山=眺望装置(ビューポイント)として設計する。
- **御町屋通り**: 庭園内に**宿場町の再現街路**(小田原宿を模したことで知られる)。町屋列が街道状に並ぶ
  ブロックが上池の脇にある。大名庭園には「町の景」をまるごと作る発想がある —
  プロジェクトの machiya 資産([[tameike-daichi-machiya]])を庭園内に転用できる正当な根拠。
- **宗教点景**: 地蔵堂・文珠堂・奥ノ院など堂塔38。庭の丘や池畔に小祠・堂を散らすのは
  下屋敷では「多いほど正しい」。
- **御庭舞台**: 能舞台が御殿でなく**庭の中**に独立して建つ。
- **田園の景**: **畑(2ヶ所以上)・芝野**が庭園の正式な構成要素。**全面を林と池で埋めない。**
  馬場は下辺の隅。

**Unityでの優先順位**: 水系(池2段+滝)→築山(眺望)→回遊路→茶亭・堂塔の点在→畑・芝野の帯→
御殿(隅に小さく)→外周(長屋は最小限)。茶亭は Small House ×0.72 をコースの見せ場ごとに。
築山は中島レシピの拡大形(cos-falloffの多重盛り)で、頂上に床机級の平場を切る。

## 上屋敷の庭 — 既定は「ある」 ★(2026-08-24 是正)

[福井図] に回遊庭園が描かれないのは **6,600坪という狭さの帰結**であって、上屋敷一般の性質ではない
(しかも [福井図の年代]B のとおり寛永〜明暦期・龍ノ口の**別敷地**)。**n=1 を類型に昇格させない。**

上屋敷が庭を持つ実例は A 級で複数ある:

- **[汐留遺跡庭園]A** — 仙台藩伊達家**上屋敷**の**表向**に石組護岸の池・中島・岩島・橋、
  玉川上水を滝から引き込んだ流れと沢渡(1991-2001 発掘)
- **[小石川後楽園]A** — 水戸徳川家の江戸屋敷の庭(創建時は中屋敷、**のち上屋敷**)。特別史跡・特別名勝
- **[内藤2024]A** 表2-1/3-1 — 江戸の大名庭園の集成に**上屋敷が多数**。毛利(桜田上屋敷・差図に池泉3)/
  井伊掃部頭(享和元年改**上屋敷**絵図)/ 丹羽左京大夫(永田町)/ **松平出羽守(永田町)**

**したがって上屋敷の庭は既定で「ある」とし、無いと書くときにこそ理由を要求する。**

⚠ 逆向きの歯止めは残す — **下屋敷の大庭園の語彙(大池・滝・宿場町・堂塔・畑・田園の景)を
上屋敷へ持ち込まない**([大名庭園研究]B)。**とくに「畑」は [戸山図]=下屋敷13万坪の景**であり、
**上屋敷の平面に菜園を名指しした史料は 2026-08-24 現在で未発見**(松江松平の考証3巡目で確認)。

## 大名庭園4例の設計語彙

### 浜御庭【将軍の庭】6万3,560坪 [浜御庭図] — 海辺庭園・舟運の類型
- **潮入りの池**: **海水を引いていたため淡水魚に加え海水魚も生息**。多腕の入り組んだ汽水池で、
  海側の**水門**で海とつながる。→ 海・堀に面した庭園の池は「水門で外水域と接続」が正しい作法
  (溜池・外堀沿いの庭園池に水門+導水路を付ける根拠)。
- **舟運セット**: **御上り場**(水路から入る際の入り口=舟着き)+**御船蔵**+**船手組屋敷**
  (将軍の御座船を管理)が水際の一角にまとまる。→ 水辺の御庭・下屋敷は「舟で入る」動線を
  第一級の正面として作ってよい(門と同格)。
- **陸側の管理ゾーン**: 陸の門(中御門・浜大手御門)まわりに**浜奉行役宅・大番所**。
  庭園専用地でも門脇に役宅+番所の管理クラスタが付く。
- **中島茶屋**: 大池の中島に茶屋を置き橋2本で渡す。
- 文脈: **簡単に城外へ出られない将軍にとって浜御庭訪問は数少ない楽しみの一つ**(御成先としての庭園)。

### 後楽園【水戸藩】[後楽園図] — 「見立て」と儒教プログラムの類型
- **見立て(名所の縮景)が骨格**: **清水観音堂・渡月橋**(京都に見立てた建築物)、
  **西湖の堤**(中国杭州・西湖の堤の縮景=**池の入江を一直線に横断する堤道**)。
  → 堤道(直線の土手道が水面を横切る)・崖上の堂が正当な語彙になる。
- **儒教プログラム**: **円月橋**(中国の儒学者・朱舜水の指導により造成=円形の反り石橋)、
  **得仁堂**(園内最古の建築物。儒教の聖者である伯夷・叔斉の像を祀る)。堂は仏堂だけでなく儒教廟もある。
- **蓬莱島**: 大池の中央に大きな島。**赤門**・**涵徳亭**(茶亭)も点景。
- **内庭**: 主庭園とは別に、隅に**独自の池を持つ囲われた内庭**(御殿に付属する私的な庭)。
  「大庭園+御殿脇の内庭」の二重構造は [西川1959]系「表向・奥向それぞれに庭園池」と同じ思想。
- 機能: **毎年正月に藩主主催で梅の花見。藩主自ら家臣に酌をするなど藩内交流の場** →
  庭園=宴会・儀礼インフラ。梅林ゾーンが要る。
- 外周は**築地塀**(長屋ではない)。

### 六義園【大和郡山藩】[六義園図] — 下屋敷内庭園・池中心の回遊
- **駒込下屋敷内に築かれた庭園。5代綱吉もしばしば訪れた**(将軍御成の対象=大名庭園の格の証明)。
- 中央大池+島、周囲を**築山群**(図の濃い塗り=盛土の丘)が幾重にも囲み、その谷間を回遊路が縫う。
  平地の庭でも「築山の連なりで囲む」ことで山景を作る(戸山の麻呂ヵ嶽の分散形)。
- **茶屋は視対象で命名して置く**: **吹上茶屋**(吹上浜=池の浜洲を見る)・**滝見の茶屋**(滝の前)・
  **心泉亭・宜春亭**。→ 「見せ場の正面に、見せ場の名を付けて」置く。
- 入口は隅に1つ。庭園単体の門は簡素でよい。

### 4例から抽出した設計語彙
水門+外水接続 / 舟着き(御上り場)+船蔵 / 堤道(西湖の堤型) / 円月橋級の石橋 /
儒教廟・観音堂などの堂塔 / 蓬莱島(大島) / 内庭(御殿脇の囲い庭) / 築山群で谷をつくる /
浜洲(吹上浜型) / 滝+滝見茶屋の対 / 梅林(宴会の場) / 宿場町の景 / 畑・芝野。
**茶屋・堂は「何を見るための建物か」を決めてから向きと位置を置く。**

## 旗本・御家人3例

共通の前提(図の注記): **屋敷は幕府から下賜されたもので所有権はない。幕府の命で転居を命じられる場合も。**

### 吉良上野介邸(上級旗本・高家, 2,559坪) [吉良図] — 警護長屋の類型
- **外周に長屋30軒**。動機が図に明記: **赤穂浪士に狙われていた吉良は、襲撃に備えて屋敷の周囲に
  長屋を築き、大勢の警護の士を住まわせた** → **長屋の疎密は「格」だけでなく「警備要求」の
  パラメータでもある**。
- 門は**表門+門番所**(前辺)と**裏門**(後辺)の前後貫通型(中屋敷と同じ)。
- 主屋は**前後に細長い一連の複合体**が敷地中央を貫き、玄関→広間→書院(前寄り)、料理ノ間・台所(中程)、
  湯殿2ヶ所(中・奥)。**「庭」は棟と棟の間のポケット中庭として点在**(凡例で庭=点描)。
  → 2,500坪級の主屋は1棟でなく「雁行連結+坪庭」で表現する。
- **土蔵は4棟に分散**(左辺沿い2・前辺近く1・ほか)。

### 武井善八郎邸(中級旗本, 412坪・建坪210坪) [武井図] — 建家図の実名版
- **建ぺい率51%**(210/412)。[鈴木1985]の「22〜55%」の上限寄り。中級旗本はかなり密に建て込む。
- **前辺: 門+長屋(家臣が居住・10人ほど)+土間**。門の内側に**板塀2条**で前庭を仕切る —
  長屋門格でなく「門+前面長屋+内側の板塀スクリーン」という構成も実例がある。
- **接客動線が部屋名で読める**: 式台→玄関→**使者の間**(訪問客が控える)→**書院**
  (主人が会うときは書院に通された)+次の間。表の座敷は書院+使者の間のペアで作る。
- 主屋はU字型で**裏庭を抱き**、裏庭に**土蔵+井戸**。私的ゾーン(居間・寝間・納戸・湯殿2・トイレ)は両翼の奥。
- **井戸は前庭(上の間脇)と裏庭の2ヶ所** — 接客用と勝手用を分ける。
- トイレは外周塀際にも複数(外向きの用足し=家臣・来客用)。

### 山本政恒邸(御家人・御徒=将軍の警護役, 敷地200坪・建坪約30坪) [山本図] — 組屋敷と貸家
- **御家人は組単位で屋敷を与えられた**: 御徒は一組30人・全20組、下谷・本所・深川で**組単位に
  数千坪を拝領**し、個人に均すと200坪前後(=御徒町の地名の由来圏)。区画割りは組地の内部分割として作る。
- **街路沿いに「貸家」**(仲御徒町通り沿い、門の脇の長い棟)。図の注記:
  **屋敷地の一部を貸して生活の足しにするのは御家人に限らず普通の経済行為** →
  下級武家地の街路沿いには貸家(町屋状の棟)が正当に建つ。edogoyomi の町屋資産を武家地の表に
  使ってよい史実根拠([[tameike-daichi-machiya]])。
- 母屋は**建坪30坪・田の字プラン**(8畳+8畳(床・押入)+6畳+6畳+台所(水口)+物置+トイレ、玄関付き)。
  Village Kit なら House/Small House 1棟が正尺。
- それでも**庭は池+築山+花壇**を持つ(池は瓢箪形、背後に築山、脇に花壇)。
  200坪の御家人屋敷にも小池庭が成立する。

### 上屋敷が備える役割 — **最小の一覧**(各邸の指図はこれを満たすか、満たさない理由を書く)

各邸の `program`(在るべき役割)は**この表を外の錨として持つ**。⚠ 錨が無いと、
役割と棟を**同時に消せば検査が通る**(2026-08-25 土井邸・検図14巡 中-6:
表役所/米蔵/土蔵/稲荷が同時削除で無音だった)。生成器はこの表を機械で読む —
**行の書式(`| 役割 | 要否 | 典拠 |`)を崩さないこと。**

**別の区画に属す役割**: 表役所 / 玄関・式台 / 居間・中奥 / 奥向 / 台所・勝手 / 厩

上の役割は互いに**別の場**なので、雪隠・湯殿はそれぞれに要る(区画をまたいで用を足しに行く図は
成り立たない)。各邸の検査はこの行を機械で読み、`program.by`(役割→棟)と自邸の区画分けを
突き合わせること。⚠ **書院と局は入れない** — 書院は玄関と同じ表向、局は奥向と同じ区画に属してよい。
**人の別ではなく場の別**を分ける集合にしないと、正しい構成まで落ちる(2026-08-26 松平)。
⛔ **行の書式(`**別の区画に属す役割**: A / B / …`)を崩さないこと。**

⚠ **「必須」は類型としての必須**(確度B〜A)であって、その邸に在ったことの典拠ではない。
各邸は役割ごとに**存在・位置・規模の確度を分けて**持つこと。
⛔ 「任意」を落とすときも**落とした理由を書く** — 沈黙は「落とした」のか「捨てた」のかを区別しない。

### 建蔽率の史料値 — 数値は必ずここから引く

**大名上屋敷の建蔽率の史料値は [福井図] の一点しかない。** これと旗本の実測だけが建蔽率:

| 値 | 対象 | 典拠 |
|---|---|---|
| **5〜6割** | 福井藩上屋敷(御殿+長屋) | [福井図] 目測 |
| **51%** | 武井邸(中級旗本 412坪/建坪210坪) | [武井図] |
| **22〜55%** | 旗本建家図8例(建坪の約80%が主屋) | [鈴木1985] |

⚠ **[追川2017] の 47.7% / 28.6% / 15% は建蔽率ではない** — 原典は**表長屋の規模比**
(表長屋が外周・表構えに占める割合)。建蔽率の表に混ぜて引用したのは読み違え
(2026-08-22 松江松平邸の検図で発覚・是正)。表長屋の比較にだけ使う:

| 表長屋の規模比 | 対象 | 典拠 |
|---|---|---|
| 47.7% | 尾張市谷邸 | [追川2017] |
| 28.6% | 小浜邸 | [追川2017] |
| 15% | 加賀本郷邸(88,482坪) | [追川2017] |

→ **中小藩ほど外周を長屋で使い切る**。表長屋は収容力より景観装置。
⚠ **3例は必ず揃えて引く** — 下端の加賀本郷15%を落として「28.6〜47.7%の帯」と書くと帯が
狭く見え、自図の適合が良く見える(2026-08-23 松江松平の考証で発生・是正)。
⚠ **自分が過去に建てた屋敷の数値を基準にしない**(SKILL.md §A-5)。
