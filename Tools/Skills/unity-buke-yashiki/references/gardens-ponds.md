## 庭の構成レシピ

- **前庭(門→玄関)**: tobiishi の参道を緩いベジェで、躑躅は門一式ゾーンの外、松1-2本ずつ、灯籠1基。
  **前庭は主に開けておく**(白洲/馬場感)。門から御殿前まで15-20mが正解。
- **奥庭/回遊**: 松8-20本、岩組1-2群、曲がる飛石のループ、
  下草(boxwood/fern)を樹下に散らし、灯籠2-4基、井戸は台所脇。
  **樹木はランダム yaw + スケールジッタ。グリッドに置かない。**
  ⚠ **旧版の「桜を隅に群、竹を遠い隅」は撤回した(2026-08-23)。**
  桜=開花木はシーンの季節(春でない)に合わず、**竹叢は江戸の水辺79事例中1例の例外**
  ([橋本・堀1998])。樹種は下の「植栽」節の年代・類型で選ぶ。
- **庭は1つではない**([西川1959]): 表向・奥向それぞれに庭を持ってよい。書院/座敷の前面に必ず庭。
  庭の一隅に稲荷宮(旗本屋敷では北東角=鬼門)。
- **生活感の合成物**: 薪棚(4柱+8本の丸太+傾けた屋根板)、俵(RiceBarrel_01 ×2-3 を蔵の扉脇)、
  竹立て+桶を台所に、馬柵(fence A x8 を y0.5 で2列)。
- **庭木は建物・長屋・通路から必ず退避させる**(竹叢が屋根を貫く)。中心点判定では canopy の重なりを
  拾えないので、路地は「境界からの符号付き距離のバンド」でまとめて空ける。
- **池を掘る前に置いた小物は埋没/水没する** — 掘削後に必ず再据えする
  (地面をサンプルし、`ground < waterY+0.15` なら池心から離れる方向へ `≥ waterY+0.18` まで進める)。

## 地表の仕上げ

- **ground zones**: 区画ポリゴン内だけスプラットを塗る — 白洲(bare 0.8)、庭(grass 0.42-0.72 + Perlin)、
  馬場・蔵前(dirt 0.5-0.6)。境界は距離ランプ(−3..+2m)× GLSL-smoothstep したノイズ。
  三屋敷全体で約1245テクセル @4m/texel。
- **水際の草**: NatureManufacture Meadow の草プレハブは URP ネイティブ。**交差させた2本1組**
  (同じ場所に回転違いを2つ)で、地面が `waterY−0.35 〜 +0.8` の帯に置く。
- **外周の閉塞チェック**: ポリゴンの各辺を4m刻みでサンプルし「1.5m以内に地面+1mより高い壁があるか」を
  判定する。三屋敷ではこれで1箇所だけ穴が見つかった(es_dobei で埋めた。**両面マテリアル必須** —
  [[edogoyomi-mon-dobei-conventions]])。

## 池を掘る — WaterBaker(手掘り禁止)

`WaterBaker.Create(outlineWorldPts, depth)`(`Assets/Edo/Editor/WaterBaker.cs`)
→ `Water` 配下に WaterBody 生成 + Edo/Water マテリアル資産 + 地形スナップ + 掘削 +
`waterY = median(shore) − 0.3` を設定。
既定(`verticalWalls=false`, `raiseBanks=true`)で庭池は正しい。**深さ2.0**。

- 形は**瓢箪**(2つの葉+約9mのくびれ)= 自然に見え、橋を架ける場所もできる。
  輪郭15点で十分(Chaikin 平滑化×2 がかかる)。
- **安全**: TerrainData の scratchpad コピー + clean git を Create 前に。
  ロールバックは `WaterBaker.RestoreTerrain(wb)`(snap は後の Recarve で上書きされない)または git。
  **Create 直後の `RestoreAndDelete` は正確な取り消し**(snap=Create時点の現況なので巻き戻し無害)。
- **snap 矩形の重なり注意**: 余白150mなので庭池の矩形は溜池/外堀と必ず重なる。今掘る分には安全
  (snapshot=現況)だが、**将来どちらかを Recarve/Restore すると他方が潰れる**
  ([[waterbody-overlapping-snapshot-regions]] の内側セルのみ修復)。
- 掘削後は**水に落ちた物を全部再配置**: 植栽→岸、岩組→汀線に0.25沈める(護岸石の半水没が定番)、
  灯籠→岸、飛石→池を回るループに再敷設(くびれの橋を渡る)。
- 橋のデッキ ≈ `waterY+0.35`(縁テクセルは waterY より0.3ほど下がる)。
  **橋はくびれの実測水面幅に合わせる** — 設計ポリゴンの頂点間距離(16.1m)と掘削後に地面が水位へ達する
  実際の水面幅(24.3m)は全く違う。取付部を盛っても2mグリッドの補間で頭打ち(7.8mで停滞)になるので、
  最後は**橋を走り方向(ローカル長軸)にスケール**するのが早い(13.5→16.9m, ×1.25)。
- **検証は数値で、目視でなく**:
  - 中心の地面 = `waterY − depth` ✓
  - 各輪郭頂点から**正しい外向き法線**で2-8m進み、地面が `waterY+0.05` に達すること
    (0/15 floating = 合格)
  - ⚠ **法線を重心からの方向で代用しない**。非凸の池(くびれ・出島)で内側へ march して誤検出する
    (72点中4点が偽陽性)。正しくは**隣接2辺の法線平均**を取り、`PIP(p + n*0.8)` が真なら反転。

## 既存の池を作り直す

`RestoreTerrain` / `RestoreAndDelete` / `Recarve` は**スナップ矩形の全域**(輪郭bbox+余白150m)を
スナップショットで上書きする。鍋島池のそれは X[-142,194] Z[46,376] = 336×330m で三屋敷全域を含み、
中身は「池を掘った時点=その後の段丘造成より前」の地形。**呼べば造成が全部消える。**

安全な作り直し手順:
1. 旧池の盆地を**局所矩形だけ**で手動に埋め戻す(内側は周囲の段レベルへ、外周14→20mでフェザー)
2. `wb.snap` を**現在の地形から取り直す**(`td.GetHeights(sX,sZ,sW,sH)` をそのまま代入、`hasSnap=true`)
3. `wb.outline` / `waterY` / `depth` を新設計に差し替え(GameObject・メッシュ・マテリアルは再利用可)
4. `WaterBaker.Recarve(wb)` — この時点で「復元」は現況の書き戻し=無害になる

- **Recarve の平滑化(`verticalWalls=false` で4パス)はスナップ矩形の全域にかかる。**
  池と無関係の地形も鈍る(実測で最大0.18m、実害なしだったが**掘削後に必ず設計値と突き合わせる**)。
- **他水域が壊れていないかの検査を輪郭の重心でやらない**。溜池のような細長い水域は重心が陸に乗る
  (「★埋まった」と誤報した)。bbox をグリッド走査して**ポリゴン内部の点だけ**で水面下率を出す。

### ユーザーが WaterBody の輪郭だけ編集した池の「地形追い掘り」
1. 作業域の地形をバックアップ(bin)
2. 新輪郭で 内側=掘(`waterY−0.55−0.25d`、既に深い所は触らない)/
   外側 d<14 の旧池底(現況 `<waterY+0.2`)だけ岸として盛る(`waterY+0.45+0.30d`, cap)
3. 変更セルのみ 3x3 平滑×2
4. 内側は最後に必ず `≤ waterY−0.5` を再強制
5. 境界±1.3mの全セルを `≤ waterY−0.45` に切って「メッシュ内に地形が水面上に残る細片」を除去
6. `wb.snap` を現況から取り直す(**flatten順は `z*sW+x`**、WaterBaker.cs L78 と同順)

⚠ **作業 bbox は「輪郭が実際に変わった区間」に絞る。** 輪郭全体との距離判定だけで盛ると、
形が変わっていない側(堰・水路・隣接水域)の水面下セルを「旧池底」と誤認して埋める
(どんどん堰の水路133セルを+7.9m埋めた実例。バックアップとのセル差分検査で検出)。
**掘り/盛りの後は必ずバックアップと diff し、変わるはずのない領域の raised/lowered=0 を確認する。**

水面メッシュは WaterBody エディタが輪郭編集時に再生成している(メッシュbbox≒輪郭bboxで確認)。
汀線検証の合格閾値: 内側2m<`waterY−0.1`、外側 march 8m 以内に `≥waterY+0.05`。

## 護岸(発掘裏づけ)

裸の縁は水たまりに見える。Edo の池は必ず護岸を持つ。
発掘(尾張藩市谷邸・仙台藩芝口邸・戸山荘)で4形式が確認されている。**視線で使い分ける**:

- **石組護岸** = 主視点の**対岸**(御殿・奥向きから見た側=見せ場)。
  石は長軸 0.45–1.2m(役石 1.25–1.5 を4個に1個)、**1/3埋め**、天端は `waterY +0.1..+0.6` で
  **水平にしない**、出入り ±0.15m、間隔=幅×0.78(連続した壁に読ませる)。
  荒磯の立石(y-scale ×1.9、傾5–12°)を岬・出島の先端に。
- **州浜** = 視点に近い穏やかな入江。淡い砂利スプラット(bare 0.75)を水面下1.2mから内陸1.5mまで、
  **そこの岸の草は消す**(州浜は clean)、平石4–6個を半分埋める。縁は草へフェード。
  ⚠ **「池中心からの距離+標高帯」で塗ると平坦地全体が該当して池が巨大な裸地円盤に沈む。**
  **方位ビン毎に水際線半径 r(θ) を実測**し `d ≤ r(θ)+3.0` の帯だけ塗る。
- **乱杭** = 実用側の岸。杭列モジュール(16本/2m、r 3.4–5.2cm、傾±4°)を Blender で headless 生成
  (`blender --background --python`、FBX は `axis_forward=-Z axis_up=Y bake_space_transform`)
  → `mcp__unityMCP__import_model_file`。
  ⚠ **インポート後の幅が×54ズレた** — 必ずバウンズを測って設計寸法に補正する。
  `y = waterY−0.33`(頭が +0.2..0.4 出る)。検証: 各モジュールの地面が `waterY ± 0.45` 以内。
- **橋挟み石**(1.0–1.35m)を橋の4隅に。**中島**は石の輪(12個 × 0.38–0.72m、
  `r ≈ island_top_r + 0.3..0.8`)。**岩島**(大1+肩1、基部を水没棚に0.1沈める)で
  表向の「中島+岩島+橋」の3点セットが完成。**岬灯籠**=雪見灯籠を岬に。
- **石材は池全体で一系統に統一**(旧芝離宮の根府川石方式)。岩組・飛石と同じ JG_Rock セットを使う。
- **配置は平滑化した鑿線を歩く**(`WaterGeom.SmoothTagged(outline, sharp, 2)`)。
  各サンプルで**外向きに進んで最初に地面が waterY を超える点**=真の汀線に置く
  (掘削は縁の頂点を水面より0.5–0.8m下げるので、輪郭点そのものは汀線ではない)。
  ゾーンは局所(u,v)窓で切り、橋の取付部は空ける。

## 植栽 — 庭師の技術と年代 ★★

**樹種を年代で検める。**「日本庭園らしい木」で選ぶと、その時代に無い木が入る。

### 年代の関門
- ⛔ **ソメイヨシノを植えない。** 江戸末期に染井村の植木屋が売り出したとされる新しい品種で、
  「染井吉野」の命名は**明治33年(1900)**。**安政3年(1856)の大名庭園にあったとは言えない**
  【確度B — 品種史。当屋敷の記録は無い】。桜を置くなら**ヤマザクラ・シダレザクラ・里桜**。
  ただし本プロジェクトは**季節が春でないので開花木そのものを置かない**(CLAUDE.md 規則9)。
- ⛔ **孟宗竹の竹叢を庭に広げない。** 江戸に孟宗竹は在るが、在ったのは**吹上御苑と近郊農村の筍畑**
  【確度B】。水辺・崖の竹叢は 79事例中1例の例外([橋本・堀1998] 確度A)。
  **竹垣の材としての竹は別**(これは問題ない)。
- **外来種は導入年を確かめる。** 幕末以降に入った木(ヒマラヤスギ、セイヨウシャクナゲ等)は不可。

### 型(幕末の大名屋敷として穏当なもの)【確度B=類型】
| 層 | 樹種 | 使い所 |
|---|---|---|
| **主木** | **クロマツ**(池畔・海の見立て)/ アカマツ(築山・山の見立て) | 庭の骨格。**松が主**で動かない |
| 中木 | モミジ(イロハカエデ)・モッコク・モチノキ・カシ・シイ | 中景。常緑と落葉を混ぜる |
| 低木・刈込 | **サツキ・ツツジの大刈込**(江戸の大名庭園の定番)・ツゲ・マサキ | 汀と園路の縁を締める |
| 下草 | シダ・ヤブラン・コケ | 樹下。裸地を残さない |
| 花木(控えめに) | ウメ(奥庭の梅林)・ハギ・カエデの紅葉 | 季節の一点。**群植しない** |

- **常緑を骨格に、落葉を景に。** 全部落葉にすると冬に骨組みが消える
- **松の仕立て**: 池畔のクロマツは**幹を水へ傾ける**。門被り・根上りは主景の一本だけ
- **刈込は塊で使う**(点在させない)。大刈込は江戸の大名庭園の見せ場

## 石組・点景物の作法 ★

### 庭石(護岸石とは別に、景として立てる石)
- **主石・副石・添石**の三石が基本単位。**不等辺三角**に組み、**等間隔・一直線に置かない**
- **石は立てる。寝かせない。**『作庭記』の禁忌(石の面と背を取り違えない)
- **1/3 は埋める。**地面に置いただけの石は「転がっている」に見える
- **石材は庭全体で一系統。** 江戸の庭石は**伊豆石・根府川石・秩父青石・真鶴**が船で入った
  【確度B — 江戸の石材流通。当屋敷の記録は無い】。産地を混ぜない

### 点景物と年代
- **雪見灯籠** — 江戸期に成立した形式。池の岬・汀に据えるのは可【確度B】
- **春日灯籠・織部灯籠** — 社寺・茶庭の系。**主庭に春日型を乱立させない**
- **飛石** — 芯々 **0.4〜0.5m 前後**、石間の目地 3〜6cm。**歩幅に合わせる**もので、
  等間隔の点列にしない。曲がりの内側に大きめの石(**踏分石**)を置く
- **蹲踞・手水鉢** — 茶庭(露地)の要素。**主庭に置かない**。役石(手燭石・湯桶石)と組で
- **垣** — 建仁寺垣・四つ目垣・光悦垣。**用途で使い分ける**(遮る=建仁寺、透かす=四つ目)

## 作庭の見立て — 美観を検める ★★

**「検算は通るが庭に見えない」図が作れてしまう。**汀線が矩形でなく、水源が通り、土量が釣り合っていても、
それだけでは庭にならない。ユーザー指摘(2026-08-23):「**美観が良いかも判断軸に入りませんか**」。

### 典拠
- **『築山庭造伝』**(前編1735/後編1828・籬島)— **幕末の作庭の実務書**。真・行・草の三体、
  築山と平庭の型。江戸の庭を起こすときの第一の拠り所【確度A=近世の刊行手引書】
- **『作庭記』**(11世紀・橘俊綱伝)— 現存最古。石組の心得、島の型、水の流し方【確度A】
- 実例の坪数・水面比は `estate-types.md` の**庭園4例**から引く。
  ⚠ **自分の作った庭から比率の目安を作らない**(§A-5)

### 見立ての要点(『築山庭造伝』『作庭記』)

| | 要点 | 破ったときの症状 |
|---|---|---|
| **汀の余白** | 池は庭を**埋めない**。汀と庭の境の間に土手・園路・植栽の帯が要る | 池が箱に詰まった水たまりに見える |
| **築山は池の景の一部** | 築山は対岸の背景として**池に臨んで**立てる。別区画に置かない | 山が脇の空地に置かれた土塊に見える |
| **島は円にしない** | 『作庭記』の島の型=山島・野島・磯島・松皮島・雲形・霞形。**真円は無い** | 池に碁石が浮いて見える |
| **不等辺・奇数** | 石組も植栽も **3/5/7**、不等辺三角。左右対称を避ける | 造園でなく装飾に見える |
| **見隠れ** | 一点から**水面の全部が見えてはいけない**。岬・築山・植栽で遮り、歩くと現れる | 一目で終わる庭になる |
| **前景・中景・遠景** | 主視点から三層に重なること(汀の石 / 水と島 / 築山と借景) | 平板な絵になる |
| **等間隔を避ける** | 汀線の折れ、飛石、灯籠、植栽の間隔に強弱をつける | 機械が並べた列に見える |
| **主景は一点** | 主室から見た構図を**一つ**決め、他はそれに従わせる | 焦点の無い庭になる |
| **回遊は同心円にしない** | 園路が汀と平行に一周すると単調。**離れ・寄り・上り**をつける | 池のまわりを回るだけの道になる |
| **真行草** | 大名上屋敷の主庭は **行**(石組を使うが草体の柔らかさを残す)が穏当 | 真=硬すぎ / 草=格が足りない |

### 数値に落とせる代理指標(機械検査にできる)

- **水面 / 庭** の面積比 — 実例(`estate-types.md` 庭園4例)から幅を引いて比べる
- **汀から庭境までの最小距離** — ここが小さいと「余白が無い」。**最小1.5間は欲しい**【P=実測の目安】
- **汀線の頂点間隔の変動係数** — 0 に近い=等間隔=機械的
- **対称性** — 主軸まわりに折り返して重なるなら不合格
- **見隠れ率** — 主視点から見える水面の割合。**100% は不合格**(遮る物が無い)
- **築山の見え** — 主視点→対岸の視線に対し、築山の頂が**対岸の上に出る**か(単純な視線計算)
- **島の真円度** — 外接円と面積の比。真円に近いほど悪い

**数値が全部通っても、画像を見て「庭に見えない」なら不合格。**逆に画像が良くても
水が通っていなければ造れない。**両方**を見るのが庭方の仕事。

## 中島・築山

- **中島**: 掘った池の中に cos 減衰の円盤を隆起させる(頂 `waterY+0.35`、r_top≈2.6 → r_base≈5.6)。
  ハイトマップに直接書く。夏の雪見灯籠+小松+岩2個で仕上げる。
  ⚠ **将来その池を Recarve すると島は平らに戻る**(ポリゴン全域を掘り直すため)。再実行が要る。
- **築山**: 中島レシピの拡大形(cos-falloff の多重盛り)。
  [戸山図]の麻呂ヵ嶽のように**頂上に床机級の平場**を切ると眺望装置になる。
  [六義園図]のように**築山群で谷を作って回遊路を通す**のが平地庭園の作法。
