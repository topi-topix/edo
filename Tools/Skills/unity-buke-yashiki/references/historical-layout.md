## 大名屋敷

- **A** [高知2000] 「周囲を長屋・門・蔵で囲繞し、中央に御殿と役所」。
  **A** [西川1959] 御殿を囲む**中間帯**に土蔵・馬場・作事小屋・中間足軽長屋、その外側に**定府家臣の長屋**。
  発掘でも御殿/長屋/表御門の三区分が確認(宇和島藩伊達家屋敷跡)。
- **A** [西川1959] **表向→中奥→奥向が「一列に順次連続」**。表御門→玄関→広間→使者之間→書院→廊下→
  中奥→御錠の口→奥向→長局(正徳期 津軽藩柳原屋敷図)。
  **分棟しても中庭と長い廊下でつなぎ、離しすぎない** — 表御殿と御殿を72m離して破綻させた実例あり
  (6.5mに詰めて是正)。
- **A** 江戸は**一殿舎一機能**(上方の蔵屋敷は1棟にまとめる)。表と奥の**境に塀**を通す
  (加賀本郷邸で基礎検出)。
- **B** [西川1959] **小藩(2万石級)の江戸屋敷の下限構成** — 慶長11年 肥後人吉藩相良家(2万2千石)
  「江戸御屋形作日記」の殿舎は「広間、**中門**、書院、台所、**風呂**、**雪隠**、廊下、**局**、門」。
  **風呂(湯殿)と雪隠は最小構成にも入るが独立棟ではない**(室として持つ)。**局**は奥の女中部屋。
  2〜3万石級の棟・室の一覧を作るときは**この9つを下限として突き合わせる**。
  ⚠ 中門は同じ台帳の「1万石級での中門は史料未確認」と**緊張関係にある** — 断定しない。
  ⚠ この事実は [西川1959] の本文の中に埋もれており、2026-08-25 に土井邸で
  「在るべき役割の一覧」を作ったとき**参照されずに湯殿・雪隠・局が落ちた**。索引としてここに立てる。
- **A** 座敷群は横一列でなく **L字(鉤の手)**。書院/座敷の前面に必ず庭。
- **A** 台所は**表向・奥向の中間的位置**、江戸の実例では**御殿中央部の北**かつ中奥付近。井戸を隣接。
  → [福井図]で「大台所が敷地のほぼ中心」として独立に追認された。
- **A** [高知2000] 米蔵は**搬出入門の直近**に張り付く(大坂東屋敷「米出御門」直近に御米蔵)。
- **A** **厩は表門まわりの長屋列と同じ帯**、作事系施設と一緒(長州藩麻布屋敷)。馬場は庭園に隣接し
  厩は馬場の近く。番所は表門の脇、**片側だけでも史実的**(加賀本郷邸は右側のみ)。
  ⚠ [中屋敷図]では**厩・馬場が裏門側** — **両類型ある**。屋敷ごとに選ぶ。
- **A** 庭は**1つではない**。表向・奥向それぞれに庭園池(仙台藩芝口邸の発掘で護岸工法まで別系統)。
  主庭は池泉回遊式で**谷・低地形を利用**(尾張藩市谷邸「楽々園」は埋没谷、御殿は池を望む東側)。
  庭の一隅に稲荷宮。
- **B** [西川1959] 中屋敷=**上屋敷の諸機能を規模を縮小して配置**。定府(妻子同居)家臣が主なので
  長屋は一戸あたり間口が大きい。中門は国持クラスなら可、1万石級での中門は史料未確認。

## 旗本屋敷

- **A** [鈴木1985] **建家図8例すべてで「敷地の中央部に主屋、道路側に長屋(長屋門形式)、敷地の周囲に
  土蔵・物置・雪隠」**。建ぺい率22〜55%、**建坪の約80%が主屋** → **主屋を中央から外すのは誤り**。
- **A** 門を入った**正面が玄関式台**(旗本三嶋家: 西側道路沿いを表長屋、北寄りに門、正面に玄関式台、
  奥へ母屋が展開)。
- **A** 主屋は4つの居所(表の座敷/主人居間/寝間/**台所**)。**台所は玄関の背後**、または3居所の結節点。
  井戸を隣接。
- **A** 千石級でも表・中奥・奥の三分化は保たれる。庭は**奥の隅**、**北東角(鬼門)に稲荷社**。
- **A** 拝領格坪 1,000〜1,900石=700坪。**馬は500石でも1頭あればよい方** → 旗本屋敷の厩は省略可。
- 省略されるもの: 中門・御成門・能舞台・長局・馬場・**独立台所棟**・回遊式庭園・大規模長屋群。

## 外周を塀にするか長屋にするか

**両方の類型が実在し、成文規則は見つかっていない。屋敷ごとの判断領域。**
ユーザーの裁定(2026-08-13): 「藩の好みということであれば書類上残っていなくてわからないので
あればどちらでもよい」。

### 長屋を避ける類型 [追川2017](本文未入手・記録された引用)
宮崎勝美1994を引用し「**築地塀こそが正式で伝統的な屋敷囲いであり、家臣団の住居を兼用する表長屋は
略式で薄礼のものであるとの意識**」ゆえ「**表門に連なる塀に、長屋塀を構築することを避けた**」。
実例: 加賀藩本郷邸 = 表門(赤門)のある本郷通り側は錦絵18点に長屋が一切描かれない /
南の春日通り側は「延々と続く**盲長屋**」/ 東側は長屋塀+石垣+石組下水溝。

### 長屋を回す類型 [福井図]
**福井藩上屋敷図は表門(台所門)のある辺も長屋**で埋まっている。

### 判断手順
1. その屋敷個別の絵図・古写真があればそれが最優先(SKILL.md §A-3)。
2. 無ければどちらでも可。
3. 実務上は **平坦な辺に長屋、急斜面の辺は塀**(`perimeter.md` の勾配限界)で決めてよい。
   長屋は剛体8mモジュールなので勾配13.7%の辺では物理的に成立しない。
4. **切絵図では長屋か塀かの描き分けは無い**(屋敷絵図・錦絵・古写真が必要)。

## 外周の構法(史実)

- **表長屋は外側に窓を設けない「盲長屋」**。瓦葺き・塗屋造り・腰はなまこ壁。
- **石垣＋塀が江戸大名屋敷の標準解**: 屋敷境の石組下水溝の護岸石垣を土留めとし、その**直上**に
  長屋/塀を建てる(1650年代以降に成立)。犬走りは**狭い**(城のように数m取らない)が、
  **ゼロではない** — 天端の縁ぎりぎりには建てない。屋敷境では **0.30m(≒1尺)** で足りる。
  ⚠ ここを「面一」と読んで長屋を天端の縁に建てたことがある(2026-08-18 にユーザーが是正)。
  据えの実装は `perimeter.md`「囲いは石垣の天端に犬走りを残して据える」が正典。
- 長屋塀型なら屋敷境から礎石まで **1.0-1.5m**、古式の長屋型(別建ち)なら **3-6.5m** の空閑地。
- 規模で変わる: 加賀邸(88,482坪)は表長屋15%、尾張市谷邸47.7%、小浜邸28.6% —
  **中小藩ほど外周を長屋で使い切る**。表長屋は収容力より景観装置。

⭐ **屋根について台帳が支えるのは一点だけ**(2026-08-24 土井邸で確定):
**長屋門の官製現物2件([山脇]A・[西澄寺]A)はいずれも切妻**。長屋門を採るならこれに従う。
⛔ **「独立門=入母屋」という一般化はしない** — [黒門]A(入母屋)と [赤門]A(**切妻**)が割れる。
⛔ **[下丸子]A の入母屋に説明を付けない【確度?】。留保したまま残す**(同門が長屋門か独立門かが
官製文言から定まらない。試みた説明は二つとも反証済み — sources.md の当該エントリを見よ)。
そのため **下丸子から番所・潜戸の形式を長屋門へ移すのは型式をまたぐ移植で、確度は B/U**。

実寸([西澄寺武家屋敷門]A): 一棟の桁行9間16.89m / 梁間2.5間4.37m / 門戸6間11.31m /
**中央2間(3.64m)に門扉・その両脇1間が潜戸・両側1間は板壁** / 番所は桁行1.5間。
[山脇武家屋敷門]A: 桁行21.8m / 梁間4.7m / 二階建。
⛔ **「両番所=国持・御守殿の格」は誤り**(2026-08-23 反証)。加賀・鳥取という最上格2例だけを
見た標本の偏りで、**5万石の譜代上屋敷が両番所を持つ現物**([山脇])がある。

適用例(プロジェクトでの運用):
- **5万3千石譜代上屋敷(岡部)= 長屋門 + 片流れの張出し両番所**(2026-08-23 改定。旧「k_mon+片番所」は撤回)
- 7万石譜代上屋敷 = 長屋門 + 両番所(⚠ 旧記述の k_mon は独立門なので上の階梯と合わない。要見直し)
- 2500石大身旗本 = h_mon 長屋門
- 御小姓組番士・500石布衣(二ノ丸御留守居) = kabukimon 腕木門(布衣は+番所1で体面を付ける)
- 数百石級の小旗本 = 板塀 + kabukimon

**中屋敷の表門**は「表長屋に組み込まれた長屋門」が標準類型。
「国持=独立門(k_mon)」は**上屋敷の正門格式**で、中屋敷に適用してはならない
(鍋島邸で誤適用し、溜池の絵画資料[西面に長屋列]に基づき長屋門へ差し戻した実例)。
ただしユーザー判断で中屋敷に独立門+盲長屋列という構成もあり得る。

**格の3段階を面積とボリュームで見せる**:
旗本 = House+Small House+蔵1 / 1万石中屋敷 = Big House+役所+蔵2 /
国持中屋敷 = Manor+表役所+奥向き+台所群+蔵3列+回遊庭園。

## 史料で確認できなかったこと — 推測で埋めない

- 表門〜玄関の標準距離
- 土蔵を御殿から離す寸法規範
- 「供待」の位置
- **「表は南面が原則」は誤り** — 江戸は**街路の位置が方位より優先**。
  加賀本郷邸の表門は西辺、高知藩江戸上屋敷の玄関は東北隅。
