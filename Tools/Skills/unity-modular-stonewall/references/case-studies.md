# 実証済みの個別ケース

## 14. 浅い折れ角と内部擁壁（松平大和守邸で実証, 2026-08-02）

**浅い折れ（Δ≲35°）に正方形の出隅ブロックを使ってはならない。** R1で片面を合わせても
apex が反対側の壁外面から `2.4·cosΔ` はみ出す（Δ=20°で2.26m街路側へ突出）。出隅ブロックが
成立するのは Δ≳60°、理想は90°前後（Δ>90°は apex が内側に隠れてむしろ安全）。
浅い折れは**ブロック無しで両run の直線材を頂点越しに ~2.4m 延長して重ねる**（R4の
「隙間より重なり」）。外面同士の楔状隙間は両体が交差点を越えていれば埋まる。
R2の閉形式スライド量は `k = 2.4 − 2.4/sinΔ`（Δ=90で0）。

**テラス段差の内部擁壁は「護岸規格」で作る。** 6〜8mの段差を2mグリッド地形に切ると、
壁線がグリッドに対し斜めのとき遷移帯が±1.4mの階段状ジグザグになり、厚2.4mの標準規格
(scale x=1) では壁体に隠しきれず土の楔が化粧面の前に飛び出す。§8の
**scale (2, sy, 1.3)・ピッチ2.4m（厚4.8m）**なら遷移帯が体内に収まる。
- **化粧面（勾配石積み）は body 側 = 進行方向の左**。低地側から見える壁は
  「左=低地側」になる進行方向で置く（逆にすると中空の裏面が低地側に見える。一度やった）。
- ピボット線は高地側の盛土到達線に置き、遷移帯 lerp はピボットの手前2.4m以内に収める。
  裏面(開口)が高地側の盛土に完全に埋まることを確認する。
- 低地側から見て凹（L字の内側）になる内部コーナーは入隅だが、ブロック無しの重ね継ぎで
  実用上問題なく納まる。

## 15. 区割り変更後の壁高再設計(三屋敷再編 2026-08-08)

- **区画ポリゴンはユーザーが置いた石垣runのラインフィット交点から導出する**(ブックマーク不要)。
  PCA でrun毎に線を出し、隣接面と交差させた点がコーナー。latSpread≤0.06 なら信頼できる。
- **段付き壁の天端は「整地後の両側実地盤」から再バケット**: 設計値で先に段を決めると、造成後に
  両側とも低い区間で壁がヒレ状に突き出す(鍋島北壁東部で実例: 段11.8-8.8 → 実測後 10.5/9.5/8.0 に再設定)。
  手順: 高さ設定→整地→壁沿い両側±5mをサンプル→coping=max(両側)+0.3〜0.5 を 0.5 刻みで再バケット。
- **土塀(s_hei対)再敷設の実証値**: Pd = 天端実測(mn,mx)の中心+0.1、基部=coping-0.05、
  ピッチ=L/(N*1.645)。天端実測は「壁yaw±5°フィルタ+coping±0.3フィルタ+lat±3m」の3条件必須 —
  yawフィルタ無しだと同天端の隣接runの頂点を拾い Pd が数m飛ぶ(§11の罠を再確認)。
- **石蓋(GesuiFuta)は単一メッシュ**なので新しい門前へ移設可能。側溝の芯は近傍メッシュ頂点の
  法線射影平均で実測してから載せる。敷地内に取り残された旧側溝runは SetActive(false)。

## 16. 虎御門枡形で実証(2026-08-10)

- **Yaguramon A から安政期(基準年次)の「渡櫓なし櫓門」を作る**: `Exterior/Roof` と `Exterior/Wall` を
  SetActive(false) → Base(櫓台石垣×2+門扉+柱+庇)だけが残り、幕末外郭門の正史の姿になる。
  ×1.5 で台上端=基準+6.0m・開口6.2m。台が壁線を占有する区間は straight をスキップ(§4と同じ)。
- **Castle Wall (scale x=1) の天端実測**: pivot から進行方向左へ 0.000〜1.400m(中心+0.700)。
  §11の土塀芯はこの規約なら **Pd=+0.8(左)**、基部=coping-0.05。sy に依存しない。
- **水際に立つ壁の基部**: 同一 run 内で陸側/水側が混ざるときは、全ピース posY=堀床(例2.0)で
  sy を伸ばして coping を揃えるのが最も安全(陸側は埋まるだけ)。枡形SW壁で採用(posY2/sy2)。
- **橋・堰の護岸面の汀線**: 掘り込みポリゴン縁の2mグリッドランプで gap 0.25〜1.0m が残る。
  §6の SMIN と同じく **護岸面から壁体内へ+1.4m(体厚2.4の内側)まで床高で掘り込む**と gap=0.00。
- 出隅の閉形式(yaw=θout-90, pos=頂点)は 4/4 コーナーで一発合格だった。オフセットピボット線
  同士の出隅は2本のピボット線の交点に置く(v6/v8で実証)。
- **WaterBodyの`sharp`配列を丸ごと new List で置き換えてはならない**(虎御門で事故)。既存頂点は
  ほぼ全て直角(sharp=true)で掘られており、falseに落とすと RebuildSurface が角を丸め、下流全域の
  水面が石垣から剥がれる。頂点を挿入するときは旧配列を同じインデックス対応で継承し、新頂点分だけ
  挿入する。旧フラグはコミット済みシーンの `sharp: 0100...`(1バイト=1頂点のhex列)から読める。
- **勾配壁の際の体内掘りは「面+2.6m」まで**(外堀下流で実証)。壁面は上部ほど後退する(6.6m高で
  約1.7m)ので、+1.4mの掘りでは2mグリッドの階段状の土楔が壁の上半分を貫通して見える。
