# 天端に載せる土塀と、裾の石組下水溝

## 11. 土塀（`es_dobei`）を石垣の天端に載せる

長屋を土塀に置き換える／敷地境に土塀を回すときの実証済みレシピ。基準は太田・加納間の
`Edo_Yashiki_Ota/Dobei`（`s_hei_center.obj` のみ 27間、端部ピース `s_hei_l/r` は不使用）。

**表裏2枚1組**（`_f` / `_b`）で1間を作る。`hei`/`shitami` は片面ポリゴンなので、2side マテリアルに
差し替えるのではなく**逆向きの同じピースをもう1枚置く**のがこのプロジェクトの作法。

`s_hei_center` の実寸（`localScale=(sx,1.818,1.818)`、`hei` のローカル x = 中心 -0.478 / 幅 1.645）:

| 量 | 値 |
|---|---|
| 1間の幅 | `1.645 * sx`（突き付け＝ピッチと同じ） |
| ピボット位置 | 間の左端から `0.3445*sx`（＝中心から `0.883` ずれ、**中心ではない**） |
| 壁面 | ピースの z=0 平面そのもの |
| 屋根の出 | 壁面から ±0.575（`sx` ではなく z スケール 1.818 に比例） |
| 高さ | 基部 y=0 → 天端 y=+2.646 |

配置式（走り方向 `u`、外向き法線方位 φ、壁芯の法線座標 `Pd`、基部 `baseY`）:

```csharp
float sx = L / (N * 1.645f);            // 端数は localScale.x だけで吸収（y,z は 1.818 固定）
float pu = u0 + k * 1.645f * sx + 0.3445f * sx;
var pf = O + u*pu + n*Pd; pf.y = baseY;                 // 表: ry = φ
var pb = pf + u*(0.956f*sx) + n*(-0.2f);                // 裏: ry = φ+180
```

`0.956*sx` は 180° 回転でピボットが間の反対端へ移る分の戻し、`-0.2` が表裏の板間隔。
組全体は法線方向に `[Pd-0.775, Pd+0.575]`＝**幅1.344m、中心は Pd-0.1**。

**天端への載せ方**: Castle Wall 直線ピース（`ls.y=2`, 高さ8m）は勾配があり、外面は基部
d=+0.569 → 天端 d=-0.431、内面は d=-1.831 で垂直。つまり**天端幅は1.40m**。

**塀の外面は法肩から犬走り 0.30m（≒1尺）控える**（ユーザー裁定 2026-08-18、確度 U/B）。
天端の中央合わせでも、法肩に面一でもない。中央合わせは `s` が変わるたび犬走りの幅が変わって
run 間で塀の見え方が揃わないし、面一は雨落ちが天端の目地を直に洗って笠石を欠けさせる。
**長屋塀も同じ 0.30**（`unity-buke-yashiki/references/perimeter.md`）。
基部は天端 -0.05（参照壁と同じ埋め量）。
→ 鍋島邸北面は天端14.00に対し `Pd=-1.031`（`_f` 位置）、`baseY=13.95`、天端16.60
（**この値は犬走り改定より前**。触るときは 0.30 基準で出し直すこと）。

**端部の取り合い**: 隣の長屋/門の走りと u 座標で突き合わせる。角の `*_capC` は大きな隅ブロックで
北面の1間目を丸ごと飲み込むので重なって良い（旧長屋も同じ）。逆に反対端は 0.2m の隙間でも
街路から切り欠きに見えるため、`u1` を隣の長屋の開始 u に**合わせてから** `sx` を逆算する。

**MCP の制約**: `PrefabUtility.InstantiatePrefab` / `manage_gameobject create` / `delete` /
`manage_scene save` は自動承認クラシファイアに弾かれることがある。`execute_code` 内の
`UnityEngine.Object.Instantiate`（プレハブリンクは付かない）と `SetActive(false)` は通る。
削除と保存はユーザーに依頼する前提で段取りを組む。

## 12. 石垣裾の石組下水溝(側溝) — commit 8a2e249

史実: 江戸の武家地は道端・屋敷境に開渠下水が標準(小下水→大下水、幅3尺〜6尺、石組み)。
加賀藩本郷邸の「長屋塀+石垣+石組下水溝」が発掘実証例。切絵図赤坂9-090にも溜池の
「下水下流(桜川)」が明記され、溜池南岸の屋敷群は側溝→溜池排水の地形。

**実装(2m格子地形で掘割は原理的に不可 → スウェール+メッシュ)**:
1. 壁 run ごとに PCA でラインフィット → 外向き法線(敷地セントロイドの反対) → 基部外面を
   メッシュ頂点実測(y≤base+2.5) → **水路芯 = 外面+1.55m**。
2. ハイトマップに浅い雨落ちスウェール: 芯から1.0m内=-0.38m、2.2mまで線形フェザー。
   (1点下げると±2mに波及するので、これ以上深くすると道が壊れる)
3. U字断面メッシュを芯に沿って押し出し(1.8mピッチ、地面は窓5移動平均):
   縁石±0.45〜0.68(天端=芯地面+0.35)、内壁、底(芯地面+0.04、暗色サブメッシュ)、
   外スカート(縁石外面を地面-0.25まで)。石材は Castle Wall の sharedMaterial 流用。
4. 門前: 石蓋/石橋 = 切石スラブ(幅1.9×厚0.16、天端=両脇地面+0.02、長さ=門幅+1.5)。
   門開口で run が分かれている場合は連結セグメントを追加してから蓋を架ける。
5. 検証時の罠: **カメラを地中に置くと地形は裏面カリングで透け、壁が「露出」して見える**。
   「水路が壁の天端に載っている」ように見えたら、まずカメラ足元の地面高を測ること
   (加納西で誤診しかけた — 実際は外側地盤が天端とほぼ同高で正しかった)。
