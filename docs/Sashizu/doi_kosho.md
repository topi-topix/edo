## 表門 — 長屋門+片番所(格子付)・片潜門

**番所と潜戸の形式**は **[下丸子武家屋敷門]** の官製構造形式「**片番所格子付、片潜門**」による。
東京都教育委員会の掲示が「遺存例の少ない**1〜5万石の小大名格**の形式」と明記しており、
二万三千石はこの帯に入る【**掲示に「1〜5万石の小大名格」と書かれていること=A(実見)** / **当家がその帯に入るという当てはめ=B**(帯の判定自体が形式からの逆推なので独立検証ではない)/ **採用=U**(2026-08-23)】。
⚠ **同門の屋根(入母屋造)は採らない。** 理由は下の「屋根」を見よ。
**門の実在は確度S**(被害書上の {{門の記録数}} 記録が「表門倒」を記す)。⚠ **位置(東辺)に S は付かない** —
一次史料が「表門は東辺」と書いているわけではない(上の「表門が東辺にあることの確度は分解して書く」を見よ)。

**型式は長屋門を採る【B】**(2026-08-23 決定)。理由は三つ。

① **当家に表長屋が実在した=確度S。** 典拠は **真田家文書(下座見)「土井大隅守様 表御長屋瓦落」**
と **むし倉後記續篇「土井大隅守樣 表長や瓦落」**(同一報告の異転写)
(『新収日本地震史料』所収、東京大学地震研究所 地震史料集DBで実見)— 当屋敷を名指しする一次記録。
⚠ **ただしSなのは「在ったこと」までで、この一行は長屋の位置を書いていない。**
「表」を屋敷の表向(公の側)と読み、街路に面する辺が**東辺しか無い**という幾何と、
[福井図](B・図の目測)「長屋は外周に連続した帯」から、**東辺に載せるのは確度B**の推論である。
つまり「門と同じ辺に長屋が通る」までを言うと **S+B** であって S ではない。

② **最も格の近い官製記録付きの現物**([山脇武家屋敷門]A = **5万石・譜代・上屋敷の表門**)が
「**長屋門**、桁行21.8m…**切妻造**」。石高は倍以上違うが、譜代・上屋敷・表門という条件は当家に最も近い。

③ [西澄寺武家屋敷門]A も桁行9間で完結する門長屋で、一棟に納める形が実在する。

**屋根は切妻**【確度B — **型式からの帰結**】。根拠は次の一点に限る —
**長屋門の官製現物2件がいずれも切妻である**。当家は長屋門を採るのでその線に従う。

| 現物 | 型式 | 屋根 |
|---|---|---|
| [山脇武家屋敷門]A(5万石・譜代・上屋敷) | **長屋門** | 切妻造 |
| [西澄寺武家屋敷門]A(門長屋・一棟で完結) | **長屋門型** | 切妻造 |
| [黒門]A(32.5万石) | 独立門 | 入母屋造 |
| [赤門]A(独立の三間薬医門) | 独立門 | **切妻造** |
| [下丸子武家屋敷門]A(1〜5万石) | **?** | 入母屋造 |

⛔ **[下丸子武家屋敷門] の入母屋には説明を付けない【確度?】。** 同門が長屋門か独立門かが官製文言から定まらず、
**留保したまま残す**。これまで二つの説明を試みたが、いずれも反証された:
① 「二度の移築で端部を納め直した」→ 長屋から切り縮められたことが記録で確かめられる唯一の現物
[山脇武家屋敷門]A(原形58間 → 門と左右番所のみ移築)が**切妻のまま**で反証(2026-08-23)。
② 「独立門=入母屋だから同門は独立門型」→ **[赤門]A(独立の三間薬医門)が切妻造**で反証(2026-08-24)。
「官製文言の語順が [黒門] と同じ」という論拠も採らない — **文化庁と都教委は発行主体が違い、
記載様式の差は型式の証拠にならない**。

⚠ したがって**番所と潜戸を下丸子から採るのは型式をまたぐ移植**であり、確度は A でなく **B/U**。
番所の数と潜戸の数は階梯表が型式を越えて石高で並べる指標なので移してよいと判断した。
[山脇武家屋敷門]A(長屋門・5万石)が「片流**面出**番所」= 室ごと張り出すのに対し、下の帯の下丸子が
格子窓だけなのは、**格が下がるほど張り出しが減る**向きで整合する。

**これらをまとめて解くのは [下丸子武家屋敷門] の実測図**(未解決を見よ)— 桁行・梁間・門戸部の間数に加え、
**「長屋門か独立門か」**がそこで決まる。

⚠ **「表門倒」と「表御長屋(の被災)」を独立門の証拠に使うのはやめる。** この二語は**別々の文書**
(岡本家文書と真田家文書)に現れるもので、一つの記事の中で対比されてはいない。
加えて**長屋門でも門の部分と長屋の部分は別の名で呼ばれる**ので、名が分かれること自体は型式を弁別しない。

## 動線 — 表門を入ってからどう動くか【すべて設計判断U】

当屋敷の指図が無いので、動線は**類型と地形から構成した想定**。設計値 `routes`、図は「動線」の節。

- **表向(客・使者)** — 表門 → 白洲 → 石段 → 前庭の白洲 → 石段 → 玄関の郭(窪み) → 御式台。**門の軸の石段は {{門の軸の石段}} 本**(内訳は上の「敷地の造成」を見よ)。
  **門の軸の一本道**で、登るほど格が上がる。門を入って正面に御殿が見えず、二度踊り場を挟んでから
  玄関に達するので、屋敷の奥行が実寸以上に効く。式台で履物を脱ぎ、御玄関 → 取次へ。
- **役方(日勤)** — 表門 → 白洲を南西へ折れる → 厩の郭の壁と前庭の壁のあいだの窓 → 表役所の郭 → 表役所棟。
  **下段だけを通るので**外の**石段を一つも使わない**(縦断の勾配は生成器が算出する。
  石段を切るまでもなく歩ける)。表役所を門前面に置いた最大の理由がこれで、
  毎日出入りする役人を段で妨げない。自然のベンチがそのまま使えたので造成も要らない。
- **厩・供廻り** — 表門を入ってすぐ南、白洲から**土の斜路**で一段降りて厩の郭へ。
  乗物と馬を白洲へ立ち入らせない。**厩を一段下げたのは自然の高さに合わせたため【設計判断U】** —

  [富山市埋文]A まで)。**馬は石段を降りないので、ここだけ石段でなく斜路にする。**
  排水が下へ流れる利もあるが、これは典拠のない工学的推論【U】。
- **奥向** — 御式台 → 玄関棟 → 渡廊下 → 居間棟(中奥) → **御錠口** → 奥棟。
  奥へ入る廊下はこの一本だけ。
- **勝手(賄・物資)は通用門から入る【存在=B([福井図]B に小門の実例。通用口の**数**を縛る規定は典拠台帳に無い)/ 位置=U】** —
  表長屋(北)に潜りを開ける。**ここが街路と屋敷内が水平で取り付く唯一の点**で、位置はそれで決まる。
    格式が規定するのは**表門の型式**(長屋門か・番所を出格子にするか)であって**通用口の数ではない**。
  現に南端には木戸(Ura_Kido)が既に開いており、二つ目を保留する筋が通らなかった。
  **米は御米蔵へ納まる**が、⚠ **蔵は通用門より一段高く、荷は石段を上げる。**

  蔵は石段の上り口の直上に寄せて担ぎ距離を最短にした。
