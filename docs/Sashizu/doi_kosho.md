## 屋敷の性格

三河刈谷藩 二万三千石。**譜代・雁間詰(城主格)**の上屋敷。外桜田永田町、三べ坂前身の
南北道の**西側に位置し、東面して門を開く**。北と西は松平出羽守(松江藩)上屋敷と背中合わせ、
南は岡部内膳正(岸和田藩)上屋敷。跡地は駐日メキシコ大使館(永田町2-15)。

**基準年次=嘉永3年(1850)** — 基図の年次。より後の記録(安政2年の地震被害書上)は
「倒れる前の姿」として遡って使い、より前の記録(天保9年武鑑)は当主が先代の年次であることを断る。

- **基図と読図**: 尾張屋版 外桜田永田町絵図(嘉永3・NDL pid 1286657)を IIIF 実見。
  「土井大隅守」+家紋(**六つ水車**・実見)=上屋敷、**文字の頭=東=表門は東辺**。
  読図の向きは**絵図の上=シーンの東**(方位盤を信じない — 三べ坂東街区で確立した読み)。
  上妻文庫の「**山王三部坂** 土井大隅守様」も、屋敷が三べ坂(三部坂)に面する傍証。
  CODH 江戸マップ 7-062 は刈谷藩上屋敷 [H231] と同定済み。
  天保9年武鑑「上 赤坂御門之内」(所在の確認のみ — 当主は先代の年次)。【確度 S/A】
- **当主**: 土井利善。天保元年浜松藩井上家生まれ、弘化4年末期養子で家督・大隅守。
  **嘉永5〜6年は大坂加番で江戸不在**。安政5年奏者番(「雁之間席ヨリ」)、文久3年寺社奉行。
  参府は隔年6月(丑卯巳未酉亥)。慶応2年隠居。【確度 A — 柳営補任・大坂加番一覧の翻刻】
- **家格=雁間**: 安政地震の被害書上(岡本家文書)が殿席順の列挙で当家を**雁間の部**に置き、
  柳営補任も「雁之間席ヨリ」。刈谷土井家は利勝三男利長の分家(新規取立)なので、譜代古参の
  帝鑑間ではなく**城主格新参の雁間** — 御殿の書院はこの格で作り、上へ上げない。【確度 A】
- **区画は町割の正典 `parcels.json` の `doi` と同値**(ユーザーのブックマーク角+敷地割ツールでの
  修正・確度U)。元文3年規定の表に 2〜3万石の欄は**無い** —
  前後の欄から**内挿する(内挿は当方の操作)**と約1.3〜1.8倍で、「規定より広い実例」
  (渡辺備中守=1.45倍)の範囲。元文3年自体も確度B(原典未確認)。幕府側の坪数記録
  (『屋敷渡預絵図証文』)の繰りは未実施。
- **屋敷指図(建物平面)は現存未確認。** 国書DB・NDL・内閣文庫・ジャパンサーチ・刈谷市
  古典籍DBを横断して無し。刈谷市歴史博物館・愛知県公文書館への照会が次の一手。
  **御殿の構成は類型(B)、室割りは想定(?)。**

## 表門 — 長屋門+出格子(格子出)番所

型式は『青標紙』の「**1万石大名=長屋門+格子出両番所**」の条を、二万三千石(城主格)へ
**外挿した設計判断**【B→実質U — 故実書は規範であり、しかも当該石高の条ではない。
sources.md の[表門格式表]が石高別門形式表の使用に⛔を付けた推論と同型であることを自覚して使う】。
**門の実在と位置(東辺)は確度S**。なお被害書上が「表門倒」と「表御長屋潰」を**別項で立てる**ことは、
長屋門(一体構造)でなく独立門+表長屋だった可能性も残す — 決定的ではないが、確度の限界として記す。

- **番所は長屋門の躯体内・出格子の「片番所」**【階梯表B + 採用はユーザー裁定U(2026-08-23)】。
  `historical-layout.md` の門の格式階梯が **5万石以下=長屋門+片番所・出格子・片潜り門** とし、
  これは現物2件([山脇武家屋敷門]A・[西澄寺武家屋敷門]A)と独立に一致する。二万三千石はこの帯。
  ⚠ **『青標紙』1万石条の外挿による「両番所」は撤回した**(2026-08-23)。
  「万石級の標準形」という断定も撤回する — 故実書の規範と現物の階梯が食い違う論点で、
  **現物で裏の取れる階梯表を採る**という判断。
  桁行は [西澄寺武家屋敷門](A)の実測から **7.5間=13.64m**(門戸部6間+番所1.5間)。
  ⚠ 現行の設計値10.0mは**門戸部6間11.31mにも足りず、番所が物理的に入らない**。
  寸法の差し替えは辺5の割り付け(表長屋の s 区切り・段の境界)を動かすので `_pending.monsun` の連鎖に従う。
- **袖塀は無い** — 長屋門の両袖がそのまま表長屋へ連続する(岡部の検討で確認済みの
  「門長屋」型)。囲いの線は 表長屋(南)→長屋門→表長屋(北) の一連。
- 石垣畳出は使わない【**設計判断・確度U** — 畳出の石高規範は sources.md に無い。
  基壇は地形を受ける土留めとしてのみ使う】。

## 敷地の造成 — **地形を測って、その自然の平場を面にする**

⚠ **2026-08-23 ユーザー指示で原則を入れ替えた。** それまでは「面の高さを先に決めて地形を合わせる」
作りで、玄関棟を平均1.65m の盛土に載せ、窪みを埋めて平らにしていた。
**いまは逆** — 先に地形を測って自然の平場(ベンチ)を見つけ、**その高さをそのまま面にする**。
窪みは埋めず、窪みのまま使う。

実測で見つかった平場は**5枚**(2026-08-23・確度P):

| 面 | 範囲(グリッド) | 実測の高さ | 起伏 | 何を置くか |
|---|---|---|---|---|
| 下段のベンチ | u−22..−8, v16..30 | 18.8 | 小 | 表役所・厩・白洲 |
| 前庭のベンチ | u−6..10, v12..22 | 21.7 | 小 | 前庭の白洲・門内北 |
| **窪み** | u−4..10, v26..46 | **25.0** | 0.84 | **玄関棟** |
| **北東の横長の帯** | u10..18, v26..46 | **26.0** | 0.81 | **書院棟** |
| **大平坦地** | u−18..14, v46..80 | **26.6** | 0.49 | 中奥・奥向・台所・土蔵 |

**全7棟が自然地形の ±0.44m 以内に載る。** 造成は面の縁の摺り付けだけになり、
盛土は敷地全体で 3,031m³・最大3.0m(いずれも [菊地2003] の 1〜4m の内)。

- **北東の肩(28.5まで上がる)は造成しない** — 奥庭の築山にそのまま使う。
- 段のつなぎは 19.2→21.9(9段)→**25.0(10段)** で御式台に達し、**外の石段は二つだけ**。
  玄関の郭から書院の郭へは **1.0m=階段廊下3段**、主面へは **1.6m=階段廊下5段**(勝手は外階段5段)。
- ⚠ **土留めは落差のある縁にだけ置く。** 天端と法尻の差を実測で確かめ、設計値に `drop` として持たせ、
  生成器が壁高(4s)との釣り合いと、**高さの違う段が接する辺すべてに壁が載っているか**を総当たりで検査する。
- 段の外は**法面**(盛土1:1.5/切土1:1)で現地形へ摺り付け、段の縁に垂直の段差を残さない。
- ⚠ 南辺(岡部境)の塀 run(Hei_N3/N4a/N4b)は**更新後の共有境界に載っていない** — 岡部の指図側の宿題。

地形が込み入っているので、**断面を東西5本・南北6本の格子で通した**(設計値 `sections`)。
**造成の話は現況図から始める** — 段彩(2m)と等高線で造成前の地形を描き、隣の松江松平・岡部の
区画も重ねてある。**切盛図**はその地形と造成後の地盤の差を1間の格子で塗ったもので、
**暖色=盛土/寒色=切土/無彩=±0.3m以内/地の色=造成しない**。断面にも同じ配色を敷き、
**無造成の区間は地盤線に太い緑帯**を置いて「触っていない」ことを図の上で示す。

## 動線 — 表門を入ってからどう動くか【すべて設計判断U】

当屋敷の指図が無いので、動線は**類型と地形から構成した想定**。設計値 `routes`、図は「動線」の節。

- **表向(客・使者)** — 表門 → 白洲 → 石段9段 → 前庭の白洲 → 石段9段 → 中段 → 石段7段 → 御式台。
  **門の軸の一本道**で、登るほど格が上がる。門を入って正面に御殿が見えず、二度踊り場を挟んでから
  玄関に達するので、屋敷の奥行が実寸以上に効く。式台で履物を脱ぎ、御玄関 → 取次へ。
- **役方(日勤)** — 表門 → 白洲を南へ折れる → 門前面 → 表役所の郭 → 表役所棟。
  **下段(19.2)だけを通るので石段を一つも使わない。** 表役所を門前面に置いた最大の理由がこれで、
  毎日出入りする役人を段で妨げない。自然のベンチがそのまま使えたので造成も要らない。
- **厩・供廻り** — 表門を入ってすぐ南。乗物と馬を白洲へ立ち入らせない。
- **奥向** — 御式台 → 玄関棟 → 渡廊下 → 居間棟(中奥) → **御錠口** → 奥棟。
  奥へ入る廊下はこの一本だけ。
- **勝手(賄・物資)は通用門から入る【存在・位置=U】** — 表長屋(北)の s=64 に潜りを開ける。
  ここは道が21.4で前庭面21.9と**ほぼ同高**なので、段差なしで荷が入る。
  ⚠ 以前は「門を増やすと格式に触れる」として保留していたが、**これも誤り**(2026-08-23 是正)。
  格式が規定するのは**表門の型式**(長屋門か・番所を出格子にするか)であって**通用口の数ではない**。
  現に南端には木戸(Ura_Kido)が既に開いており、二つ目を保留する筋が通らなかった。
  これで米も薪も**表門と門内の白洲を通らず**、登りも 7.4m・19段 → 5.2m・15段 に減る。

## 建物の構成 — 連続御殿複合【確度 B=類型/室割りは ?】

2万3千石の小藩なので棟数を絞る: 玄関+書院(表)/居間(中奥)/奥棟+女中部屋(奥向)/
台所/表役所(前庭面)/土蔵2(主面・勝手裏)/厩。開放地は白洲と中庭だけ。

- **表役所を門前面(門を入って南の下段)に置く【設計判断U】** — [高知2000](A)の
  「中央に御殿と役所」の類型を**採らず**、[浜御庭図](B)の門まわり管理クラスタを採る。
  この結果、**表向が二つの標高に分かれ、御殿との連絡は門の軸の石段3本(屋外)になる** —
  「建屋は基本つながる」原則(§B-2)からの逸脱として明示する。屋敷指図が出れば見直す。
  下段のベンチが自然のまま14×14間取れるので、この位置なら**造成をほとんど要しない**
  (盛土0.4以下)ことが位置決めの決め手になった。
- **米蔵は通用門の直近=中段(北隅)に置く【[高知2000]A の類型に従う】** — 「**米蔵は搬出入門の直近**」
  (大坂東屋敷「米出御門」)。⚠ 以前は「街路に面する辺が東辺しかなく搬出入門を蔵の近くに開けない」
  という区画由来の制約から A と逆に置いていたが、**通用門を開けたことでその制約は消えた**(2026-08-23 裁定)。
  中段(北隅)は通用門の直近であり、[西川1959](A)の「御殿を囲む中間帯=土蔵・作事小屋」にも合う。
  これで**勝手の動線が御式台前の白洲を通らなくなる**。
  ⚠ 面の高さは実測ベンチでないので、蔵の矩形で §3a の探索を回し直して地形に決めさせる(`_pending.kitasumi`)。
- **主面の勝手裏の土蔵は文書・什器蔵として残す【設計判断U】** — 米蔵を北隅へ移すぶん、棟数を再検討する。
- **家中長屋を建てる【存在=確度S / 位置・延長=U】** — 被害書上の藤岡屋日記「御殿向**家中長屋**等
  所々破損」は「表御長屋**潰**」(真田家文書)と被害の程度が別で、**表長屋とは別棟の家中長屋**を示す。
  ⚠ 以前は「外周の塀が隣家所有だから長屋帯を回せない」として置いていなかったが、**これは誤り**
  (2026-08-23 是正)。帰属の裁定([丸の内三丁目]A)が言うのは「**境の囲いは1条**」までで、
  **自領の内側に犬走りを取って建てることは妨げない**。隣家の塀の裏に自分の長屋を建てるのは普通の作り。
  **位置は確度Aの型に従い、外周に沿って連続した帯として回す** — [西川1959](A)「御殿を囲む中間帯の
  外側に定府家臣の長屋」/ [福井図](A)「長屋は外周に連続した帯」。境界からは犬走り1間を取る。
  長屋は御殿と同じ面に載る必要がないので、**辺ごとにその場所の自然の高さを採る**(§B-1)。
  ⚠ 2026-08-23 時点の3本は境界から16〜31m内側に浮いており、この型に反する(`_pending.kachu` で是正待ち)。
  **規模(必要床面積)は算出しない【確度U】** — 石高→軍役→江戸詰人数の比率に典拠がなく、
  当家の江戸詰人数の史料も無い。確度Aで押さえられるのは1戸の実寸だけ
  ([西川1959] 岡山藩江戸向屋敷 大工方仕様書)。推測に推測を掛けた数字を図に書けば
  §A-3/§A-5 が禁じる既成事実化になる。**延長は外周に回した結果として出す。**

- **書院上段は12畳・広間は24畳に留める**【設計判断U — 「雁間=12畳」という規範史料は無い。
  雁間詰の格に対し帝鑑間以上の規模へ上げないための自制であって、史料値ではない】。
- **室名に将軍の御殿の語彙を使わない** — 番号法の続き間(三之間等)・遠侍・御用部屋・
  御湯殿上之間などは江戸城・二条城の語彙。藩邸では御番所・御用所・御次などに置く
  (松平邸検査で確立した規則)。
