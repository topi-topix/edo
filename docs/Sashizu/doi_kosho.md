## 屋敷の性格

三河刈谷藩 二万三千石。**譜代・雁間詰(**城主**。刈谷城を現に持つ — 「城主格」は城を持たない家への格の付与で別概念)**の上屋敷。外桜田永田町、三べ坂前身の
南北道の**西側に位置し、東面して門を開く**。北と西は松平出羽守(松江藩)上屋敷と背中合わせ、
南は岡部内膳正(岸和田藩)上屋敷。跡地は駐日メキシコ大使館(永田町2-15)【典拠未取得=**?**】。

**基準年次=嘉永3年(1850)** — 基図の年次。より後の記録(安政2年の地震被害書上)は
「倒れる前の姿」として遡って使い、より前の記録(天保9年武鑑)は当主が先代の年次であることを断る。

- **基図と読図**: 尾張屋版 外桜田永田町絵図(嘉永3・NDL pid 1286657)を IIIF 実見。
  「土井大隅守」+家紋(**六つ水車**・実見)=上屋敷【⚠ **紋→家の対応に典拠が無い【確度?】** — 当たり先は『寛政重修諸家譜』土井氏・武鑑。実見の切り出し領域も未記録】、**文字の頭=東=表門は東辺**。
  読図の向きは**絵図の上=シーンの東**(方位盤を信じない — 三べ坂東街区で確立した読み)。
  上妻文庫の「**山王三部坂** 土井大隅守様」も、屋敷が三べ坂(三部坂)に面する傍証。
  CODH 江戸マップ 7-062 は刈谷藩上屋敷 [H231] と同定済み。
  天保9年武鑑「上 赤坂御門之内」(所在の確認のみ — 当主は先代の年次)。【確度 S/A】
- **当主**: 土井利善。天保元年、井上家(**当時 陸奥棚倉藩**。浜松復帰は弘化2年の正春の代)に生まれ、
  弘化4年に末期養子で家督・大隅守。
  **嘉永5〜6年は大坂加番で江戸不在**。安政5年奏者番(「雁之間席ヨリ」)、文久3年寺社奉行。
  慶応2年隠居。【確度 A — 柳営補任・大坂加番一覧の翻刻】
  ⚠ 参府の年回り(隔年6月・丑卯巳未酉亥)は**典拠が無い【確度 ?】**。刈谷市史近世編か武鑑の交代月を当てる。
  仮に正しくても「嘉永3=在国」は**通年ではない**(前年6月に参府していれば前半は在府)。
- **家格=雁間**: 安政地震の被害書上(岡本家文書)が殿席順の列挙で当家を**雁間の部**に置き、
  柳営補任も「雁之間席ヨリ」。刈谷土井家は利勝三男利長の分家(新規取立)なので、譜代古参の
  帝鑑間ではなく**城主格新参の雁間** — 御殿の書院はこの格で作り、上へ上げない。【確度 A】
- **区画は町割の正典 `parcels.json` の `doi` と同値**(ユーザーのブックマーク角+敷地割ツールでの
  修正・確度U)。元文3年規定の欄に 2〜3万石の欄は無いが、**[西川1959](A・本文入手済)が引く
  『青標紙』拝領屋敷格坪覚には 2〜3万石の欄が実在する**([西川1959]A の直接値)。
  ⚠ **区画多角形はユーザーのブックマーク角由来(U)なので、実測坪と規定坪の比を格の議論に使わない。**
  規定坪数(格坪)と実拝領は一致しないのが常で、当邸の実拝領は『屋敷渡預絵図証文』(未入手)を待つ。
  比較に使えるのは P/U 由来でない例だけ(高知藩江戸上屋敷 7,052坪 ↔ 10〜15万石=7,000坪)。
  ⚠ 渡辺備中守の「1.45倍」も**下書き実測**由来(P/U)なので、引き合いに出さない。
  ⚠ 2026-08-23 に**内挿(当方の操作=U)を外した** — 直接値があるので挟む必要がない。
  幕府側の坪数記録(『屋敷渡預絵図証文』)の繰りは未実施。
- **屋敷指図(建物平面)は現存未確認。** 国書DB・NDL・内閣文庫・ジャパンサーチ・刈谷市
  古典籍DBを横断して無し。刈谷市歴史博物館・愛知県公文書館への照会が次の一手。
  **御殿の構成は類型(B)、室割りは想定(?)。**

## 外周 — 一次記録から直接言える【確度 S】

**安政2年(1855)江戸地震の被害書上5点**(いずれも『新収日本地震史料』所収・東大地震研DBで実見)が
当屋敷の外周をそのまま記している:

| 記録 | 記事 |
|---|---|
| 安政度地震大風之記 | 「上 土井大隅守殿 **右外構練塀潰**其外所々大破」(岡部・安部と3邸一括) |
| 別本 藤岡屋日記 | 「一土井大隅守**表門倒**、其外御殿向家中長屋等所々破損」 |
| 岡本家文書(雁間の部) | 「一土井大隅守様 **表門倒玄関大破**」 |
| 真田家文書(下座見) | 「**表御長屋潰** 土井大隅守様」 |
| 上妻文庫 | 「一山王三部坂土井大隅守様**表御門倒**」 |

- **表(東)=表長屋+表門、当家が建てる辺=練塀** — 一次記録が確定するのは**種別だけ**。
  ⚠ 「安政度地震大風之記」は岡部・安部と**3邸一括**の記事で、**どの辺の塀か・誰が所有した塀かは
  書かれていない**。設計では南辺3辺は岡部所有、西辺2辺は松平所有の**練塀**としている(いずれも当家は建てない)。
  内閣府報告書の「外の長屋のねり壁」は現代語訳で、**原文は「外構練塀」**。
- 被害像は「表門倒+玄関大破+表長屋潰+外構練塀潰、御殿は倒壊せず(所々破損)」で一貫。
  隣の松江・岡部は「表門無別条」— **当邸だけ表門が倒れた**。
- 嘉永期の姿としては「安政2年に倒れる前の門」を建てる。被災の再現はシーンの基準年次
  (嘉永)の範囲外。
- **表門が東辺にあることの確度は分解して書く** — 切絵図の文字の頭の向きの**実見=A**、
  それが表門の向きを指すという読み(切絵図の作法)=**B**、結論としての東辺は
  **街路に面する辺が東辺・ジョグ・楔しか無いという幾何からも支持される**。
  ⚠ 一次史料が「表門は東辺」と書いているわけではないので **S を付けない**
  (sources.md は同じ図の岡部について「状況証拠=確度U止まり」と明記している)。

## 表門 — 長屋門+片番所(格子付)・片潜門

**番所と潜戸の形式**は **[下丸子武家屋敷門]** の官製構造形式「**片番所格子付、片潜門**」による。
東京都教育委員会の掲示が「遺存例の少ない**1〜5万石の小大名格**の形式」と明記しており、
二万三千石はこの帯に入る【石高帯=**A**。採用はユーザー裁定U(2026-08-23)】。
⚠ **同門の屋根(入母屋造)は採らない。** 理由は下の「屋根」を見よ。
**門の実在は確度S**(被害書上5点が「表門倒」を記す)。⚠ **位置(東辺)に S は付かない** —
一次史料が「表門は東辺」と書いているわけではない(上の「表門が東辺にあることの確度は分解して書く」を見よ)。

**型式は長屋門を採る【B】**(2026-08-23 決定)。理由は三つ。

① **当家に表長屋が実在した=確度S。** 典拠は **真田家文書(下座見)「表御長屋潰 土井大隅守様」**
(『新収日本地震史料』所収、東京大学地震研究所 地震史料集DBで実見)— 当屋敷を名指しする一次記録。
⚠ **ただしSなのは「在ったこと」までで、この一行は長屋の位置を書いていない。**
「表」を屋敷の表向(公の側)と読み、街路に面する辺が**東辺しか無い**という幾何と、
[福井図](A)「長屋は外周に連続した帯」から、**東辺に載せるのは確度B**の推論である。
つまり「門と同じ辺に長屋が通る」までを言うと **S+B** であって S ではない。

② **最も格の近い官製記録付きの現物**([山脇武家屋敷門]A = **5万石・譜代・上屋敷の表門**)が
「**長屋門**、桁行21.8m…**切妻造**」。石高は倍以上違うが、譜代・上屋敷・表門という条件は当家に最も近い。

③ [西澄寺]A も桁行9間で完結する門長屋で、一棟に納める形が実在する。

**屋根は切妻**【確度B — **型式からの帰結**】。根拠は次の一点に限る —
**長屋門の官製現物2件がいずれも切妻である**。当家は長屋門を採るのでその線に従う。

| 現物 | 型式 | 屋根 |
|---|---|---|
| [山脇]A(5万石・譜代・上屋敷) | **長屋門** | 切妻造 |
| [西澄寺]A(門長屋・一棟で完結) | **長屋門型** | 切妻造 |
| [黒門]A(32.5万石) | 独立門 | 入母屋造 |
| [赤門]A(独立の三間薬医門) | 独立門 | **切妻造** |
| [下丸子]A(1〜5万石) | **?** | 入母屋造 |

⛔ **[下丸子] の入母屋には説明を付けない【確度?】。** 同門が長屋門か独立門かが官製文言から定まらず、
**留保したまま残す**。これまで二つの説明を試みたが、いずれも反証された:
① 「二度の移築で端部を納め直した」→ 長屋から切り縮められたことが記録で確かめられる唯一の現物
[山脇]A(原形58間 → 門と左右番所のみ移築)が**切妻のまま**で反証(2026-08-23)。
② 「独立門=入母屋だから同門は独立門型」→ **[赤門]A(独立の三間薬医門)が切妻造**で反証(2026-08-24)。
「官製文言の語順が [黒門] と同じ」という論拠も採らない — **文化庁と都教委は発行主体が違い、
記載様式の差は型式の証拠にならない**。

⚠ したがって**番所と潜戸を下丸子から採るのは型式をまたぐ移植**であり、確度は A でなく **B/U**。
番所の数と潜戸の数は階梯表が型式を越えて石高で並べる指標なので移してよいと判断した。
[山脇]A(長屋門・5万石)が「片流**面出**番所」= 室ごと張り出すのに対し、下の帯の下丸子が
格子窓だけなのは、**格が下がるほど張り出しが減る**向きで整合する。

**これらをまとめて解くのは [下丸子] の実測図**(未解決を見よ)— 桁行・梁間・門戸部の間数に加え、
**「長屋門か独立門か」**がそこで決まる。

⚠ **「表門倒」と「表御長屋潰」を独立門の証拠に使うのはやめる。** この二語は**別々の文書**
(岡本家文書と真田家文書)に現れるもので、一つの記事の中で対比されてはいない。
加えて**長屋門でも門の部分と長屋の部分は別の名で呼ばれる**ので、名が分かれること自体は型式を弁別しない。
独立門の可能性が消えたわけではないが、**現状これを支える積極的な典拠は無い**。

- **番所は長屋門の躯体内・出格子の「片番所」**【階梯表B + 採用はユーザー裁定U(2026-08-23)】。
  `historical-layout.md` の門の格式階梯が **5万石以下=長屋門+片番所・出格子・片潜り門** とし、
  ⚠ **一番弱い環はここ。** 現物2件([山脇]A=5万石・[西澄寺]A=5〜10万石格)が裏づけるのは
  階梯表の**上の段**である。当家が乗る段は 2026-08-23 に**下丸子門の官製記述で立て直した** —
  [しんこうWeb 表門]B の「五万石以下の**旗本**屋敷」は、この掲示が伝言ゲームで崩れたものと説明がつく
  (旗本は1万石未満)。⛔ ただし **「1〜5万石」は所有者から出た数字ではなく、都教委が"形式から"
  下した判定**であり、形式→石高の推論を形式判定で裏づける構図なので**独立検証ではない**。
  元の屋敷の伝承は池田31.5万石/毛利36.9万石/生坂1.5万石の三説で互いに矛盾する【?】。
  ⚠ **番所は張り出さない。** 官製は「片番所**格子付**」で、現物でも壁面から出るのは庇付きの格子窓だけ、
  番所の室は躯体内に納まる(目測0.4〜0.6m)。室ごと一間張り出すのは [山脇]A(5万石・「片流**面出**番所附属」)
  の姿で、**下の段に持ち込むと格が1段上がる**。旧設計値の1.7mはこれにあたるので撤回した。
  番所と潜戸はともに**向かって左**、右は板壁のみ【現物1件の写真読み=P/U】。
  ⚠ **『青標紙』1万石条の外挿による「両番所」は撤回した**(2026-08-23)。
  「万石級の標準形」という断定も撤回する — 故実書の規範と現物の階梯が食い違う論点で、
  **現物で裏の取れる階梯表を採る**という判断。
  桁行は門戸部(中央の門扉+**片潜り戸**+両側の板壁)に番所を足した間数で取る
  【**西澄寺A からの減算=B / 上位格の間数をそのまま踏襲した点と江戸間への換算=U**】。
  ⚠ 減らしたのは潜戸1間だけで、**扉・板壁・番所の間数は上位格のまま流用している**。
  また西澄寺の実測は1間あたり1.87〜1.89mで**江戸間1.818ではない** — 借りているのは間数であって寸法ではない。
  ⚠ 板壁1+潜戸1+扉2+板壁1 と並べると**扉の中心が門戸部の中心から半間ずれる**。
  現物は**潜戸と番所を片側へ寄せ、反対側の長い板壁で釣り合わせて扉を中央に置いている**ように見えるので、
  総長を変えずに「番所+潜戸+扉+板壁2」の割りに読み替え、**扉の中心を躯体の中心に置く**【写真読み=U】。
  ⚠ [西澄寺武家屋敷門](A)は5〜10万石格で門戸部が広く**両潜戸**なので、寸法をそのまま借りない。
  潜戸を片側に減らして一間落とした。**下丸子門の実測**が要る(2026-08-23 に調べたが Web に無い)。
  棟高は隣接の表長屋の実測に合わせ、梁間も同実測とほぼ一致する。
  ⚠ 旧設計値は門戸部だけでも足りず番所が入らなかった — 2026-08-23 に是正し、
  辺5の割り付け(表長屋の s 区切り・段の境界・土留めの位置)も連動して更新した。
  **寸法は `doi_sashizu.json` の `gate` が正典**(文章に写さない)。
- **袖塀は無い** — 長屋門の両袖がそのまま表長屋へ連続する([西澄寺]A(門長屋・一棟で完結)の型)。囲いの線は 表長屋(南)→長屋門→表長屋(北) の一連。
- 石垣畳出は使わない【**設計判断・確度U** — 畳出の石高規範は sources.md に無い。
  基壇は地形を受ける土留めとしてのみ使う】。

## 囲いの帰属 — 外周の大半は隣家所有

**岡部境(南辺3辺・184.7m)は自然の段丘の肩を走り、土井側が終始高い。** 区画多角形どうしは
0.00m で一致しており、「岡部の塀が共有境界に載っていない」という旧宿題は解消した。
当家で建てる物は増えないが、**この辺へ向けて盛土してはならない** — 盛れば土が隣地へ落ちる。
現状は素地のままなので適合している。

⚠ **段差を言うときは測った幅を書く。** 以前ここに「最大5.2m」と書いていたのは**境界の両側 ±3m**で
測った値で、岡部が ±1.2m で出した 2.1m と矛盾しない(同じ土手を違う幅で測っただけ)。
**幅を書かない段差の値は隣家と突き合わない。**

⚠ **地盤の食い違いは無い。** 岡部は敷地内を**江戸期の復元地盤**(近代の日比谷高校の造成を戻したもの)
で設計しているが、**区画の外は現況のまま**としているので、**境界線上の値は当方の現況実測と完全に一致する**
(辺9 の s=0/20/40/60/80/90/100/120/140 で 16.06/23.47/26.33/26.40/25.88/23.31/21.87/19.22/18.37)。
同じ境界を別の地盤の上で設計してはいない。

2026-08-23 に岡部が天端を引き直した結果、**土井側から見た埋没は最大0.21m**(`N_Hei1`)/ 0.08m(`N_Hei3`)まで下がった。

**松平境も同じ測り方で実測した**(境界から土井側へ1.2m)。`S_Hei_E2` で +0.08m、`S_Hei_C` で **+0.73m** 基壇が埋まる。後者は松平側が「土井側の高みでは基壇が最大0.7m埋まる=許容」と明記しているものと**独立に一致した**。⚠ ただし岡部境では埋没を0まで詰め、松平境では0.73mを許容しており、**規則が家ごとに違う**。揃えるかは隣家の裁定待ち。

⚠ **西辺は全区間が練塀**(2026-08-23 に松平側で改訂。以前は「斜面は木柵」としていたが、
**相手のある屋敷境は斜面でも練塀で通す**という判断に変わった — 岡部境で先に採った方針に揃えたもの)。
斜面なので天端は区間ごとに落とし、起伏は**石垣基壇**で吸う。当屋敷は建てない。

## 敷地の造成 — **地形を測って、その自然の平場を面にする**

⚠ **2026-08-23 ユーザー指示で原則を入れ替えた。** それまでは「面の高さを先に決めて地形を合わせる」
作りで、玄関棟を1m を超える盛土に載せ、窪みを埋めて平らにしていた。
**いまは逆** — 先に地形を測って自然の平場(ベンチ)を見つけ、**その高さをそのまま面にする**。
窪みは埋めず、窪みのまま使う。

実測で見つかった平場は**7枚**(2026-08-23・確度P。**範囲と高さは `doi_sashizu.json` の
`planes` / `terraces` が正典** — この表は何のための平場かを示すだけで、数値を写さない):

| 平場 | 何を置くか |
|---|---|
| 厩のベンチ | **厩棟**(白洲より一段低い) |
| 下段のベンチ | 表役所・白洲 |
| 前庭のベンチ | 前庭の白洲・門内北 |
| 北隅の平坦部 | **米蔵** |
| **窪み** | **玄関棟** — 埋めずに窪みのまま面にした |
| **北東の横長の帯** | **書院棟** |
| **大平坦地** | 中奥・奥向・台所・土蔵 |

**棟は自然地形に素で載せる**(合格の目安 |設計面 − 自然地形| ≤ 0.5m)。造成は面の縁の摺り付けが主で、
切盛は [菊地2003] の 1〜4m の内。**量は指図の「切盛」の節の表で読む** — この文章に数値を写さない。

- **北東の肩は造成しない** — 奥庭の築山にそのまま使う。
- ⚠ **面は要る広さだけ取る。** 2026-08-23 の検図で二つ直した。(a) **厩**を白洲の高さへ引き上げていた
  (全面が盛土)→ 厩自身のベンチへ降ろし、白洲からは**土の斜路**で降りる(馬は石段を降りない)。(b) **米蔵の郭**が米蔵の6倍あった
  → 自然の平坦部に合わせて絞り、街路に面する表長屋(北2)の下だけを石垣基壇として別に立てた。
  **基壇が全面盛土なのは設計どおり**(斜面の街路に建屋を載せる型)で、郭の盛土とは別に数える。
- 段のつなぎは 門前面→前庭面→玄関の郭 の三段で御式台に達し、**外の石段は門の軸の二つだけ**
  (K_Monzen と K_Genkan。K_Shu は勝手の外階段、R_Umaya_Sunro は厩へ降りる土の斜路、K_Kita は米蔵の郭への段)。
  玄関の郭から書院の郭・主面へは**屋内の階段廊下**で上がる(落差は `kaidans`/`links` を引く)。
- ⚠ **土留めは落差のある縁にだけ置く。** 天端と法尻の差を実測で確かめ、設計値に `drop` として持たせ、
  生成器が壁高(4s)との釣り合いと、**高さの違う段が接する辺すべてに壁が載っているか**を総当たりで検査する。
- 段の外は**法面**(盛土1:1.5/切土1:1)で現地形へ摺り付け、段の縁に垂直の段差を残さない。

地形が込み入っているので、**断面を東西・南北の格子で通した**(本数と位置は設計値 `sections`)。
**造成の話は現況図から始める** — 段彩(2m)と等高線で造成前の地形を描き、隣の松江松平・岡部の
区画も重ねてある。**切盛図**はその地形と造成後の地盤の差を1間の格子で塗ったもので、
**暖色=盛土/寒色=切土/無彩=±0.3m以内/地の色=造成しない**。断面にも同じ配色を敷き、
**無造成の区間は地盤線に太い緑帯**を置いて「触っていない」ことを図の上で示す。

## 動線 — 表門を入ってからどう動くか【すべて設計判断U】

当屋敷の指図が無いので、動線は**類型と地形から構成した想定**。設計値 `routes`、図は「動線」の節。

- **表向(客・使者)** — 表門 → 白洲 → 石段 → 前庭の白洲 → 石段 → 玄関の郭(窪み) → 御式台。**外の石段は二つだけ**(門の軸の K_Monzen と K_Genkan。K_Shu は勝手の外階段)。
  **門の軸の一本道**で、登るほど格が上がる。門を入って正面に御殿が見えず、二度踊り場を挟んでから
  玄関に達するので、屋敷の奥行が実寸以上に効く。式台で履物を脱ぎ、御玄関 → 取次へ。
- **役方(日勤)** — 表門 → 白洲を南へ折れる → 門前面 → 表役所の郭 → 表役所棟。
  **下段(19.2)だけを通るので**外の**石段を一つも使わない**(⚠ 表役所の郭へ入る所だけ、盛土の法面を2mで0.6m登る — ここに3段を切るか動線を西へ寄せるかは実装時に決める)。 表役所を門前面に置いた最大の理由がこれで、
  毎日出入りする役人を段で妨げない。自然のベンチがそのまま使えたので造成も要らない。
- **厩・供廻り** — 表門を入ってすぐ南、白洲から**土の斜路**で一段降りて厩の郭へ。
  乗物と馬を白洲へ立ち入らせない。**厩を一段下げたのは自然の高さに合わせたため【設計判断U】** —
  「一段低く置く」ことの類型的典拠は典拠台帳に無い(段丘上の屋敷が複数の平坦面を持つこと自体は
  [富山市埋文]A まで)。**馬は石段を降りないので、ここだけ石段でなく斜路にする。**
  排水が下へ流れる利もあるが、これは典拠のない工学的推論【U】。
- **奥向** — 御式台 → 玄関棟 → 渡廊下 → 居間棟(中奥) → **御錠口** → 奥棟。
  奥へ入る廊下はこの一本だけ。
- **勝手(賄・物資)は通用門から入る【存在=B([福井図]A に小門の実例。通用口の**数**を縛る規定は典拠台帳に無い)/ 位置=U】** —
  表長屋(北)に潜りを開ける。**ここが街路と屋敷内が水平で取り付く唯一の点**で、位置はそれで決まる。
  ⚠ 以前は「門を増やすと格式に触れる」として保留していたが、**これも誤り**(2026-08-23 是正)。
  格式が規定するのは**表門の型式**(長屋門か・番所を出格子にするか)であって**通用口の数ではない**。
  現に南端には木戸(Ura_Kido)が既に開いており、二つ目を保留する筋が通らなかった。
  **米は御米蔵へ納まる**が、⚠ **蔵は通用門より一段高く、荷は石段を上げる。**
  街路は北端でも米蔵の郭の高さまで登らないので、**当敷地では段差なしの搬入は成立しない** —
  [高知2000] の援用は「**直近**」に限り、「段差なしで荷が入る」は満たさないと明示する。
  蔵は石段の上り口の直上に寄せて担ぎ距離を最短にした。
  台所へは米蔵の郭 → 書院の郭 → 主面と回る。**表門も門内の白洲も御式台前の白洲も通らない。**
