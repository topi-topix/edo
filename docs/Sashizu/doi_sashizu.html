基準年次と確度

基準年次=嘉永3年(1850) — 基図(尾張屋版切絵図)の年次。安政2年の地震記録は「倒れる前の姿」として遡って使い、武鑑(天保9年版で所在確認)は当主が先代の年次であることを断る。
当主=土井利善(弘化4年家督・大隅守/嘉永5-6年は大坂加番で江戸不在/安政5年奏者番)。
外周の構成は当屋敷の一次記録から直接言える(確度S) — 安政江戸地震の被害書上5点が「表門倒・玄関大破」「表長屋潰」「外構練塀潰」を記す。表=表長屋+長屋門、他辺=練塀。
屋敷指図(建物平面)は現存未確認 — 御殿の構成は類型(B)、室名・畳数は想定(?)。書院は雁間詰城主格で作り、帝鑑間格へ上げない(確度A=殿席の同時代史料2点)。区画多角形はユーザーのブックマーク角(U)。

敷地は4つの水平面+造成しない斜面。造成も囲いも面から決め、囲いの天端=面の高さ。面の高さは自然地形の段(ベンチ)に載せて盛土を抑える。面の高さと縁の位置は自然地形の段(ベンチ)と法肩から決めた — 全10段が[菊地2003] の 1〜4m に収まり、大半は 1m 未満。表役所の郭は自然のベンチにほぼ素で載る。南東の低み・下段と上段を分ける段丘崖・南西の谷の頭・西の低みは造成しない — 樹林と庭のまま、面の縁に竹垣。斜面の植生は松+雑木(竹林にしない=[橋本・堀1998])。東辺の道は南へ大きく落ちるので、表長屋(南)の基壇石垣が道へ露出する(台地肩)。街路・隣地への影響はゼロ — 面の造成は区画線で切り、境界の高低差は垂直の基壇石垣で受ける。

屋敷の性格

三河刈谷藩 二万三千石。譜代・雁間詰(城主格)の上屋敷。外桜田永田町、三べ坂前身の 南北道の西側に位置し、東面して門を開く。北と西は松平出羽守(松江藩)上屋敷と背中合わせ、 南は岡部内膳正(岸和田藩)上屋敷。跡地は駐日メキシコ大使館(永田町2-15)。

基準年次=嘉永3年(1850) — 基図の年次。より後の記録(安政2年の地震被害書上)は 「倒れる前の姿」として遡って使い、より前の記録(天保9年武鑑)は当主が先代の年次であることを断る。

  • 基図と読図: 尾張屋版 外桜田永田町絵図(嘉永3・NDL pid 1286657)を IIIF 実見。 「土井大隅守」+家紋(六つ水車・実見)=上屋敷、文字の頭=東=表門は東辺。 読図の向きは絵図の上=シーンの東(方位盤を信じない — 三べ坂東街区で確立した読み)。 上妻文庫の「山王三部坂 土井大隅守様」も、屋敷が三べ坂(三部坂)に面する傍証。 CODH 江戸マップ 7-062 は刈谷藩上屋敷 [H231] と同定済み。 天保9年武鑑「上 赤坂御門之内」(所在の確認のみ — 当主は先代の年次)。【確度 S/A】
  • 当主: 土井利善。天保元年浜松藩井上家生まれ、弘化4年末期養子で家督・大隅守。 嘉永5〜6年は大坂加番で江戸不在。安政5年奏者番(「雁之間席ヨリ」)、文久3年寺社奉行。 参府は隔年6月(丑卯巳未酉亥)。慶応2年隠居。【確度 A — 柳営補任・大坂加番一覧の翻刻】
  • 家格=雁間: 安政地震の被害書上(岡本家文書)が殿席順の列挙で当家を雁間の部に置き、 柳営補任も「雁之間席ヨリ」。刈谷土井家は利勝三男利長の分家(新規取立)なので、譜代古参の 帝鑑間ではなく城主格新参の雁間 — 御殿の書院はこの格で作り、上へ上げない。【確度 A】

表門 — 長屋門+出格子(格子出)番所

型式は『青標紙』の「1万石大名=長屋門+格子出両番所」の条を、二万三千石(城主格)へ 外挿した設計判断【B→実質U — 故実書は規範であり、しかも当該石高の条ではない。 sources.md の[表門格式表]が石高別門形式表の使用に⛔を付けた推論と同型であることを自覚して使う】。 門の実在と位置(東辺)は確度S。なお被害書上が「表門倒」と「表御長屋潰」を別項で立てることは、 長屋門(一体構造)でなく独立門+表長屋だった可能性も残す — 決定的ではないが、確度の限界として記す。

  • 番所は長屋門の躯体内(出格子)。放れ門+張出番所(松江=国主)とも、 独立門+片番所(岡部=設計判断)とも違う、万石級の標準形。
  • 袖塀は無い — 長屋門の両袖がそのまま表長屋へ連続する(岡部の検討で確認済みの 「門長屋」型)。囲いの線は 表長屋(南)→長屋門→表長屋(北) の一連。

敷地の造成 — 地形を測って、その自然の平場を面にする

⚠ 2026-08-23 ユーザー指示で原則を入れ替えた。 それまでは「面の高さを先に決めて地形を合わせる」 作りで、玄関棟を平均1.65m の盛土に載せ、窪みを埋めて平らにしていた。 いまは逆 — 先に地形を測って自然の平場(ベンチ)を見つけ、その高さをそのまま面にする。 窪みは埋めず、窪みのまま使う。

動線 — 表門を入ってからどう動くか【すべて設計判断U】

当屋敷の指図が無いので、動線は類型と地形から構成した想定。設計値 routes、図は「動線」の節。

  • 表向(客・使者) — 表門 → 白洲 → 石段9段 → 前庭の白洲 → 石段9段 → 中段 → 石段7段 → 御式台。 門の軸の一本道で、登るほど格が上がる。門を入って正面に御殿が見えず、二度踊り場を挟んでから 玄関に達するので、屋敷の奥行が実寸以上に効く。式台で履物を脱ぎ、御玄関 → 取次へ。
  • 役方(日勤) — 表門 → 白洲を南へ折れる → 門前面 → 表役所の郭 → 表役所棟。 下段(19.2)だけを通るので石段を一つも使わない。 表役所を門前面に置いた最大の理由がこれで、 毎日出入りする役人を段で妨げない。自然のベンチがそのまま使えたので造成も要らない。
  • 厩・供廻り — 表門を入ってすぐ南。乗物と馬を白洲へ立ち入らせない。
  • 奥向 — 御式台 → 玄関棟 → 渡廊下 → 居間棟(中奥) → 御錠口 → 奥棟。 奥へ入る廊下はこの一本だけ。
  • 勝手(賄・物資)は通用門から入る【存在・位置=U】 — 表長屋(北)の s=64 に潜りを開ける。 ここは道が21.4で前庭面21.9とほぼ同高なので、段差なしで荷が入る。 ⚠ 以前は「門を増やすと格式に触れる」として保留していたが、これも誤り(2026-08-23 是正)。 格式が規定するのは表門の型式(長屋門か・番所を出格子にするか)であって通用口の数ではない。 現に南端には木戸(Ura_Kido)が既に開いており、二つ目を保留する筋が通らなかった。 これで米も薪も表門と門内の白洲を通らず、登りも 7.4m・19段 → 5.2m・15段 に減る。

建物の構成 — 連続御殿複合【確度 B=類型/室割りは ?】

2万3千石の小藩なので棟数を絞る: 玄関+書院(表)/居間(中奥)/奥棟+女中部屋(奥向)/ 台所/表役所(前庭面)/土蔵2(主面・勝手裏)/厩。開放地は白洲と中庭だけ。

  • 表役所を門前面(門を入って南の下段)に置く【設計判断U】 — [高知2000](A)の 「中央に御殿と役所」の類型を採らず、[浜御庭図](B)の門まわり管理クラスタを採る。 この結果、表向が二つの標高に分かれ、御殿との連絡は門の軸の石段3本(屋外)になる — 「建屋は基本つながる」原則(§B-2)からの逸脱として明示する。屋敷指図が出れば見直す。 下段のベンチが自然のまま14×14間取れるので、この位置なら造成をほとんど要しない (盛土0.4以下)ことが位置決めの決め手になった。
  • 土蔵2棟は主面の勝手裏(奥蔵)【設計判断U】 — 米蔵ではなく文書・什器蔵の想定。 米蔵=搬出入門直近の類型([高知2000] A)とは逆だが、当家は街路に面する辺が 東辺しかなく、搬出入門を蔵の近くに開けない区画由来の制約を優先した。
  • 家中長屋を建てる【存在=確度S / 位置・延長=U】 — 被害書上の藤岡屋日記「御殿向家中長屋等 所々破損」は「表御長屋潰」(真田家文書)と被害の程度が別で、表長屋とは別棟の家中長屋を示す。 ⚠ 以前は「外周の塀が隣家所有だから長屋帯を回せない」として置いていなかったが、これは誤り (2026-08-23 是正)。帰属の裁定([丸の内三丁目]A)が言うのは「境の囲いは1条」までで、 自領の内側に犬走りを取って建てることは妨げない。隣家の塀の裏に自分の長屋を建てるのは普通の作り。 北(松平境の裏)・西(西の低みの法肩の手前)・表(下段の郭、表役所の南)の3本を、 いずれも自然地形の素直な帯へ回す。南辺は台所棟と区画の狭まりで帯が取れないので置かない。
  • 書院上段は12畳・広間は24畳に留める【設計判断U — 「雁間=12畳」という規範史料は無い。 雁間詰の格に対し帝鑑間以上の規模へ上げないための自制であって、史料値ではない】。
  • 室名に将軍の御殿の語彙を使わない — 番号法の続き間(三之間等)・遠侍・御用部屋・ 御湯殿上之間などは江戸城・二条城の語彙。藩邸では御番所・御用所・御次などに置く (松平邸検査で確立した規則)。
  • 玄関は「玄関大破」(S)の玄関 — 式台+玄関+御番所・使者之間+取次。 供待は長屋門の躯体内に取る(位置は確度?)。
  • 奥向へ入る廊下は御錠口の一本だけ【設計判断U】。棟数7・土蔵2棟も同じく類型からの設計判断。
  • 池は掘らない(典拠なし)。奥庭は築山・梅(非開花の株 — 季節則)。稲荷社は屋敷神の 一般類型【B・位置はU】。
