棟は自然地形に素で載せる(合格の目安 |設計面 − 自然地形| ≤ 0.5m)。造成は面の縁の摺り付けが主で、 切盛は [菊地2003] の 1〜4m の内。量は指図の「切盛」の節の表で読む — この文章に数値を写さない。

  • 北東の肩は造成しない — 奥庭の築山にそのまま使う。
  • ⚠ 面は要る広さだけ取る。 2026-08-23 の検図で二つ直した。(a) 厩を白洲の高さへ引き上げていた (全面が盛土)→ 厩自身のベンチへ降ろし、白洲からは土の斜路で降りる(馬は石段を降りない)。(b) 米蔵の郭が米蔵の6倍あった → 自然の平坦部に合わせて絞り、街路に面する表長屋(北2)の下だけを石垣基壇として別に立てた。 基壇が全面盛土なのは設計どおり(斜面の街路に建屋を載せる型)で、郭の盛土とは別に数える。
  • 段のつなぎは 門前面→前庭面→玄関の郭 の三段で御式台に達し、外の石段は門の軸の二つだけ (K_Monzen と K_Genkan。K_Shu は勝手の外階段、R_Umaya_Sunro は厩へ降りる土の斜路、K_Kita は米蔵の郭への段)。 玄関の郭から書院の郭・主面へは屋内の階段廊下で上がる(落差は kaidans/links を引く)。
  • ⚠ 土留めは落差のある縁にだけ置く。 天端と法尻の差を実測で確かめ、設計値に drop として持たせ、 生成器が壁高(4s)との釣り合いと、高さの違う段が接する辺すべてに壁が載っているかを総当たりで検査する。
  • 段の外は法面(盛土1:1.5/切土1:1)で現地形へ摺り付け、段の縁に垂直の段差を残さない。

地形が込み入っているので、断面を東西・南北の格子で通した(本数と位置は設計値 sections)。 造成の話は現況図から始める — 段彩(2m)と等高線で造成前の地形を描き、隣の松江松平・岡部の 区画も重ねてある。切盛図はその地形と造成後の地盤の差を1間の格子で塗ったもので、 暖色=盛土/寒色=切土/無彩=±0.3m以内/地の色=造成しない。断面にも同じ配色を敷き、 無造成の区間は地盤線に太い緑帯を置いて「触っていない」ことを図の上で示す。

動線 — 表門を入ってからどう動くか【すべて設計判断U】

当屋敷の指図が無いので、動線は類型と地形から構成した想定。設計値 routes、図は「動線」の節。

  • 表向(客・使者) — 表門 → 白洲 → 石段 → 前庭の白洲 → 石段 → 玄関の郭(窪み) → 御式台。外の石段は二つだけ(門の軸の K_Monzen と K_Genkan。K_Shu は勝手の外階段)。 門の軸の一本道で、登るほど格が上がる。門を入って正面に御殿が見えず、二度踊り場を挟んでから 玄関に達するので、屋敷の奥行が実寸以上に効く。式台で履物を脱ぎ、御玄関 → 取次へ。
  • 役方(日勤) — 表門 → 白洲を南へ折れる → 門前面 → 表役所の郭 → 表役所棟。 下段(19.2)だけを通るので石段を一つも使わない。 表役所を門前面に置いた最大の理由がこれで、 毎日出入りする役人を段で妨げない。自然のベンチがそのまま使えたので造成も要らない。
  • 厩・供廻り — 表門を入ってすぐ南、白洲から土の斜路で一段降りて厩の郭へ。 乗物と馬を白洲へ立ち入らせない。厩を一段下げたのは自然の高さに合わせたため【設計判断U】 — 「一段低く置く」ことの類型的典拠は典拠台帳に無い(段丘上の屋敷が複数の平坦面を持つこと自体は [富山市埋文]A まで)。馬は石段を降りないので、ここだけ石段でなく斜路にする。 排水が下へ流れる利もあるが、これは典拠のない工学的推論【U】。
  • 奥向 — 御式台 → 玄関棟 → 渡廊下 → 居間棟(中奥) → 御錠口 → 奥棟。 奥へ入る廊下はこの一本だけ。
  • 勝手(賄・物資)は通用門から入る【存在=B([福井図]A に小門の実例。通用口の数を縛る規定は典拠台帳に無い)/ 位置=U】 — 表長屋(北)に潜りを開ける。ここが街路と屋敷内が水平で取り付く唯一の点で、位置はそれで決まる。 ⚠ 以前は「門を増やすと格式に触れる」として保留していたが、これも誤り(2026-08-23 是正)。 格式が規定するのは表門の型式(長屋門か・番所を出格子にするか)であって通用口の数ではない。 現に南端には木戸(Ura_Kido)が既に開いており、二つ目を保留する筋が通らなかった。 米は御米蔵へ納まるが、⚠ 蔵は通用門より一段高く、荷は石段を上げる。 街路は北端でも米蔵の郭の高さまで登らないので、当敷地では段差なしの搬入は成立しない — [高知2000] の援用は「直近」に限り、「段差なしで荷が入る」は満たさないと明示する。 蔵は石段の上り口の直上に寄せて担ぎ距離を最短にした。 台所へは米蔵の郭 → 書院の郭 → 主面と回る。表門も門内の白洲も御式台前の白洲も通らない。
