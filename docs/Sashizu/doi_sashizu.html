基準年次と確度

基準年次=嘉永3年(1850) — 基図(尾張屋版切絵図)の年次。安政2年の地震記録は「倒れる前の姿」として遡って使い、武鑑(天保9年版で所在確認)は当主が先代の年次であることを断る。
当主=土井利善(弘化4年家督・大隅守/嘉永5-6年は大坂加番で江戸不在/安政5年奏者番)。
外周の構成は当屋敷の一次記録から直接言える(確度S) — 安政江戸地震の被害書上5点が「表門倒・玄関大破」「表長屋潰」「外構練塀潰」を記す。表=表長屋+長屋門、他辺=練塀。
屋敷指図(建物平面)は現存未確認 — 御殿の構成は類型(B)、室名・畳数は想定(?)。書院は雁間詰城主格で作り、帝鑑間格へ上げない(確度A=殿席の同時代史料2点)。区画多角形はユーザーのブックマーク角(U)。

敷地は4つの水平面+2つの斜面。造成も囲いも面から決め、囲いの天端=面の高さ。南西の谷(岡部の郭へ落ちる)と南東の低みは造成しない — 樹林と庭のまま、面の縁に竹垣。斜面の植生は松+雑木(竹林にしない=[橋本・堀1998])。東辺の道は南へ大きく落ちるので、表長屋(南)の基壇石垣が道へ露出する(台地肩)。街路・隣地への影響はゼロ — 面の造成は区画線で切り、境界の高低差は垂直の基壇石垣で受ける。

其八　表門まわり

長屋門(両番所は躯体内・出格子)。型式=青標紙の1万石の条からの外挿(確度B→設計判断)/実在と被災=安政地震の記録(S)

型式は『青標紙』の1万石大名の条(長屋門・番所格子出)を二万三千石(城主格)へ外挿した設計判断。安政二年の被害書上は「表門倒」— 嘉永期の姿として倒れる前の門を建てる。被害書上が「表門倒」と「表長屋潰」を別項で立てることは独立門の可能性も残す(確度の限界)。在庫部材の実寸が門口に合わない場合は縮小流用か新造(部材表参照)。石垣畳出は使わない(設計判断)。

屋敷の性格

三河刈谷藩 二万三千石。譜代・雁間詰(城主格)の上屋敷。外桜田永田町、三べ坂前身の 南北道の西側に位置し、東面して門を開く。北と西は松平出羽守(松江藩)上屋敷と背中合わせ、 南は岡部内膳正(岸和田藩)上屋敷。跡地は駐日メキシコ大使館(永田町2-15)。

基準年次=嘉永3年(1850) — 基図の年次。より後の記録(安政2年の地震被害書上)は 「倒れる前の姿」として遡って使い、より前の記録(天保9年武鑑)は当主が先代の年次であることを断る。

  • 基図と読図: 尾張屋版 外桜田永田町絵図(嘉永3・NDL pid 1286657)を IIIF 実見。 「土井大隅守」+家紋(六つ水車・実見)=上屋敷、文字の頭=東=表門は東辺。 読図の向きは絵図の上=シーンの東(方位盤を信じない — 三べ坂東街区で確立した読み)。 上妻文庫の「山王三部坂 土井大隅守様」も、屋敷が三べ坂(三部坂)に面する傍証。 CODH 江戸マップ 7-062 は刈谷藩上屋敷 [H231] と同定済み。 天保9年武鑑「上 赤坂御門之内」(所在の確認のみ — 当主は先代の年次)。【確度 S/A】
  • 当主: 土井利善。天保元年浜松藩井上家生まれ、弘化4年末期養子で家督・大隅守。 嘉永5〜6年は大坂加番で江戸不在。安政5年奏者番(「雁之間席ヨリ」)、文久3年寺社奉行。 参府は隔年6月(丑卯巳未酉亥)。慶応2年隠居。【確度 A — 柳営補任・大坂加番一覧の翻刻】
  • 家格=雁間: 安政地震の被害書上(岡本家文書)が殿席順の列挙で当家を雁間の部に置き、 柳営補任も「雁之間席ヨリ」。刈谷土井家は利勝三男利長の分家(新規取立)なので、譜代古参の 帝鑑間ではなく城主格新参の雁間 — 御殿の書院はこの格で作り、上へ上げない。【確度 A】
  • 区画はユーザーのブックマーク角(確度U)。元文3年規定の表に 2〜3万石の欄は無い — 前後の欄から内挿する(内挿は当方の操作)と約1.3〜1.8倍で、「規定より広い実例」 (渡辺備中守=1.45倍)の範囲。元文3年自体も確度B(原典未確認)。幕府側の坪数記録 (『屋敷渡預絵図証文』)の繰りは未実施。
  • 屋敷指図(建物平面)は現存未確認。 国書DB・NDL・内閣文庫・ジャパンサーチ・刈谷市 古典籍DBを横断して無し。刈谷市歴史博物館・愛知県公文書館への照会が次の一手。 御殿の構成は類型(B)、室割りは想定(?)。

外周 — 一次記録から直接言える【確度 S】

安政2年(1855)江戸地震の被害書上5点(いずれも『新収日本地震史料』所収・東大地震研DBで実見)が 当屋敷の外周をそのまま記している:

記録記事
安政度地震大風之記「上 土井大隅守殿 右外構練塀潰其外所々大破」(岡部・安部と3邸一括)
別本 藤岡屋日記「一土井大隅守表門倒、其外御殿向家中長屋等所々破損」

  • 表(東)=表長屋+表門、その他の辺=練塀 — 囲いの種別が当屋敷の一次記録で確定する。 内閣府報告書の「外の長屋のねり壁」は現代語訳で、原文は「外構練塀」。
  • 被害像は「表門倒+玄関大破+表長屋潰+外構練塀潰、御殿は倒壊せず(所々破損)」で一貫。 隣の松江・岡部は「表門無別条」— 当邸だけ表門が倒れた。
  • 嘉永期の姿としては「安政2年に倒れる前の門」を建てる。被災の再現はシーンの基準年次 (嘉永)の範囲外。

表門 — 長屋門+出格子(格子出)番所

型式は『青標紙』の「1万石大名=長屋門+格子出両番所」の条を、二万三千石(城主格)へ 外挿した設計判断【B→実質U — 故実書は規範であり、しかも当該石高の条ではない。 sources.md の[表門格式表]が石高別門形式表の使用に⛔を付けた推論と同型であることを自覚して使う】。 門の実在と位置(東辺)は確度S。なお被害書上が「表門倒」と「表御長屋潰」を別項で立てることは、 長屋門(一体構造)でなく独立門+表長屋だった可能性も残す — 決定的ではないが、確度の限界として記す。

  • 番所は長屋門の躯体内(出格子)。放れ門+張出番所(松江=国主)とも、 独立門+片番所(岡部=設計判断)とも違う、万石級の標準形。
  • 袖塀は無い — 長屋門の両袖がそのまま表長屋へ連続する(岡部の検討で確認済みの 「門長屋」型)。囲いの線は 表長屋(南)→長屋門→表長屋(北) の一連。
  • 石垣畳出は使わない【設計判断・確度U — 畳出の石高規範は sources.md に無い。 基壇は地形を受ける土留めとしてのみ使う】。

囲いは1条・境界の塀は隣家所有の裁定(確度U)に従う。当家の練塀が現れるのは 東辺南端(南東の低みの前)とジョグ・楔だけになる。

⚠ S と U の関係を正直に書く: 被害書上は当家名で「外構練塀潰」と記すが、当家所有の練塀は 外周のごく一部で、残りは隣家所有(U の裁定)。この記録は塀の種別(練塀)を保証するだけで、 どの辺の塀か・誰の所有かは語らない(「安政度地震大風之記」は岡部・安部と3邸一括の記事でもある)。 帰属を S 記録から論じない。逆に、この記録を「土井が南辺の塀を持っていた」傍証と読む説も 成り立ちうる — その場合は帰属裁定(U)の再考をユーザーに諮る。現行指図は U の裁定に従う。

敷地の造成 — 面から決める

敷地は4つの水平面+斜面(設計値 planes)。松平邸と同じ原則 — 面は一枚の水平面、 囲いの天端=面の高さ、段差は面の境(門・郭境の延長線・頂点)にだけ立つ。

  • 門前面 — 長屋門・白洲・厩。敷居=道なり。表門の軸に石段を二つ重ねて中段→主面へ登る。 東辺の道は南へ大きく落ちるので、表長屋(南)の基壇石垣が道へ露出する(台地肩)。 南縁は土留めで受け、その天端に竹垣 — 盛土の規範(1〜4m)を超える隅を素の法面にしない。
  • 東辺の南端 — 南東の低み(非造成)の前で内側に面が無いため、表長屋でなく 道なりの練塀とする(表長屋は面のある区間だけ)。木戸はこの練塀に道なりの敷居で開く。
  • 門前面(北) — 道の登りに合わせた小面。段は表門の開口と北袖で受け、 出入りは北袖の土留めの開口+石段の一箇所。
  • 中段 — 表役所・土蔵2棟。
  • 主面 — 御殿複合。北縁は松平の練塀(天端27.0)の裏に付く(面の高さと0.3差)。
  • 斜面(造成しない) — 南西の谷(岡部の郭へ落ちる)・南東の低み。樹林と庭 (植生は [橋本・堀1998] に従い松+雑木の3帯 — 設計値 slopeBands。竹林にしない)。
  • ⚠ 南辺(岡部境)は岡部の築地塀の天端より主面が高い。境界へ素で寄せず、 庭・法面の縁を挟む(取り合いの断面は実装前に岡部指図と突き合わせる)。

建物の構成 — 連続御殿複合【確度 B=類型/室割りは ?】

2万3千石の小藩なので棟数を絞る: 玄関+書院(表)/居間(中奥)/奥棟+女中部屋(奥向)/ 台所/表役所(中段)/土蔵2/厩。開放地は白洲と中庭だけ。

  • 書院上段は12畳・広間は24畳に留める【設計判断U — 「雁間=12畳」という規範史料は無い。 雁間詰の格に対し帝鑑間以上の規模へ上げないための自制であって、史料値ではない】。
  • 室名に将軍の御殿の語彙を使わない — 番号法の続き間(三之間等)・遠侍・御用部屋・ 御湯殿上之間などは江戸城・二条城の語彙。藩邸では御番所・御用所・御次などに置く (松平邸検査で確立した規則)。
  • 玄関は「玄関大破」(S)の玄関 — 式台+玄関+御番所・使者之間+取次。 供待は長屋門の躯体内に取る(位置は確度?)。
  • 奥向へ入る廊下は御錠口の一本だけ【設計判断U】。棟数7・土蔵2棟も同じく類型からの設計判断。
  • 池は掘らない(典拠なし)。奥庭は築山・梅(非開花の株 — 季節則)。稲荷社は屋敷神の 一般類型【B・位置はU】。
