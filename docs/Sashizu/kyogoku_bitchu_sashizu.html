屋敷の性格

丹後峯山藩 一万一千百四十四石。菊間詰(譜代格)の上屋敷。永田町、山王社の東の台地上。 北と西は丹羽左京大夫(二本松藩)上屋敷と、南は内藤紀伊守(村上藩)上屋敷と背中合わせで、 道に面するのは東辺だけ。跡地は国会議事堂〜衆議院議員会館の一帯。

基準年次=安政3年(1856)(CLAUDE.md)。安政江戸地震(安政2年10月2日)の翌年で、 描くのは復旧が済んだ姿。

  • 区画の同定: 尾張屋版 外桜田永田町絵図(NDL pid 1286657)の当区画に「京極備中守」。 家紋は四つ目結を原画像で実見(江戸マップ 7-082)【確度A】。 ⚠ 切絵図から読めるのは「当区画が京極の屋敷であること」までで、屋敷の別(上/中/下)は 本来は武鑑で取る。当家については上屋敷とする既往の判断([[sanno-buke-shanin]] 2026-08-11)を 引き継ぐが、武鑑の条は未確認【確度B】。
  • 当主: 京極高富。嘉永2年12月16日に従五位下備中守へ叙任し、安政期も備中守 (ほか周防守・主膳正)【確度B — Web二次(ja.wikipedia「京極高富」)。原典未確認】。 基準年次の安政3年に「備中守」で正しい。⭐ 当プロジェクトの識別子 kyogoku_bitchu はこれによる (CLAUDE.md 規則15「屋敷を苗字だけで呼ばない・識別子は官位まで入れる」)。
  • ⛔ 〔安政度地震大風之記〕の「上 京極飛驒守殿／右表長屋小潰其外所々大破」を当邸に当てない。 当家に飛驒守を称した記録が無く、記事の区域「永田町ゟ麴町貝坂辺」には但馬豊岡藩京極家 (一万五千石・上屋敷は麹町)も入る。⛔ したがって「京極=練塀でなく表長屋」を当邸へ波及させない (sources.md [安政地震被害書上] の当該注)。当邸の被災記録は無い。

地形と面 — 面の高さは地形が決めた

敷地は東の台地と南西の一段低い平場の二段からなり、その境の法面が敷地の中央を南北に走る。 北西は谷へ落ちる斜面で、平場は取れない。台地は北へ行くほど痩せるので、 主郭は南の広いブロックと東の腕からなるΓ形になる。

面の高さは設計者が決めていない。江戸期復元地盤を 0.5間で走査し、起伏の小さい矩形を探して その矩形の高さをそのまま採った(sashizu.md §3a)。⭐ その結果、土留めが1本も要らない — 二つの郭はどちらも自然のベンチにそのまま載り、郭の縁が自然の法肩・法尻と一致する。 全14棟が |設計面 − 江戸期地盤| ≤ 0.5m を 100% 満たす。

江戸期の地盤 —【2026-08-31 ユーザー裁定2=B】

地盤の正本 base_dem.json は国土地理院 DEM5A/10B 由来の現代の地面で、跡地の近代の掘削を含む。 区画の中に周りより深い塊が三つあり、うち二つ(台地の縁に食い込む窪みと西辺の窪み)を戻し、 北西の谷は自然地形として残す。谷の中の掘り込みだけは谷底の高さまで均す。 手順は kyogoku_bitchu_edo_recon.json、成果は kyogoku_bitchu_edo_world.json (生成器 Tools/Sashizu/build_kyogoku_bitchu_edo_dem.py・冪等)。

  • 台地の縁の窪みを人工と見る根拠は東の面の勾配。同じ縁が南では緩やかに上がるのに、 この区間だけ数mを数mで立ち上げている。⭐ 埋め戻すと南から続く下段のベンチが北へ通るので、 復元の妥当性はその連続性で検証できる【確度P】。
  • ⚠ 西辺の窪みは区画に収まらない — 同じ平坦が丹羽側へ続く。当家は自分の区画の中だけを戻し、 区画線に向かって復元の効きを 0 まで落とす(const の edgeTaper)。共有辺に新しい段差を作らないため。
  • ⚠ 北西隅だけはそれができない — 掘り込みが区画の隅そのものにあり、隅では区画線までの距離が どの向きにも短い。ここは効きを落とす距離を短く採ったので、当家の江戸期地盤と丹羽の現況が食い違う。 区画に掛かる面積はわずかで上には樹林しか置かないが、外周の囲いの基壇はここに立つ。 丹羽の指図が起きたら両家で揃えて解く(_pendingItems P3・掲示板へ起票済)。

郭の使い分け —【2026-08-31 ユーザー裁定1=A】

上段=御殿複合の郭 / 南西の平場=家中長屋の郭 / 台地の縁と北西=庭と樹林。 西の窪みは造成しないまま主庭に使う。座敷はこの窪みを東から見下ろす ([西川1959]A「主庭は池泉回遊式で谷・低地形を利用」/ 尾張藩市谷邸「楽々園」は埋没谷を庭とし、 御殿は池を望む東側に建つ)。

外周

表門のある東辺だけが道に面する。残る三辺は隣家と背中合わせで、道が無い。

  • 東辺 = 長屋門 + 表長屋。[福井図]A は上屋敷の外周を全周長屋+隅矢倉とし、 表門のある辺も長屋とする。[追川2017] は表長屋の規模比を加賀本郷15%/小浜28.6%/尾張市谷47.7% と示し、中小藩ほど外周を長屋で使い切る(⚠ 3例は必ず揃えて引く。下端を落とすと帯が狭く見える)。
  • 他の辺 = 練塀(築地塀)。⚠ 当邸の記録は無い。同じ街区の丹羽・土井・岡部について 〔安政度地震大風之記〕が「外構練塀」と記す【その3邸について確度S】ので、 街区の類推として採る【当邸については確度B】。
  • 表門の格式: 長屋門+片番所(格子付)・片潜門。番所と潜戸の形式は [下丸子武家屋敷門]A の 官製構造形式による。東京都教育委員会の掲示が「遺存例の少ない1〜5万石の小大名格の形式」と 明記しており、当家はこの帯に入る【石高帯の記載=A(実見)/ 当てはめ=B / 長屋門という型式の選択=U】。 ⚠ 屋根は切妻 — 長屋門の官製現物2件([山脇]A・[西澄寺]A)がいずれも切妻。 ⛔「独立門=入母屋」の一般化はしない([黒門]A は入母屋、[赤門]A は切妻で割れる)。 ⛔ 番所の室ごと一間張り出す「面出番所」は採らない — それは5万石級([山脇]A)の姿で、 下の帯に持ち込むと格が1段上がる。張り出すのは格子窓だけ。
  • ⛔ 隅櫓は置かない。[福井図]は上屋敷に隅矢倉を描くが、あれは32万石級の姿。 1万石級の上屋敷に隅櫓を置く典拠が無く、外構が練塀であることとも合わない。
  • 囲いの座の割り方: 1本の run の中で素地が一定以上振れたら run を割り、座はその run の素地の最大に採る。 差は基壇石垣が受ける。⛔ 座を中央値に採ると塀の根が地面に埋まる区間ができる。 斜面では段違いに水平な run を連ねる(勾配なりに塀を傾けない — 練塀は版築なので壁面が水平にしかならない)。
  • ⚠ 背中合わせの辺の囲いは1条で、どちらの家が持つかは史料未確認。 2026-08-11 の実装の取り決め(丹羽が京極との境を、内藤が京極との境を持つ)を暫定で踏襲し、 当家は道に面する辺だけを建てる。⛔ 建てない辺も座と露出は設計しておく — 隣家がその数字で建てられるように、また造成が辺の外へ出ないことを検査できるように。 岡部では同じ論点が「擁壁を持つ側が持つ」へユーザー裁定で反転した前例がある【要裁定・P2】。

御殿複合

一つの連続複合として組む(§B-2 / [福井図]A)。棟どうしの隙間は軒が重なる範囲に収め、 等間隔の格子に置かない。表門を入って北東から南西へ、表向 → 中奥 → 奥向 が [西川1959]A の言う「一列に順次連続」する形に並ぶ。台地がΓ形なので、 表向は東の腕に、中奥・奥向・勝手は南の広いブロックに割れる。

  • 玄関は表門の芯に正対する。門を入って正面が御式台([鈴木1985]A の旗本建家図8例と同じ作法)。
  • 謁見(大広間)と接待(表書院)は別室([福井図]A の要点)。
  • 台所は表向と奥向の中間([西川1959]A「御殿中央部の北」)。当邸は御殿がΓ形なので、 表(北東)と奥(南西)の折れ点の東に置き、井戸を東に隣接させる。
  • 御錠口を中奥棟の西端に置き、ここから西を奥向とする。藩士はこの線に入れない (外周長屋=藩士 → 中間 → 中心=藩主 の同心円防御。[福井図]A)。
  • 湯殿と雪隠は独立棟でなく室として持つ([西川1959]A・慶長11年 人吉相良家二万二千石 「江戸御屋形作日記」の下限構成=広間・中門・書院・台所・風呂・雪隠・廊下・局・門)。 ⭐ 表向・中奥・奥向のそれぞれに置く — 区画をまたいで用を足しに行く図は成り立たない。
  • ⛔ 中門は置かない。同じ台帳が「1万石級での中門は史料未確認」とも書いており、 下限構成の記載と緊張関係にある。断定しない。
  • ⛔ 御成セット(御成門・能舞台・御成風呂)は置かない。御成最盛期(秀忠〜家光)の装置で、 安政3年の一万石級の屋敷に持ち込まない。当家への御成の記録も無い。
  • ⛔ 前庭に屋根を架けない。表門から玄関までは開けた白洲。

庭

庭は一つではない([西川1959]A「表向・奥向それぞれに庭園池」)。表向は大広間・書院の西の前庭、 奥向は奥向棟の西の奥庭、そして郭の外の西の窪みが主庭。

  • ⛔ 池は掘らない。当邸に池の典拠が無く、山王社北の3邸でも「典拠なし=作らない」としている ([[reconstruction-evidence-labeling]])。⚠ ただし [西川1959]A は主庭が谷・低地形を利用すると言い、 隣の丹羽邸では発掘で池跡が確認されている(東京都埋文センター『溜池遺跡』2011)。 西の窪みは池を置くには理想的な地形なので、典拠が出たら見直す【P4】。
  • ⛔ 北西の斜面を竹林にしない。[橋本・堀1998](査読論文A)= 江戸の水辺79事例中、竹薮は1例の例外。 正しくは黒松を疎に交えた雑木の樹林(法肩=樹林/中部=低木/下部=草地の3帯)。
  • ⛔ 開花木(春の桜)を置かない。季節は春ではない(CLAUDE.md 規則10)。
  • ⛔ 自作の低ポリゴンの木を置かない。植栽は在庫のパックから採る(同)。
  • 稲荷社を郭の北東の隅(鬼門)に置く([西川1959]A「庭の一隅に稲荷宮」)。

建蔽率

分母は敷地全体(CLAUDE.md 規則6)。⛔ 可建地・平坦地に分母を替えない。 敷地の半分あまりが斜面と窪みで、そこには棟を置かない(§B-1「棟が入らないベンチは面にしない」)。 史料値は [福井図] の五〜六割(三十二万石・六千六百坪)と、[鈴木1985] の旗本建家図8例 22〜55%。 ⚠ 自分が過去に建てた屋敷の数値を基準にしない(§A-5)。
