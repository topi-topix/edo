## 屋敷の性格

出雲松江藩 十八万六千石。**親藩(結城秀康系の御家門)・出雲国主・大広間詰**の上屋敷。
外桜田永田町 — 赤坂御門から永田馬場へ抜ける大通りの南側、山王社の北。
西は溜池の東岸へ落ちる大斜面、南は土井大隅守邸と背中合わせ、南東の谷は岡部内膳正邸
(嘉永期の表記。安政2年以降の「筑前守」はプロジェクト内通称)に接する。
跡地は閑院宮邸を経て現在の衆参両院議長公邸。

- **基図と読図**: NDL 外桜田永田町絵図(嘉永版・pid 1286657)を IIIF で実見(2026-08-12)。
  家紋(葵紋系=雲州松平)+「松平出羽守」表記=**上屋敷**。切絵図の文字の頭は北北西の大通り側
  → 表門=北辺と読んだ。方位盤でなく街路の位置で合わせる。江戸マップβ [7-061](1850)/
  [14-460](1852)でも同区画を確認。【確度 A — 原画像実見】
- **区画の多角形はユーザーのブックマーク角(確度 U)。** 切絵図からの起こしではない。
  拝領11,942坪はWeb調査の二次値で**出所の書誌が未確定(確度 ?)** — 実測13,364坪との差+12%は
  下書き優先の方針による。
- **当主**: 嘉永6年(1853)9月5日までは斉貴(鷹書の大収集家・蘭癖。家老の諫死と近習のクーデター露見を
  経て強制隠居)、以降は定安(19歳で家督)。切絵図の表記はどちらも「松平出羽守」。
  嘉永前半の斉貴は参勤の義務を果たさず**ほぼ連続在府** — この屋敷が生活の場だった。
  【確度 A — 西島太郎「松江藩主の居所と行動」】
- **当屋敷の指図・絵図は散逸。** 同論文が「藩主松平家の史料も散逸している」と明言し、
  国文学研究資料館の松江松平家文書(全110点)にも屋敷絵図は確認できない。
  **敷地と表門まわり以外の内部構成はすべて類型からの想定**で、確度を付して残す。【確度 B】
- 宝永元年(1704)の記録に、家中が上屋敷を「赤坂館」と呼んだ形跡がある(綱近の隠居で
  「赤坂館から青山館へ移る」)。翻刻の書誌未確認・当該期の屋敷が当地かも未確認のため
  **呼称は採らない**。【確度 B】

## 表門 — 屋根付き独立門+両唐破風番所

**明治初期撮影の実写真が現存する**(江戸東京博物館 温古写真集11「旧雲州松江藩松平候上屋敷門」
資料番号 88005761)。大熊喜邦の昭和14年調査で現存していた大名屋敷表門5件の一つ
(書誌未確定=確度?。ユーザー照会候補)で、東京大空襲で焼失した。

写真から読めるもの(2026-08-21 ToMuCo で実見)【確度 A】:

- 門本体は**背の高い角柱二本+冠木**。柱頭に冠(銅板包みか)、柱の内面に長い飾金物。
  **写真の時点で冠木の上に屋根は無い。**
- **左右に向唐破風造の番所が街路側へ張り出す**。出格子が正面と側面に回り、
  切石積みの基壇に載る。屋根は箱棟+鬼飾り、唐破風に彫刻の兎毛通。
- 門扉は縦板に筋金具と乳鋲。**袖塀に潜り戸**。
- **門の両翼は海鼠壁の長屋**で、門寄りは**二階建て**。左手奥に入母屋・白漆喰の大屋根。

**嘉永期の正は「冠木上に切妻の小屋根を載せた独立門」とする(確度 B)。** 理由:

1. 台紙の説明書きが「…早くから撤去され、(唐破風)造の両番所と門柱が残(っていた)が
   戦災で亡失した」と読め、**写真は撤去後の姿**である可能性が高い。
2. **屋根なしの冠木門は門の格式の最下層**(裏門・足軽門の型)。最上格の両唐破風番所と
   同じ門構えには両立しない — この不整合自体が、屋根が写真以前に失われたことの傍証。
3. 現存する唯一の国主上屋敷表門 [黒門](因州池田32.5万石・確度A)は**屋根付きの独立門+
   左右唐破風番所**。

写真の姿(屋根なし)は**明治初の現状(確度A)**として部材の代替形に保持し、
**ToMuCo 原板の高精細確認で確定させる — 未解決の筆頭**。

**両唐破風番所+切石基壇は国主の表門の格。** 根拠は [黒門] 一本(現存・確度A)。
鳥取池田は外様なので、この意匠が親藩専用でないことも同じ実例が示す。

### 岡部邸表門の検討(2026-08-21 考証)との突き合わせ

同じ街区で先行した岡部邸の表門指図で出た指摘を、当図にも当てはめて確認した:

- **[表門格式表](石高別の門形式表)は根拠にしない** — 出典404で確度?へ降格済み。
  当図の根拠は写真(A)と[黒門](A)のみで、この表は使っていない。
- **番所は門に接して建ち、囲いの線を引き継ぐ。離した小屋にしない** — 当図の門構えは
  門柱→袖塀(潜り戸)→番所→表長屋の連続一列。番所が街路側へ張り出すのは写真どおり
  (切石基壇の畳出)で、列から離れているのではない。
- **袖塀(繋塀)は要る** — 写真どおり両袖に置き、潜り戸も写真から。
- **片番所/両番所の格** — 岡部(5.3万石)は片番所に落とした。当家は国主18.6万石で、
  両唐破風番所は写真そのもの+[黒門]の格と整合。
- **赤門を一般の表門の型に使わない**(御守殿門) — 当図は赤門を根拠列に入れていない。
- **袖塀の実装** — 岡部では既存パネルのストレッチで代用したが、当門は新造部材なので
  袖塀・潜り戸まで含めて一体で起こす(部材表に明記)。

## 御成門・能舞台 — 家門の装置【類型=B/当家に在ったかは ?】

御成対応の3点セット(御成門+能舞台+御成風呂)は**家門・大藩の上屋敷の装置**で、
正典の[福井図]は**同じ結城秀康系**(越前家本家)の実例。ただし**当家への御成の記録は未確認**であり、
嘉永期の斉貴の乱行と隠居劇を考えると現実の御成は考えにくい — 「格式として維持されている装置」
として置く。**御成5棟は御殿床面積の約14%を占め、この指図の推定の中で最も弱い環に最大の面積が
乗っている**ことを明記しておく。御成門の型式は未解決(?)で、実装は薬医門在庫の等倍代用。

## 敷地の造成 — 面から決める

**敷地全体を「4つの水平面+2つの斜面」として設計する**(設計値 `planes`)。
造成も囲いも、まずこの面から決まる。

| 面 | 何が載るか |
|---|---|
| 表郭 | 表門・白洲・厩。表門の敷居=道なり |
| 主平面 | 御殿複合・奥郭・御成道。敷地の主面 |
| 東上段 | 御蔵。主平面から石段6段 |
| 堀端の裾 | 堀端通り沿いの塀の帯 |
| 西斜面/南西の谷(+北西の登り) | 造成しない=竹林と庭。法肩に竹垣 |

1. **面は一枚の水平面。** 切盛は最大2.4m(北辺中央の鞍部の盛土)。段の造成は敷地ポリゴンで
   クリップし、隣地・道へ一切波及させない。
2. **囲いの天端=面の高さ。** その辺が縁になっている面の高さを塀・長屋がそのまま持つので、
   面が変わらない限り天端も変わらない — 南の土井境は P0 から辺2の肩まで162mが一本の天端。
   段差の発生点は**面の境**(門の開口・郭境の延長線・区画の頂点)に限る。
   道・隣地との高低差はすべて**石垣基壇**で受ける — 台地の上に建つ屋敷が道へ石垣の面を
   見せるのは、溜池端の台地肩の素直な姿。面に属さない斜面沿いの塀だけ地形なりの段を許し、
   石垣の小口で納める。外周帯(内側幅3m)の整地は切盛±1.7mに収まる区間のみ。
3. **斜面の面は造成しない。** 石段は開口の中でなく法面に載せる(蹴上・踏面は既定値)。

### 斜面の植生 — 黒松を疎に交えた雑木の樹林【確度 B】

**竹林ではない。** 斜面は法肩からの下りで三帯に分ける — 上部1/3=松を交えた樹林 /
中部=低木・下草 / 下部〜堀端の裾=草地。設計値は `slopeBands`。

根拠(強い順):

- **[橋本・堀1998]**(査読論文・確度A)は朱引内79事例を悉皆調査し、**溜池の水辺の樹木として
  採録された2例(白山祠・山王権現)はいずれも松**、同じ外堀水系の武家地の斜面
  (赤坂紀伊国坂)は「樹林」型とする。**竹薮は79例中1例のみ**(愛宕下 藪小路)で、
  しかも「珍しい樹種で単調な空間にアクセントを付添える」扱い —
  **竹林は江戸の武家地斜面の既定の姿ではない。**
- 同論文は幕府御用地の緑を「**外から敷地内の建物を隠蔽し、内から緑の間に水面が眺められる形態**」
  と記す。西庭の数寄屋から溜池を望ませる当図の意図と一致し、**竹である必要はない。**
- **『江戸名所図会』巻之七「溜池」**(確度S=図の実見)は、左頁遠景に「山王」の題簽を持ち
  **当該崖線そのもの**を描く。稜線=松と丸い樹冠の広葉樹の樹林、**崖面はハッチング(草地・裸地)**で
  樹は稜線と上部に集まる → 法面全体を樹林で埋めない三帯構成の根拠。
- **広重「赤坂桐畑」**(確度S=図の実見)も対岸の山王の斜面を松+広葉樹で描き、**竹は無い**。
  なお桐は溜池の**南岸(赤坂側)の土手**の護岸植栽で、東岸の崖の樹相ではない。
- 反証: 竹の地下茎は表層30〜50cmに留まり、**急斜面の竹林はむしろ表層崩壊を助長する**
  (林野庁・確度A)。「崩落防止で崖に竹」は成り立たない。
- 嘉永期の江戸に孟宗竹は在り得るが、在ったのは**吹上御苑と近郊農村の筍畑**(確度B)。
  武家屋敷の竹の類型は**矢竹の生垣**であって斜面被覆ではない。竹は京橋竹河岸に他国から
  入る「材」だった — **竹垣(R_West)の材としての竹は問題ない。**

⚠ **撤回した前案(竹林)は、隣の岡部邸に揃えた自己参照だった。** 岡部邸の西斜面も同じ崖線なので
同じ是正が要る(未実施)。当屋敷そのものの植栽の一次史料は無いので確度はBに留まる。
**大崎園(下屋敷)の茶苑から上屋敷の斜面を類推することはできない** — 機能(遊興地/本宅)・
年代(不昧没1818と嘉永の30年差)・記録(残るのは茶室の絵画と平面図)の三点で架橋できない。
- **西斜面(溜池東岸)と南西の谷(岡部境)の面は造成しない。** 竹林と庭のまま、法肩に竹垣。
- 段は郭の境で起こし、石段は開口の中でなく法面に載せる。蹴上・踏面は既定値。

## 建物の構成 — 連続御殿複合+街路側の長屋帯【確度 B=類型/室割りは ?】

[福井図](同族の正典)と[西川1959]の型に従う。開放地は白洲と中庭だけ。

- **表向** — 白洲から御式台・御玄関(北面)。東へ大広間(上段・下段・次之間)、黒書院。
  西へ表役所(御用部屋・目付・勘定・祐筆 = 藩庁)。
- **御成** — 黒書院の東、御成庭を渡廊下で越えて御成書院。北の白洲に能舞台+橋掛リ+楽屋
  (舞台は御成書院の広縁から観る)。御成湯殿は御成書院の東。御成門から御成道が直進。
- **中奥** — 御座之間・御休息之間・御小姓部屋・御寝所。**御書物之間・御時計之間は斉貴の嗜好**
  (鷹書大収集・西洋文物への傾倒=松江歴史館 NARITAKE 展・確度B)**からの想定の設え。
  室として在った典拠は無い(確度 ?)**。大台所は敷地のほぼ中心、料理・膳所の室群が付く。
- **奥向** — 入る廊下は**御錠口の一本だけ**。御対面所・奥御座之間・長局二列(計20戸)・奥台所。
- **室名・畳数はすべて想定(確度 ?)。** 上段の系列は 御成36 > 大広間32 > 御座24 > 黒書院18 で、
  **二条城大広間一之間(48畳=将軍御殿)を超える室は作らない**。将軍御殿の室名
  (一〜四之間の番号法・御湯殿上之間)と大奥の呼称(側)は使わない。
- **茶** — 西庭に数寄屋(四畳半+水屋)。溜池を法肩の竹垣越しに望む。不昧(治郷)以来の茶の
  家元格(B)からの想定で、**当屋敷に在った典拠は無い(確度 ?)**。不昧の大茶苑は大崎の
  下屋敷の話(嘉永期には解体済み)なので、上屋敷には一亭だけを置く。
- **奥庭の石井戸枠** — **慶長18年銘・約2m四方の実物が跡地(議長公邸)に現存する(確度 A)**。
  ただし**奥庭という配置は想定(確度 ?)** — 家康拝領を直政が移したという移設の伝承がある以上、
  現在地=嘉永期の位置とは限らない。
- **土蔵・作事** — 東上段に御土蔵三棟+御作事小屋。御蔵門(通用門)から搬入。土蔵に廊下は付けない。
- **厩** — 表郭の西、表門の内。

## 建蔽率と収容力

分母は敷地全体。数字は生成器が json から算出する(この文書に写さない)。

- **大名上屋敷の建蔽率の史料値は [福井図] の5〜6割の一点しかない。** 当図はそれより大きく低い
  (広い拝領地・御成の白洲・奥庭・造成しない斜面の帰結)。数字を上げるために空地へ棟を足さない。
- **表長屋の規模比**(表長屋延長/外周長)は約3割で、[追川2017] の実測帯
  (小浜28.6%〜尾張市谷47.7%)に収まる — 原典に忠実な比較指標はこちら。
- **収容力の下限**: 表長屋約400坪は、単身勤番の相場(1人2〜3畳)で数百人規模を収容でき、
  類例スケール(庄内14万石: 勤番+定府約1,200人/彦根30万石: 約3,200人)から見た
  上屋敷長屋の下限を割らない。【確度 B — 類例からの検算】
