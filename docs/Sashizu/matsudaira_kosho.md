## 屋敷の性格

出雲松江藩 十八万六千石。**親藩(結城秀康系の御家門)・出雲国主・大広間詰**の上屋敷。
外桜田永田町 — 赤坂御門から永田馬場へ抜ける大通りの南側、山王社の北。
西は溜池の東岸へ落ちる大斜面、南は土井大隅守邸と背中合わせ、南東の谷は岡部内膳正邸
(嘉永期の表記。安政2年以降の「筑前守」はプロジェクト内通称)に接する。
跡地は閑院宮邸を経て現在の衆参両院議長公邸。

- **基図と読図**: NDL 外桜田永田町絵図(嘉永版・pid 1286657)を IIIF で実見(2026-08-12)。
  家紋(葵紋系=雲州松平)+「松平出羽守」表記=**上屋敷**【確度 A — 原画像実見】。
  江戸マップβ [7-061](1850)/[14-460](1852)でも同区画を確認。
- **表門=北辺は【確度 A】** — [五千分一東京図31](明治16年官製実測図・0.32m/px)が北辺の
  **開口1箇所とその両脇の長大建物(表長屋)を直接描く**。門は空襲まで現存した
  ([泥絵と大名屋敷]の現存5件の一つ)ので、明治16年の開口位置は嘉永期へ外挿できる
  (門の位置=A寄りのB/長屋の有無・長さの外挿=B)。
  切絵図(NDL1286657)の 2026-08-12 の読みは補正前の方位のままで**読みとしては ?**だが、
  結論の典拠はもう切絵図に依らない。再実見は「切絵図の読み方の検証」として残すのみ。
- **表門の s(辺沿い位置)は五千分一図の開口が正**(json の gate に反映済み)。
  近代実測図の系列(五千分一→地籍図→火保図→空中写真)を史料ルートとして正式に立てる。
  次の裏取りは火保図(_pending.kaho)と地理院 mapps の戦前空中写真。
- **区画の多角形はユーザーのブックマーク角(確度 U)。** 切絵図からの起こしではない。
  拝領11,942坪はWeb調査の二次値で**出所の書誌が未確定(確度 ?)** — 実測12,844坪との差+7.6%は
  下書き優先の方針による。**2026-08-22 の区画修正は隣地との共有点一致のためで、拝領坪数へ
  寄せる操作はしていない**(U と ? はどちらも寄せる先にならない)。なお拝領・実測とも
  [元文3年] 規定(10〜15万石=7,000〜7,200坪)の1.7〜1.8倍で、規定超過としては通例の範囲。
- **当主**: 嘉永6年(1853)9月5日までは斉貴(鷹書の大収集家・蘭癖。家老の諫死と近習のクーデター露見を
  経て強制隠居)、以降は定安(19歳で家督)。切絵図の表記はどちらも「松平出羽守」。
  嘉永前半の斉貴は参勤の義務を果たさず**ほぼ連続在府** — この屋敷が生活の場だった。
  【確度 A — 西島太郎「松江藩主の居所と行動」】
- **当屋敷の指図・絵図は散逸。** 同論文が「藩主松平家の史料も散逸している」と明言し、
  国文学研究資料館の松江松平家文書(全110点)にも屋敷絵図は確認できない。
  **敷地と表門まわり以外の内部構成はすべて類型からの想定**で、確度を付して残す。【確度 B】
- 宝永元年(1704)の記録に、家中が上屋敷を「赤坂館」と呼んだ形跡がある(綱近の隠居で
  「赤坂館から青山館へ移る」)。翻刻の書誌未確認・当該期の屋敷が当地かも未確認のため
  **呼称は採らない**。【確度 B】

## 表門 — 屋根なし冠木門+両唐破風番所

**明治初期撮影の実写真が現存する**(江戸東京博物館 温古写真集11「旧雲州松江藩松平候上屋敷門」
資料番号 88005761)。大熊喜邦の昭和14年調査で現存していた大名屋敷表門5件の一つ
(書誌確定: [泥絵と大名屋敷] 大熊喜邦・昭和14。現物未見)で、東京大空襲で焼失した。

**位置は [五千分一東京図31](明治16年官製実測図・0.32m/px)で確定** — 北辺の開口はただ1箇所
(北東の折れ点から辺沿い西へ、値は json の gate.s)、両脇に長大建物(表長屋の両翼)、西側は
建物のない垣が続く。門は空襲まで現存したので明治16年の開口位置は嘉永期へ強く外挿できる
【位置=A寄りB/長屋の有無・長さの外挿=B】。当初の位置(道の高みからの設計判断【U】)は
この実測と食い違ったため撤回した(2026-08-23)。**確度の順位: 実測A > プロジェクト規則U。**

写真から読めるもの(2026-08-21 ToMuCo で実見)【確度 A】:

- 門本体は**背の高い角柱二本+冠木**。柱頭に冠(銅板包みか)、柱の内面に長い飾金物。
  **写真の時点で冠木の上に屋根は無い。**
- **左右に向唐破風造の番所が街路側へ張り出す**。出格子が正面と側面に回り、
  切石積みの基壇に載る。屋根は箱棟+鬼飾り、唐破風に彫刻の兎毛通。
- 門扉は縦板に筋金具と乳鋲。**袖塀に潜り戸**。
- **門の両翼は海鼠壁の長屋**で、門寄りは**二階建て**。左手奥に入母屋・白漆喰の大屋根。

**嘉永期の正は「屋根なしの冠木門+両唐破風番所」とする(2026-08-23 改説)。** 根拠:

1. 『日本案内記 関東篇』昭和5年([日本案内記 関東篇]・官製・確度A)が現役の当門を
   「**冠木門に属し、両側に唐破風造の番所を附属**」と記述 — 写真Aと独立に屋根なしを裏づける。
2. 前案(切妻小屋根説・2026-08-22)の決め手だった「屋根なし冠木門(最下層の格)と最上格の
   両唐破風番所は両立しない」という論拠は、**焼失規定**([焼失規定と冠木門]: 焼失後は冠木門しか
   再建できず、両番所の唐破風だけで格式を判別した)で崩れた — 両立する制度的説明が存在する。
   **前案は撤回**。ただし焼失規定の原典裏取り(『青標紙』・普請奉行の達)は未了(_pending)。
3. [黒門](屋根付き独立門+両唐破風番所)は「焼失していない国主表門」の型であり、
   当門に外挿する理由にならない。

台紙注記「早くから撤去され…」の読みと ToMuCo 原板の高精細確認は**傍証の検証**として残す。

**両唐破風番所+切石基壇は国主の表門の格。** 根拠は [黒門] 一本(現存・確度A)。
鳥取池田は外様なので、この意匠が親藩専用でないことも同じ実例が示す。

### 岡部邸表門の検討(2026-08-21 考証)との突き合わせ

同じ街区で先行した岡部邸の表門指図で出た指摘を、当図にも当てはめて確認した:

- **[表門格式表](石高別の門形式表)は根拠にしない** — 出典404で確度?へ降格済み。
  当図の根拠は写真(A)と[黒門](A)のみで、この表は使っていない。
- **番所は門に接して建ち、囲いの線を引き継ぐ。離した小屋にしない** — 当図の門構えは
  門柱→袖塀(潜り戸)→番所→表長屋の連続一列。番所が街路側へ張り出すのは写真どおり
  (切石基壇の畳出)で、列から離れているのではない。
- **袖塀(繋塀)は要る** — 写真どおり両袖に置き、潜り戸も写真から。
- **片番所/両番所の格** — 岡部(5.3万石)は片番所に落とした。当家は国主18.6万石で、
  両唐破風番所は写真そのもの+[黒門]の格と整合。
- **赤門を一般の表門の型に使わない**(御守殿門) — 当図は赤門を根拠列に入れていない。
- **袖塀の実装** — 岡部では既存パネルのストレッチで代用したが、当門は新造部材なので
  袖塀・潜り戸まで含めて一体で起こす(部材表に明記)。

## 御成門・御成セット — 撤去(2026-08-23)

御成対応の3点セット(御成門+能舞台+御成風呂)は当初、[福井図](同じ結城秀康系)の類型で
置いていたが、**撤去した**。理由:

1. **当家への御成の記録がどの経路からも出てこない。** 御成先の統計(秀忠29回・家光約300回=
   大半は寵臣譜代)に当家が現れない([御成の回数]・B)。直政の年譜にも御成の項目なし(?)。
2. **御成を受けた最大の家(加賀本郷邸・寛永6年に家光+秀忠)ですら、幕末の門の構成は
   大御門+御守殿門で御成門は無い**([加賀本郷邸の御成]・A)。「御成門は御成が無くても
   格式装置として維持された」という前提はこの実例で反証されている。
3. **[福井図]の御成セットは寛永〜明暦期・龍ノ口上屋敷(当邸成立前・別敷地)の装置**
   ([福井図の年代]・B)。骨格(連続御殿複合・外周長屋帯)の外挿は有効でも、
   御成セットは御成最盛期に固有で、200年後の嘉永期の屋敷へ既定で持ち込めない。
4. [五千分一東京図31] の北辺の開口は1箇所のみ — 御成門の開口を裏づける物証も無い。

なお御殿床面積の約14%を占めていた最弱の推定を落としたので、建蔽率は下がる —
**数字を上げるために空地へ棟を足さない**(絶対規則6)。福井図ジオラマ現物の実見(御成セットが
本当に描かれているかの検証)は未了(_pending)。

## 囲いの種別

| 面 | 相手 | 囲い |
|---|---|---|
| 北辺(大通り) | 赤坂御門→永田馬場の往来 | 門の両翼だけ**表長屋(海鼠壁・二階)**【五千分一図+写真=A】。西は練塀(図では垣=外挿B、練塀は裁定U)。東翼は面の段に合わせ3段の雛壇【P/U — 図は連続1棟。段割りは造成の帰結】 |
| 北東辺・東辺 | 三べ坂前身の南北道 | 表長屋(平屋)。南端の低みは石垣基壇で受ける(長屋のまま) |
| 南辺(台地上) | 土井大隅守邸(背中合わせ) | 練塀。**囲いは1条・松平が持つ**(区画トポロジの裁定=U) |
| 南辺の谷下り・南東の谷 | 土井邸・岡部内膳正邸 | **地形なりの木柵**(松平所有)。塀は台地の肩まで |
| 西辺(堀端通り=溜池東岸)・北西の登り | 往来・崖 | **地形なりの木柵**。囲いの実体は崖と樹林+法肩の竹垣 |

(辺の番号は設計値 json の `_edges` が正典 — この文書には写さない)

- **練塀と石垣基壇は面(造成した平場)の縁にだけ立てる。斜面・谷・水際に塀は立てない**
  【ユーザー裁定 2026-08-23=U】。囲いの働きは崖と樹林が担い(外から建物を隠す=[橋本・堀1998]の
  幕府御用地の緑と同じ形態)、生活面の縁に竹垣、境界線上は木柵で標示する。
  水際の木柵は広重「赤坂桐畑」が溜池対岸に描く柵に倣う【B — 岡部邸の溜池側と同じ判断】。
  崖の中腹・崖下に石垣基壇を積んで塀を通す型には典拠が無かった(撤回)。

- **二階の範囲は写真の画角外**(_pending.nijukai)。西翼は全長・東翼は門寄り2段を二階とした【P/U】。

- **長屋の配置は [追川2017] の一般則より当屋敷の実測を採る。** 追川の一般則は「表門に連なる塀に
  長屋塀を構築することを避けた」(加賀本郷は表門側に長屋を置かず裏手が長屋)で、当図とは**逆**だが、
  [五千分一東京図31] が**門の両脇に長大建物を直接描く**(A)ので実測が勝つ。
  一般則との食い違いは食い違いとして記録する — 「整合」と書かない。【A>B】
- 境界の塀を練塀としたのは隣の土井邸の記録(安政地震で「外構練壁が潰れる」)に種別を
  合わせたもので、**当家の塀種の史料は無い**。【確度 ?】
- **隅櫓は1基**(北東=北東辺と東辺道の出隅。長屋の隅に立つ)。[福井図]で隅矢倉は上屋敷格の
  装置だが、**当家の櫓の典拠は無い**【確度 ?】。他の隅は木柵・練塀の隅で、
  塀の隅に単独で立つ櫓の典拠が無いため置かない。

## 敷地の造成 — 面から決める

**敷地全体を「4つの水平面+2つの斜面」として設計する**(設計値 `planes`)。
造成も囲いも、まずこの面から決まる。

| 面 | 何が載るか |
|---|---|
| 表郭 | 表門・白洲・厩。表門の敷居=道なり |
| 主平面 | 御殿複合・奥郭。敷地の主面 |
| 東上段 | 御蔵。主平面から石段6段 |
| 堀端の裾 | 堀端通り沿いの塀の帯 |
| 西斜面/南西の谷(+北西の登り) | 造成しない=樹林と庭。面の縁に竹垣 |

1. **面は一枚の水平面。** 切盛の量は設計値 json(terraces の note)を正とする — この文書には
   写さない。西斜面の近代掘削の埋め戻しは**拝領時造成とは別勘定の「復元」**として扱う
   【出自判定は ? — 近代造成の記録は未確認】。段の造成は敷地ポリゴンでクリップし、
   隣地・道へ一切波及させない。
2. **囲いの天端=面の高さ。** その辺が縁になっている面の高さを塀・長屋がそのまま持つので、
   面が変わらない限り天端も変わらない — 南の土井境は P0 から辺2の肩までが一本の天端。
   段差の発生点は**面の境**(門の開口・郭境の延長線・区画の頂点)に限る。
   道・隣地との高低差はすべて**石垣基壇**で受ける — 台地の上に建つ屋敷が道へ石垣の面を
   見せるのは、溜池端の台地肩の素直な姿。面に属さない斜面沿いの塀だけ地形なりの段を許し、
   石垣の小口で納める。外周帯(内側幅3m)の整地は切盛±1.7mに収まる区間のみ。
3. **斜面の面は造成しない。** 石段は開口の中でなく法面に載せる(蹴上・踏面は既定値)。

### 斜面の植生 — 黒松を疎に交えた雑木の樹林【確度 B】

**竹林ではない。** 斜面は法肩からの下りで三帯に分ける — 上部1/3=松を交えた樹林 /
中部=低木・下草 / 下部〜堀端の裾=草地。設計値は `slopeBands`。

根拠(強い順):

- **[橋本・堀1998]**(査読論文・確度A)は朱引内79事例を悉皆調査し、**溜池の水辺の樹木として
  採録された2例(白山祠・山王権現)はいずれも松**、同じ外堀水系の武家地の斜面
  (赤坂紀伊国坂)は「樹林」型とする。**竹薮は79例中1例のみ**(愛宕下 藪小路)で、
  しかも「珍しい樹種で単調な空間にアクセントを付添える」扱い —
  **竹林は江戸の武家地斜面の既定の姿ではない。**
- 同論文は幕府御用地の緑を「**外から敷地内の建物を隠蔽し、内から緑の間に水面が眺められる形態**」
  と記す。西庭の数寄屋から溜池を望ませる当図の意図と一致し、**竹である必要はない。**
- **『江戸名所図会』巻之七「溜池」**(確度A=図の実見。当屋敷の一次史料ではないので S は付けない)は、左頁遠景に「山王」の題簽を持ち
  **当該崖線そのもの**を描く。稜線=松と丸い樹冠の広葉樹の樹林、**崖面はハッチング(草地・裸地)**で
  樹は稜線と上部に集まる → 法面全体を樹林で埋めない三帯構成の根拠。
- **広重「赤坂桐畑」**(確度A=図の実見)も対岸の山王の斜面を松+広葉樹で描き、**竹は無い**。
  なお桐は溜池の**南岸(赤坂側)の土手**の護岸植栽で、東岸の崖の樹相ではない。
- 反証: 竹の地下茎は表層30〜50cmに留まり、**急斜面の竹林はむしろ表層崩壊を助長する**
  (林野庁・確度A)。「崩落防止で崖に竹」は成り立たない。
- 嘉永期の江戸に孟宗竹は在り得るが、在ったのは**吹上御苑と近郊農村の筍畑**(確度B)。
  武家屋敷の竹の類型は**矢竹の生垣**であって斜面被覆ではない。竹は京橋竹河岸に他国から
  入る「材」だった — **竹垣(R_West)の材としての竹は問題ない。**

⚠ **撤回した前案(竹林)は、隣の岡部邸に揃えた自己参照だった。** 岡部邸の西斜面も同じ崖線なので
同じ是正が要る(未実施)。当屋敷そのものの植栽の一次史料は無いので確度はBに留まる。
**大崎園(下屋敷)の茶苑から上屋敷の斜面を類推することはできない** — 機能(遊興地/本宅)・
年代(不昧没1818と嘉永の30年差)・記録(残るのは茶室の絵画と平面図)の三点で架橋できない。
- **西斜面(溜池東岸)と南西の谷(岡部境)の面は造成しない。** 樹林と庭のまま、面の縁に竹垣。
- 段は郭の境で起こし、石段は開口の中でなく法面に載せる。蹴上・踏面は既定値。

## 建物の構成 — 連続御殿複合+街路側の長屋帯【確度 B=類型/室割りは ?】

[福井図](同族の正典。骨格のみ — 年代の限界は [福井図の年代])と[西川1959]の型に従う。
開放地は白洲・中庭・明地・馬場。

- **表向** — 白洲から御式台・御玄関(北面、表門の軸)。西へ大広間(上段・下段・次之間)・
  黒書院・表役所(御用部屋・目付・勘定・祐筆 = 藩庁)が連続。東は東肩の帯を経て東上段(御蔵)。
- **中奥** — 御座之間・御休息之間・御小姓部屋・御寝所。**御書物之間・御時計之間は斉貴の嗜好**
  (鷹書大収集・西洋文物への傾倒=松江歴史館 NARITAKE 展・確度B)**からの想定の設え。
  室として在った典拠は無い(確度 ?)**。大台所は敷地のほぼ中心、料理・膳所の室群が付く。
- **奥向** — 入る廊下は**御錠口の一本だけ**。御対面所・奥御座之間・長局二列・奥台所。
  西の奥ゾーン(表門の移設に伴う再割付)。長局南列は掘削跡の埋め戻し面(json 参照)に載る。
- **明地・馬場** — 北辺西の内側は**造成しない明地(薮)**【確度? — 五千分一図で建物なしの区間
  =外挿B。幕府の火除地ではなく屋敷内の空地】。主郭東翼に**馬場**【確度? — 上屋敷の類型からの
  想定・当家の記録なし】、残余は作事の資材置場・明地。
- **室名・畳数はすべて想定(確度 ?)。** 上段の序列と畳数は json の `_munes` を正とし、
  **二条城大広間一之間(48畳=将軍御殿)を超える室は作らない**。将軍御殿の室名
  (一〜四之間の番号法・御湯殿上之間)と大奥の呼称(側)は使わない。玄関棟の待合は
  「供待」とし、奥向の役所を指す「御広敷」の名は使わない。
- **西の池泉庭【確度B=典拠なき類型。ユーザー裁定 U で採用(2026-08-23)】** —
  御殿複合の西、u-75〜-46 の帯に池泉庭を置き、東入りを中奥の西面まで届かせる。
  **当屋敷の庭園の一次史料は無い**(江戸期の指図・絵図は散逸/西島2013)。ただし
  「無かった」も同じく典拠の無い推定であり、18万6千石・親藩国主の上屋敷という格から見れば
  池泉庭を欠くほうが例外にあたる。よって**類型(B)と明記したうえで置く**。
  一般類型で埋めた物を既成事実にしない(規則6)ため、図・表とも確度Bを外さない。
  - **近代の掘削跡は池に使わない。** 南西の自然高 20m の窪みは近代の掘削跡(json `Fukugen`)で、
    ここを池にすると20世紀の穴を江戸の庭に仕立てることになる。埋め戻して台地面に復す方針は変えない。
  - **築山泉水** — 池は平面(27.0)を 1.3m 掘り、出た土を築山(主・西)と汀の土手へ回す。
    土量は生成器が算出する。
  - **水源は湧水と井戸【確度 ?】** — **青山上水は享保7年(1722)に廃止**されており、嘉永期の赤坂に
    上水は無い。台地縁(溜池東岸)の湧水に拠ったとする想定で、掛樋・上水からの引水は描かない。
  - **借景** — 西縁の向こうは崖と溜池。庭は溜池を額装する向きに開く。
- **水回りは庭に背を向ける【ユーザー裁定 U(2026-08-23)】** — 御湯殿・奥台所を庭側(西)から
  奥の内側へ移した。御湯殿は奥御殿の東面に付き、西の池泉庭からは奥御殿20間の躯体で遮られる。
  奥台所は大台所の真南に付け、勝手庭・勝手井戸と一体で使う(庭からは長局18間で遮られる)。
- **茶** — 数寄屋(四畳半+水屋)は池畔に残す。不昧(治郷)以来の茶の
  家元格(B)からの想定で、**当屋敷に在った典拠は無い(確度 ?)**。不昧の大茶苑は大崎の
  下屋敷の話(嘉永期には解体済み)なので、上屋敷には一亭だけを置く。
- **奥庭の石井戸枠** — **慶長18年銘・約2m四方の実物が跡地(議長公邸)に現存する(確度 A)**。
  ただし**奥庭という配置は想定(確度 ?)** — 家康拝領を直政が移したという移設の伝承がある以上、
  現在地=嘉永期の位置とは限らない。
- **土蔵・作事** — 東上段に御土蔵+御作事小屋(棟数は json)。御蔵門(通用門)から搬入。土蔵に廊下は付けない。
- **稲荷社** — 通例の北東角(鬼門)は東上段の蔵・隅櫓で塞がるため南東の奥庭に置く【確度 ? — 鬼門の類型から外した配置】。
- **厩** — 表郭の西、表門の内。

## 建蔽率と収容力

分母は敷地全体。数字は生成器が json から算出する(この文書に写さない)。

- **大名上屋敷の建蔽率の史料値は [福井図] の5〜6割の一点しかない。** 当図はそれより大きく低い
  (広い拝領地・表門前の白洲・西の池泉庭・造成しない斜面の帰結)。数字を上げるために空地へ棟を足さない。
- **表長屋の規模比**(表長屋延長/外周長。数値は生成器が算出)は [追川2017] の実測3例
  (加賀本郷15%・小浜28.6%・尾張市谷47.7%)の帯の中位に収まる — 原典に忠実な比較指標はこちら。
  3例は必ず揃えて引く(下端を落とすと帯が狭く見える)。国主・広大地の類例としては加賀本郷が最も近い。
- **収容力**: 類例(庄内・彦根)の人数が江戸の全屋敷(上中下)合計か上屋敷単独か確認できておらず、
  **上屋敷単独の収容力は類例と比較できない【確度 ?】** — 下限主張はしない。
  建蔽率の妥当性を収容力で補強しない。
