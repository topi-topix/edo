## 屋敷の性格

**基準年次 = 嘉永3年(1850)。当主 = 松平斉貴(出羽守)**【[西島・松江藩主]A。嘉永6年9月5日隠居 → 定安】。
基図は同年の [NDL1286657]S。**年次の異なる材料は必ず年次を添えて引く** — 拝領坪数の [大江戸今昔めぐり]B は安政3年(1856)基準、[寛政武鑑]A は寛政元年(1789)、[五千分一東京図31]A は明治16年(1883)。

出雲松江藩 十八万六千石。**親藩(結城秀康系の御家門)・出雲国主・大広間詰**の上屋敷。
外桜田永田町 — 赤坂御門から永田馬場へ抜ける大通りの南側、山王社の北。
西は溜池の東岸へ落ちる大斜面、南は土井大隅守邸と背中合わせ、南東の谷は岡部内膳正邸
(嘉永期の表記。安政2年以降の「筑前守」はプロジェクト内通称)に接する。
跡地は閑院宮邸を経て現在の衆参両院議長公邸。

- **基図と読図**: NDL 外桜田永田町絵図(嘉永版・pid 1286657)を IIIF で実見(2026-08-12)。
  **屋敷の別(上屋敷)は武鑑で取る**【A(翻刻)】 — [寛政武鑑 松江] に「**上 赤坂御門之内 大手ヨリ十八町**」。⚠ **切絵図は屋敷の別を書かない**([江戸マップ地名データセット]A)ので、切絵図から読めるのは**当区画が松平出羽守家の屋敷であること**まで(家紋+受領名の実見=A)。嘉永期への外挿は ①大手からの距離と方位が当区画と一致 ②[五千分一東京図31]A の北辺の門の開口 ③[日本案内記 関東篇]A が同門を「旧雲州松平…上屋敷の表門」と記すこと、で支える【外挿=B】。
  江戸マップβ [7-061](1850)/[14-460](1852)でも同区画を確認。
- **表門=北辺は【確度 A】** — [五千分一東京図31](明治16年官製実測図・0.32m/px)が北辺の
  **開口1箇所とその両脇の長大建物(表長屋)を直接描く**。門は空襲まで現存した
  ([泥絵と大名屋敷]の現存5件の一つ)ので、明治16年の開口位置は嘉永期へ外挿できる
  (門の位置=A寄りのB/長屋の有無・長さの外挿=B)。
  切絵図(NDL1286657)の 2026-08-12 の読みは補正前の方位のままで**読みとしては ?**だが、
  結論の典拠はもう切絵図に依らない。再実見は「切絵図の読み方の検証」として残すのみ。
- **表門の s(辺沿い位置)は五千分一図の開口が正**(json の gate に反映済み)。
  近代実測図の系列(五千分一→地籍図→火保図→空中写真)を史料ルートとして正式に立てる。
  次の裏取りは火保図(_pending.kaho)と地理院 mapps の戦前空中写真。
- **区画の多角形はユーザーのブックマーク角(確度 U)。** 切絵図からの起こしではない。
  ⚠ **2026-08-24 是正: 拝領坪数は 10,225坪余**([大江戸今昔めぐり 岡部区画]<span class="cert">B</span>。
  岡部邸の考証で隣家の記載として実見)。従前の **11,942坪はWeb調査の二次値(確度?)** で、
  同一史料系の 10,225坪余 と 1,717坪 食い違うので**採らない**。実測12,844坪との差は **+25.6%**。
  下書き優先の方針による。
  **2026-08-22 の区画修正は隣地との共有点一致のためで、拝領坪数へ寄せる操作はしていない**
  (U と ? はどちらも寄せる先にならない)。なお拝領・実測とも
  規定超過は **1.46倍**([西川1959]A が引く『青標紙』格坪覚 10〜15万石=7,000坪。18.6万石は表の範囲外)
  ／ 1.42〜1.46倍([元文3年]B 7,000〜7,200坪)。⚠ 目安は原典未確認なので超過率を設計の根拠に使わない。
- **当主**: 嘉永6年(1853)9月5日までは斉貴(鷹書の大収集家・蘭癖。家老の諫死と近習のクーデター露見を
  経て強制隠居)、以降は定安(19歳で家督)。切絵図の表記はどちらも「松平出羽守」。
  嘉永前半の斉貴は参勤の義務を果たさず**ほぼ連続在府** — この屋敷が生活の場だった。
  【確度 A — 西島太郎「松江藩主の居所と行動」】
- **藩主家伝来の絵図は散逸(西島2013)。ただし文化年間頃『江戸上屋敷絵図』が私蔵で現存し上水樋と池泉が読める([内藤2024] 経由・未実見)。** 同論文が「藩主松平家の史料も散逸している」と明言し、
  国文学研究資料館の松江松平家文書(全110点)にも屋敷絵図は確認できない。
  **敷地と表門まわり以外の内部構成はすべて類型からの想定**で、確度を付して残す。【確度 B】
- 宝永元年(1704)の記録に、家中が上屋敷を「赤坂館」と呼んだ形跡がある(綱近の隠居で
  「赤坂館から青山館へ移る」)。翻刻の書誌未確認・当該期の屋敷が当地かも未確認のため
  **呼称は採らない**。【確度 B】

## 表門 — 屋根なし冠木門+両唐破風番所

**明治初期撮影の実写真が現存する**(江戸東京博物館 温古写真集11「旧雲州松江藩松平候上屋敷門」
資料番号 88005761)。大熊喜邦の昭和14年調査で現存していた大名屋敷表門5件の一つ
(書誌確定: [泥絵と大名屋敷] 大熊喜邦・昭和14。現物未見)で、東京大空襲で焼失した。

**位置は [五千分一東京図31](明治16年官製実測図・0.32m/px)で確定** — 北辺の開口はただ1箇所
(北東の折れ点から辺沿い西へ、値は json の gate.s)、両脇に長大建物(表長屋の両翼)、西側は
建物のない垣が続く。門は空襲まで現存したので明治16年の開口位置は嘉永期へ強く外挿できる
【位置=A寄りB/長屋の有無・長さの外挿=B】。当初の位置(道の高みからの設計判断【U】)は
この実測と食い違ったため撤回した(2026-08-23)。**確度の順位: 実測A > プロジェクト規則U。**

写真から読めるもの(2026-08-21 ToMuCo で実見)【確度 A】:

- 門本体は**背の高い角柱二本+冠木**。柱頭に冠(銅板包みか)、柱の内面に長い飾金物。
  **写真の時点で冠木の上に屋根は無い。**
- **左右に向唐破風造の番所が街路側へ張り出す**。出格子が正面と側面に回り、
  切石積みの基壇に載る。屋根は箱棟+鬼飾り、唐破風に彫刻の兎毛通。
- 門扉は縦板に筋金具と乳鋲。**袖塀に潜り戸**。
- **門の両翼は海鼠壁の長屋**で、門寄りは**二階建て**。左手奥に入母屋・白漆喰の大屋根。

**嘉永期の正は「屋根なしの冠木門+両唐破風番所」とする(2026-08-23 改説)。** 根拠:

1. 『日本案内記 関東篇』昭和5年([日本案内記 関東篇]・官製・確度A)が現役の当門を
   「**冠木門に属し、両側に唐破風造の番所を附属**」と記述 — 写真Aと独立に屋根なしを裏づける。
2. 前案(切妻小屋根説・2026-08-22)の決め手だった「屋根なし冠木門(最下層の格)と最上格の
   両唐破風番所は両立しない」という論拠は、**焼失規定**([焼失規定と冠木門]: 焼失後は冠木門しか
   再建できず、両番所の唐破風だけで格式を判別した)で崩れた — 両立する制度的説明が存在する。
   ただし焼失規定の原典裏取り(『青標紙』・普請奉行の達)は未了(_pending)。
3. [黒門](屋根付き独立門+両唐破風番所)は「焼失していない国主表門」の型であり、
   当門に外挿する理由にならない。

台紙注記「早くから撤去され…」の読みと ToMuCo 原板の高精細確認は**傍証の検証**として残す。

両唐破風番所+切石畳出は **10万石以上の帯**の意匠([武家屋敷門の格式階梯]B。同帯の現物が [黒門]A=鳥取池田32.5万石)。当家18.6万石はこの帯に入る。**ただし当門の形式の典拠は帯ではなく写真そのもの**([松江上屋敷門写真]A+[日本案内記 関東篇]A)で、帯は整合の確認にとどまる。
鳥取池田は外様なので、この意匠が親藩専用でないことも同じ実例が示す。

### 岡部邸表門の検討(2026-08-21 考証)との突き合わせ

同じ街区で先行した岡部邸の表門指図で出た指摘を、当図にも当てはめて確認した:

- **[表門格式表](石高別の門形式表)は根拠にしない** — 出典404で確度?へ降格済み。
  当図の根拠は写真(A)と[黒門](A)のみで、この表は使っていない。
- **番所は門に接して建ち、囲いの線を引き継ぐ。離した小屋にしない** — 当図の門構えは
  門柱→袖塀(潜り戸)→番所→表長屋の連続一列。番所が街路側へ張り出すのは写真どおり
  (切石基壇の畳出)で、列から離れているのではない。
- **袖塀(繋塀)は要る** — 写真どおり両袖に置き、潜り戸も写真から。
- **片番所/両番所の格** — 岡部(5.3万石)は片番所に落とした。当家は国主18.6万石で、
  両唐破風番所は写真そのもの+[黒門]の格と整合。
- **赤門を一般の表門の型に使わない**(御守殿門) — 当図は赤門を根拠列に入れていない。
- **袖塀の実装** — 岡部では既存パネルのストレッチで代用したが、当門は新造部材なので
  袖塀・潜り戸まで含めて一体で起こす(部材表に明記)。

## 御成門・御成セット — 撤去(2026-08-23)

御成対応の3点セット(御成門+能舞台+御成風呂)は当初、[福井図](同じ結城秀康系)の類型で
置いていたが、**撤去した**。理由:

1. **当家への御成の記録がどの経路からも出てこない。** 御成先の統計(秀忠29回・家光約300回=
   大半は寵臣譜代)に当家が現れない([御成の回数]・B)。直政の年譜にも御成の項目なし(?)。
2. **御成を受けた最大の家(加賀本郷邸・寛永6年に家光+秀忠)ですら、幕末の門の構成は
   大御門+御守殿門で御成門は無い**([加賀本郷邸の御成]・A)。「御成門は御成が無くても
   格式装置として維持された」という前提はこの実例で反証されている。
3. **[福井図]の御成セットは寛永〜明暦期・龍ノ口上屋敷(当邸成立前・別敷地)の装置**
   ([福井図の年代]・B)。骨格(連続御殿複合・外周長屋帯)の外挿は有効でも、
   御成セットは御成最盛期に固有で、200年後の嘉永期の屋敷へ既定で持ち込めない。
4. [五千分一東京図31] の北辺の開口は1箇所のみ — 御成門の開口を裏づける物証も無い。

なお御殿床面積の約14%を占めていた最弱の推定を落としたので、建蔽率は下がる —
**数字を上げるために空地へ棟を足さない**(絶対規則6)。福井図ジオラマ現物の実見(御成セットが
本当に描かれているかの検証)は未了(_pending)。

## 取り合い — 面で決める、芯では決めない【作法U 2026-08-29】

囲いの図はこれまで**全体設計**しか持っていなかった — 開口がどこにあり、どの run がどの辺の
どこからどこまでか、まで。そこで止めると、実装は「門は開口の芯に、長屋は run の頭から丸ごとの
モジュールを並べる」としか置けず、**どの面がどの面に接するかが成り行き**になる。
実際にそうなり、同じ門の左右で食い込みと隙間が同時に出た(ユーザーが実測で発見)。

ユーザーの言葉:「オブジェクト同士の位置関係は常に**どの点同士を接するか**を厳密に考えないと
隙間が空く」。これを受けて、開口の両側とすべての隅について**接する面を名指しした取り合い表**を
設計値に持たせた(生成器が図と表にする)。決めごとは三つ:

- **可動側を必ず決める。** 門・番所・隅櫓・区画の頂点は位置そのものが意味を持つので**固定側**。
  動くのは run(長屋・練塀)の側。可動側を決めないと、両方が動くか、両方が動かない。
- **閉じの許容は「隙間 > めり込み」。** 0 を狙い、外すならめり込む側へ外す。
  隙間は郭の内が素通しで見えるので不可。
- **表長屋の鎖は在庫部材の実寸の整数倍でしか置けない。** 継ぎ目は面一(重ねると海鼠紋・瓦・窓が
  二重になる)。だから鎖の長さは棟数で決まり、**run の s の側をそれに合わせる**。
  端数は開口や隅へ押し出さず、**練塀に継ぐ遊び端**で吸う(練塀は駒を伸縮できる)。

表長屋を長さ可変の一体物にした裁定(2026-08-29)で、鎖の端数は消えた — 開口の縁から縁までを
1本で埋めるので、隅や開口へ端数を押し出す必要が無い。

**隅では表長屋の帯が腕ぶんだけ練塀に変わる。** 隅部材(留め継ぎ / 在庫の正規90°隅)は頂点に据えて
動かさない部材で、両辺へ腕を伸ばす。練塀の側は駒が伸縮するので run をそのまま頂点まで通し、
隅部材が端の腕を兼ねればよい。長屋の側は**長さ指定の一体物なので隅まで伸ばせない**から、
run を腕ぶん退がらせ、退がった区間は短い練塀で継ぐ。長屋の妻面は腕より内側で郭内へ露出する
(表門の番所の背後と同じ姿)。北の隅と南東の角の二箇所がこれにあたる。

⚠ **腕ぶんの練塀を `runs` に書き起こすこと** — 2026-08-29 に、この区間が取り合い表の腕としてしか
存在せず、`runs` に一本も無いまま「隅部材が塞いでいる」ことになっていた。腕は建てる対象の一覧に
渡らないので、実装では隅がそのまま口として残り、**外から敷地内へ踏み込める唯一の箇所**になっていた。
図の上の面の当たりを測る検査は腕を実体として数えるので鳴らない。**帳簿の側を測る検査**
(`perimeter_ledger_check` — 全頂点の取り合いと全辺の被覆を区間の帳簿で検める)を足して塞いだ。
西辺の木柵だけの辺は「標示であって遮蔽ではない/遮蔽は法面が受ける」と設計値に宣言を置き、
検査がそれを読んで除外する形にした(宣言を消せば鳴る)。

- **門扉は「出どころ」まで書く。** 開口が閉じている事実(`leaf`)と、扉を**門の躯体が持つのか
  別部材を据えるのか**(`leaf.by`)は別のこと。通用門二つは冠木門の躯体が自前の扉を持つので
  別部材を重ねてはならず(重ねると門の顔が覆われる)、表門は新造で躯体が扉を持たないので
  別部材を据える。実装は門の名前で決め打ちせず、据えた門の実メッシュを見て判断する【U 2026-08-29】。

## 棟の続き方 — 入側は南北の二辺。妻には回さない【ユーザー裁定U 2026-08-27】

表向の四棟（表役所・黒書院・大広間・玄関）は**一列に連なる一体**で、棟の境は**襖の通り**で続く。
入側/縁は**南（白洲側）と北（中庭側）の二辺**だけに置き、**妻（u 方向）には回さない**。

**典拠** — [西川1959]（正徳期 津軽藩柳原屋敷図・寛政6年 井伊藩上屋敷絵図ほか、実在の大名屋敷図の分析・確度A）:

> 「表向殿舎は長屋の中に設けられた表御門から玄関、広間、使者の間に**連なつて**、書院が上段、
> 二之間、三之間と**片側に入側をもつて一列にならび**…書院**から廊下をへだてて**、小座敷、
> 御座の間など…中奥の部分が連なり、更に**御錠の口をへだてて**奥向の殿舎に連なる」

同じ段落で、**ゾーンの境だけ「へだてて」と書き分けている**（表向↔中奥＝廊下／中奥↔奥向＝御錠口）。
さらに台所については「あるいは各々独立して」と、独立している場合は明示する。
**書き分ける人が表向の中では書いていない** — 表向の中に廊下を挟まない、と読む。
当図の渡廊下（表向↔中奥）と御錠口（中奥↔奥向）はこの記述と一致する。

⛔ **四方に入側を回して棟どうしを突き付ける前案（2026-08-14 の裁定）は撤回。** 境に入側が二列
並んで **2間（3.64m）の廊下**になり、しかも**両側に座敷がある＝中廊下**だった。
中廊下型は明治以降の型（`sashizu.md` §1a）。加えて実装は入側の外縁に建具を一切置いていなかったので、
実体は「仕切りの無い開けっぱなしの板敷き」で、濡縁が二重に重なっていた。

**四方入側を選んだ理由（妻側の白壁が廊下に面する）は、片側入側では起こらない** —
妻の向こうは廊下ではなく隣の座敷だから、境は襖でよい。棟が接しない妻（列の両端＝表役所の西、玄関の東）
だけが白壁になる。

**動かないもの**: 棟の間数・外形・玄関と門の軸・屋根と谷・建蔽率・造成・外周。
動線（R_Omote / R_Yaku）も v=15.5 の南入側を走っており、もともとこの形を前提にしていた。
**動くもの**: 室割り（身舎が妻の側へ一間ずつ広がる。室は確度 ? なので失う典拠は無い）。

**奥向は一様ではない。**同じ「棟が接している」でも、典拠が指す答えが棟ごとに違う。

| 棟 | 判断 | 典拠 |
|---|---|---|
| 奥御殿 ＋ 御湯殿 | **連続させる**(妻の入側を落とし襖の通りで続く) | [相良家]『江戸御屋形作日記』の殿舎に風呂は入るが「**風呂(湯殿)は独立棟ではない**」 |
| 長局(北) | **切り離して渡廊下**(2間) | [西川1959]「更に上陣下陣に分れた**長局がならんでいる**」— 御殿本体とは別の要素。長局(南)は既に渡廊下でつないでいる |
| 奥台所 | **切り離して渡廊下**(2間) | [西川1959]「台所…**あるいは各々独立して**」— 独立を明示している |
| 中奥・大台所 | **変更なし** | 元から隣と2間以上離れていて突き付けが無い。四方入側でも中廊下は生じない |

⚠ **四方入側そのものが誤りなのではない。** 誤りは**突き付けた所に入側を二列並べること**で、
離れて建つ棟が四方に縁を回すのは普通のこと。だから中奥・長局・奥台所は四方のまま残す。

追随: 長局(北) u+2 / 奥台所 u+4 / 勝手庭 u[8,16]→[12,18] / 井戸 Ido_Oku2 u11→13.5 /
御膳所口 u[0,1]→[4,5](新しい奥台所の正面へ)。谷は V_Oku2・V_Oku3 が消え、軒谷の区間が引き直しになる。

## 屋根の取り合い — 谷樋で納める【ユーザー裁定U 2026-08-27】

棟は**入側の外縁で接している**(壁は共有しない — 身舎の壁どうしは入側二列ぶん 2間 離れている)。
各棟の大棟は桁行=u に架かるので、接合部では**両棟の妻側の屋根面が向かい合って谷になる**。

**谷の辺には軒を出さない。** 両棟とも外形の縁で屋根を切ると、屋根面は軒先の高さのまま突き合い、
そこに谷樋が走る。水は縦樋を立てず、谷樋の両端の軒先から落とす【確度P=一般類型】。
**棟の間数は一つも動かない** — 室割り・玄関の軸・建蔽率のいずれにも影響しない。

⛔ **棟を離して渡廊下を挟む案(2026-08-26 の暫定裁定A)は撤回した。** 理由は二つ:

1. **廊下として広すぎる。** 棟の外形にはすでに入側が一間ずつ含まれているので、間に渡廊下を
   足すと入側1間＋渡廊下＋入側1間で**廊下の帯が4間(7.3m)**になる。廊下の幅は柱間で決まる
   一定値(一間)であって、足し算で広げるものではない(`sashizu.md` §1a)。
2. **一間の隙間では渡廊下が成立しない。** 切妻屋根は両端が 0.30m 長く、隣の棟の軒の出 0.90m と
   1.20m ずつ重なる。重なりの合計 2.40m が廊下の長さ 1.818m を超える
   (`buildings.md`「渡廊下は1間では成立しない」)。平面で見ても、両隣の軒 0.90＋0.90＝1.80m が
   一間の隙間をほぼ埋めてしまい、渡廊下の屋根は完全に隠れて軒どうしが 18mm で向かい合うだけになる。

**渡廊下は離れた棟をつなぐ部材**であって、連なる棟の継ぎ目に使うものではない。当図で渡廊下が
架かるのは、行と行の間(表向↔中奥、長局の北列↔南列)の **2間以上** 空いた所だけ。

**谷は二種ある。**

- **妻谷**(表向3・奥向3) — 列の中で妻側の屋根面が向かい合う所。上記のとおり軒を出さずに突き合わせる。
- **軒谷**(5区間・計69m) — **中奥と奥向が結界の帯(1間)を挟んで**、平行な長辺の軒で向かい合う所。
  軒の出 0.90×2 が帯(1.818m)をほぼ埋めるので**両者は 18mm で出会う**。ここは軒をそのままにして、
  合わせ目の下へ樋を寄せて吊る(寄せ樋)。帯の下を通るのは**御錠口と御膳所口だけ**で、渡廊下は架けない
  (結界は「面として閉じていないと意味がない」— 帯を廊下で通すと口が三つになる)。

**実装への影響** — 屋根部材は**辺ごとに軒の出を落とせる版**が要る
(現行の `build_goten_roof.py` は W'=W+2E の対称生成)。谷樋 6本(表向 23.6m×3 / 奥向 12.7m×3)。
谷の位置・長さ・両側の大棟の高さは json の `valleys` を正とする。
