表門 — 屋根なし冠木門+両唐破風番所

明治初期撮影の実写真が現存する(江戸東京博物館 温古写真集11「旧雲州松江藩松平候上屋敷門」 資料番号 88005761)。大熊喜邦の昭和14年調査で現存していた大名屋敷表門5件の一つ (書誌確定: [泥絵と大名屋敷] 大熊喜邦・昭和14。現物未見)で、東京大空襲で焼失した。

位置は [五千分一東京図31](明治16年官製実測図・0.32m/px)で確定 — 北辺の開口はただ1箇所 (北東の折れ点から辺沿い西へ、値は json の gate.s)、両脇に長大建物(表長屋の両翼)、西側は 建物のない垣が続く。門は空襲まで現存したので明治16年の開口位置は嘉永期へ強く外挿できる 【位置=A寄りB/長屋の有無・長さの外挿=B】。当初の位置(道の高みからの設計判断【U】)は この実測と食い違ったため撤回した(2026-08-23)。確度の順位: 実測A > プロジェクト規則U。

写真から読めるもの(2026-08-21 ToMuCo で実見)【確度 A】:

  • 門本体は背の高い角柱二本+冠木。柱頭に冠(銅板包みか)、柱の内面に長い飾金物。 写真の時点で冠木の上に屋根は無い。
  • 左右に向唐破風造の番所が街路側へ張り出す。出格子が正面と側面に回り、 切石積みの基壇に載る。屋根は箱棟+鬼飾り、唐破風に彫刻の兎毛通。
  • 門扉は縦板に筋金具と乳鋲。袖塀に潜り戸。
  • 門の両翼は海鼠壁の長屋で、門寄りは二階建て。左手奥に入母屋・白漆喰の大屋根。

嘉永期の正は「屋根なしの冠木門+両唐破風番所」とする(2026-08-23 改説)。 根拠:

1. 『日本案内記 関東篇』昭和5年([日本案内記 関東篇]・官製・確度A)が現役の当門を 「冠木門に属し、両側に唐破風造の番所を附属」と記述 — 写真Aと独立に屋根なしを裏づける。 2. 前案(切妻小屋根説・2026-08-22)の決め手だった「屋根なし冠木門(最下層の格)と最上格の 両唐破風番所は両立しない」という論拠は、焼失規定([焼失規定と冠木門]: 焼失後は冠木門しか 再建できず、両番所の唐破風だけで格式を判別した)で崩れた — 両立する制度的説明が存在する。 前案は撤回。ただし焼失規定の原典裏取り(『青標紙』・普請奉行の達)は未了(_pending)。 3. [黒門](屋根付き独立門+両唐破風番所)は「焼失していない国主表門」の型であり、 当門に外挿する理由にならない。

御成門・御成セット — 撤去(2026-08-23)

御成対応の3点セット(御成門+能舞台+御成風呂)は当初、[福井図](同じ結城秀康系)の類型で 置いていたが、撤去した。理由:

1. 当家への御成の記録がどの経路からも出てこない。 御成先の統計(秀忠29回・家光約300回= 大半は寵臣譜代)に当家が現れない([御成の回数]・B)。直政の年譜にも御成の項目なし(?)。 2. 御成を受けた最大の家(加賀本郷邸・寛永6年に家光+秀忠)ですら、幕末の門の構成は 大御門+御守殿門で御成門は無い([加賀本郷邸の御成]・A)。「御成門は御成が無くても 格式装置として維持された」という前提はこの実例で反証されている。 3. [福井図]の御成セットは寛永〜明暦期・龍ノ口上屋敷(当邸成立前・別敷地)の装置 ([福井図の年代]・B)。骨格(連続御殿複合・外周長屋帯)の外挿は有効でも、 御成セットは御成最盛期に固有で、200年後の嘉永期の屋敷へ既定で持ち込めない。 4. [五千分一東京図31] の北辺の開口は1箇所のみ — 御成門の開口を裏づける物証も無い。

なお御殿床面積の約14%を占めていた最弱の推定を落としたので、建蔽率は下がる — 数字を上げるために空地へ棟を足さない(絶対規則6)。福井図ジオラマ現物の実見(御成セットが 本当に描かれているかの検証)は未了(_pending)。

敷地の造成 — 面から決める

敷地全体を「4つの水平面+2つの斜面」として設計する(設計値 planes)。 造成も囲いも、まずこの面から決まる。

面何が載るか
表郭表門・白洲・厩。表門の敷居=道なり
主平面御殿複合・奥郭。敷地の主面
東上段御蔵。主平面から石段6段
堀端の裾堀端通り沿いの塀の帯
西斜面/南西の谷(+北西の登り)造成しない=樹林と庭。面の縁に竹垣

1. 面は一枚の水平面。 切盛の量は設計値 json(terraces の note)を正とする — この文書には 写さない。西斜面の近代掘削の埋め戻しは拝領時造成とは別勘定の「復元」として扱う 【出自判定は ? — 近代造成の記録は未確認】。段の造成は敷地ポリゴンでクリップし、 隣地・道へ一切波及させない。 2. 囲いの天端=面の高さ。 その辺が縁になっている面の高さを塀・長屋がそのまま持つので、 面が変わらない限り天端も変わらない — 南の土井境は P0 から辺2の肩までが一本の天端。 段差の発生点は面の境(門の開口・郭境の延長線・区画の頂点)に限る。 道・隣地との高低差はすべて石垣基壇で受ける — 台地の上に建つ屋敷が道へ石垣の面を 見せるのは、溜池端の台地肩の素直な姿。面に属さない斜面沿いの塀だけ地形なりの段を許し、 石垣の小口で納める。外周帯(内側幅3m)の整地は切盛±1.7mに収まる区間のみ。 3. 斜面の面は造成しない。 石段は開口の中でなく法面に載せる(蹴上・踏面は既定値)。

斜面の植生 — 黒松を疎に交えた雑木の樹林【確度 B】

竹林ではない。 斜面は法肩からの下りで三帯に分ける — 上部1/3=松を交えた樹林 / 中部=低木・下草 / 下部〜堀端の裾=草地。設計値は slopeBands。

根拠(強い順):

  • [橋本・堀1998](査読論文・確度A)は朱引内79事例を悉皆調査し、**溜池の水辺の樹木として 採録された2例(白山祠・山王権現)はいずれも松**、同じ外堀水系の武家地の斜面 (赤坂紀伊国坂)は「樹林」型とする。竹薮は79例中1例のみ(愛宕下 藪小路)で、 しかも「珍しい樹種で単調な空間にアクセントを付添える」扱い — 竹林は江戸の武家地斜面の既定の姿ではない。
  • 同論文は幕府御用地の緑を「外から敷地内の建物を隠蔽し、内から緑の間に水面が眺められる形態」 と記す。西庭の数寄屋から溜池を望ませる当図の意図と一致し、竹である必要はない。
  • 『江戸名所図会』巻之七「溜池」(確度A=図の実見。当屋敷の一次史料ではないので S は付けない)は、左頁遠景に「山王」の題簽を持ち 当該崖線そのものを描く。稜線=松と丸い樹冠の広葉樹の樹林、崖面はハッチング(草地・裸地)で 樹は稜線と上部に集まる → 法面全体を樹林で埋めない三帯構成の根拠。
  • 広重「赤坂桐畑」(確度A=図の実見)も対岸の山王の斜面を松+広葉樹で描き、竹は無い。 なお桐は溜池の南岸(赤坂側)の土手の護岸植栽で、東岸の崖の樹相ではない。
  • 反証: 竹の地下茎は表層30〜50cmに留まり、急斜面の竹林はむしろ表層崩壊を助長する (林野庁・確度A)。「崩落防止で崖に竹」は成り立たない。
  • 嘉永期の江戸に孟宗竹は在り得るが、在ったのは吹上御苑と近郊農村の筍畑(確度B)。 武家屋敷の竹の類型は矢竹の生垣であって斜面被覆ではない。竹は京橋竹河岸に他国から 入る「材」だった — 竹垣(R_West)の材としての竹は問題ない。

⚠ 撤回した前案(竹林)は、隣の岡部邸に揃えた自己参照だった。 岡部邸の西斜面も同じ崖線なので 同じ是正が要る(未実施)。当屋敷そのものの植栽の一次史料は無いので確度はBに留まる。 大崎園(下屋敷)の茶苑から上屋敷の斜面を類推することはできない — 機能(遊興地/本宅)・ 年代(不昧没1818と嘉永の30年差)・記録(残るのは茶室の絵画と平面図)の三点で架橋できない。

  • 西斜面(溜池東岸)と南西の谷(岡部境)の面は造成しない。 樹林と庭のまま、面の縁に竹垣。
  • 段は郭の境で起こし、石段は開口の中でなく法面に載せる。蹴上・踏面は既定値。

建蔽率と収容力

分母は敷地全体。数字は生成器が json から算出する(この文書に写さない)。

  • 大名上屋敷の建蔽率の史料値は [福井図] の5〜6割の一点しかない。 当図はそれより大きく低い (広い拝領地・表門前の白洲・奥庭・造成しない斜面の帰結)。数字を上げるために空地へ棟を足さない。
  • 表長屋の規模比(表長屋延長/外周長。数値は生成器が算出)は [追川2017] の実測3例 (加賀本郷15%・小浜28.6%・尾張市谷47.7%)の帯の中位に収まる — 原典に忠実な比較指標はこちら。 3例は必ず揃えて引く(下端を落とすと帯が狭く見える)。国主・広大地の類例としては加賀本郷が最も近い。
  • 収容力: 類例(庄内・彦根)の人数が江戸の全屋敷(上中下)合計か上屋敷単独か確認できておらず、 上屋敷単独の収容力は類例と比較できない【確度 ?】 — 下限主張はしない。 建蔽率の妥当性を収容力で補強しない。
