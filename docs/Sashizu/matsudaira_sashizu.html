屋敷の性格

出雲松江藩 十八万六千石。親藩(結城秀康系の御家門)・出雲国主・大広間詰の上屋敷。 外桜田永田町 — 赤坂御門から永田馬場へ抜ける大通りの南側、山王社の北。 西は溜池の東岸へ落ちる大斜面、南は土井大隅守邸と背中合わせ、南東の谷は岡部内膳正邸 (嘉永期の表記。安政2年以降の「筑前守」はプロジェクト内通称)に接する。 跡地は閑院宮邸を経て現在の衆参両院議長公邸。

表門 — 屋根なし冠木門+両唐破風番所

明治初期撮影の実写真が現存する(江戸東京博物館 温古写真集11「旧雲州松江藩松平候上屋敷門」 資料番号 88005761)。大熊喜邦の昭和14年調査で現存していた大名屋敷表門5件の一つ (書誌確定: [泥絵と大名屋敷] 大熊喜邦・昭和14。現物未見)で、東京大空襲で焼失した。

位置は [五千分一東京図31](明治16年官製実測図・0.32m/px)で確定 — 北辺の開口はただ1箇所 (北東の折れ点から辺沿い西へ、値は json の gate.s)、両脇に長大建物(表長屋の両翼)、西側は 建物のない垣が続く。門は空襲まで現存したので明治16年の開口位置は嘉永期へ強く外挿できる 【位置=A寄りB/長屋の有無・長さの外挿=B】。当初の位置(道の高みからの設計判断【U】)は この実測と食い違ったため撤回した(2026-08-23)。確度の順位: 実測A > プロジェクト規則U。

写真から読めるもの(2026-08-21 ToMuCo で実見)【確度 A】:

  • 門本体は背の高い角柱二本+冠木。柱頭に冠(銅板包みか)、柱の内面に長い飾金物。 写真の時点で冠木の上に屋根は無い。
  • 左右に向唐破風造の番所が街路側へ張り出す。出格子が正面と側面に回り、 切石積みの基壇に載る。屋根は箱棟+鬼飾り、唐破風に彫刻の兎毛通。
  • 門扉は縦板に筋金具と乳鋲。袖塀に潜り戸。

敷地の造成 — 面から決める

敷地全体を「4つの水平面+2つの斜面」として設計する(設計値 planes)。 造成も囲いも、まずこの面から決まる。

斜面の植生 — 黒松を疎に交えた雑木の樹林【確度 B】

竹林ではない。 斜面は法肩からの下りで三帯に分ける — 上部1/3=松を交えた樹林 / 中部=低木・下草 / 下部〜堀端の裾=草地。設計値は slopeBands。

根拠(強い順):

  • [橋本・堀1998](査読論文・確度A)は朱引内79事例を悉皆調査し、**溜池の水辺の樹木として 採録された2例(白山祠・山王権現)はいずれも松**、同じ外堀水系の武家地の斜面 (赤坂紀伊国坂)は「樹林」型とする。竹薮は79例中1例のみ(愛宕下 藪小路)で、 しかも「珍しい樹種で単調な空間にアクセントを付添える」扱い — 竹林は江戸の武家地斜面の既定の姿ではない。
  • 同論文は幕府御用地の緑を「外から敷地内の建物を隠蔽し、内から緑の間に水面が眺められる形態」 と記す。西庭の数寄屋から溜池を望ませる当図の意図と一致し、竹である必要はない。
  • 『江戸名所図会』巻之七「溜池」(確度A=図の実見。当屋敷の一次史料ではないので S は付けない)は、左頁遠景に「山王」の題簽を持ち 当該崖線そのものを描く。稜線=松と丸い樹冠の広葉樹の樹林、崖面はハッチング(草地・裸地)で 樹は稜線と上部に集まる → 法面全体を樹林で埋めない三帯構成の根拠。
  • 広重「赤坂桐畑」(確度A=図の実見)も対岸の山王の斜面を松+広葉樹で描き、竹は無い。 なお桐は溜池の南岸(赤坂側)の土手の護岸植栽で、東岸の崖の樹相ではない。
  • 反証: 竹の地下茎は表層30〜50cmに留まり、急斜面の竹林はむしろ表層崩壊を助長する (林野庁・確度A)。「崩落防止で崖に竹」は成り立たない。
  • 嘉永期の江戸に孟宗竹は在り得るが、在ったのは吹上御苑と近郊農村の筍畑(確度B)。 武家屋敷の竹の類型は矢竹の生垣であって斜面被覆ではない。竹は京橋竹河岸に他国から 入る「材」だった — 竹垣(R_West)の材としての竹は問題ない。

⚠ 撤回した前案(竹林)は、隣の岡部邸に揃えた自己参照だった。 岡部邸の西斜面も同じ崖線なので 同じ是正が要る(未実施)。当屋敷そのものの植栽の一次史料は無いので確度はBに留まる。 大崎園(下屋敷)の茶苑から上屋敷の斜面を類推することはできない — 機能(遊興地/本宅)・ 年代(不昧没1818と嘉永の30年差)・記録(残るのは茶室の絵画と平面図)の三点で架橋できない。

  • 西斜面(溜池東岸)と南西の谷(岡部境)の面は造成しない。 樹林と庭のまま、面の縁に竹垣。
  • 段は郭の境で起こし、石段は開口の中でなく法面に載せる。蹴上・踏面は既定値。
