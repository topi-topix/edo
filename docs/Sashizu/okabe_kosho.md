### 表門は地震で無事だった — 一次史料が名指しで書く

⭐ [安政地震被害書上] 記事ID **J1400017**（〔別本 藤岡屋日記 上〕東京都公文書館・
『新収日本地震史料』第5巻別巻2-1 p.330）に、当屋敷を名指す一行がある。

> 一岡部筑前守所々破損、**表門無別条**、尤潰家出火等無之

<span class="cert">確度 S — 当屋敷を名指す一次記録</span>。基準年次は地震の翌年なので、
**表門は建て替えの必要がなく、そのまま建っている**。
⛔ **EDO-0056 が各邸へ求めた「焼失規定による冠木門への降格」の再評価は、当家では史料が
正面から否定する形で決着した。**
⭐ **表門については、沈黙を読む必要がそもそも無い** — 別記録が積極的に「無別条」と書いている。

⚠ **書式に注意** — 当記録は**名が先・被害が後**（各行が「一」＋名＋被害）で、
真田家文書／むし倉後記續篇（**被害が先・名が後**）とは別書式である。
混同すると被害の割り当てが1つずれる。
⚠ 同記録の**土井の条**は当図が既に引用していたが、**岡部の条は未引用だった**。

⭐ **傍証** — 同記録は「一永田町渡辺備中守**表長屋**壁落家根瓦落其外所々破損有之、表門無別条」とも書く。
近隣の同格の屋敷にも表長屋があったことの、独立の裏づけになる。

⚠ **記録どうしの緊張を隠さない** — 当記録の「尤**潰家**出火等無之」は、
大風之記の「右外構練塀**潰**」や真田／むし倉の「御殿向**半**潰」と字面が食い違って見える。
⭕ **塀は「家」ではない**こと、**半潰は全潰ではない**ことで両立しうるが、これは当方の
読み合わせであって原典が明示しているわけではない<span class="cert">確度 U（解釈）</span>。
⭐ 復旧の重みづけに効く — **建てるのは再建された練塀だが、表門と御殿は建て替えでなく修復の姿**。

  ⚠ 2026-08-24 に規約を**一本化**した — 本文に「2.5m」、検査に別の数字と二重に持っていた。
- **本数・露出・天端差はここに書かない。** 正典は json `runs` と `const`、算出と表示は「外周の展開」の章、
  検査は `base_check()` と `corners_table()`。

頂点番号は 2026-08-22 の13頂点版（旧番号の対応は json `_polygon`）。
南辺の旧注記のうち「神社へ生活の場を向けるのは薄礼」は**規範の典拠なし**、
「土留めの帰属＝高い側が持つ」は**工学的理屈で史実の規則ではない**（sources.md §2）—
いずれもユーザー裁定（確度 U）として維持する。

**段と折れは塀が自由に越える。** 長屋は床から棟 5.3m の反復モジュールなので段を跨げず、
段の変わる隅には櫓が要った。**練塀にはその制約がない** — 笠は単純な切妻状で、
留め継ぎで折れ、段違いで落とせる。<span class="cert">【確度 B】</span>

## 囲いの据え方

- **犬走りを残す。** 長屋も練塀も、石垣の法肩から **1尺（0.30m）**控える。
  天端の縁ぎりぎりに建てると軒からの雨落ちが目地を洗い、笠石が縁で欠ける。
  城の犬走りは数mに及ぶが、屋敷境ではこれで足りる。【確度 U／B】
- **run の天端は一直線。** 面の縁は水平、斜面は一定勾配。地形追従で一枚ずつ落とさない。
- **段は折れ目に置かない。** 折れの前後で隣地の地盤が変わらないなら、そこに段を置く理由が無い。
  段は隣地の地盤が実際に落ちる位置へ移す。
- **天端は郭の地盤に合わせる。** 隣地の地盤から出した高さを天端にすると、
  こちらの地盤との間に意味のない段が立つ。隣が高い側で塀が 1m ほど埋まるのは正常。

## 隅の納め

折れ角は現地が決めるもので毎回違う。**角度を決め打ちした部材を作らない。**

- 在庫の出隅ブロック（`Castle Wall Corner`・2.4m 角）が成立するのは折れ角 Δ≳60°。
  Δ が浅いと apex が反対側の壁面から `2.4·cosΔ` はみ出す。
- 浅い折れは**留め（とめ）継ぎの隅部材**で納める。`Tools/Blender/build_kado.py` が
  在庫のモジュールを二本の腕に複製し、角度を二等分する面で切って接ぐ。**折れ角は引数**。
- **折れるだけでなく天端が上がる隅**は留めでは吸えないが、当屋敷では**隅櫓を使わない** —
  天端を run ごとの一直線にしたことで、隅と継ぎ目の天端差が**基壇の小口（隅石）で受けられる範囲**に
  収まったため（json `yagura` は空。段差の現行値は json `runs` の seat0/seat1 から出す）。
  「[福井図]に 3 基／[中屋敷図]に無い ＝ 上屋敷格の装置」という論は n=1 対 n=1 で弱く、
  撤去の裁定とともに落とす。

## 造成

- **地形は現地形に従う** — 街路・坂・水系は現地形、敷地内は拝領時造成の再現。
- **段の縁は石垣の体内へ 1.4m 食い込ませる。** 地形は 2m 格子なので、段の設計面を
  石垣の内面ちょうどで終わらせると端数がそのまま割れ目になる。
- **造成の落としは石の体内で行う。** 法肩より外に段の土を残すと、格子の端数が
  石垣の化粧面の前に立つ土の楔になる。

## 西斜面の植生 — 黒松を疎に交えた雑木の樹林【確度 B】

西辺の溜池側は郭の天端から堀端へ落ちる斜面で、**竹林ではない**。法肩から下へ三帯に分ける —
上部=松を交えた樹林 / 中部=低木・下草 / 下部〜裾=草地(高木を置かない)。設計値は `slopeBands`。

- **[橋本・堀1998]**(査読論文・確度A)は朱引内79事例の悉皆調査で、
  **溜池の水辺の樹木として採録された2例(白山祠・山王権現)はいずれも松**。同じ外堀水系の武家地の斜面(赤坂紀伊国坂)は
  「樹林」型とする。**竹薮は79例中1例のみ**(愛宕下 藪小路)で「珍しい樹種でアクセントを付添える」扱い。
- 同論文は幕府御用地の緑を「**外から敷地内の建物を隠蔽し、内から緑の間に水面が眺められる形態**」と記す。
  西辺を塀で閉じず開けておく当図の意図と一致し、**竹である必要はない。**
- **『江戸名所図会』巻之三（天璣之部）第7冊 挿画「溜池」**（[名所図会・溜池]・確度S=図の実見）は左頁遠景に「山王」の題簽を持ち、
  **この崖線そのもの**を描く。稜線=松+丸い樹冠の広葉樹、**崖面はハッチング(草地・裸地)**。
  広重「赤坂桐畑」の対岸(山王)も松+広葉樹で、**どちらにも竹は描かれていない**。
- 反証: 竹の地下茎は表層30〜50cmに留まり、**急斜面の竹林は表層崩壊を助長する**(林野庁・確度A)。
- 安政期の江戸の孟宗竹は**吹上御苑と近郊農村の筍畑**にしか無い(確度B)。武家屋敷の竹の類型は
  **矢竹の生垣**で斜面被覆ではない。竹は京橋竹河岸に他国から入る「材」だった。

⚠ **竹垣(四つ目垣)は別物で、これは残す** — 垣の材としての竹に問題は無い。

## 生活面の法肩の竹垣 — 郭内に土留めは置かない

**郭内の土留めは 0 本**（2026-08-23 に3本とも全廃）。
⛔ **全廃の理由を「どの縁も落差が小さく、壁はいずれも露出1m未満だから」と書いていたのは誤りで、
2026-08-25 に撤回した。** 実際は竹垣7本中4本の縁が落差 2m を超える（最大 3.28m・数値は指図が算出）。
全廃の本当の理由は、**2026-08-23 時点の面の高さでは壁が地中に埋まったから**である。
⚠ **地盤を作り直した後の落差でこの判断を検め直していない** — 落差3m級の縁を高さ0.9mの
四つ目垣だけで受けている。`sashizu.md` §3b の「縁ごとに測って表にしてから土留めか法面かを決める」の
回し直しを `_pending` に立てた。
段の縁は法面（盛土 1:1.5／切土 1:1.0）で摺り付く。**石垣が出るのは外周の基壇だけ。**

**造成しない斜面へ向く生活面の法肩には、低い竹垣（四つ目垣）を回す。**
本数・延長・位置は**段の多角形から算出**する（json に持たない。指図の該当章）。

- **城の石垣とは事情が違う。** 城の天端は武者走りで、落ちるのは寄せ手の問題だから柵を立てない。
  ここは屋敷の中の生活面なので、同じ作法を持ち込まない。
- **竹垣にする理由。** 郭の境は防御線ではなく段差なので、閉じる必要が無い。
  低い柵なら段の下の庭が見通せる。
  ⚠ 「西辺の溜池側で既に同じ竹垣を使っている」は**誤り**（2026-08-24 検図） —
  辺5（溜池の堤）は `F_Hori` の**木柵**で、四つ目垣ではない。作りが揃うという理由は取り下げる。
- **高さ 0.9m・法肩から内へ `const.inubashiri` + 0.15m。**
  隅では法線が交わるぶん詰まる（実距離の範囲は 指図の該当章の表が算出）。
- **石段・坂・参道の開口では切る。** 昇り降りの動線を塞がない
  （`auto_rails()` の `_in_opening()` と `crossing_check()` が機械で保証する）。
- **外周の囲いが載っている辺には回さない。** 練塀＋基壇が既に受けている落差を
  高さ0.9mの竹垣が二重になぞらない（`_on_walled_edge()`）。

**採らなかった案 — 郭を締める内塀。** 郭の境を塀で締める作りも大名屋敷にはあるが、
(a) 敷地の中が視覚的に分断され、(b) 表と奥の結界は御錠口で既に成立している。
段差を示すだけなら柵で足りる。
