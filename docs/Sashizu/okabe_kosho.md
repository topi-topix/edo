## 表門 — 放れ門（独立門）＋片番所

**外周が総築地塀になったので、放れ門（独立門）に片番所を付ける。**
位置は**東辺（三べ坂沿い）**。<span class="cert">【確度 U — ユーザーの区割り指定を優先】</span>

### 従前の根拠は崩れている

2026-08-15 に「冠木門 → 長屋門」と変えた唯一の典拠 [表門格式表]（5万石以上は長屋門）は、
**記載された出典本文に存在しなかった**（出典URLは404、Wayback で復元した本文に石高別の表は無く、
「五万石以下の**旗本**屋敷」という破綻した記述を含む）。確度は B → **?** へ降格した。
<span class="cert">【2026-08-21 考証方の指摘】</span>

あわせて前提も一つ外れていた。**「外周に長屋が無ければ長屋門は成立しない」は成り立たない** —
長屋門は門の両側に門番部屋・仲間部屋を持つ一棟の建物で、両袖が築地塀に連続する単独の長屋門
（門長屋）は形式として成立する。「長屋門を建てたらその辺は長屋塀」は**このプロジェクトの実装作法**
であって史実の規則ではなかった。<span class="cert">【確度 B】</span>

**したがって形式は典拠からは決まらない。放れ門を採るのは設計判断である。**
<span class="cert">【確度 U — 五万三千石の表門の典拠は無い】</span>

### 納まり

- **番所は門に接して建ち、その外壁が外周線を引き継ぐ。** 離した小屋にはしない。
  順は **門柱 → 繋塀（袖塀）→ 番所 → 築地塀**。
  [黒門]（旧因州池田屋敷表門・鳥取32.5万石の上屋敷表門・重文・確度 A）は門の左右に唐破風造の番所。
  [赤門]（重文・確度 A）は 門 → 海鼠壁の繋塀 → 唐破風造の番所 の順。
- **片番所（出格子）にする。** 左右両方に唐破風番所を置くのは国持・御守殿の格（加賀102万石・鳥取32.5万石）で、
  五万三千石には上がりすぎる。[高知2000]系も「番所は表門の脇、片側だけでも史実的」とする。<span class="cert">【確度 A】</span>
- **袖塀（繋塀）は要る。実体として置く。** 従前の「袖塀は不要」は長屋門前提の記述で、独立門では逆になる。
  「端パネルのストレッチで代用」も撤回 — その処理は長屋専用で、総築地塀化後は何も建たない
  （2026-08-21 の事故で判明）。繋塀は塀と同じ断面の短い run として実体を建てる。
- **赤門は表門ではなく御守殿門。** 朱塗りと両唐破風番所は将軍家の姫を迎えた家の特権なので、
  当家には当てられない。<span class="cert">【確度 A — 文京区公式】</span>

## 囲いの種別 — 外周は総築地塀

**2026-08-21 にユーザー裁定で大きく変更した。長屋塀を全廃し、東辺（P0–P10）・北東の隅切り（P10–P9）・
北辺の東端（P9–P8）を含め、外周をすべて築地塀にする。**【確度 U】

**これは「格式を上げる変更」ではない。** [追川2017→宮崎1994] の原文は
「**表門に連なる塀**に、長屋塀を構築することを避けた」で、**表門のある一辺の話**である。
同じ引用が挙げる加賀藩本郷邸自身が、南＝盲長屋／東＝長屋塀＋石垣で総築地塀ではない。
[追川2017] が実測した3邸（加賀 15%・尾張市谷 47.7%・小浜 28.6%）は**すべて表長屋を持つ**ので、
0% は観測範囲の外にある。`estate-types.md` の「**中小藩ほど外周を長屋で使い切る**」に照らすと、
五万三千石で外周長屋ゼロは類型としてむしろ逆向きである。
**史実の類型から外れる変更**として書く。<span class="cert">【確度 U — ユーザー裁定 2026-08-21】</span>

**捨てるものを明示しておく。** [西川1959]（確度 A）は二層構造を記録している —
御殿を囲む中間帯に中間足軽長屋、**その外側に定府家臣の長屋**。外周を消すと外層が丸ごと消える。
[福井図] は外周長屋を「江戸勤番の藩士が居住し、いざというとき藩主の盾になる」とするので、
**外周という位置そのものが機能**だった。家臣住居は 488坪 → 268坪（−45%）になる。
建蔽率は 33.7% → 約 31.8% で史料値レンジ（22〜55%）を外れないので、**問題は建蔽率ではなく収容力**。

**囲いは 1 条。**[丸の内三丁目]（確度 A）— 隣り合う 2 家の屋敷境に引かれたのは 1 条の区画溝で、
両家がそれぞれ建てて二重になる作りではない。**どちらが持つかを定めた規則は史料未確認**なので、

**段と折れは塀が自由に越える。** 長屋は床から棟 5.3m の反復モジュールなので段を跨げず、
段の変わる隅には櫓が要った。**築地塀にはその制約がない** — 笠は単純な切妻状で、
留め継ぎで折れ、段違いで落とせる。<span class="cert">【確度 B】</span>

## 囲いの据え方

- **犬走りを残す。** 長屋も築地塀も、石垣の法肩から **1尺（0.30m）**控える。
  天端の縁ぎりぎりに建てると軒からの雨落ちが目地を洗い、笠石が縁で欠ける。
  城の犬走りは数mに及ぶが、屋敷境ではこれで足りる。【確度 U／B】
- **run の天端は一定。** 地形追従で一枚ずつ落とさない。段は run の継ぎ目で落とす。
- **段は折れ目に置かない。** 折れの前後で隣地の地盤が変わらないなら、そこに段を置く理由が無い。
  段は隣地の地盤が実際に落ちる位置へ移す。
- **天端は郭の地盤に合わせる。** 隣地の地盤から出した高さを天端にすると、
  こちらの地盤との間に意味のない段が立つ。隣が高い側で塀が 1m ほど埋まるのは正常。

## 隅の納め

折れ角は現地が決めるもので毎回違う。**角度を決め打ちした部材を作らない。**

- 在庫の出隅ブロック（`Castle Wall Corner`・2.4m 角）が成立するのは折れ角 Δ≳60°。
  Δ が浅いと apex が反対側の壁面から `2.4·cosΔ` はみ出す。
- 浅い折れは**留め（とめ）継ぎの隅部材**で納める。`Tools/Blender/build_kado.py` が
  在庫のモジュールを二本の腕に複製し、角度を二等分する面で切って接ぐ。**折れ角は引数**。
- **折れるだけでなく天端が上がる隅は、留めでは吸えない。** 隅櫓で納める。

隅櫓は[福井図]では上屋敷の外周に 3 基あり、[中屋敷図]には無い → **上屋敷格の装置**。【確度 B】

## 造成

- **地形は現地形に従う** — 街路・坂・水系は現地形、敷地内は拝領時造成の再現。
- **段の矩形は石垣の体内へ 1.4m 食い込ませる。** 地形は 2m 格子なので、段の設計面を
  石垣の内面ちょうどで終わらせると端数がそのまま割れ目になる。
- **造成の落としは石の体内で行う。** 法肩より外に段の土を残すと、格子の端数が
  石垣の化粧面の前に立つ土の楔になる。

## 建物の構成

**連続御殿複合 ＋ 外周長屋帯。** 開放地は白洲と中庭だけ。

- **表向** — 白洲を横切り石段を上がって車寄せ（向拝）・御式台・御玄関。
  車寄せは玄関棟の東面に三間×一間で出し、大棟を壁と平行（南北）に通した低い切妻とする
  — 妻入りにすると屋根が玄関棟の軒を越えて谷が要る。式台は玄関の床から一段下がり、前に沓脱を置く。
  **前庭に屋根が架かるのはここまで。** 渡廊下で表御殿群へ渡り、三之間・二之間・大広間。
  北へ渡廊下で書院群（黒書院・白書院）。
- **中奥** — 御座之間・御休息之間・御小姓部屋・御風呂屋。
  北の台所群に大台所・御料理間・御膳所・御納戸。
- **奥向** — 奥向へ入る廊下は**御錠口の一本だけ**。台所棟から奥向棟へ直結する廊下は撤去した
  （二本あると錠の意味がなくなる）。奥向棟・長局棟・西の下郭はすべてこの一本の先にあり、
  錠で締め切れる。奥御座之間・御対面所。南に長局二列を別棟で置き、渡廊下で結ぶ。
- **雁行する棟の取り合い** — 谷や隅は生成せず、各棟は独立した入母屋のまま置いて、
  その軒下を渡廊下の低い切妻がくぐる。福井図・二条城も同じ形。【ユーザー裁定 2026-08-14】

## 郭の縁の柵

**郭の土留めの天端に、低い竹垣（四つ目垣）を回す。**

四本の土留めはいずれも**落差 6〜8m**で、天端は御殿と廊下のすぐ脇を女中・家臣が歩く面である。
素の縁のままにはしない。

- **城の石垣とは事情が違う。** 城の天端は武者走りで、落ちるのは寄せ手の問題だから柵を立てない。
  ここは屋敷の中の生活面なので、同じ作法を持ち込まない。
- **竹垣にする理由。** 郭の境は防御線ではなく段差なので、閉じる必要が無い。
  低い柵なら段の下の庭・長屋列が見通せ、石垣も隠れない。
  西辺の溜池側で既に同じ竹垣を使っているので、屋敷の中で作りが揃う。
- **高さ 0.9m・法肩から内へ 0.45m。** 天端幅は 1.4×s（2.1〜2.8m）あるので、
  柵の外に犬走りが残り、雨落ちが目地に直に当たらない。
- **石段の開口では切る。** 昇り降りの動線を塞がない。
- **家臣長屋が載る区間には立てない**（W1・W2 の z 949〜1037）。躯体そのものが縁を塞いでいる。

**採らなかった案 — 内塀（築地塀）。** 郭の境を塀で締める作りも大名屋敷にはあるが、
(a) 敷地の中が視覚的に分断され、(b) せっかくの石垣が隠れ、(c) 表と奥の結界は御錠口で
既に成立している。段差を示すだけなら柵で足りる。
