## 屋敷の性格

譜代雁間 五万三千石の**上屋敷**。赤坂・山王社の北、三べ坂に面する。
敷地は三方を武家地と社寺に囲まれ、西は溜池の岸へ落ちる。

- **基準年次は嘉永3年（1850・基図の板年）。** 当時の当主は10代 内膳正（長和）。
  ⚠ 長和は**嘉永3年9月24日に没し**、弟の長発が跡を継ぐ（<span class="cert">確度 B — Web二次</span>）
  ので、「当主＝長和」と言えるのは同年9月まで。長和は天保14年より奏者番（門の格には効かない）。
  「岡部筑前守」は12代 長寛（安政2年家督）以降の受領名。**基準年次が嘉永3年なので表題は「内膳正」を採る**
  （実装のメニュー名 `Edo/岡部筑前守上屋敷/…` は歴史的な事情でそのまま）。
  安政江戸地震（安政2年）系の記録は「倒れる前の姿」として遡って使う（土井邸と同じ作法）。
  <span class="cert">【確度 U — 呼称の設計判断】</span>

- **御成の装置は作らない。** 御成門・能舞台・御成風呂は家門・大藩の設備で、当家に典拠がない。[加賀本郷邸の御成]A は**御成を受けた最大の家でも幕末プランに御成門が無い**ことを示す。
  福井図で御成門を持つ越前松平は家門。
  【確度 B — 一般類型／当屋敷の一次史料は未確認】
- **池は掘らない。** 泉水庭は州浜と築山のみ。典拠がない物を既成事実にしない。
  【確度 ? — 未確認】
- **敷地内の構成は一般類型。** 当屋敷の指図・絵画は未発見。
  【確度 B】

## 表門 — 長屋門（門長屋）＋片流れの張出し両番所

どの辺かは**東辺（三べ坂沿い）**で確定 — NDL1286657 で「岡部内膳正」の文字の頭が
東辺を向く（IIIF 実見・<span class="cert">確度 A</span>）。

### 形式は実例から決まった（2026-08-23 改稿）

従前は「典拠が無いので放れ門＋片番所を採るのは設計判断」としていたが、
**同格の現物が官製記録つきで見つかったので確度 A／B で埋まった。**

| 実例 | 石高・格・屋敷 | 形式 | 番所 |
|---|---|---|---|
| [山脇武家屋敷門]（重文・文化庁） | **岡崎藩本多家 5万石・譜代・江戸上屋敷の表門** | **長屋門** 桁行21.8m・梁間4.7m・二階建・切妻造 | **片流面出番所** |
| [西澄寺武家屋敷門]（都指定） | 蜂須賀家の屋敷門（「中屋敷」は伝。解説は「5〜10万石**程度**の大名の屋敷門としての格式」） | 長屋門 桁行9間16.89m・梁間2.5間4.37m・門戸6間11.31m（中央2間が門扉・両脇1間が潜戸・両側1間は板壁） | **両出番所**（桁行1.5間） |
| [黒門]（重文） | 鳥取池田 32.5万石・上屋敷 | 独立門・入母屋造 | 両番所・**向唐破風造** |
| [赤門]（重文） | 加賀 102万石・**御守殿門** | 三間薬医門＋左右繋塀（各4.1m）＋番所 | 両番所・**前後唐破風造** |

**階梯**（[武家屋敷門の格式階梯]・<span class="cert">確度 B</span>。上の官製構造形式2件と独立に一致する）:
10万石以上＝唐破風の両番所／**5〜10万石＝長屋門＋片流れの張出し両番所**／5万石以下＝片番所。

- **五万三千石は「5〜10万石」の帯に入る。** よって長屋門＋両出番所。屋根は唐破風にしない。
- **撤回**：「左右両方に番所を置くのは国持・御守殿の格だから五万三千石には上がりすぎる」は
  **反証された**。最上格の2例（加賀・鳥取）しか見ていない標本の偏りで、
  5万石の譜代上屋敷が両番所を持つ現物（山脇門）がある。
- **撤回**：「独立門＋繋塀＋番所」は、官製記録では**102万石の御守殿門（赤門）の構造形式そのもの**。
  中小藩の表門に当てない。
- **「門長屋」（一棟で閉じる長屋門）の現物は西澄寺門。** 桁行9間で完結し、
  中央2間が門扉、その両脇1間が潜戸、**両側1間は板壁**。両袖を練塀へ継ぐ納まりはここから採る。
- ⚠ **山脇門は「門長屋」の証拠にならない。** 原形は「桁行五十八間（約120m）**もの長屋門**」で、
  現在の「袖が塀に付く」姿は昭和〜平成の移築で左右を切り縮めた結果である。
  **江戸期の姿は門の両袖が120mの表長屋**であり、これは**総練塀の反証**にあたる —
  同格（5万石譜代上屋敷）の現物が、むしろ長大な表長屋を持っていた。
  総練塀は <span class="cert">確度 U（ユーザー裁定）</span>のままで、
  **史実の類型から外れる変更**という位置づけを弱めない。
- <span class="cert">【一番弱い環】</span>**番所の数は文化庁の記録に無い。**
  官製の構造形式は「片流面出番所附属」とだけ書き、数を書いていない。「門と左右番所」の出所は
  学校側の記述（[山脇武家屋敷門] 参照）。両番所を支える主証拠は**西澄寺門**（桁行1.5間の番所が両端）。
  なお山脇門の再建時の当主は老中で、老中格による嵩上げの可能性も残る。

**寸法** — 実例の実測は <span class="cert">確度 A</span>、**当屋敷への採用値は
<span class="cert">確度 U</span>（外挿）**。実測の幅は 一棟の桁行 16.89〜21.8m（9〜12間）／
梁間 4.37〜4.7m（2.5間）／門戸部 11.31m（6間）／**扉開口は西澄寺の「中央2間」= 3.64m**。
設計値は json の `gate`。

⚠ **部材は要選定。** 在庫の `es_kmon/k_mon` は放れ門なので使えない。
また `asset-catalog.md` の「k_mon 幅 14.4m」は**屋根の妻端間**で、柱間は 8.87m（4.9間）—
間口として引くと過大になる。

### 明治図から門を読む道は閉じた

[五千分一東京図31] を実見したが、**明治16年の東辺一帯は既に永田町一丁目の町地**
（明治5年の町立て・[永田町の町立て]）で、当時の高崎邸の囲いは崖の法肩まで後退し、
取付道も北辺に移っている。門開口・番所・大名塀はいずれも無い。
松平出羽守邸で門が読めたのは、あの区画が「宮内省用地」として一筆のまま残ったためで、
**岡部には当たらない**。<span class="cert">【確度 A — 不存在の確認】</span>
次に当たるべきは『御府内往還其外沿革図書』（幕府普請方）の永田町・山王の丁。

### 北東の袋小路（土井境の楔）と辻番所（2026-08-23 実見）

ユーザーの着眼（「土井との間の行き止まりの隙間道は表門の入口では？」）を受けて
NDL1286657 を実見した。

- **袋小路は切絵図に道として実在する。** 黄色で描かれ、三べ坂の折れ点（P12）から
  土井境を南西へ入り、**行き止まりで終わる**（その先は境界線のみ）。
  **図形の存在＝確度 A（実見）／「黄色＝街路」という同定＝確度 B（凡例の解釈）。**
  区画正典の楔（幅 約10.4m）・下書きの袋小路スタブと**矛盾しない** — ただし下書きは同じ
  切絵図由来なので独立検証ではない（<span class="cert">確度 P</span>）。
- **口の街路上に辻番所。** 黒枠の小さな四角が袋小路の口・岡部側の角に描かれる。
  [しんこうWeb 表門]「敷地外の黒い■は辻番所」に合致し、同型の四角が同図の他の辻
  （半蔵御門・麹町の辻・渡辺の角）にも繰り返し出る。**門ズレ印（黒い■）の読みは棄却** —
  印は敷地外（街路上）にあり、中屋敷の■（塗り潰し）とも形が違う。
  **図形の存在＝A（実見）／辻番所という同定＝B。** 辻番は近隣武家の組合で維持する街路上の
  共同設備で、どちらの屋敷にも属さない。
- **表門がこの小路に開く読みは採らない** — 正門の辺は文字の頭（東辺・確度A）と衝突する。
  ただし、口に辻番を置く袋小路は**奥に出入口（通用口・裏門）を持つのが通例**で、
  岡部・土井のどちらか（または両方）の勝手口がここに開いたと推定するのが最も整合的。
  どちらの家かは未確定。<span class="cert">【確度 B — 類型／U — 当屋敷への適用】</span>
- **帰結**: 独立な手がかりは「紋の位置」と「北東角に袋小路＋辻番の結節点があること」の**二つ**
  （提案の門位置は紋から導いた従属変数なので、収束の根拠には数えない）。
  「屋敷の出入りの角は北東」という読みを**弱く**補強する。

### 納まり

- **門・両番所は一棟の長屋門。** 番所は門の躯体に含まれ、離した小屋にはしない。
  **袖塀は無い** — 長屋門の両袖がそのまま練塀へ連続する（門長屋）。
  囲いの線は 練塀（南）→ 長屋門 → 練塀（北）の一連。
- **番所の屋根は片流れの張出し。** 唐破風にしない（[黒門] 32.5万石・[赤門] 御守殿門の格）。
- **赤門は表門ではなく御守殿門。** 朱塗りと両唐破風番所は将軍家の姫を迎えた家の特権なので、
  当家には当てられない。<span class="cert">【確度 A — 文京区公式】</span>
- **叩き（門前）と門の足元の納まりは引き直し待ち** — 現行の設計値は放れ門 `k_mon` の実測で、
  形式が変わったので無効（json `_pending.open`）。

## 囲いの種別 — 外周は総練塀

**三層に分けて読む。**

0. **語は「練塀」。** 一次記録が使う唯一の語が「外構練塀」なので、構法は**練塀**（瓦と土を交互に積む）で通す。
   隣の土井邸・松江松平邸の指図も練塀を採るので、街区で構法が割れない。
   ⚠ 2026-08-23 まで当図だけ「築地塀」（版築）と書いていた。**S が保証するのは「塀」までで、
   練塀という構法まで当屋敷で確かめられたわけではない**が、記録の語から離れる理由も無い。

1. **外構が「塀」であったこと ＝ 確度 S（暫定）。** [安政地震被害書上] の3邸一括の記事
   「上 土井大隅守殿 右外構練塀潰其外所々大破」に**当屋敷が含まれる**。
   当屋敷を名指す同時代の記録が「外構＝練塀」と言っている以上、種別は推定ではない。
   <span class="cert">【確度 S（暫定）】</span>
   ⚠ **原文で当家が名指しされる箇所は `sources.md` に未引用**（引かれているのは土井を名指す断片だけ）。
   東大地震研の地震史料集DBで全文を採って `sources.md` へ追記するまで、この S は**暫定**とする。
2. **どの辺か・全周かは書かれていない ＝ 確度 U。** 同じ記事は辺も所有も語らない。
   全13辺のうち **10辺に塀、1辺（堀端）に木柵**を当家が建てるという配りは**当方の裁定**である。
3. **どちらの家が持つかを定めた規則も史料未確認 ＝ 確度 U。** [丸の内三丁目]（確度 A）が言うのは
   「屋敷境に引かれたのは**1条**の区画溝で、両家が二重に建てる作りではない」ところまでで、
   どちらが持つかは決めていない（`sources.md` §2 が「⛔ 未解決 — 典拠なし」と明記）。

**表長屋を0本にしたことだけは類型から外れる。** [追川2017] が実測した3邸（加賀 15%・
尾張市谷 47.7%・小浜 28.6%）は**すべて表長屋を持ち**、`estate-types.md` の
「中小藩ほど外周を長屋で使い切る」に照らすと五万三千石で外周長屋ゼロは逆向きである。
⚠ 同論文が引く「表門に連なる塀に、長屋塀を構築することを避けた」（宮崎1994 経由・**本文未入手**）は
**表門のある一辺の話**で、全周の根拠にはならない。<span class="cert">【確度 U — ユーザー裁定 2026-08-21】</span>

**捨てるものを明示しておく。** [西川1959]（確度 A）は二層構造を記録している —
御殿を囲む中間帯に中間足軽長屋、**その外側に定府家臣の長屋**。外周を消すと外層が丸ごと消える。
[福井図] は外周長屋を「江戸勤番の藩士が居住し、いざというとき藩主の盾になる」とするので、
**外周という位置そのものが機能**だった。ここで失われるのは面積ではなく、その位置と役目である。
**収容人数を根拠に敷地内へ棟を足すことはしない** — 家臣の員数に典拠が無く、
長屋の躯体面積から逆算した数字は自作の成果物にすぎないため。<span class="cert">【確度 U】</span>

## 囲いの据え方

- **犬走りを残す。** 長屋も練塀も、石垣の法肩から **1尺（0.30m）**控える。
  天端の縁ぎりぎりに建てると軒からの雨落ちが目地を洗い、笠石が縁で欠ける。
  城の犬走りは数mに及ぶが、屋敷境ではこれで足りる。【確度 U／B】
- **run の天端は一直線。** 面の縁は水平、斜面は一定勾配。地形追従で一枚ずつ落とさない。
- **段は折れ目に置かない。** 折れの前後で隣地の地盤が変わらないなら、そこに段を置く理由が無い。
  段は隣地の地盤が実際に落ちる位置へ移す。
- **天端は郭の地盤に合わせる。** 隣地の地盤から出した高さを天端にすると、
  こちらの地盤との間に意味のない段が立つ。隣が高い側で塀が 1m ほど埋まるのは正常。

## 隅の納め

折れ角は現地が決めるもので毎回違う。**角度を決め打ちした部材を作らない。**

- 在庫の出隅ブロック（`Castle Wall Corner`・2.4m 角）が成立するのは折れ角 Δ≳60°。
  Δ が浅いと apex が反対側の壁面から `2.4·cosΔ` はみ出す。
- 浅い折れは**留め（とめ）継ぎの隅部材**で納める。`Tools/Blender/build_kado.py` が
  在庫のモジュールを二本の腕に複製し、角度を二等分する面で切って接ぐ。**折れ角は引数**。
- **折れるだけでなく天端が上がる隅**は留めでは吸えないが、当屋敷では**隅櫓を使わない** —
  天端を run ごとの一直線にしたことで、隅と継ぎ目の天端差が**基壇の小口（隅石）で受けられる範囲**に
  収まったため（json `yagura` は空。段差の現行値は json `runs` の seat0/seat1 から出す）。
  「[福井図]に 3 基／[中屋敷図]に無い ＝ 上屋敷格の装置」という論は n=1 対 n=1 で弱く、
  撤去の裁定とともに落とす。

## 西斜面の植生 — 黒松を疎に交えた雑木の樹林【確度 B】

  「樹林」型とする。**竹薮は79例中1例のみ**(愛宕下 藪小路)で「珍しい樹種でアクセントを付添える」扱い。

- **『江戸名所図会』巻之三（天璣之部）第7冊 挿画「溜池」**（[名所図会・溜池]・確度S=図の実見）は左頁遠景に「山王」の題簽を持ち、

## 生活面の法肩の竹垣 — 郭内に土留めは置かない

**`okabe_edo_dem.json` ＝ 江戸期の復元地盤**（近代造成を戻したもの・確度U/B）、
**`okabe_dem.json` ＝ 現況の世界座標2m格子**（現況図の段彩・等高線用）。
**`okabe_edo_world.json` ＝ 江戸期の復元地盤の世界座標2m格子**（現況図の段彩・等高線、
断面の破線、外周の地盤プロファイルはすべてここから出す）。

⚠ **区画内セルの約 75% は復元値**で、実測が残るのは台地の南半と北東の帯だけ。
台地の 24.8 は盛土を免れた実測 563 セルの中央値 24.76（振れ ±0.6m）から採った。
**面の高さの検査（|設計面−自然地形| ≦ 0.5m）は、復元した区域では自分が置いた値を測り返している**
にすぎない（§A-6「地形の出自を疑う」）。この弱点を消せる一番安い一手は
[五千分一東京図31] の 12〜14m 等高線を1〜2点読むこと。

**設計・検図・作図はすべて江戸期の復元地盤を基準面にする。** 現況（`okabe_terrain.json` /
`okabe_dem.json`）を使うのは「近代造成の除去量」を出すときだけ。
2026-08-23 の検図で断面の破線と外周の地盤プロファイルだけ現況のままだったのを是正した。

### 切盛は二層で持つ

**拝領時造成**（江戸期の地盤に対して）と、**近代造成の除去**（日比谷高校の校庭・校舎の盛土を削る分）を
分けて数える（設計値は json の `grading`）。**後者は史実の土工ではない** — 量を史実の切土として
報告してはならない。

### 必ず入れる四つの図

`sashizu.md` §3a〜§3d に従い、**現況図（段彩＋等高線）・切盛図（暖色＝盛土／寒色＝切土）・
断面（東西南北の格子）・動線図（表向／役方／勝手／奥向）**を入れた。
とくに**勝手の動線**は、米や薪が表門から石段を登る設計になっていないかを図で確かめるためのもので、
当図では**通用口（袋小路）から北東のランプを登って台所へ**入る経路を引いてある。

### 囲いは面の縁にだけ立てる

**塀と石垣基壇は面（造成した平場）の縁にだけ立てる。斜面・谷・水際の囲いは崖と樹林＋法肩の竹垣が担い、
境界は木柵で標示する**（松江松平邸で確立したプロジェクトの作法・<span class="cert">確度 U</span>）。
辺ごとの性格は json の `edges`、地盤は `edgeProfile`（実測・<span class="cert">確度 P</span>）。
水際の木柵は [広重・赤坂桐畑]（<span class="cert">確度 B</span>）が溜池対岸に描く柵に倣う。
