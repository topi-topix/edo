## 囲いの据え方

- **犬走りを残す。** 長屋も練塀も、石垣の法肩から **1尺（0.30m）**控える。
  天端の縁ぎりぎりに建てると軒からの雨落ちが目地を洗い、笠石が縁で欠ける。
  城の犬走りは数mに及ぶが、屋敷境ではこれで足りる。【確度 U／B】
- **run の天端は一直線。** 面の縁は水平、斜面は一定勾配。地形追従で一枚ずつ落とさない。
- **段は折れ目に置かない。** 折れの前後で隣地の地盤が変わらないなら、そこに段を置く理由が無い。
  段は隣地の地盤が実際に落ちる位置へ移す。
- **隅では両側の天端を揃える。** 頂点と、一直線上で run が替わる点では、両側の端の天端を高いほうに揃え、
  差は同じ辺の中の継ぎ目で落とす。値の扱いは json `_runs` の注記。<span class="cert">【確度 U — 検分2巡 2026-10-01】</span>
- **天端は郭の地盤に合わせる。** 隣地の地盤から出した高さを天端にすると、
  こちらの地盤との間に意味のない段が立つ。隣が高い側で塀が 1m ほど埋まるのは正常。

## 隅の納め

折れ角は現地が決めるもので毎回違う。**角度を決め打ちした部材を作らない。**

- 在庫の出隅ブロック（`Castle Wall Corner`・2.4m 角）が成立するのは折れ角 Δ≳60°。
  Δ が浅いと apex が反対側の壁面から `2.4·cosΔ` はみ出す。
- 浅い折れは**留め（とめ）継ぎの隅部材**で納める。`Tools/Blender/build_kado.py` が
  在庫のモジュールを二本の腕に複製し、角度を二等分する面で切って接ぐ。**折れ角は引数**。
- **折れるだけでなく天端が上がる隅**は留めでは吸えないが、当屋敷では**隅櫓を使わない** —
  天端を run ごとの一直線にしたことで、隅と継ぎ目の天端差が**基壇の小口（隅石）で受けられる範囲**に
  収まったため（json `yagura` は空。段差の現行値は json `runs` の seat0/seat1 から出す）。
  「[福井図]に 3 基／[中屋敷図]に無い ＝ 上屋敷格の装置」という論は n=1 対 n=1 で弱く、
  撤去の裁定とともに落とす。

  （昭和22〜48年の用地買収・昭和30年の整備事業。範囲と標高は json `sections` と `okabe_terrain.json`）。**使わない。**
- **台地面の北半** … z1000 以北で +1〜4m 盛土（校舎面）。**使わない。**
- **西斜面の裾** … −2〜3m 切土（外堀通り側の街区造成）。
