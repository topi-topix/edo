## 屋敷の性格

譜代雁間 五万三千石の**上屋敷**。赤坂・山王社の北、三べ坂に面する。
敷地は三方を武家地と社寺に囲まれ、西は溜池の岸へ落ちる。

- **基準年次は嘉永3年（1850・基図の板年）。** 当時の当主は10代 内膳正（長和）。
  ⚠ 長和は**嘉永3年9月24日に没し**、弟の長発が跡を継ぐ（<span class="cert">確度 B — Web二次</span>）
  ので、「当主＝長和」と言えるのは同年9月まで。長和は天保14年より奏者番（門の格には効かない）。
  「岡部筑前守」は12代 長寛（安政2年家督）以降の受領名で、**家の通称として表題に用いる**。
  安政江戸地震（安政2年）系の記録は「倒れる前の姿」として遡って使う（土井邸と同じ作法）。
  <span class="cert">【確度 U — 呼称の設計判断】</span>

- **御成の装置は作らない。** 御成門・能舞台・御成風呂は家門・大藩の設備で、当家に典拠がない。
  福井図で御成門を持つ越前松平は家門。
  【確度 B — 一般類型／当屋敷の一次史料は未確認】
- **池は掘らない。** 泉水庭は州浜と築山のみ。典拠がない物を既成事実にしない。
  【確度 ? — 未確認】
- **敷地内の構成は一般類型。** 当屋敷の指図・絵画は未発見。
  【確度 B】

従前は「典拠が無いので放れ門＋片番所を採るのは設計判断」としていたが、
**同格の現物が官製記録つきで見つかったので確度 A／B で埋まった。**

10万石以上＝唐破風の両番所／**5〜10万石＝長屋門＋片流れの張出し両番所**／5万石以下＝片番所。

- **五万三千石は「5〜10万石」の帯に入る。** よって長屋門＋両出番所。屋根は唐破風にしない。
- **撤回**：「左右両方に番所を置くのは国持・御守殿の格だから五万三千石には上がりすぎる」は
  **反証された**。最上格の2例（加賀・鳥取）しか見ていない標本の偏りで、
  5万石の譜代上屋敷が両番所を持つ現物（山脇門）がある。
- **撤回**：「独立門＋繋塀＋番所」は、官製記録では**102万石の御守殿門（赤門）の構造形式そのもの**。
  中小藩の表門に当てない。
- **「門長屋」（一棟で閉じる長屋門）の現物は西澄寺門。** 桁行9間で完結し、
  中央2間が門扉、その両脇1間が潜戸、**両側1間は板壁**。両袖を築地塀へ継ぐ納まりはここから採る。
- ⚠ **山脇門は「門長屋」の証拠にならない。** 原形は「桁行五十八間（約120m）**もの長屋門**」で、
  現在の「袖が塀に付く」姿は昭和〜平成の移築で左右を切り縮めた結果である。
  **江戸期の姿は門の両袖が120mの表長屋**であり、これは**総築地塀の反証**にあたる —
  同格（5万石譜代上屋敷）の現物が、むしろ長大な表長屋を持っていた。
  総築地塀は <span class="cert">確度 U（ユーザー裁定）</span>のままで、
  **史実の類型から外れる変更**という位置づけを弱めない。
- <span class="cert">【一番弱い環】</span>**番所の数は文化庁の記録に無い。**
  官製の構造形式は「片流面出番所附属」とだけ書き、数を書いていない。「門と左右番所」の出所は
  学校側の記述（[山脇武家屋敷門] 参照）。両番所を支える主証拠は**西澄寺門**（桁行1.5間の番所が両端）。

### 明治図から門を読む道は閉じた

### 北東の袋小路（土井境の楔）と辻番所（2026-08-23 実見）

ユーザーの着眼（「土井との間の行き止まりの隙間道は表門の入口では？」）を受けて
NDL1286657 を実見した。

- **袋小路は切絵図に道として実在する。** 黄色で描かれ、三べ坂の折れ点（P12）から
  土井境を南西へ入り、**行き止まりで終わる**（その先は境界線のみ）。
  **図形の存在＝確度 A（実見）／「黄色＝街路」という同定＝確度 B（凡例の解釈）。**
  区画正典の楔（幅 約10.4m）・下書きの袋小路スタブと**矛盾しない** — ただし下書きは同じ
  切絵図由来なので独立検証ではない（<span class="cert">確度 P</span>）。
- **口の街路上に辻番所。** 黒枠の小さな四角が袋小路の口・岡部側の角に描かれる。
  [しんこうWeb 表門]「敷地外の黒い■は辻番所」に合致し、同型の四角が同図の他の辻
  （半蔵御門・麹町の辻・渡辺の角）にも繰り返し出る。**門ズレ印（黒い■）の読みは棄却** —
  印は敷地外（街路上）にあり、中屋敷の■（塗り潰し）とも形が違う。
  **図形の存在＝A（実見）／辻番所という同定＝B。** 辻番は近隣武家の組合で維持する街路上の
  共同設備で、どちらの屋敷にも属さない。
- **表門がこの小路に開く読みは採らない** — 正門の辺は文字の頭（東辺・確度A）と衝突する。
  ただし、口に辻番を置く袋小路は**奥に出入口（通用口・裏門）を持つのが通例**で、
  岡部・土井のどちらか（または両方）の勝手口がここに開いたと推定するのが最も整合的。
  どちらの家かは未確定。<span class="cert">【確度 B — 類型／U — 当屋敷への適用】</span>
- **帰結**: 独立な手がかりは「紋の位置」と「北東角に袋小路＋辻番の結節点があること」の**二つ**
  （提案の門位置は紋から導いた従属変数なので、収束の根拠には数えない）。
  「屋敷の出入りの角は北東」という読みを**弱く**補強する。

## 囲いの種別 — 外周は総築地塀

**2026-08-21 にユーザー裁定で大きく変更した。長屋塀を全廃し、東辺・北東の隅切り・
北辺の東端を含め、外周をすべて築地塀にする。**【確度 U】

**これは「格式を上げる変更」ではない。** [追川2017] に記録されている引用（宮崎1994 経由。
⚠ **本文未入手で原文照合はできていない**）は「表門に連なる塀に、長屋塀を構築することを避けた」で、
**表門のある一辺の話**である。
同じ引用が挙げる加賀藩本郷邸自身が、南＝盲長屋／東＝長屋塀＋石垣で総築地塀ではない。
[追川2017] が実測した3邸（加賀 15%・尾張市谷 47.7%・小浜 28.6%）は**すべて表長屋を持つ**ので、
0% は観測範囲の外にある。`estate-types.md` の「**中小藩ほど外周を長屋で使い切る**」に照らすと、
五万三千石で外周長屋ゼロは類型としてむしろ逆向きである。
**史実の類型から外れる変更**として書く。<span class="cert">【確度 U — ユーザー裁定 2026-08-21】</span>

**捨てるものを明示しておく。** [西川1959]（確度 A）は二層構造を記録している —
御殿を囲む中間帯に中間足軽長屋、**その外側に定府家臣の長屋**。外周を消すと外層が丸ごと消える。
[福井図] は外周長屋を「江戸勤番の藩士が居住し、いざというとき藩主の盾になる」とするので、
**外周という位置そのものが機能**だった。ここで失われるのは面積ではなく、その位置と役目である。
建蔽率は外周・郭の引き直し後に json から再計算する — 従前の値は旧区画ベースで**失効**。
拝領坪数が未確認である以上、史料値レンジ [鈴木1985] との突き合わせも参考に留める。
**収容人数を根拠に敷地内へ棟を足すことはしない** — 家臣の員数に典拠が無く、
長屋の躯体面積から逆算した数字は自作の成果物にすぎないため。<span class="cert">【確度 U — ユーザー裁定 2026-08-22】</span>

両家がそれぞれ建てて二重になる作りではない。**どちらが持つかを定めた規則は史料未確認**なので、
南辺・北辺とも**岡部が持つ**とユーザーが裁定した。<span class="cert">【確度 U】</span>

**段と折れは塀が自由に越える。** 長屋は床から棟 5.3m の反復モジュールなので段を跨げず、
段の変わる隅には櫓が要った。**築地塀にはその制約がない** — 笠は単純な切妻状で、
留め継ぎで折れ、段違いで落とせる。<span class="cert">【確度 B】</span>

## 囲いの据え方

- **犬走りを残す。** 長屋も築地塀も、石垣の法肩から **1尺（0.30m）**控える。
  天端の縁ぎりぎりに建てると軒からの雨落ちが目地を洗い、笠石が縁で欠ける。
  城の犬走りは数mに及ぶが、屋敷境ではこれで足りる。【確度 U／B】
- **run の天端は一定。** 地形追従で一枚ずつ落とさない。段は run の継ぎ目で落とす。
- **段は折れ目に置かない。** 折れの前後で隣地の地盤が変わらないなら、そこに段を置く理由が無い。
  段は隣地の地盤が実際に落ちる位置へ移す。
- **天端は郭の地盤に合わせる。** 隣地の地盤から出した高さを天端にすると、
  こちらの地盤との間に意味のない段が立つ。隣が高い側で塀が 1m ほど埋まるのは正常。

## 隅の納め

折れ角は現地が決めるもので毎回違う。**角度を決め打ちした部材を作らない。**

- 在庫の出隅ブロック（`Castle Wall Corner`・2.4m 角）が成立するのは折れ角 Δ≳60°。
  Δ が浅いと apex が反対側の壁面から `2.4·cosΔ` はみ出す。
- 浅い折れは**留め（とめ）継ぎの隅部材**で納める。`Tools/Blender/build_kado.py` が
  在庫のモジュールを二本の腕に複製し、角度を二等分する面で切って接ぐ。**折れ角は引数**。
- **折れるだけでなく天端が上がる隅**は留めでは吸えないが、当屋敷では**隅櫓を使わない** —
  総築地塀にしたことで 6.5m の段を櫓なしで納められるようになったため（json `yagura`（空＝置かない））。
  「[福井図]に 3 基／[中屋敷図]に無い ＝ 上屋敷格の装置」という論は n=1 対 n=1 で弱く、
  撤去の裁定とともに落とす。

## 造成

- **地形は現地形に従う** — 街路・坂・水系は現地形、敷地内は拝領時造成の再現。
- **段の矩形は石垣の体内へ 1.4m 食い込ませる。** 地形は 2m 格子なので、段の設計面を
  石垣の内面ちょうどで終わらせると端数がそのまま割れ目になる。
- **造成の落としは石の体内で行う。** 法肩より外に段の土を残すと、格子の端数が
  石垣の化粧面の前に立つ土の楔になる。

## 西斜面の植生 — 黒松を疎に交えた雑木の樹林【確度 B】

西辺の溜池側は郭の天端から堀端へ落ちる斜面で、**竹林ではない**。法肩から下へ三帯に分ける —
上部=松を交えた樹林 / 中部=低木・下草 / 下部〜裾=草地(高木を置かない)。設計値は `slopeBands`。

- **[橋本・堀1998]**(査読論文・確度A)は朱引内79事例の悉皆調査で、**溜池の水辺の樹木として
  採録された2例(白山祠・山王権現)はいずれも松**、同じ外堀水系の武家地の斜面(赤坂紀伊国坂)は
  「樹林」型とする。**竹薮は79例中1例のみ**(愛宕下 藪小路)で「珍しい樹種でアクセントを付添える」扱い。
- 同論文は幕府御用地の緑を「**外から敷地内の建物を隠蔽し、内から緑の間に水面が眺められる形態**」と記す。
  西辺を塀で閉じず開けておく当図の意図と一致し、**竹である必要はない。**
- **『江戸名所図会』巻之三（天璣之部）第7冊 挿画「溜池」**（[名所図会・溜池]・確度S=図の実見）は左頁遠景に「山王」の題簽を持ち、
  **この崖線そのもの**を描く。稜線=松+丸い樹冠の広葉樹、**崖面はハッチング(草地・裸地)**。
  広重「赤坂桐畑」の対岸(山王)も松+広葉樹で、**どちらにも竹は描かれていない**。
- 反証: 竹の地下茎は表層30〜50cmに留まり、**急斜面の竹林は表層崩壊を助長する**(林野庁・確度A)。
- 嘉永期の江戸の孟宗竹は**吹上御苑と近郊農村の筍畑**にしか無い(確度B)。武家屋敷の竹の類型は
  **矢竹の生垣**で斜面被覆ではない。竹は京橋竹河岸に他国から入る「材」だった。

⚠ **竹垣(四つ目垣)は別物で、これは残す** — 垣の材としての竹に問題は無い。

## 郭の縁の柵

**郭の土留めの天端に、低い竹垣（四つ目垣）を回す。**

四本の土留めはいずれも**落差 6〜8m**で、天端は御殿と廊下のすぐ脇を女中・家臣が歩く面である。
素の縁のままにはしない。

- **城の石垣とは事情が違う。** 城の天端は武者走りで、落ちるのは寄せ手の問題だから柵を立てない。
  ここは屋敷の中の生活面なので、同じ作法を持ち込まない。
- **竹垣にする理由。** 郭の境は防御線ではなく段差なので、閉じる必要が無い。
  低い柵なら段の下の庭・長屋列が見通せ、石垣も隠れない。
  西辺の溜池側で既に同じ竹垣を使っているので、屋敷の中で作りが揃う。
- **高さ 0.9m・法肩から内へ 0.45m。** 天端幅は 1.4×s（2.1〜2.8m）あるので、
  柵の外に犬走りが残り、雨落ちが目地に直に当たらない。
- **石段の開口では切る。** 昇り降りの動線を塞がない。
- **家臣長屋が載る区間には立てない**（W1・W2 の z 949〜1037）。躯体そのものが縁を塞いでいる。

**採らなかった案 — 内塀（築地塀）。** 郭の境を塀で締める作りも大名屋敷にはあるが、
(a) 敷地の中が視覚的に分断され、(b) せっかくの石垣が隠れ、(c) 表と奥の結界は御錠口で
既に成立している。段差を示すだけなら柵で足りる。

竹垣だったという史料は無い。柵の種別は 確度 ?】

## 敷地の造成 — 面から決める（2026-08-23 ゼロベース改稿）

**土井邸・松江松平邸の指図に揃えて組み直した。** 座標系は**回転フレーム**（原点＝表門の芯、
u＝東辺〈三べ坂〉沿い北＋、v＝敷地の奥〈西〉＋）で、**辺12がちょうど v=0 に乗る**。

### 面の高さは設計者が決めない — 地形を測ってベンチの高さをそのまま採る

CLAUDE.md 規則3・`sashizu.md` §3a（2026-08-23 のスキル改定で明文化）に従い、
**先に高さを決めて地形を合わせるのをやめ、江戸期の復元地盤を1間刻みで総当たり走査して
起伏の小さい矩形（自然の平場＝ベンチ）を探した。** 面の高さはその矩形の中央値を丸めた値で、
**段の数はベンチの数が決めている**（「何面にしよう」と先に決めていない）。

見つかったベンチは **13.3 ／ 22.7 ／ 24.8 の3枚**。

**段の縁は等高線に沿った多角形で持つ**（設計値 `terraces[].poly`）。矩形で持っていたときは、
縁が等高線を斜めに横切るため、縁のすぐ外に自然の高まりが残って切盛図で「切り残し」に見えていた
（門前面の西縁で最大 +1.52m）。多角形は江戸期地盤で |Δ|≦0.5m のセルの連結成分の輪郭を
1間の許容で簡約したもの。**段の縁で法面の勾配（盛土1:1.5／切土1:1）を超える段差は0箇所**。
平場は 3,753坪 → **5,105坪**（36%増）になり、造成量は最大 盛1.16／切1.05m に収まっている。

| 面 | 高さの出どころ | 中身 |
|---|---|---|
| **門前面** | 江戸期の低い帯のベンチ | 長屋門・白洲・厩・供待・蔵・家臣長屋 |
| **東南の下郭** | 台地の南東にある**自然の窪み** | 土蔵・中間足軽長屋。**埋めずに一段低い郭として使い、階段廊下でつなぐ**（規則3） |
| **主面** | 台地のベンチ | 御殿複合と庭 |

棟が入らないため（「棟が入らないベンチは面にしない」）。斜面のまま残し、
通用口からの勝手の動線がここを登る。

- **門前面** — 長屋門・白洲・厩・供待・蔵・家臣長屋。**門の敷居＝門口の道なり＋雨仕舞いの持ち上げ**
  （敷居＝道なりは CLAUDE.md 規則7 からのプロジェクト規則・<span class="cert">確度 U</span>）。

  §B-1「平場にできない急斜面は庭・法面であって、建物で埋める場所ではない」。
  **参道の石段だけが東の崖を横切る。**

### 明治16年の敷地 — 三帯構造

| 帯 | x | 明治16年の高さ | 図の記載 |
|---|---|---|---|
| 西の急斜面 | −695〜−590 | 10〜12 → 24 へ登る | 「荒」（荒地）。南西隅に小池 |
| **中央の台地** | −590〜−455 | **24〜26（平坦）** | 「畑」（当時は高崎邸） |
| **東の崖** | −455〜−425 | 24〜26 → 13.7 へ **10〜12m 落ちる** | 等高線5〜6本 |
| 東の低地 | −425〜−375 | **12〜14** | 永田町一丁目の町屋（明治5年の町立て後） |

主郭の高さは**現況の自然面を均した値**として json `planes` に持つ（盛土の量も同項）。
明治16年図の台地（24〜26）とも食い違わないが、検証の分解能は ±2m 程度
（等高線間隔 2m・量水標零位と現行 T.P. の差 ±0.5〜1m 未検証・ジオリファレンス ±10〜15m）なので、
**この一致を根拠には使わない**。⚠ 誤差の効き方は場所で違う — 台地（平坦）では ±2m に丸まるが、
**崖線上では水平誤差がそのまま高さ誤差へ転写する**（勾配 0.35 なら ±3.5〜5m）。

### 設計への帰結

1. **崖線・台地面は明治16年の読みを正とする。** 三帯構造（門前の低い帯／内部崖／台地）が
   敷地の骨格で、旧設計の「南北の段の帯」はこの骨格に合っていなかった。
2. **東の低い帯（12〜14）は江戸期は屋敷内。** 切絵図では岡部区画が三べ坂に直接面し、
   間に町屋は無い（NDL1286657 実見・<span class="cert">確度 A</span>）。明治16年の町屋帯は
   明治5年の町立て後の姿（[永田町の町立て]。同史料は江戸期この一帯が武家地だったことも記す —
   切絵図と独立の裏づけ）。東辺を崖の法肩へ引き直す案（実面積が約2割減る）は
   切絵図と矛盾するので**採らない**。地籍地図での境界確認は未解決に残す。
3. **三べ坂は坂上＝北・坂下＝南**（[千代田区の坂]。由来は所引の『新撰東京名所図会』、
   坂上・坂下は区の記述から・<span class="cert">確度 A</span>）。名の由来は
   **岡部筑前守・安部摂津守・渡辺丹後守** — 三べ坂西街区の切絵図の「渡辺備中守」と
   **同家の可能性が高い**（伯太藩渡辺家は備中守→丹後守の受領名替わり・[伯太藩渡辺家の受領名]・
   <span class="cert">確度 B — 要一次確認</span>。「別家」と断定しない）。
   岡部の東辺前面は坂下の緩い区間で、**大きな勾配は岡部より北（土井・松平の前面）**
   （縦断は json `edgeProfile`）。
4. **拝領坪数は未確認。** 区画実測（面積は polygon から導出）は、二次情報の目安

   区画は下書き実測（<span class="cert">確度 P</span>）であり、拝領坪数の一次史料は未入手。
5. **北辺の現況高は与件にしない。** 新坂（明治10年代）が岡部／土井境を通り、明治16年の
