基準年次と確度

基準年次=嘉永3年(1850) — 基図(尾張屋版切絵図)の年次。安政2年の地震記録は「倒れる前の姿」として遡って使い、武鑑(天保9年版で所在確認)は当主が先代の年次であることを断る。
当主=岡部内膳正 長和(10代。⚠ 嘉永3年9月24日に没し弟の長発が継ぐので、「当主=長和」と言えるのは同年9月まで【確度B — Web二次】)。「岡部筑前守」は12代 長寛(安政2年家督)以降の受領名で、家の通称として表題に用いる。
外周の構成は当屋敷の一次記録から直接言える(確度S) — 安政江戸地震の被害書上5点が3邸一括の記事「上 土井大隅守殿 右外構練塀潰其外所々大破」に岡部も含まれ、外構が練塀であったことは確度S(ただし辺・所有は語らない)。
屋敷指図(建物平面)は現存未確認 — 御殿の構成は類型(B)、室名・畳数は想定(?)。書院は雁間詰城主格で作り、帝鑑間格へ上げない(確度A=殿席の同時代史料2点)。区画多角形はユーザーのブックマーク角(U)。

囲いの据え方

  • 犬走りを残す。 長屋も築地塀も、石垣の法肩から 1尺（0.30m）控える。 天端の縁ぎりぎりに建てると軒からの雨落ちが目地を洗い、笠石が縁で欠ける。 城の犬走りは数mに及ぶが、屋敷境ではこれで足りる。【確度 U／B】
  • run の天端は一定。 地形追従で一枚ずつ落とさない。段は run の継ぎ目で落とす。
  • 段は折れ目に置かない。 折れの前後で隣地の地盤が変わらないなら、そこに段を置く理由が無い。 段は隣地の地盤が実際に落ちる位置へ移す。
  • 天端は郭の地盤に合わせる。 隣地の地盤から出した高さを天端にすると、 こちらの地盤との間に意味のない段が立つ。隣が高い側で塀が 1m ほど埋まるのは正常。

隅の納め

折れ角は現地が決めるもので毎回違う。角度を決め打ちした部材を作らない。

  • 在庫の出隅ブロック（Castle Wall Corner・2.4m 角）が成立するのは折れ角 Δ≳60°。 Δ が浅いと apex が反対側の壁面から 2.4·cosΔ はみ出す。
  • 浅い折れは留め（とめ）継ぎの隅部材で納める。Tools/Blender/build_kado.py が 在庫のモジュールを二本の腕に複製し、角度を二等分する面で切って接ぐ。折れ角は引数。
  • 折れるだけでなく天端が上がる隅は留めでは吸えないが、当屋敷では隅櫓を使わない — 総築地塀にしたことで 6.5m の段を櫓なしで納められるようになったため（json yagura（空＝置かない））。 「[福井図]に 3 基／[中屋敷図]に無い ＝ 上屋敷格の装置」という論は n=1 対 n=1 で弱く、 撤去の裁定とともに落とす。

造成

  • 地形は現地形に従う — 街路・坂・水系は現地形、敷地内は拝領時造成の再現。
  • 段の矩形は石垣の体内へ 1.4m 食い込ませる。 地形は 2m 格子なので、段の設計面を 石垣の内面ちょうどで終わらせると端数がそのまま割れ目になる。
  • 造成の落としは石の体内で行う。 法肩より外に段の土を残すと、格子の端数が 石垣の化粧面の前に立つ土の楔になる。

西斜面の植生 — 黒松を疎に交えた雑木の樹林【確度 B】

西辺の溜池側は郭の天端から堀端へ落ちる斜面で、竹林ではない。法肩から下へ三帯に分ける — 上部=松を交えた樹林 / 中部=低木・下草 / 下部〜裾=草地(高木を置かない)。設計値は slopeBands。

  • [橋本・堀1998](査読論文・確度A)は朱引内79事例の悉皆調査で、**溜池の水辺の樹木として 採録された2例(白山祠・山王権現)はいずれも松**、同じ外堀水系の武家地の斜面(赤坂紀伊国坂)は 「樹林」型とする。竹薮は79例中1例のみ(愛宕下 藪小路)で「珍しい樹種でアクセントを付添える」扱い。
  • 同論文は幕府御用地の緑を「外から敷地内の建物を隠蔽し、内から緑の間に水面が眺められる形態」と記す。 西辺を塀で閉じず開けておく当図の意図と一致し、竹である必要はない。
  • 『江戸名所図会』巻之三（天璣之部）第7冊 挿画「溜池」（[名所図会・溜池]・確度S=図の実見）は左頁遠景に「山王」の題簽を持ち、 この崖線そのものを描く。稜線=松+丸い樹冠の広葉樹、崖面はハッチング(草地・裸地)。 広重「赤坂桐畑」の対岸(山王)も松+広葉樹で、どちらにも竹は描かれていない。
  • 反証: 竹の地下茎は表層30〜50cmに留まり、急斜面の竹林は表層崩壊を助長する(林野庁・確度A)。
  • 嘉永期の江戸の孟宗竹は吹上御苑と近郊農村の筍畑にしか無い(確度B)。武家屋敷の竹の類型は 矢竹の生垣で斜面被覆ではない。竹は京橋竹河岸に他国から入る「材」だった。

⚠ 竹垣(四つ目垣)は別物で、これは残す — 垣の材としての竹に問題は無い。

郭の縁の柵

郭の土留めの天端に、低い竹垣（四つ目垣）を回す。

面の高さは設計者が決めない — 地形を測ってベンチの高さをそのまま採る

CLAUDE.md 規則3・sashizu.md §3a（2026-08-23 のスキル改定で明文化）に従い、 先に高さを決めて地形を合わせるのをやめ、江戸期の復元地盤を1間刻みで総当たり走査して 起伏の小さい矩形（自然の平場＝ベンチ）を探した。 面の高さはその矩形の中央値を丸めた値で、 段の数はベンチの数が決めている（「何面にしよう」と先に決めていない）。

見つかったベンチは 13.3 ／ 22.7 ／ 24.8 の3枚。

段の縁は等高線に沿った多角形で持つ（設計値 terraces[].poly）。矩形で持っていたときは、 縁が等高線を斜めに横切るため、縁のすぐ外に自然の高まりが残って切盛図で「切り残し」に見えていた （門前面の西縁で最大 +1.52m）。多角形は江戸期地盤で |Δ|≦0.5m のセルの連結成分の輪郭を 1間の許容で簡約したもの。段の縁で法面の勾配（盛土1:1.5／切土1:1）を超える段差は0箇所。 平場は 3,753坪 → 5,105坪（36%増）になり、造成量は最大 盛1.16／切1.05m に収まっている。

北東（u19〜29）は面にしない。 起伏4.1mのランプでベンチが4×5間しか取れず、 棟が入らないため（「棟が入らないベンチは面にしない」）。斜面のまま残し、 通用口からの勝手の動線がここを登る。

合格の目安 |設計面 − 自然地形| ≤ 0.5m を全7棟が満たす（最大 0.19m）。 拝領時造成は盛土・切土とも 400m³ 台、最大 0.49／1.05m に収まった （面の高さを地形から採る前は最大 3.44m だった）。

  • 門前面 — 長屋門・白洲・厩・供待・蔵・家臣長屋。門の敷居＝門口の道なり＋雨仕舞いの持ち上げ （敷居＝道なりは CLAUDE.md 規則7 からのプロジェクト規則・確度 U）。 江戸期の低い帯（明治16年図で 12〜14）にほぼ素で載る。
  • 主面 — 御殿複合と庭。台地面。南半は自然面にほぼ素で載る。
  • 斜面（造成しない） — 東の崖（落差12.8m・勾配41%）／西斜面／北の法面／南西の谷。 §B-1「平場にできない急斜面は庭・法面であって、建物で埋める場所ではない」。 参道の石段だけが東の崖を横切る。

地形のデータは2枚、切盛は二層で持つ

okabe_terrain.json ＝ 現況（回転フレーム1間格子・実測・確度P）、 okabe_edo_dem.json ＝ 江戸期の復元地盤（近代造成を戻したもの・確度U/B）、 okabe_dem.json ＝ 現況の世界座標2m格子（現況図の段彩・等高線用）。 ⚠ 江戸期地盤のうち実測されているのは南半だけで、北半は校舎の盛土を台地面へ戻した復元値。

切盛は二層で持つ

拝領時造成（江戸期の地盤に対して）と、近代造成の除去（日比谷高校の校庭・校舎の盛土を削る分）を 分けて数える（設計値は json の grading）。後者は史実の土工ではない — 量を史実の切土として 報告してはならない。

必ず入れる四つの図

sashizu.md §3a〜§3d に従い、現況図（段彩＋等高線）・切盛図（暖色＝盛土／寒色＝切土）・ 断面（東西南北の格子）・動線図（表向／役方／勝手／奥向）を入れた。 とくに勝手の動線は、米や薪が表門から石段を登る設計になっていないかを図で確かめるためのもので、 当図では通用口（袋小路）から北東のランプを登って台所へ入る経路を引いてある。

囲いは面の縁にだけ立てる

塀と石垣基壇は面（造成した平場）の縁にだけ立てる。斜面・谷・水際の囲いは崖と樹林＋法肩の竹垣が担い、 境界は木柵で標示する（松江松平邸で確立したプロジェクトの作法・確度 U）。 辺ごとの性格は json の edges、地盤は edgeProfile（実測・確度 P）。 水際の木柵は [広重・赤坂桐畑]（確度 B）が溜池対岸に描く柵に倣う。

区画の正典は parcels.json

区画ポリゴンの正典は docs/Sashizu/parcels.json（id=okabe）。 指図 json の polygon は その同期コピーで、編集は Unity の Edo/敷地割（⌘⇧K）で行う。 2026-08-22 にユーザーが区画を修正し（南辺が北へ移動・13頂点化）、同期した。 外周 run・郭・下郭は旧区画の値のままで、引き直しの順序は json の _pending.junjo。 【確度 U — ユーザーの区割り。境界の同定根拠はブックマークの角マーク】

近代造成と造成前の地形（2026-08-22 考証）

シーンの地形は 2026-08-22 に現代の実地形（国土地理院 DEM）へ初期化された（実測値は json の edgeProfile と sections）。現況は日比谷高校ほかの近代造成を含むので、その一段前として [五千分一東京図31]（明治16年測図・等高線2m・確度 S）で 近代造成前＝明治16年時点の地形を読んだ。江戸期の地形への等置は確度 B の外挿 （最初の大規模改変が大正5〜8年の山王荘造営、という下の造成史に依る）。 ジオリファレンスは日枝神社境内で較正し、独立3点が 10m 以内で一致 （確度 P — ±10〜15m）。

設計への帰結

1. 崖線・台地面は明治16年の読みを正とする。 三帯構造（門前の低い帯／内部崖／台地）が 敷地の骨格で、旧設計の「南北の段の帯」はこの骨格に合っていなかった。 2. 東の低い帯（12〜14）は江戸期は屋敷内。 切絵図では岡部区画が三べ坂に直接面し、 間に町屋は無い（NDL1286657 実見・確度 A）。明治16年の町屋帯は 明治5年の町立て後の姿（[永田町の町立て]。同史料は江戸期この一帯が武家地だったことも記す — 切絵図と独立の裏づけ）。東辺を崖の法肩へ引き直す案（実面積が約2割減る）は 切絵図と矛盾するので採らない。地籍地図での境界確認は未解決に残す。 3. 三べ坂は坂上＝北・坂下＝南（[千代田区の坂]。由来は所引の『新撰東京名所図会』、 坂上・坂下は区の記述から・確度 A）。名の由来は 岡部筑前守・安部摂津守・渡辺丹後守 — 三べ坂西街区の切絵図の「渡辺備中守」と 同家の可能性が高い（伯太藩渡辺家は備中守→丹後守の受領名替わり・[伯太藩渡辺家の受領名]・ 確度 B — 要一次確認。「別家」と断定しない）。 岡部の東辺前面は坂下の緩い区間で、大きな勾配は岡部より北（土井・松平の前面） （縦断は json edgeProfile）。 4. 拝領坪数は未確認。 区画実測（面積は polygon から導出）は、二次情報の目安 （[青標帋] 4,500坪／[元文3年] 5,000〜5,100坪・どちらも原典未確認）の約2倍。 区画は下書き実測（確度 P）であり、拝領坪数の一次史料は未入手。 5. 北辺の現況高は与件にしない。 新坂（明治10年代）が岡部／土井境を通り、明治16年の 測図時点で既に切られている。北辺の天端は明治16年図の読み直しで決める（_pending ③b）。 なお切絵図の袋小路が新坂と近い向き・位置にあることは、袋小路の読みの傍証になる （確度 B）。
