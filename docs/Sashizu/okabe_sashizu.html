屋敷の性格

譜代雁間 五万三千石の上屋敷。赤坂・山王社の北、三べ坂に面する。 敷地は三方を武家地と社寺に囲まれ、西は溜池の岸へ落ちる。

  • 御成の装置は作らない。 御成門・能舞台・御成風呂は家門・大藩の設備で、当家に典拠がない。 福井図で御成門を持つ越前松平は家門。 【確度 B — 一般類型／当屋敷の一次史料は未確認】
  • 池は掘らない。 泉水庭は州浜と築山のみ。典拠がない物を既成事実にしない。 【確度 ? — 未確認】
  • 敷地内の構成は一般類型。 当屋敷の指図・絵画は未発見。 【確度 B】

表門

長屋門。[表門格式表] は 5万石以上に長屋門・石仕上げ・片庇を定める。 位置は東辺（三べ坂沿い）。2026-08-12 の考証では切絵図の文字の頭から「北東辺」としていたが、 ユーザーの区割り指定を優先した。【確度 U】

  • 番所は門に組み込む。 長屋門なので門の躯体に番所が入る。脇に離して小屋を置くのは誤り。
  • 袖塀は要らない。 門の左右がそのまま長屋へ連続する。
  • 門の形式と辺の囲いの種別は必ず整合させる。 長屋門なので東辺は長屋塀。

囲いの種別 — 面ごとに変える

[追川2017→宮崎1994]「築地塀こそが正式で伝統的な屋敷囲いであり、家臣団の住居を兼用する表長屋は 略式で薄礼のもの」。格式の要る面ほど築地塀、裏手ほど長屋。【確度 B】

囲いは 1 条。[丸の内三丁目]（確度 A）— 隣り合う 2 家の屋敷境に引かれたのは 1 条の区画溝で、 両家がそれぞれ建てて二重になる作りではない。どちらが持つかを定めた規則は史料未確認なので、 南辺・北辺とも岡部が持つとユーザーが裁定した。【確度 U】

囲いの据え方

  • 犬走りを残す。 長屋も築地塀も、石垣の法肩から 1尺（0.30m）控える。 天端の縁ぎりぎりに建てると軒からの雨落ちが目地を洗い、笠石が縁で欠ける。 城の犬走りは数mに及ぶが、屋敷境ではこれで足りる。【確度 U／B】
  • run の天端は一定。 地形追従で一枚ずつ落とさない。段は run の継ぎ目で落とす。
  • 段は折れ目に置かない。 折れの前後で隣地の地盤が変わらないなら、そこに段を置く理由が無い。 段は隣地の地盤が実際に落ちる位置へ移す。
  • 天端は郭の地盤に合わせる。 隣地の地盤から出した高さを天端にすると、 こちらの地盤との間に意味のない段が立つ。隣が高い側で塀が 1m ほど埋まるのは正常。

隅の納め

折れ角は現地が決めるもので毎回違う。角度を決め打ちした部材を作らない。

  • 在庫の出隅ブロック（Castle Wall Corner・2.4m 角）が成立するのは折れ角 Δ≳60°。 Δ が浅いと apex が反対側の壁面から 2.4·cosΔ はみ出す。
  • 浅い折れは留め（とめ）継ぎの隅部材で納める。Tools/Blender/build_kado.py が 在庫のモジュールを二本の腕に複製し、角度を二等分する面で切って接ぐ。折れ角は引数。
  • 折れるだけでなく天端が上がる隅は、留めでは吸えない。 隅櫓で納める。

隅櫓は[福井図]では上屋敷の外周に 3 基あり、[中屋敷図]には無い → 上屋敷格の装置。【確度 B】

造成

  • 地形は現地形に従う — 街路・坂・水系は現地形、敷地内は拝領時造成の再現。
  • 段の矩形は石垣の体内へ 1.4m 食い込ませる。 地形は 2m 格子なので、段の設計面を 石垣の内面ちょうどで終わらせると端数がそのまま割れ目になる。
  • 造成の落としは石の体内で行う。 法肩より外に段の土を残すと、格子の端数が 石垣の化粧面の前に立つ土の楔になる。

建物の構成

連続御殿複合 ＋ 外周長屋帯。 開放地は白洲と中庭だけ。

  • 表向 — 白洲を横切り石段を上がって車寄せ（向拝）・御式台・御玄関。 車寄せは玄関棟の東面に三間×一間で出し、大棟を壁と平行（南北）に通した低い切妻とする — 妻入りにすると屋根が玄関棟の軒を越えて谷が要る。式台は玄関の床から一段下がり、前に沓脱を置く。 前庭に屋根が架かるのはここまで。 渡廊下で表御殿群へ渡り、三之間・二之間・大広間。 北へ渡廊下で書院群（黒書院・白書院）。
  • 中奥 — 御座之間・御休息之間・御小姓部屋・御風呂屋。 北の台所群に大台所・御料理間・御膳所・御納戸。
  • 奥向 — 奥向へ入る廊下は御錠口の一本だけ。台所棟から奥向棟へ直結する廊下は撤去した （二本あると錠の意味がなくなる）。奥向棟・長局棟・西の下郭はすべてこの一本の先にあり、 錠で締め切れる。奥御座之間・御対面所。南に長局二列を別棟で置き、渡廊下で結ぶ。
  • 雁行する棟の取り合い — 谷や隅は生成せず、各棟は独立した入母屋のまま置いて、 その軒下を渡廊下の低い切妻がくぐる。福井図・二条城も同じ形。【ユーザー裁定 2026-08-14】

郭の縁の柵

郭の土留めの天端に、低い竹垣（四つ目垣）を回す。

四本の土留めはいずれも落差 6〜8mで、天端は御殿と廊下のすぐ脇を女中・家臣が歩く面である。 素の縁のままにはしない。

  • 城の石垣とは事情が違う。 城の天端は武者走りで、落ちるのは寄せ手の問題だから柵を立てない。 ここは屋敷の中の生活面なので、同じ作法を持ち込まない。
  • 竹垣にする理由。 郭の境は防御線ではなく段差なので、閉じる必要が無い。 低い柵なら段の下の庭・長屋列が見通せ、石垣も隠れない。 西辺の溜池側で既に同じ竹垣を使っているので、屋敷の中で作りが揃う。
  • 高さ 0.9m・法肩から内へ 0.45m。 天端幅は 1.4×s（2.1〜2.8m）あるので、 柵の外に犬走りが残り、雨落ちが目地に直に当たらない。
  • 石段の開口では切る。 昇り降りの動線を塞がない。
  • 家臣長屋が載る区間には立てない（W1・W2 の z 949〜1037）。躯体そのものが縁を塞いでいる。

採らなかった案 — 内塀（築地塀）。 郭の境を塀で締める作りも大名屋敷にはあるが、 (a) 敷地の中が視覚的に分断され、(b) せっかくの石垣が隠れ、(c) 表と奥の結界は御錠口で 既に成立している。段差を示すだけなら柵で足りる。
