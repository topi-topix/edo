囲いの種別 — 外周は総練塀

三層に分けて読む。

0. 語は「練塀」。 一次記録が使う唯一の語が「外構練塀」なので、構法は練塀（瓦と土を交互に積む）で通す。 隣の土井邸・松江松平邸の指図も練塀を採るので、街区で構法が割れない。 ⚠ 2026-08-23 まで当図だけ「築地塀」（版築）と書いていた。S が保証するのは「塀」までで、 練塀という構法まで当屋敷で確かめられたわけではないが、記録の語から離れる理由も無い。

1. 外構が「塀」であったこと ＝ 確度 S（暫定）。 [安政地震被害書上] の3邸一括の記事 「上 土井大隅守殿 右外構練塀潰其外所々大破」に当屋敷が含まれる。 当屋敷を名指す同時代の記録が「外構＝練塀」と言っている以上、種別は推定ではない。 【確度 S（暫定）】 ⚠ 原文で当家が名指しされる箇所は sources.md に未引用（引かれているのは土井を名指す断片だけ）。 東大地震研の地震史料集DBで全文を採って sources.md へ追記するまで、この S は暫定とする。 2. どの辺か・全周かは書かれていない ＝ 確度 U。 同じ記事は辺も所有も語らない。 全13辺のうち 10辺に塀、1辺（堀端）に木柵を当家が建てるという配りは当方の裁定である。 3. どちらの家が持つかを定めた規則も史料未確認 ＝ 確度 U。 [丸の内三丁目]（確度 A）が言うのは 「屋敷境に引かれたのは1条の区画溝で、両家が二重に建てる作りではない」ところまでで、 どちらが持つかは決めていない（sources.md §2 が「⛔ 未解決 — 典拠なし」と明記）。

表長屋を0本にしたことだけは類型から外れる。 [追川2017] が実測した3邸（加賀 15%・ 尾張市谷 47.7%・小浜 28.6%）はすべて表長屋を持ち、estate-types.md の 「中小藩ほど外周を長屋で使い切る」に照らすと五万三千石で外周長屋ゼロは逆向きである。 ⚠ 同論文が引く「表門に連なる塀に、長屋塀を構築することを避けた」（宮崎1994 経由・本文未入手）は 表門のある一辺の話で、全周の根拠にはならない。【確度 U — ユーザー裁定 2026-08-21】

捨てるものを明示しておく。 [西川1959]（確度 A）は二層構造を記録している — 御殿を囲む中間帯に中間足軽長屋、その外側に定府家臣の長屋。外周を消すと外層が丸ごと消える。 [福井図] は外周長屋を「江戸勤番の藩士が居住し、いざというとき藩主の盾になる」とするので、 外周という位置そのものが機能だった。ここで失われるのは面積ではなく、その位置と役目である。 収容人数を根拠に敷地内へ棟を足すことはしない — 家臣の員数に典拠が無く、 長屋の躯体面積から逆算した数字は自作の成果物にすぎないため。【確度 U】

屋敷境は勾配によらず塀で通す。木柵は相手が屋敷でない辺（水際・堀端）に限る。 【確度 U — 設計判断。史料の裏づけは無い】 [追川2017] も [丸の内三丁目] も塀と斜面の関係を語らないので、B は名乗れない。 ✅ 2026-08-23 決着 — 松江松平邸が岡部側の規則へ寄せた。同邸の S_Hei_Okabe4（28.4m）と S_Hei_Okabe5（35.1m）が木柵から練塀へ改まり、岡部の辺7（28.4m）＋辺6（35.1m）＝ 63.6m と 長さも構法も一致する。屋敷境は勾配によらず塀という規則が街区で通った。 【確度 U — ユーザー裁定】

天端は run ごとに一直線。

  • 面の縁になっている区間は水平に通し、天端＝面の高さ。 段は run の継ぎ目でだけ落ちる（「隣が高い側で塀が1mほど埋まるのは正常」）。
  • 造成しない斜面の区間は一定勾配で地形を追う。石垣基壇の露出が 2.5m を超えないところで 次の run へ渡す。段々に刻まないのと、地形から浮いた高石垣を作らないのを同時に満たす形。
  • 現行は 18本 ／ 基壇の露出 0.23〜3.10m ／ 隅と継ぎ目の天端差は最大 2.22m。 数値の正典は json runs（本文にも図にも写さない）。

頂点番号は 2026-08-22 の13頂点版（旧番号の対応は json _polygon）。 南辺の旧注記のうち「神社へ生活の場を向けるのは薄礼」は規範の典拠なし、 「土留めの帰属＝高い側が持つ」は工学的理屈で史実の規則ではない（sources.md §2）— いずれもユーザー裁定（確度 U）として維持する。

段と折れは塀が自由に越える。 長屋は床から棟 5.3m の反復モジュールなので段を跨げず、 段の変わる隅には櫓が要った。練塀にはその制約がない — 笠は単純な切妻状で、 留め継ぎで折れ、段違いで落とせる。【確度 B】

囲いの据え方

  • 犬走りを残す。 長屋も練塀も、石垣の法肩から 1尺（0.30m）控える。 天端の縁ぎりぎりに建てると軒からの雨落ちが目地を洗い、笠石が縁で欠ける。 城の犬走りは数mに及ぶが、屋敷境ではこれで足りる。【確度 U／B】
  • run の天端は一直線。 面の縁は水平、斜面は一定勾配。地形追従で一枚ずつ落とさない。
  • 段は折れ目に置かない。 折れの前後で隣地の地盤が変わらないなら、そこに段を置く理由が無い。 段は隣地の地盤が実際に落ちる位置へ移す。
  • 天端は郭の地盤に合わせる。 隣地の地盤から出した高さを天端にすると、 こちらの地盤との間に意味のない段が立つ。隣が高い側で塀が 1m ほど埋まるのは正常。

隅の納め

折れ角は現地が決めるもので毎回違う。角度を決め打ちした部材を作らない。

  • 在庫の出隅ブロック（Castle Wall Corner・2.4m 角）が成立するのは折れ角 Δ≳60°。 Δ が浅いと apex が反対側の壁面から 2.4·cosΔ はみ出す。
  • 浅い折れは留め（とめ）継ぎの隅部材で納める。Tools/Blender/build_kado.py が 在庫のモジュールを二本の腕に複製し、角度を二等分する面で切って接ぐ。折れ角は引数。
  • 折れるだけでなく天端が上がる隅は留めでは吸えないが、当屋敷では隅櫓を使わない — 天端を run ごとの一直線にしたことで、隅と継ぎ目の天端差が基壇の小口（隅石）で受けられる範囲に 収まったため（json yagura は空。段差の現行値は json runs の seat0/seat1 から出す）。 「[福井図]に 3 基／[中屋敷図]に無い ＝ 上屋敷格の装置」という論は n=1 対 n=1 で弱く、 撤去の裁定とともに落とす。

造成

  • 地形は現地形に従う — 街路・坂・水系は現地形、敷地内は拝領時造成の再現。
  • 段の縁は石垣の体内へ 1.4m 食い込ませる。 地形は 2m 格子なので、段の設計面を 石垣の内面ちょうどで終わらせると端数がそのまま割れ目になる。
  • 造成の落としは石の体内で行う。 法肩より外に段の土を残すと、格子の端数が 石垣の化粧面の前に立つ土の楔になる。

西斜面の植生 — 黒松を疎に交えた雑木の樹林【確度 B】

西辺の溜池側は郭の天端から堀端へ落ちる斜面で、竹林ではない。法肩から下へ三帯に分ける — 上部=松を交えた樹林 / 中部=低木・下草 / 下部〜裾=草地(高木を置かない)。設計値は slopeBands。

  • [橋本・堀1998](査読論文・確度A)は朱引内79事例の悉皆調査で、**溜池の水辺の樹木として 採録された2例(白山祠・山王権現)はいずれも松**、同じ外堀水系の武家地の斜面(赤坂紀伊国坂)は 「樹林」型とする。竹薮は79例中1例のみ(愛宕下 藪小路)で「珍しい樹種でアクセントを付添える」扱い。
  • 同論文は幕府御用地の緑を「外から敷地内の建物を隠蔽し、内から緑の間に水面が眺められる形態」と記す。 西辺を塀で閉じず開けておく当図の意図と一致し、竹である必要はない。
  • 『江戸名所図会』巻之三（天璣之部）第7冊 挿画「溜池」（[名所図会・溜池]・確度S=図の実見）は左頁遠景に「山王」の題簽を持ち、 この崖線そのものを描く。稜線=松+丸い樹冠の広葉樹、崖面はハッチング(草地・裸地)。 広重「赤坂桐畑」の対岸(山王)も松+広葉樹で、どちらにも竹は描かれていない。
  • 反証: 竹の地下茎は表層30〜50cmに留まり、急斜面の竹林は表層崩壊を助長する(林野庁・確度A)。
  • 嘉永期の江戸の孟宗竹は吹上御苑と近郊農村の筍畑にしか無い(確度B)。武家屋敷の竹の類型は 矢竹の生垣で斜面被覆ではない。竹は京橋竹河岸に他国から入る「材」だった。

⚠ 竹垣(四つ目垣)は別物で、これは残す — 垣の材としての竹に問題は無い。

切盛は二層で持つ

拝領時造成（江戸期の地盤に対して）と、近代造成の除去（日比谷高校の校庭・校舎の盛土を削る分）を 分けて数える（設計値は json の grading）。後者は史実の土工ではない — 量を史実の切土として 報告してはならない。

必ず入れる四つの図

sashizu.md §3a〜§3d に従い、現況図（段彩＋等高線）・切盛図（暖色＝盛土／寒色＝切土）・ 断面（東西南北の格子）・動線図（表向／役方／勝手／奥向）を入れた。 とくに勝手の動線は、米や薪が表門から石段を登る設計になっていないかを図で確かめるためのもので、 当図では通用口（袋小路）から北東のランプを登って台所へ入る経路を引いてある。

囲いは面の縁にだけ立てる

塀と石垣基壇は面（造成した平場）の縁にだけ立てる。斜面・谷・水際の囲いは崖と樹林＋法肩の竹垣が担い、 境界は木柵で標示する（松江松平邸で確立したプロジェクトの作法・確度 U）。 辺ごとの性格は json の edges、地盤は edgeProfile（実測・確度 P）。 水際の木柵は [広重・赤坂桐畑]（確度 B）が溜池対岸に描く柵に倣う。

近代造成と造成前の地形（2026-08-22 考証）

シーンの地形は 2026-08-22 に現代の実地形（国土地理院 DEM）へ初期化された（実測値は json の edgeProfile と sections）。現況は日比谷高校ほかの近代造成を含むので、その一段前として [五千分一東京図31]（明治16年測図・等高線2m・確度 S）で 近代造成前＝明治16年時点の地形を読んだ。江戸期の地形への等置は確度 B の外挿 （最初の大規模改変が大正5〜8年の山王荘造営、という下の造成史に依る）。 ジオリファレンスは日枝神社境内で較正し、独立3点が 10m 以内で一致 （確度 P — ±10〜15m）。
