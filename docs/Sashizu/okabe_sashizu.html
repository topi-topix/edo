棟と続き間 — 階層は 棟 →（襖）→ 続き間。大広間棟・書院棟・中奥棟・台所棟は身舎を縦の襖線で二列に割り、一室が100畳を超えないようにした。大広間は一棟で、内部が一之間（上段）・二之間（下段）・三之間・四之間（鑓之間）に襖で仕切られる（図の破線）。二条城二の丸御殿の大広間が「1棟」として、一の間48畳・二の間44畳・三の間・四の間・帳台の間からなるのと同じ構成。棟は七つ（玄関棟・大広間棟・書院棟・中奥棟・台所棟・奥向棟・長局棟）。

廊下は一続き — 入側・渡廊下・外廊下は別系統ではなく一本の廊下である。各棟の外周を巡る入側が、隣の棟の入側と辺を共有して直に繋がり、離れた棟へは渡廊下で渡り、郭の縁では外廊下となって隣の郭へ抜ける。二条城二の丸御殿で六棟を取り囲む廊下が一周しているのと同じ。幅は入側・渡廊下・外廊下とも一間（1.818m）で一定。入側は「濡縁と座敷の間の一間幅の通路」が定義なので、これ以上広げない。入側は身舎の四方に回る（前後だけにすると妻側の白壁が廊下に面してしまう）。ただし一間の渡廊下は成立しない — 切妻屋根は両端が0.30長く、両隣の棟の軒0.90と1.20ずつ重なるので、重なりの合計2.40mが廊下の長さ1.818mを超える。指図で2mだった隙間は二間（3.64m）へ広げた。図では廊下の領域を一色で塗ってあり、白地で切れていなければ歩いて行ける。ただし一続きなのは郭の中まで（改訂 2026-08-15）— 郭と郭の間は 6〜8m の段差で、そこを渡るのは屋外の石段であって廊下ではない。機械検査も「郭ごとに連結成分＝1」へ改めた（踏める面＝入側の環＋四方に回る濡縁0.89m＋渡廊下・外廊下。主郭2,126m²／中段455m²／西低地1,197m²、いずれも1個）。

庭 — 表の庭は郭の外枠に沿った L 字の一枚。大広間棟・中奥棟の南辺と玄関棟の東辺の入側から望む。庭を浅くした分、大広間棟と中奥棟を南へ広げた（身舎 12間×20間 ＝ 21.8×36.4m）。

坪庭 — 大広間棟・中奥棟・書院棟・台所棟の四棟に囲まれた中央に坪庭（16間×7間 ＝ 29.1×12.7m）を取る。四辺の廊下は新設ではなく各棟の入側の延長で、南辺は大広間棟と中奥棟の上辺の入側を継いだもの、北辺は書院棟と台所棟の下辺の入側を継いだもの。東西は各対の中央を縦に渡る廊下で、これが坪庭の東西の縁になる。奥の内庭は全周を廊下で囲わず、下郭へ向かう一本だけを西縁に通した。庭は奥向棟の入側と、その廊下から望む。

表向

白洲を横切り石段を上がって車寄せ（向拝）・御式台・御玄関。車寄せは玄関棟の東面に三間×一間で出し、大棟を壁と平行（南北）に通した低い切妻とする — 妻入りにすると屋根が玄関棟の軒を越えて谷が要る。式台は玄関の床から一段（0.30m）下がり、前に沓脱を置く。前庭に屋根が架かるのはここまで。渡廊下で表御殿群へ渡り、三之間・二之間・大広間。北へ渡廊下で書院群（黒書院・白書院）。

奥向

奥向へ入る廊下は御錠口の一本だけ。台所棟から奥向棟へ直結する廊下は撤去した（二本あると錠の意味がなくなる）。奥向棟・長局棟・西の下郭はすべてこの一本の先にあり、錠で締め切れる。奥御座之間・御対面所。南に長局二列を別棟で置き、渡廊下で結ぶ。

用途の判断 — 西辺は溜池の汀で塀のみ、街路が無い。荷車の入れない郭に蔵・厩・作事を置くのは無理があるので、それらは表門前段（街路あり）へ回し、西低地は溜池を望む奥向の下郭とした。

庭は郭の外に任せる — 西低地の中に庭を置くと、外廊下を挟んで庭が二重になる。西低地は建屋で埋め、庭は郭の西に広がる庭園帯（溜池へ下る斜面）に任せた。西縁の入側がそのまま外廊下で、廊下から西に庭園帯と溜池を望み、東に下御殿を見る。下御座之間の続き間もすべて西向きに並べ、入側ごしに同じ景を得る。

棟の切り分け — 御湯殿は奥向なので下御殿棟の北に渡廊下で直結。御膳所は勝手向なので南端に別棟（勝手棟）とし、下御殿棟とは別の渡廊下で結ぶ。両者が互いに繋がる必要はない。東半は女中部屋棟・御用部屋棟で埋め、土蔵は隅に独立して置く。土蔵・物置は入側も廊下も付かない（土蔵造の独立建物で、屋外を歩いて行く）。

段のつなぎ（改訂 2026-08-15） — 石段は郭の真ん中ではなく北端に置く。主郭の奥向棟の入側から西縁の外廊下へ出て、その西で屋外の石段を降りて中段へ、中段の北をさらに降りて西低地へ入る。西の二本は登廊(屋根付きの階段廊下)にした(2026-08-15追記) — 一度屋外へ出て降りるのは内部動線として不自然なので、石段と土留めをそのまま床・欄干として使い、上に柱と屋根を架ける。屋根は平らな切妻を斜長ぶん作り、据えるときに勾配ぶん倒すので、軒も棟も坂と平行に走り頭上が一定になる(段板から軒桁 2.20m / 大棟の下 3.73m)。屋根を架けるのは内部動線だけで、表門からの参道(石段E1・E2)は前庭を横切る公的動線なので開けたまま。
登廊の両端の取り付きも廊下で継いだので、御殿から一度も外に出ずに主郭から西低地まで降りられる(西縁の外廊下を一間延ばし、段の芯 z=1043 へ北に振ってから東西へ折れる。計6本)。
外廊下そのものは石段には架けない — 直階段は落差6.0mで長さ9.0m、8.0mで12.0mあり、これに屋根を架けると長局棟・御用部屋棟に刺さる。石段は棟の北面（z=1037.08）より北へ寄せ、盛土の法面の上に据えた（段の下に地面がある）。西縁の外廊下からは西に庭園帯と溜池、東に下御殿が見える。

なぜ折返しをやめたか — (1) 折り返すと下端が上端と同じ側へ戻るので「廊下がそのまま段になる」が上端側でしか成り立たない。(2) 石垣の開口の中だけに納めようとしたため、段の下に地面が無く宙に浮いていた（ユーザー指摘 2026-08-15）。石垣の厚み2.4mに納める必要は初めから無く、下段の上に法面を盛れば直階段が素直に載る。西の2本は直階段が長局棟・御用部屋棟に刺さるので、棟の北面より北（z=1041〜1045）へ寄せた。

石垣の作法（不変条件）

unity-modular-stonewall に従う。新しく発明しない。

  • 1本の石垣に position.y と scale.y は各 1 つ。 ピースごとに scale.y を地形から出すのは生成壁の最大の兆候（60〜80 種類の高さとノコギリ天端になる）
  • 天端は丸い数字で一直線。 地面が波打つなら地面を壁に合わせて均す — 壁を地面に合わせない
  • スケールは相似 (s, s, s)。 (1, sy, 1) は石のテクスチャを縦に引き伸ばし、勾配角を高さごとに変えてしまう（実測 7.1°〜26.6°）。相似なら勾配は一定 14.04°、目地の目も歪まない。s は 0.25 刻みで丸め、必要高さを上回る最小値を取る
    壁高 = 4.0×s ／ 底の厚み = 2.4×s ／ 天端の幅 = 1.4×s ／ coping = position.y + 4.0×s
  • 勾配は外向き。 芯線側の面は鉛直で、勾配は躯体側（外＝進行方向の左）に付く。天端で芯線から 1.4×s、根石で 2.4×s。差 1.0×s が法の出
  • ピッチ 1.800 × s、継ぎ目ごとに 0.20 × s 重ねる。2.2m を超える隙間は門だけ
  • 出隅は R1／R2 — 片方の面を隣の石垣の外面と同一平面にし、もう一方の辺はコーナーのもう一方の面のapex でない端点に合わせる。折れ角を決め打ちしない。出隅は接する run と同じ s を取る
  • 据え方は法肩から逆算する（芯線からではない）。 外周線＝其六 で確定済みの長屋の外壁面・土塀の面は動かせない。よって
    　法肩 = 外周線　→　芯線 = 法肩 − 1.4×s（内向き。author する多角形はこれ）　→　法尻 = 法肩 + 1.0×s（外向き）
    石垣の裾は外周線より 1.0×s だけ外へ出る。実際の縄張りも境界杭は法尻で取るので、これでよい
  • 隣り合う石垣が高さ違いのときは折れ点（測点 P）で変える。走りの途中の段は破損に読める。折れの無い直線上で高さを変えるなら 25〜30 ピースかけてランプする
