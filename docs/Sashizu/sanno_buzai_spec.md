## 各部材

### 1. 本殿 — 方三間・入母屋造・銅瓦葺【A】
- 前方一間通=外陣／後方二間=内陣／内陣後方一間をさらに区切って神殿
- 側面は**前方二間を舞良戸・後方一間を板壁**。後方隅柱の左右に**脇障子**
- **石造亀腹に土台立て**、縁を**腰組**で支持
- 斗栱=**出組**。**総円柱**
- 名所図会では拝殿の背後に一段高く大きな入母屋屋根が見える

### 2. 幣殿 — 三間×一間・両下造・銅瓦葺【A】
- 本殿正面庇に接続。桁行各間は等間隔。斗栱=**平三斗**
- 本殿との間に**一間の作り合い**があり、**海老虹梁**で繋ぐ(屋根で覆われた室ではない)

### 3. 拝殿 — 七間×三間・入母屋造・向拝三間・銅瓦葺【A】
- **千鳥破風 及 軒唐破風附**【A】。名所図会でもこの重なりが描かれる【S】
- 内部三室。拝殿・幣殿境は**格子戸**、両側面前方一間を**蔀戸**
- 後方二間通りの柱筋を本殿の柱筋と揃える。斗栱=**平三斗**。**総円柱**

### 4. 中門 — 一間平唐門・銅瓦葺【A】
- 透塀の東線の芯に立つ瑞垣門

### 5. 透塀 — 屋根付き・**連子**・銅瓦葺【A(葺材)/S(連子)】
- 名所図会では**屋根の下に縦の連子**が並ぶ。板塀ではない
- **モジュールで作る**(`unity-modular-stonewall` のピッチ手法を応用)。直線材・出隅・入隅・端部

### 6. 回廊 — 屋根付きの廊【S】
- 名所図会の実見: 桟瓦の屋根、軒に組物、**参道側は連子の高欄で開く**、
  **石垣の基壇の上に円柱**が立つ
- **モジュールで作る**。直線材・端部・隨身門への取り付き

### 7. 隨身門 — 三間一戸・**単層**・入母屋造【S 実見】
- 大きな入母屋屋根(強い反り)+**深い組物の帯**+円柱
- **両脇間は連子**で、その奥に**随身像**が見える
- ⚠ 銘は「樓門」なので二階建の可能性が残る【?】。当面は単層で作る

### 8. 二天門(坂下の門)【B】
- 男坂の下。左右に板塀が山裾に沿って伸びる【S】。形式は未確定

### 9. 鳥居【?】
- **江戸期の形式は不明**。現在の山王鳥居(合掌鳥居)は現状であって嘉永期の姿ではない
- 作るなら明神鳥居と山王鳥居の**両方**を出して、採用はユーザーの裁定にする

### 10. 鐘楼・鼓楼【S 銘】/ 手水舎 / 附属堂(宝形・入母屋の小堂)
- 名所図会では境内の縁に小堂が並ぶ。鐘楼は袴腰付き

## 作りの規約(`Tools/Blender/README.md` の規約を守る)

- 江戸間 **1間 = 1.818m**。Village Kit の部材を使うときは **`vklib.S = 0.909`**
- 幅=X / 高さ=Y / 厚み=Z、**見え面 = +Z**
- ピボット = **一間の中心・床レベル**
- **マテリアルは新規に作らず Village Kit の材質名を保つ**(`wood` `roof` `wall C` …)。
  新しいマテリアルを作るとリアルさが既存建物とズレる
- 屋根は**銅瓦葺** — Village Kit の `roof` 材で瓦の目を出す。檜皮・こけらにしない
- FBX を入れたら Unity で **`Edo ▸ 御殿 ▸ …マテリアルをremap`**。やらないと真っ白になる
- 出したら `EdoAssets.cs` にパスを登録(**パスの literal を新規に書かない** — CLAUDE.md 規則9)
