## 社の性格

江戸郷の総氏神・徳川歴朝の産神【B 社伝】。『江戸名所図会』本文が「**江戸第一の大社**」と書く。永田馬場の南、
溜池北東の独立丘(山王山)の頂にあり、山麓に別当・神主・社僧十坊・門前町が付属する。
**武家屋敷ではないので、`estate-types.md` の建蔽率・拝領坪数・門の格式は適用しない。**
`unity-buke-yashiki` の「連続御殿複合＋外周長屋帯」も当てはまらない。

- **切絵図の記載は「星ノ山日吉山王大権現社」**【S CODH 7-079】。⚠ **「星ノ山」の読みは未決**【?】 —
  (a)川越・喜多院の山号「星野山」(勧請の由緒と整合)/(b)丘の名「星の岡」の両論。
  ⭕ **「星ヶ岡」は明治16年の地名注記**として [五千分一東京図31] が社殿の南に載せる【A】。
  **「松の茸山」は典拠が無い**【?】。
- **社領は600石。** 家光朱印状(寛永12年6月17日)を『麹町区史』が全文翻刻している。
  天正19年に江戸城内5石 → 元和3年に麻生郷100石【地名は未確認・2026-09-01再考証検分で指摘】 → 寛永12年に500石加増で都合600石。
  【S — 朱印状の翻刻】。⛔ **他資料の誤りを指摘するときは対象の版を特定して書く** — でないと後任が
  確認できず⚠だけが残る。
- **組織は5階級** — 別当／神主／社僧(最初4坊、のち10坊)／社家(最初3人、のち6人)／巫女2人。
  ⚠ **この内訳の出所は [神殿大観・日枝] であって『江戸名所図会』本文ではない**【B】(2026-08-24 考証で是正)。
  同資料は**神主を「最初は日吉家、のち樹下家」**とする — 樹下家は当初からの神主ではない。
  別当は**天台宗僧正の観理院**、神主は**樹下家**(近江日吉大社 祝部宿禰の出)。
  『江戸名所図会』本文がこの三つを一文でまとめて書く。【S】 — ただし**一文にまとまるのは別当・神主・樹下家の三者まで**。
- **山王祭は隔年6月15日**。元和元年に山車・練物が初めて江戸城内へ入った。天和元年から神田祭と隔年。
  【A — 麹町区史】

## 社殿 — 旧国宝の指定説明から寸法が取れる【確度S — [国宝建造物目録1941] 原本実見】

昭和6年3月24日に**本殿・幣殿・拝殿・中門・透塀の5件が国宝に指定**され(原本の指定説明は「昭六・三・二四」)、昭和20年5月の空襲で
山王稲荷社殿を残して焼失した。『麹町区史』が指定説明の構造表をそのまま転記していて、
**桁行×梁間・屋根形式・透塀の実延長までここで確定する**。値は json の `munes` にある。

- ⛔ **指定の5件(本殿・幣殿・拝殿・中門・透塀)の屋根はすべて銅瓦葺。** 檜皮葺でもこけら葺でもない。
  ⛔ **楼門・回廊・随身門は目録に載らない**(指定の5件に入らない)── 当図は回廊を社殿と同材(銅瓦葺)で揃えるが、それは**設計判断**【U】であって【S】ではない
  (2026-09-09 考証19巡目 高1 で是正。指図の `runs[Kairo_*].roof` に明記した)。
- ⛔ **境内の堂宇・供の棟は本瓦葺**【U 設計判断】── **根拠は年代と防火**である。
  桟瓦の普及は享保5年(1720)以降、吉宗の防火のための瓦葺奨励による【A `[桟瓦の起源]`・原典未特定】。
  基準年次は安政2年の震火の翌年【S】⇒ 幕府造営の社地で瓦葺を採るのは年代と防火の側から支持される。
  ⛔ **家格の階梯としては支持されない** — 台帳は「⛔ 葺材の階梯を家格で切らないこと」と明記する。
  **史料は何も言わない**【?】。根拠の全文は json の `_roofMaterialBasis` が正典(⛔ ここに写さない)。
- ⭕ **供の棟(御厩・御供所)も本瓦葺**【裁定 2026-09-09 普請奉行・御供所は施主の裁定 2026-09-15】── 堂宇と分ける積極的な理由が
  史料にも意匠にも無いので同材とした【U 設計判断】。⚠ 将来分けるなら**格ではなく用途の軸**
  (馬の出入りで軒を低く葺き替えの頻度が高い等)で立て直すこと。その軸の典拠は現状無い【?】。
- **形式は幣殿型権現造・本殿入母屋造。** 東照宮系の「石の間型」ではなく、
  三芳野神社(明暦2)→**日枝(万治2)**→根津(宝永3)の系列に属する。
- **山王稲荷社の本殿は現存する。** 千代田区指定有形文化財で、
  **万治2年の造営時のものが昭和20年の空襲で境内唯一焼け残った**。千代田区内で唯一の江戸時代初期木造建築、
  関東では珍しい**縋破風形式の春日造**【A 千代田区】。⚠ 現在地が安政3年の位置とは限らない【?】。
  **柱間の割り付け【U】を確かめる代替の実測対象になる。**
- **本殿は方三間入母屋**で、久能山ほか各地の東照宮本殿と同規模。前方一間通を外陣、後方二間を内陣、
  内陣後方一間をさらに区切って神殿とする(東照宮が内陣後方に厨子を置くのと違う)。
  石造亀腹に土台立て、縁を腰組で支持。斗栱は出組。
- **向拝は三間**【A】。**出(奥行)は指定説明に書かれていない**ので、明治16年実測図の線から読む【A — 値は json の `munes[向拝]._plan`】。
- **拝殿は桁行七間梁間三間**で上野東照宮と同規模、日光に次ぐ大きさ。
  **幣殿型は向拝一間が通例だが日枝は石の間型と同格の三間を採る** — 格の上での加点。内部は三室。斗栱は平三斗。
- **総円柱。** 根津が拝殿・幣殿を角柱にするのに対し、日枝は全部円柱で通す。格式差の表現。
- **本殿と幣殿の作り合いは一間の間隔があり、海老虹梁で繋ぐ**(日光・紅葉山東照宮と同じ)
  【確度A 加藤重枝2018】。⚠ **国宝指定説明が項を立てるのは本殿・幣殿・拝殿・中門・透塀の五件だけで、
  作り合いの項は無い** — ゆえに間数も屋根形式もこの目録では確定しない。**屋根の有無は
  どちらの史料にも書かれていない**【確度?】。当図は**三棟を一続きの屋根で覆うものと読み**、
  建蔽率の分子に入れている【確度U 設計判断 — **幣殿が本殿正面庇に接続する**【確度A 加藤・重枝2018】と
  整合する読み】。**伝統的な棟の数え方では数えない**(**壁で囲われた室ではない**)が、
  **図の名簿には一件として持つ** — 建蔽率の分子・断面・Δ検査がこの一件を引くため。
- **囲いは瑞垣のタイプX** — 正面に瑞垣門(=中門)を構え、門の両側から瑞垣(=透塀)を発して
  本殿・幣殿・拝殿を一周する。霊廟に用いられた格上の形式。
  **透塀の延長は史料値がそのまま設計拘束になる**(json の透塀の矩形はこの周長に合わせてある)。

【A — 麹町区史(指定説明の転記)/加藤・重枝2018(焼失前写真と実測図集に基づく形式分析)】

⚠ **大きさは明治16年実測図の線から読む**【A [五千分一東京図31]】。**図の線は建物の外周(柱の外面)であって

## 境内の配置 — 文政3年の実測絵図で骨格が確定する【確度S】

『[江戸城内并芝上野山内其他御成絵図]』(中川高壽 寫、文政3年、NDL)の
**コマ25「山王御宮絵図」**(彩色境内平面図)と**コマ26「山王御社参之図」**(将軍参詣の動線を
朱線で示す配置図)を実見した。北が上、右が東。**基準年次の30年前で、社殿も楼門もそのまま建っている。**

**絵図は一直線の東西に描く。** 東から順に —

**坂下の門 → 男坂の石段 → 楼門 → 白洲 → 中門 → 向拝 → 拝殿 → 幣殿 → 本殿**

- **山上の門は楼門1基。** 絵図の銘は「樓門」【S 字 — 原図実見】、名所図会の題箋は「随身門」【S 字 — 原図実見】。
  **この二つを同一の門の別称と読むのは当方の同定**【U】 — 位置が同一なので同定そのものは堅いが、
  「別称である」と述べる史料は無い。⛔ 字の【S】を同定へ持ち越さない。
  楼門は**南北に長い御廻廊2棟の中央**に立ち、回廊が境内の東front を成す。もう1基は男坂の下。
- **明治16年実測図では、翼は楼門に取り付かず、間を低い屋根付きの袖塀でつなぐ**【A 実測図/S 名所図会・御宮絵図】。
  **回廊の東面(北翼・楼門・南翼)は一直線のまま傾き、楼門と男坂の軸は中門と社殿の軸より南を通る**【A】。
  当図はこの二つを採る(ユーザー裁定C「歴史に近いほう」の適用 — 値は json の `grid.frames`・`gates[中門]._v`)。
  御宮絵図の一軸は概形で【U】。袖塀の丈と形は【U】で未決。
- **門の正面は東、通り抜けは男坂の軸(東西)。** 御社参之図(コマ26)の朱線が坂下の門と楼門を
  東西一直線に通る【S】。坂下の門が東を向くことは名所図会の読み【S 図/U 向きはユーザー裁定 2026-09-06】。
  楼門・中門の正面を東とするのは同じ向きに揃えた当図の読み【U】。⛔ 数の向き(yaw)は指図の宣言から出す。
- **社殿を囲うのは透塀で、その正面(東)に中門。** 名所図会の題箋も「回廊」と「中門」を書き分ける。

## 地形と造成

**山王山は独立した台地で、山頂に平坦面がある。** 西面は急崖、東面は緩く落ちて山麓の通りに至り、
南西面は社僧十坊の帯へ落ちる。切絵図は境内全体を「緑=山林土手馬場原」一筆で塗り、
御宮絵図も**外周に緑の帯を置く**【S [外桜田永田町絵図] 凡例 ／ [山王御宮絵図] 実見】。
⚠ ここから **社叢が境内の実体で、建物は樹林の中の明地に建つ** と読むのは**当方の解釈**
【U 設計判断 — 考証18巡目 中2 で刷り分けた】。⛔ 緑は**地種・樹林の彩色記号**であって
葉の常緑性も樹林の濃さも語らない(落葉林も原も土手も同じ緑)。しかも御宮絵図の
**境内の内側は白のまま**なので「濃緑一色」は言い過ぎである。

面は4つ。**境内(山上)／前庭(男坂下)／山麓の通り／社叢の斜面**で、値は json の `planes` にある。
街路は現地形に従い、造成は境内と前庭に限る。

**⚠ この指図が「現地形」と呼ぶものは、今日の地面である。**
`sanno_dem.json`(シーンの `ModernTerrain` を `Terrain.SampleHeight` で吐いたもの・確度P)が実体で、
国土地理院の DEM と突き合わせて 8m のズレを補正してある。**建物は入っていない** —
地形のハイトマップだけを読むので、社殿もホテルも高架も高さには含まれない。
⛔ **しかし「原地形」ではない。** 言えることと言えないことを二段に割って書く。

**言えること【A】** — [五千分一東京図31](明治16年12月測図)の標高点は **台上 28.2 / 境内北西 27.1 /
南東の独立丘 27.5**。これは**神仏分離のあと・昭和二十年の焼失・昭和三十三年の再建・
ホテルと道路の切り込みのすべてより前**の測量で、**その時点で既に 27〜28m の平坦面がある**。
したがって安政3年の台上の高さをここから外挿するのは強い。**平坦面は近代の産物ではない。**
**§B-1 の残差(±1.2m)は、明治16年の台上にも見える 1.1m の自然の起伏で説明がつく**。

**言えないこと【B/?】** — **縁の位置と境内南半の土地利用**。明治元年の神仏分離で坂下の仁王門・
鐘楼などの仏教施設が撤去され、**明治14年に境内南部へ麹町公園(星ヶ岡)が置かれ**、坂下に道路が通った。
⚠ 明治4年の上知令が召し上げたのは朱印地・除地で、**境内地は別扱い**(のち官有地第一種へ編入) —

③は平場の輪郭を縮めることなので図では平面に現れる。
**②が要る縁(北縁・西縁の崖の上・25標本)は、2026-08-24 のユーザーの裁定で③に寄せた。**

## 社叢と植栽

**社叢が境内の実体で、建物は樹林の中の明地に建つ**【確度S】。切絵図は境内全体を
「緑=山林土手馬場原」の一筆で塗り、御宮絵図も外周をぐるりと濃緑で塗ったうえ、内側に樹を示す
黒い塊を散らして描く。⛔ **境内を裸地として作らない。**

樹種は松である【A 溜池側の斜面=橋本・堀1998 No.46「寺社地/松/高木/群」/ B 山上・東面への外挿=[田原ほか2011](江戸の名木は松が第一・立地は社寺が最多)・[松下1997](江戸期の境内林は松+広葉樹で照葉樹の極相ではない)】。松の種(クロマツ/アカマツ)は史料から決まらない【U】。同じ表が斜面の竹薮を例外中の例外とするので
⛔ **竹林にしない**。
⚠ **No.46 の観察は名所図会の挿絵の読みであり、図会には松を多く描く偏りが乗る**
【確度A [田原ほか2011] — 原文「図会に出てくる名木には、圧倒的にマツが多い」】。
**松を主とする判断は据えるが、これは林分の実組成の証拠ではない。**
⛔ **杉と檜は当社に当てる典拠が無いので落とした**([松下1997] は江戸期の境内絵図に杉が現れる例を示すが、当社の史料には無い)。柵は社地と公道の境を示す仕切りとして置き、玉垣(神域の標識)は参道(公道)の沿道には置かない。
⭐ **本書は「玉垣」を形の呼び名としてだけ使い、神域の標識という意味では使わない。**
線引きの判定基準は**囲う対象が土地か、植込みか**である【確度U 庭方】 — 土地(社地)を囲えば社の格が上がるが、
植込みそのものを囲う玉垣は格の標識ではない。前庭の帯の玉垣【確度S 名所図会】はこれに当たるので置く。
⚠ **囲われた植込みは名木(神木)の囲いだったという読みも成り立つ**【確度B 両論】 —
[田原ほか2011]は江戸の名木の一位が松で立地は社寺が最多とする。そう読むと、
**門被りのクロマツが玉垣の中にある**ことが自然に説明される。⛔ どちらかへ寄せない。松に交ぜるのは常緑広葉の中木(椎・樫・黐)と
落葉高木(欅・椋・榎)である【確度U 類型】。落葉高木の割合は裾で最も高く、稜へ向かって減らす
【確度U 設計値】 — 稜は風衝で丈が伸びず、中腹が最も高く育つ。
⭐ **落葉と中木の樹冠は林の形へ狭める**【確度U 庭方 2026-09-08】 — 割前は幹の数で宣言するが、
**目が読むのは樹冠**である。部材は野に一本で育った開いた形をしているので、そのまま据えると
本数では二割に満たない落葉が**南からの立面で林の天端を作ってしまい**、絵図が境内を濃緑一色に
塗る姿と噛み合わない。⛔ 丈を下げて逃げない — 社叢として正しい丈である。狭めるのは樹冠だけとする。
⛔ **孤立木は狭めない** — 前庭の一本立ち(榎・椋)と路の終端を締める欅は、
**野に一本で育った開いた形が正しい**。狭めれば門被り・木陰・路の終端の役が痩せる。

**塊は輪郭・本数・芯々が噛み合っていなければ塊にならない**【確度U 庭方 2026-09-07】 —
輪郭に入る本数は芯々(詰めた後)から決まるので、⛔ **芯々の宣言が無い塊は測れない**とし、
**輪郭に本数が入ること**を組む条件にする。
⭐ **「何本入るか」は面積では測らない**【確度U 庭方 2026-09-08】 — 面積の条件は塊(二次元の塊)に
しか当たらず、**一列の帯**(参道の林縁)は面積で落ちるのに線に沿えば余裕で入る。⛔ 検査と作図で

斜面林の側は「**麓から坂と仁王門を見せる額縁**」【確度S 名所図会】で、測っている物が違う。
⛔ **一本化しない** — 斜面林を前庭の値へ緩めれば坂の両側の裸地が痩せて額縁が効かなくなり、
前庭を斜面林の値へ締めれば門被りの松と榎の立つ余地が消える。
⭐ **斜面の帯の側の石段の肩は、層ごとに刻む**【確度U 庭方 2026-09-08】 — 低木は近く、中木は中ほど、
高木はいちばん遠い。⛔ 一つの肩で三層を代表させない。**高木の肩には幾何の上限がある** —
当図に現れる**最も細い松の樹冠の半径**より小さくなければ、樹冠が笠石の上へ届かず、
男坂が林を割る溝になる。⛔ 余裕は図が毎回刷る(部材が細くなった日に黙って割れ目が開く道を塞ぐ)。
⚠ 逆に低木の肩が広すぎると、石段の両側に**下草だけの縁**が残って麓から「刈り込んだ法面」に読める。
⛔ 高木側の不足だけを見て低木側の過剰を見落とさない。
⚠ **肩が守るのは「幹の根が擁壁を押さないこと」である**
【確度P 実測 — 造成前の地盤の正本 `docs/Sashizu/sanno_dem.json`(検図15巡目 低4)／
確度U 当方の読み】 — 正本で測ると段の天端はその通りの**造成前の地盤**より高く、
**当図の設計面は切盛の擁壁で受けた坂として据わる**(切通しになるのは下端の区間だけ)。
裏込めは段の下(内側)にあるので、肩が守るのは「幹が裏込めの上に立たないこと」ではない。
⛔ **これは安政三年の地盤の復元ではない。**正本は上知のあとの官有地・昭和の再建・ホテルと道路の
切り込みを含む**今日の地面**であって、安政三年の地面ではない
(→ `_pending`「現況地形が『自然地形』ではないこと」)。だから「男坂は切盛の坂**であった**」とは
言えない — 言えるのは**当図の設計面がその面に対してそう据わる**ことまでである。
⛔ 名所図会【確度S】が支えるのは「石段の両側に笠付きの土留め側壁がある」ことまでで、
**切通しか切盛かは支えない**。⛔ 肩の量は幾何から決まるので動かない。
⭐ **帯が割れていないかを見る不変条件は、石段の敷きを橋として渡して数える**【確度U 庭方 2026-09-08】 —
坂で切られていることは欠陥ではない。⛔ ただし**橋を架けてよいのは石段の敷きだけ**で、
⛔ **参道(道敷)は渡さない** — あの幅では樹冠が閉じないので、そこで切れるのは本物の割れ目である。
⛔ そして**橋の正当性は高木の肩の上限に従属する** — 肩が最も細い松の樹冠の半径を越えた瞬間に、
樹冠は笠石の上で触れなくなり橋の読みは偽になる。両方とも機械検査が守る。

手水は白洲の記号の位置に据え鉢を置く【確度S 位置=御宮絵図の記号 / 確度U 正体の読み】。
⛔ **覆屋(手水舎)は建てない** — 御宮絵図は朱で棟を描き分けており、そこに無い建物を足すと
典拠が非対称になる。当の記号は小さく、建物の朱ではない。井戸から手桶で満たす据え鉢は
山上の条件に合う。⛔ 近代の作法(参道右手の手水舎)を絵図より優先しない。
覆屋の有無は未解決に残す【確度?】。

部材は帯・区・塊ごとに名指ししてある【確度U 設計値】。松は在庫の黒松、中木と落葉高木は自作、
下草は在庫の羊歯と草叢で足りるが、**常緑の照葉低木だけが無い**。
前庭の帯の玉垣(柱・貫・立子)と、**井戸屋形一式**(屋形・井桁・釣瓶の横木・縁石・板石敷)も在庫に
無いので新造に立ててある。社叢の下層・林縁・平場の縁の下層がすべて低木を待つので、指図の部材名は
仮に置いてある(「未解決」の節)。
⛔ 松は夏の変種を採る(枯れ色の変種は当図の季節ではない)。
庭に使う石は**一系統に統一する**【確度U 庭方 2026-09-07】 — 板石敷・縁石・井筒の玉石・割栗・踏石が
別々の石に見えると、庭が一度に作られた物に見えない。⛔ **産地は典拠なく名指ししない**【確度?】 —
伊豆石・小松石などと書ける史料が当社について無い(未解決)。⛔ 石垣はこの系統に含めない(土木の石である)。
低木と下草は数が千の桁になるので、**個々の物として置かず地形の詳細植生として載せる**
【確度U 設計値】。⭐ **帯と区に撒く松・落葉高木・中木も個々の物として置かない**【確度U 庭方 2026-09-07】 —
本数が千の桁で、描画の重さが千万の桁になる。**地形の樹木として(段階表示と遠景の板で)載せる**。
⭕ 個々の物として置くのは、**意匠として一本ずつ位置を決めた木だけ**である — 主景の木・門被りの松・
坂の頭の松・帯の骨になる木・境内の二本で、⛔ 名簿を別に持たない(指図の「一本立ち」がそのまま名簿である)。
⛔ **一本立ちは層と丈を必ず宣言する**【確度U 庭方 2026-09-07】 — 宣言が無い間、図は既定で
**落葉高木の名簿の最大**を当て、境内の南の松二本を落葉の大木として円に描いていた。丈の宣言も
無かったので段の検査にも入っておらず、**検査が0件だったのは合格ではなく未測定**だった。
いまは層が引けなければ図は「測れていない」と刷り、検査が止める。
⛔ **一本立ちを詳細植生に落とさない** — 詳細植生は影を落とさないので、門被りも木陰も成り立たなくなる。
置く物の総数と描画の重さは図が部材の目録から算出する。
⭕ 自作の落葉高木三種は目録に入った。樹冠も重さも部材から引けるようになり、
**前庭の落葉高木の樹冠は仮値を外して樹形の規約からの従属値とした**【確度U 庭方 2026-09-07】。
⛔ 手で置いた樹冠へ戻さない — 部材を差し替えれば木陰も追随する。
⚠ 樹冠が動けば、縁台の木陰・井戸屋形の軒先・木戸の裏・前庭の視線の抜き・
**参道への林縁の張り出し**はすべて測り直しになる。数は図が毎回刷る。
⚠ 重さの見積りは、大きさを丈から選ぶ以上**どの変種が何本になるかがここでは決まらない**ので、
変種の平均で見積る【確度P 算出】。

参詣の動線は前庭で引き直した【確度U 設計値 — 存在は確度S】。旧線は**坂下の門の開口を素通りして**
石段の足へ斜めに取り付いていたが、門の左右には板塀が山裾へ伸びる【確度S】ので通れない。
いまは参道の階を降りて**帯の東を南へ真っ直ぐ下り**、門の東で西へ折れて**門口の芯を通り**、
坂の足へ真西から取り付く。御成は参道の階から二股の点まで参詣と一本に重ね、
そこで分かれて**女坂の口へ真っ直ぐ**下る。

## 部材 — 神社建築は在庫にゼロ

在庫照会の結論。社殿・鳥居・随身門・手水鉢・透塀・狛犬のいずれも、
edogoyomi / Japanese Castle / Japanese Village Kit / Waldemarst の4パックに存在しない。
流用できるのは**石灯籠**だけ。⚠ 平伏せの**踏石**に当てていた汐見坂の切石は、材の色が境内の石の受入値から外れ
目地の模様も出るので、踏石の材は新造を依頼する(json の `bom` 踏石の行)。⛔ **参道の石段は流用できない** —
汐見坂の実績品は蹴上・踏面が固定で、参道の坂の蹴上・踏面は段数からの従属値として四本とも違う
(CLAUDE.md も⛔ 参道の坂に屋敷内の既定値を当てないと定める)。段石は寸法をパラメタ化して起こす。
新造の優先順位は json の `bom` にある。**社殿本体が最優先** — 現況は Village Kit の民家を
代用していて神社に見えない。
