## 社の性格

江戸城の産土神。『江戸名所図会』本文が「**江戸第一の大社**」と書く。永田馬場の南、
溜池北東の独立丘(山王山)の頂にあり、山麓に別当・神主・社僧十坊・門前町が付属する。
**武家屋敷ではないので、`estate-types.md` の建蔽率・拝領坪数・門の格式は適用しない。**
`unity-buke-yashiki` の「連続御殿複合＋外周長屋帯」も当てはまらない。

- **山号は星野山**。切絵図の記載は「星ノ山日吉山王大権現社」で、川越・喜多院から勧請した
  由緒と整合する【S】。「星ヶ岡」は現代の坂の説明板が伝える俗称で、**江戸期の用例は未確認**【?】。
  **「松の茸山」は典拠が無い**【?】。
- **社領は600石。** 家光朱印状(寛永12年6月17日)を『麹町区史』が全文翻刻している。
  天正19年に江戸城内5石 → 元和3年に麻生郷100石 → 寛永12年に500石加増で都合600石。
  ⚠ ja.wikipedia の「400石を加え500石」は誤り。【S — 朱印状の翻刻】
- **組織は5階級** — 別当／神主／社僧(最初4坊、のち10坊)／社家(最初3人、のち6人)／巫女2人。
  別当は**天台宗僧正の観理院**、神主は**樹下家**(近江日吉大社 祝部宿禰の出)。
  『江戸名所図会』本文がこの三つを一文でまとめて書く。【S】
- **山王祭は隔年6月15日**。元和元年に山車・練物が初めて江戸城内へ入った。天和元年から神田祭と隔年。
  【A — 麹町区史】

## 社殿 — 旧国宝の指定説明から寸法が取れる【確度A】

昭和6年10月に**本殿・幣殿・拝殿・中門・透塀の5件が国宝に指定**され、昭和20年5月の空襲で
山王稲荷社殿を残して焼失した。『麹町区史』が指定説明の構造表をそのまま転記していて、
**桁行×梁間・屋根形式・透塀の実延長までここで確定する**。値は json の `munes` にある。

- ⛔ **屋根はすべて銅瓦葺。** 檜皮葺でもこけら葺でもない。
- **形式は幣殿型権現造・本殿入母屋造。** 東照宮系の「石の間型」ではなく、
  三芳野神社(明暦2)→**日枝(万治2)**→根津(宝永3)の系列に属する。
- **山王稲荷社の本殿は現存する。** 千代田区指定有形文化財で、**万治2年の造営時のものが
  昭和20年の空襲で境内唯一焼け残った**。千代田区内で唯一の江戸時代初期木造建築、
  関東では珍しい**縋破風形式の春日造**【A 千代田区】。⚠ 現在地が嘉永期の位置とは限らない【?】。
  **柱間実寸が実測図集からしか取れない社殿5棟の、代替の実測対象になる。**
- **本殿は方三間入母屋**で、久能山ほか各地の東照宮本殿と同規模。前方一間通を外陣、後方二間を内陣、
  内陣後方一間をさらに区切って神殿とする(東照宮が内陣後方に厨子を置くのと違う)。
  石造亀腹に土台立て、縁を腰組で支持。斗栱は出組。
- **向拝は三間**【A】。ただし**出(奥行)は指定説明に書かれていない** — 当図の一間出は設計値【U】。
- **拝殿は桁行七間梁間三間**で上野東照宮と同規模、日光に次ぐ大きさ。**幣殿型は向拝一間が通例だが
  日枝は石の間型と同格の三間を採る** — 格の上での加点。内部は三室。斗栱は平三斗。
- **総円柱。** 根津が拝殿・幣殿を角柱にするのに対し、日枝は全部円柱で通す。格式差の表現。
- **本殿と幣殿の作り合いは一間の間隔があり、海老虹梁で繋ぐ**(日光・紅葉山東照宮と同じ)。
- **囲いは瑞垣のタイプX** — 正面に瑞垣門(=中門)を構え、門の両側から瑞垣(=透塀)を発して
  本殿・幣殿・拝殿を一周する。霊廟に用いられた格上の形式。
  **透塀の延長は史料値がそのまま設計拘束になる**(json の透塀の矩形はこの周長に合わせてある)。

【A — 麹町区史(指定説明の転記)/加藤・重枝2018(焼失前写真と実測図集に基づく形式分析)】

⚠ **柱間の実寸は取れていない。** 『国宝・重要文化財(建造物)実測図集』東京都(その1)に平面図が
あるが未実見。当図の柱間は江戸間均等で置いてある【U】。**彫刻・彩色の具体も不明**【?】。

## 境内の配置 — 文政3年の実測絵図で骨格が確定する【確度S】

『[江戸城内并芝上野山内其他御成絵図]』(中川高壽 寫、文政3年、NDL)の
**コマ25「山王御宮絵図」**(彩色境内平面図)と**コマ26「山王御社参之図」**(将軍参詣の動線を
朱線で示す配置図)を実見した。北が上、右が東。**基準年次の30年前で、社殿も楼門もそのまま建っている。**

**軸は一直線の東西。** 東から順に —

**坂下の門 → 男坂の石段 → 楼門 → 白洲 → 中門 → 向拝 → 拝殿 → 幣殿 → 本殿**

- **山上の門は楼門1基。** 絵図の銘は「樓門」、名所図会の題箋は「随身門」で、同一の門の別称と読む。
  楼門は**南北に長い御廻廊2棟の中央**に立ち、回廊が境内の東front を成す。もう1基は男坂の下。
  現行実装も位相は同じ(石段上=随身門/石段下=仁王門)で、**相違は門の名と坂下の門の位置**。
- **社殿を囲うのは透塀で、その正面(東)に中門。** 名所図会の題箋も「回廊」と「中門」を書き分ける。
- **回廊は石垣の上に載る。** 名所図会が石段側から見上げた重なり(石垣→回廊→屋根)を描く。
- **御供所が社殿の南西に渡廊下で接続する。**
- 白洲に石灯籠が4基と、正体の分からない△が1つ。
- 境内の外周は**板塀・柵**が折れながら回る。築地塀ではない。
- **附属堂が9棟**、北列と南列に分かれて社叢の縁に並ぶ。**銘はすべて崩し字で未判読**【?】。
  名所図会の題箋には 薬師・不動・庚申・鐘楼・鼓楼・宝蔵 が現れるので、このどれかである見込み。
  判読が返るまで**推定で名を与えない**。

## 参道と坂

- **石段は東へ2本。** 切絵図でも御宮絵図でも、境内から降りる石段は東側の2本だけで、
  **南西(溜池側)には降りていない。**【S】
- **男坂は折返しの無い一直線。** 両側に笠付きの土留め側壁が付く=切通し。下端に門、
  その前に広い平坦な前庭があって茶店の縁台が並ぶ。【S】
  - 現状の段数は千代田区の説明板が伝えるが、**江戸期の段数の記録は無い**【?】。
    当図の段割りは現地形の比高と CLAUDE.md の蹴上から出した設計値【U】。
  - ⛔ **現行実装は男坂として成立していない。** 石段の下端が法尻より外へ大きく食み出していて、
    勾配が緩い雁木になっている。
- **女坂は男坂の南**を斜めに下る。⛔ **現行実装が北に置いているのは逆。**【S】
  - 別名**御成坂**。『新撰東京名所図会』が「左緩やかに通ずる石階を女坂と呼ぶは非なり。
    昔時将軍家御成の節、峻坂を避け、此坂のみ御通行遊ばされしにより、御成坂と申侍る」とする【B】。
    → **裏の脇道として作ってはならない。** 踏面を男坂より広く取り、格を落とさない。
  - ⚠ ただし御社参之図の朱線は男坂の軸を通っている。**女坂と御成の関係は説明文の判読待ち**【?】。
- **鳥居は2基。** 切絵図の参道の路面に墨の「开」記号が2つあり、二ノ鳥居は境内東麓の辻、
  一ノ鳥居はさらに東の丹羽左京大夫と五島兵右衛門に挟まれる区間【S】。
  **一ノ鳥居のシーン座標は未確定**(切絵図は非等尺で px/m 換算が効かない)【?】。
- ⛔ **江戸期の鳥居の形式は分かっていない。** 現在の山王鳥居(合掌鳥居)は文化庁の記載で
  確度Aだが、それは現状であって嘉永期の姿ではない。切絵図の記号は普通の「开」で破風が無く、
  名所図会の該当箇所は綴じ目にかかって読めない。**どちらを採るにせよ設計判断と明記する。**【?】
- ⛔ **千本鳥居(稲荷参道)・西参道・山王橋は近代。** 切絵図にも名所図会にも連続鳥居も
  南西からの参道も無い。**再現しない。**【A — 否定的証拠だが切絵図は道路を厳密に描く】

## 地形と造成

**山王山は独立した台地で、山頂に平坦面がある。** 西面は急崖、東面は緩く落ちて山麓の通りに至り、
南西面は社僧十坊の帯へ落ちる。切絵図は境内全体を「緑=山林土手馬場原」一筆で塗り、
御宮絵図も外周をぐるりと濃緑で塗る — **社叢が境内の実体で、建物は樹林の中の明地に建つ。**【S】

面は4つ。**境内(山上)／前庭(男坂下)／山麓の通り／社叢の斜面**で、値は json の `planes` にある。
街路は現地形に従い、造成は境内と前庭に限る。

- **男坂は現地形なりには据わらない。** 規定の蹴上・踏面で割った石段は東法面より格段に急なので、
  石段の区間は**切通し**になり、両側に石垣が立つ。名所図会が描く「石段の両側の笠付きの土留め側壁」と
  「坂下の門の左右の塀が石積みの上に載る」姿は、まさにこの形。断面イがこれを示す。
- **回廊の北翼は基壇の石垣の上に持ち出す。** 平坦面の東縁が北へ退くのに対し、回廊は直線で通るため。
  絵図が回廊を一本の直線で描き、名所図会が石垣の上に載せて描くのと整合する。断面ニがこれを示す。
- ⚠ **未解決 — シーンの地形と実測DEMが食い違う。** 地理院1mレーザDEMを直接引くと東法面は
  もっと急で、その断面なら男坂の切土はごく浅くて済む。シーンの Terrain は中腹が数m膨らんでいる。
  **地形を寄せ直すかどうかはユーザーの裁定**(地形の編集は Undo の外なので指図では触らない)。
- **社叢は竹林にしない。** 斜面竹林は江戸の水辺79事例中1例の例外。杉・檜を交えた常緑の高木林で置く。

## 部材 — 神社建築は在庫にゼロ

在庫照会の結論。社殿・鳥居・随身門・手水舎・神楽殿・透塀・狛犬のいずれも、
edogoyomi / Japanese Castle / Japanese Village Kit / Waldemarst の4パックに存在しない。
流用できるのは**石段**(汐見坂で実績のある段石)と**石灯籠**だけ。
新造の優先順位は json の `bom` にある。**社殿本体が最優先** — 現況は Village Kit の民家を
代用していて神社に見えない。
