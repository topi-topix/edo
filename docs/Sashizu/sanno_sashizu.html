永田馬場 星野山 ／ 江戸城の産土神 ／ 社領六百石

山王権現社(日枝神社) 指図

嘉永期の姿。社殿は万治二年造営のものが昭和二十年まで存続し、昭和六年に本殿・幣殿・拝殿・中門・透塀の五件が国宝に指定された。その指定説明を『麹町区史』が転記していて、桁行×梁間・屋根形式・透塀の実延長までここで確定する。境内の配置は文政三年の彩色実測図『山王御宮絵図』による。数値の正典は sanno_sashizu.json、文章の正典は sanno_kosho.md。この頁はその二つから組んだもので、実装は読んでいない。

境内 一万八千五百七十坪【B — 『大江戸今昔めぐり』(嘉永年間の切絵図がベース)の記載】。これは社地・別当観理院・社僧十坊を合わせた社領全体の坪数で、当図の区画の実測合計は 19,202 坪(社地 13274 坪 + 観理院 1,526 坪 + 十坊 4,402 坪)= 記載値の +3.4%【P】。多角形そのものは拝領坪数の起こしではなく、既実装の隣地から割り出した残余【U】 — 一致は裏づけであって典拠ではない。山上の平場は 8932 m²(2702 坪)【P】。⚠ 俗説の「約一万坪」は出所不明【?】。

其四　断面イ 東西(参道軸 v=0)

EW = 857 ／ 北を見る

この図が指図の要。左が西(本殿)・右が東(山麓)で、北を見る断面。規定の蹴上・踏面で割った石段は東法面より格段に急なので、男坂の区間は切通しになり両側に石垣が立つ。名所図会が描く「石段の両側の笠付きの土留め側壁」と「坂下の門の左右の塀が石積みの上に載る」姿は、まさにこの形【S】。⚠ 未解決 — 地理院1mレーザDEMを直接引くと東法面はもっと急で、その断面なら切土はごく浅くて済む。地形を寄せ直すかどうかはユーザーの裁定。

社の性格

江戸城の産土神。『江戸名所図会』本文が「江戸第一の大社」と書く。永田馬場の南、 溜池北東の独立丘(山王山)の頂にあり、山麓に別当・神主・社僧十坊・門前町が付属する。 武家屋敷ではないので、estate-types.md の建蔽率・拝領坪数・門の格式は適用しない。 unity-buke-yashiki の「連続御殿複合＋外周長屋帯」も当てはまらない。

  • 山号は星野山。切絵図の記載は「星ノ山日吉山王大権現社」で、川越・喜多院から勧請した 由緒と整合する【S】。「星ヶ岡」は現代の坂の説明板が伝える俗称で、江戸期の用例は未確認【?】。 「松の茸山」は典拠が無い【?】。
  • 社領は600石。 家光朱印状(寛永12年6月17日)を『麹町区史』が全文翻刻している。 天正19年に江戸城内5石 → 元和3年に麻生郷100石 → 寛永12年に500石加増で都合600石。 ⚠ ja.wikipedia の「400石を加え500石」は誤り。【S — 朱印状の翻刻】
  • 組織は5階級 — 別当／神主／社僧(最初4坊、のち10坊)／社家(最初3人、のち6人)／巫女2人。 別当は天台宗僧正の観理院、神主は樹下家(近江日吉大社 祝部宿禰の出)。 『江戸名所図会』本文がこの三つを一文でまとめて書く。【S】
  • 山王祭は隔年6月15日。元和元年に山車・練物が初めて江戸城内へ入った。天和元年から神田祭と隔年。 【A — 麹町区史】

社殿 — 旧国宝の指定説明から寸法が取れる【確度A】

昭和6年10月に本殿・幣殿・拝殿・中門・透塀の5件が国宝に指定され、昭和20年5月の空襲で 山王稲荷社殿を残して焼失した。『麹町区史』が指定説明の構造表をそのまま転記していて、 桁行×梁間・屋根形式・透塀の実延長までここで確定する。値は json の munes にある。

  • ⛔ 屋根はすべて銅瓦葺。 檜皮葺でもこけら葺でもない。
  • 形式は幣殿型権現造・本殿入母屋造。 東照宮系の「石の間型」ではなく、 三芳野神社(明暦2)→日枝(万治2)→根津(宝永3)の系列に属する。
  • 山王稲荷社の本殿は現存する。 千代田区指定有形文化財で、**万治2年の造営時のものが 昭和20年の空襲で境内唯一焼け残った**。千代田区内で唯一の江戸時代初期木造建築、 関東では珍しい縋破風形式の春日造【A 千代田区】。⚠ 現在地が嘉永期の位置とは限らない【?】。 柱間実寸が実測図集からしか取れない社殿5棟の、代替の実測対象になる。
  • 本殿は方三間入母屋で、久能山ほか各地の東照宮本殿と同規模。前方一間通を外陣、後方二間を内陣、 内陣後方一間をさらに区切って神殿とする(東照宮が内陣後方に厨子を置くのと違う)。 石造亀腹に土台立て、縁を腰組で支持。斗栱は出組。

  • 拝殿は桁行七間梁間三間で上野東照宮と同規模、日光に次ぐ大きさ。**幣殿型は向拝一間が通例だが 日枝は石の間型と同格の三間を採る** — 格の上での加点。内部は三室。斗栱は平三斗。

地形と造成

山王山は独立した台地で、山頂に平坦面がある。 西面は急崖、東面は緩く落ちて山麓の通りに至り、 南西面は社僧十坊の帯へ落ちる。切絵図は境内全体を「緑=山林土手馬場原」一筆で塗り、 御宮絵図も外周をぐるりと濃緑で塗る — 社叢が境内の実体で、建物は樹林の中の明地に建つ。【S】

面は4つ。境内(山上)／前庭(男坂下)／山麓の通り／社叢の斜面で、値は json の planes にある。 街路は現地形に従い、造成は境内と前庭に限る。

  • 男坂は現地形なりには据わらない。 規定の蹴上・踏面で割った石段は東法面より格段に急なので、 石段の区間は切通しになり、両側に石垣が立つ。名所図会が描く「石段の両側の笠付きの土留め側壁」と 「坂下の門の左右の塀が石積みの上に載る」姿は、まさにこの形。断面イがこれを示す。
  • 回廊の北翼は基壇の石垣の上に持ち出す。 平坦面の東縁が北へ退くのに対し、回廊は直線で通るため。 絵図が回廊を一本の直線で描き、名所図会が石垣の上に載せて描くのと整合する。断面ニがこれを示す。
  • ⚠ 未解決 — シーンの地形と実測DEMが食い違う。 地理院1mレーザDEMを直接引くと東法面は もっと急で、その断面なら男坂の切土はごく浅くて済む。シーンの Terrain は中腹が数m膨らんでいる。 地形を寄せ直すかどうかはユーザーの裁定(地形の編集は Undo の外なので指図では触らない)。
  • 社叢は竹林にしない。 斜面竹林は江戸の水辺79事例中1例の例外。杉・檜を交えた常緑の高木林で置く。

社地の範囲 — 境内 一万八千五百七十坪

『大江戸今昔めぐり』(嘉永年間の切絵図がベース)が山王社の境内に「境内18,570坪」と記す【B】。 これはユーザーがこの再現の主な参考図としているもので、2026-08-22 に図を共有された。

  • この坪数は社地・別当観理院・社僧十坊を合わせた社領全体を指す。 当図の区画の実測合計は 19,202坪(社地 13,274 + 観理院 1,526 + 十坊 4,402)で、記載値の +3.4%【P】。
  • ただし多角形そのものは拝領坪数の起こしではない — 既実装の隣地の区画から残余として割り出したもの 【U】。一致は裏づけであって典拠ではない。
  • ⚠ 俗説の「約1万坪」は出所が確認できない【?】。『御府内備考』『御府内寺社備考』『東京府志料』の 公開範囲には社地坪数の記載を見つけられなかった。
  • ⚠ 『新編武蔵風土記稿』は当たり先として不適 — 同書は武蔵国の郡村部が対象で、江戸府内は 『御府内備考』の担当。永田町の山王社は載らない。

山麓の付属 — 別当・神主・門前・十坊

  • 別当 觀理院(天台宗・僧正)。境内東麓の辻に構える。伽藍は護摩堂・客殿・書院・居間・墓所 【S 御宮絵図の銘の判読 2026-08-22】。**旧号「城琳寺」は『大江戸今昔めぐり』が「城琳寺 別当 觀理院」と 併記していて裏づけがある【B】(従前はプロジェクトのメモリ由来で原典未確認【?】だった)。⚠ 実装の区画は下書き由来【U】で、 切絵図の「辻に接するずんぐりした一区画」とは形が違う。** 切絵図では山王社(緑)と観理院(薄紅)は 接しておらず、間に白い明地が挟まる【S】。旧号「城琳寺」はプロジェクトのメモリ由来で原典未確認【?】。
  • 神主 樹下近江守邸。境内の北東麓。⚠ 切絵図で薄紅(=神社佛閣)に塗られる【S】 → 武家屋敷ではなく社家として作る。囲いと門に武家の型を使わない。 ⚠ 樹下家11〜13代は生没年・在職年が不詳で、嘉永期の当主が「近江守」である確証は無い【?】。
  • 山王門前町。二ノ鳥居の辻から北東。切絵図では白地に黒枠で「町」の注記、南北道の北端に 木戸の記号【S】。間口・軒数・坪数は取れない【?】。
  • 社僧十坊は別当配下の住坊であって独立寺院ではない。本堂・山門・鐘楼・墓地は作らない。 実体は南東(円乗院)から北西(常明院)へ描く弧で、間隔はほぼ等しい【A — CODH座標】。 ⚠ 坊の表記が史料間で揺れる。 御宮絵図(文政3)=長命院/知光院/法泉院/知乗院/延宝院、 『大江戸今昔めぐり』(嘉永期)=円成院・玄仙院、現行実装=円乗院・宝仙院。 基準年次の図に合わせるなら円成院・玄仙院。ユーザーの裁定待ち【?】。
  • 社人八家は観理院の南、南北道の西側の短冊8枚。名は切絵図の記載【S】、「社家6+巫女2=8戸」という対応は推論【B】。

部材 — 神社建築は在庫にゼロ

在庫照会の結論。社殿・鳥居・随身門・手水舎・神楽殿・透塀・狛犬のいずれも、 edogoyomi / Japanese Castle / Japanese Village Kit / Waldemarst の4パックに存在しない。 流用できるのは石段(汐見坂で実績のある段石)と石灯籠だけ。 新造の優先順位は json の bom にある。社殿本体が最優先 — 現況は Village Kit の民家を 代用していて神社に見えない。
