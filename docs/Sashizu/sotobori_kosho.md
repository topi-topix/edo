# 外堀下流の掘り直し — 考証と決めごと

指図 `sotobori_sashizu.html` の**文章の部**。寸法は `sotobori_sashizu.json`(設計値の正典)、
実測は `sotobori_terrain.json` にあり、**この文書には数値を写さない**。**現況形で書く。**
経緯は `git log docs/Sashizu/` で追う。

---

## この普請の性格

**新設ではなく復旧である。** 虎ノ門土橋の東から幸橋方向へ下る外堀(`Sotobori_00002` /
`Sotobori_00003`)は 2026-08-10 に一度掘られ、両岸に総石垣が据わり、新シ橋が架かっている。
2026-08-22 のジオリファレンス補正で**「水色の囲い」の外の造成を自然地形へ戻した**とき、
囲いに入っていたのは虎ノ門枡形とその足元だけで、**土橋の東は堀の掘削もろとも現代の地面へ復した**。

水面のメッシュは張られたままなので、いまは**乾いた地面の中に水の板が沈んでいる**。
両岸の石垣も土に埋まっている。溜池で同じ取りこぼしを直したのが `EDO-0039` で、
その報告が「同じことが外堀に残っている」と名指ししたのがこの件である。

⚠ **したがって考証の主題は「どう掘るか」ではなく「何を根拠に元へ戻すか」**である。
堀の形・水位・石垣・橋はすでに考証を通って実装されており、この指図はそれを動かさない。

## 史実(既存実装の前提。この指図では動かさない)

- **虎ノ門〜幸橋はほぼ一水位**(汐留川の川面レベル。「汐留」=潮止めの堰に由来)。
  段差は各城門の橋の堰で作る。牛込〜赤坂の土手構造はこの低地区間には当てはまらない。
  【千代田区ほか『史跡江戸城外堀跡保存管理計画書』本編・資料編 確度B】
- **この区間は両岸とも総石垣**。郭内側の設計高は「4間2尺6寸」(B地点)、郭外側も
  西新橋1丁目の出土と稲葉家の刻印で裏づけられる。【同 確度B】
- **虎御門の土橋は堰堤**で、上流(`Sotobori_00001`)と下流とで水位に段差がある。
  嘉永・安政期の虎御門に**渡櫓は無い**(享保16年ないし明和9年の焼失後、再建されていない)。
  【同 確度B】
- **新シ橋**は虎ノ門の東に架かる木橋。嘉永期の切絵図2種(尾張屋版 4-002 / 7-118)に記載がある。
  【切絵図の記載 確度A / 寸法は未実見のため 確度P】

⛔ **典拠の書誌が `sources.md` に無い。** 『保存管理計画書』は 2026-08-10 にスクラッチパッドへ
落として読んだきりで、`sources.md` に台帳の項が起きていない(「史料の取得物は残さない —
参照した物は典拠を起こして削除」の作法から外れている)。**依拠済みと未着手が同居している**ので、
上の4点は**いずれも確度B に据え置く**。台帳を起こすまで A へ上げない。→ 未解決 U5

## 設計の決めごと

### 1. 壁は垂直のまま残す

⛔ **溜池の掘り直しの手つきをそのまま持ち込まない。** 溜池では最後に変更域を 45°で
均して切り口の崖をなくしたが、**外堀は総石垣で、垂直の壁こそが正しい姿**である。
45°で均すと石垣の面が土に埋まり、堀が皿になる。勾配の頭打ちは**摺り付けの帯だけ**に掛ける。

### 2. 種地は「この堀自身の普請」だけを戻す

復元の種地は 2026-08-22 のリセット直前のハイトマップで、そこには**この堀を 2026-08-10 に
掘った形**が入っている。溜池では岸の帯にこれを使えなかった — リセット前の岸には
干場や旧平場など**他家の造成**が混ざっており、戻すと 08-22 以降に建った屋敷の平場をえぐるからである。

**外堀の工区では事情が違う。** 工区の中で現況が自然地形と食い違うセルは虎ノ門土橋の足元だけで、
そこは種地と現況が一致している(数値は `sotobori_sashizu.json` の `works.provenance` と
`sotobori_terrain.json` の `provenance`)。つまり**工区の中にはこの堀自身の普請しか無い**。
だから種地をそのまま戻してよい。⚠ この検算は**工区を汀線の外へ広げれば成り立たなくなる**ので、
工区を広げるときは必ず取り直すこと。

### 3. 工区を汀線から測って閉じる

工区は汀線の外側までで閉じ、**その外は1セルも触らない**。摺り付けは工区の内側で終わらせる。
⚠ 郭内側(北東)の土手の先には虎ノ門内の4敷地があり、郭外側(南西)には愛宕下の町屋がある。
**それらの地盤はこの普請の担当ではない** — 08-22 のリセットで平らになったままでも、
ここでは直さない(直すなら各区画の担当が造成ステージを流し直す)。

### 4. 入隅の楔だけは盛る

2026-08-10 の掘削は 00002 と 00003 の継ぎ目にある入隅の楔を床まで削っており、
種地をそのまま戻すと短い折れ(`NE3f`)が土留めとして立たない。**矩形で範囲を切った局所の盛り**
(`works.patches` の P1)でここだけ天端の直下まで戻す。
⛔ 矩形は虎ノ門土橋の水路から離して切る — **あちらの床は堰の水路**で、盛ってはならない。

### 5. Recarve を使わない

`WaterBody` の Recarve は使わない。00002 の snap は荒掘り時代のもので、押すと復元事故になる
(2026-08-10 に確認済み)。**手動掘り → RebuildSurface → SyncWaterSnaps** の順で回す。

## 施工と検査

段階は `sotobori_sashizu.json` の `stages`、合否は `checks` にある。要点だけ:

- **地形の編集は Undo の外**にある。触る前に heightmap を `.bin` で退避し、
  `TerrainData.asset` と `.unity` も別に採る。`Scene.isDirty` は当てにならない。
- **MCP のタイムアウト後の再送で多重実行が起きる。** 掘削は冪等ではないので、
  流す前に実行済みかを必ず確かめる。ガードのマーカーは **active** にする。
- **石垣は1個も動かさない**(CLAUDE.md 絶対規則1)。掘削が石垣に取り合っているかは
  「背面の地盤が天端の直下にあるか」で測る。⚠ 短い折れは評価点が数点しかないので、
  中央値だけで合否を決めず実装後に目視で確かめる。
- **新シ橋の橋脚が床に届いているか**は掘った後でなければ測れない。掘削の後に検める。
