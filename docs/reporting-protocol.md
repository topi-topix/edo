# 報告・連絡・相談の作法 — 一件一葉(いっけんいちよう)

**適用範囲: 全メンバー・全経路。** 普請奉行 → ユーザー、エージェント → 呼び出し元、
セッション → セッション、掲示板の起票、作事奉行のダイジェスト。**例外なし。**

> 2026-08-30 ユーザー指摘 —
> 「質問なのか、裁定なのか、報告なのか、情報共有なのかが非常にわかりにくい。
> 複数の質問や裁定、報告をだらだらと、箇条書きや番号もつけずに書いてくるので、
> どの質問や裁定にどう回答して良いか非常に困る。」

読み手は**あなたの文脈を持っていない**。地の文に判断を求める一文を埋めると、
読み手は全文を読み直して「私は何に答えればいいのか」を自分で探す羽目になる。
それは書き手の仕事であって、読み手の仕事ではない。

---

## 規則1 — 種別を見出しに立てる。無題で書き出さない

| 種別 | 何を求めているか | 相手の返事 | 返事は |
|---|---|---|---|
| **【裁定】** | 方針を決めていただく | **選ぶ**(A/B/C) | **要る** |
| **【質問】** | 事実・意図を教わる | **事実を答える** | **要る** |
| **【報告】** | やったこと・結果を見ていただく | — | **要らない** |
| **【共有】** | 他が知るべき知見・注意を留めていただく | — | **要らない** |

**振り分けの判別法** — 「相手の返事は何になるか」だけで決まる:

- 返事が**選択肢のどれか** → **裁定**
- 返事が**事実**(「もう決めた」「その図は使っていない」) → **質問**
- 返事が**要らない**。自分がやったこと → **報告**
- 返事が**要らない**。他がこれから踏むこと → **共有**

⛔ **迷ったら裁定にしない。** 自分で決められることを裁定に上げるのは、判断の押し付け。
選択肢と推奨が書けないなら、それは**まだ裁定を仰ぐ段階ではない**。

---

## 規則2 — 冒頭1行で「あなたに求めること」を宣言する

本文より先に、**何件・何を求めるか**を1行で書く。読み手はこの1行だけで身構えられる。

```
裁定2件・報告3件です。裁定だけお答えください(報告は読み流しで結構です)。
```

求めるものが無いなら、それも書く: `報告のみ。お返事は不要です。`

---

## 規則3 — **すべての項目**に番号と見出しを振る(返事の要らないものも)

> 2026-08-30 ユーザー指示 —
> 「選択肢以外のものに関しても、その文章に対してコメントしたいことは発生するので、
> 番号をつけるかタイトルをつけるようにしてください」

⛔ **番号を裁定・質問だけに振るのは誤り。** 報告にも共有にも、読み手が言いたいことは起きる
(「その報告2は違う」「共有1は既に知っている」)。番号も題も無いと、読み手は
**「3つ目の報告の2行目」**のような指し方しかできず、指すこと自体が手間になる。

**書き方** — 見出しは必ず `【種別+番号】 一行で分かる短い題`:

```
## 【裁定1】天端の段を門口のどちら側へ動かすか
## 【質問1】長屋門形式は、もうご裁定済みでしょうか
## 【報告1】外周が全周で閉じた(素通し 21.4m → 0.00m)
## 【共有1】外向き法線を重心で決めると凹み区画で1辺だけ反転する
```

- **番号は種別ごとの通し**(裁定1・裁定2 / 報告1・報告2・報告3)。一通の中で重複させない。
- **題は見出しだけ読んで中身が分かるもの。**「進捗」「注意」のような箱の名前は題ではない。
- 項目が長く**行ごとにコメントされうる**なら、行にも枝番を振る(**報告2-①** / **報告2-②**)。
- ⛔ **無題の段落を置かない。** 地の文はすべて、どれかの番号付き項目の中に属する。

選択肢は必ず **A / B / C** の記号。
⭐ **狙いは「1=A、2=B」「報告3だけ違う」の一言で返せる形にすること。**
これが満たせていなければ書式が悪い。

---

## 規則4 — 返事の要るものを先に、要らないものは `---` の下へ

順序は **【裁定】→【質問】→ `---` →【報告】→【共有】**。
⛔ **裁定の説明文の中に報告を挟まない。**混ぜた瞬間に、読み手はどこまでが問いか分からなくなる。
番号は振ってあるので(規則3)、下に置いた報告・共有にも**そのまま指してコメントできる**。

---

## 規則5 — 一通で仰ぐ裁定は最大3件

4件目からは次の通・次の巡回へ回す。**重要な順に出す。**
一度に大量に問われると、どれも浅くしか答えられない。

---

## 規則6 — 裁定1件は必ず6点セットで書く

掲示板の `decision` テンプレと同一。**1つでも欠けたら出さない。**

| # | 項目 | 中身 |
|---|---|---|
| ① | **どこ** | 図版番号(其◯)・辺と s・グリッド(u,v)・世界座標・隣接物から最低1つ → [規則:どこ](#付-どこを必ず示す) |
| ② | **背景** | **2文以内**。専門用語を並べない |
| ③ | **選択肢** | **A / B / C**、各1行。2つ以上 |
| ④ | **推奨** | どれか + 理由1文 |
| ⑤ | **影響** | 採ったときに動くもの。他邸への波及があれば必ず |
| ⑥ | **裁定図** | 各案を**同じ縮尺で並べた図**。⛔ 名前と数字の羅列で選ばせない |

---

## 規則7 — 地の文に判断を埋めない

⛔ **悪い例**(2026-08-30 の作事奉行の報告。実際に「何を確認すれば良い?」と差し戻された):

> …松平のFBXが出ています。其の二(B)=長屋門形式ですでにご裁定済みなら board の状態が
> 古いので、直させます。未裁定のまま先行しているなら止める必要があります。どちらでしょうか。

問いが段落の末尾に埋まっていて、種別も番号も無い。上に別件が3つ並んでいて、
**どれに答えればよいか読み手が探さされる。**

⭕ **良い例**:

```
質問1件・報告2件です。質問1だけお答えください(報告にも番号を振ってあります)。

## 【質問1】松平の長屋門形式は、もうご裁定済みでしょうか
- **どこ**: 辺13 御蔵門(s12.50〜15.50 / 中心 −555.5,1294.7)
- **なぜ聞くか**: 掲示板 EDO-0057 は awaiting-user のまま、開口つき長屋の FBX が出ています
- **どちらでも私が動きます**: 裁定済み → 板を直す / 未裁定 → 先行を止める

---
## 【報告1】巡回の鎖が31時間切れていた — ダッシュボードを最新に戻した
## 【報告2】外堀の担当セッションが不在で、10コミットが main へ未マージ
```

---

## 規則8 — 独立に答えられる事柄は、別の件として分ける

⛔ **1件に複数の裁定を詰めない。**

実例 **EDO-0057** — 「其の一=隅部材」と「其の二=門の上の切り欠き」を1件に詰めた。
両方に裁定が下りたが、**その後さらに「天端の段をどちらへ動かすか」が湧いて**、
1件の issue に3つの裁定が積み上がった。片方だけ答えても `status` が動かせず、
**巡回のたびに「未裁定が残っている」ようにしか見えない。**

一件一葉。**issue も、通も、1つの問いに1つ。**

---

## 規則9 — 内部の符牒を裸で出さない。必ず**行き先のリンク**を添える

⛔ **`U12` `EDO-0064` `其十四` `SW2` のような内部の符牒を、それだけで書かない。**
読み手はあなたの文脈を持っていない。符牒は**あなたの頭の中の索引**であって、相手の索引ではない。

> 2026-08-31 ユーザー指摘 — 「**U12 とか言われてもどんな内容だったか分かりません。**
> 必ずタスク表か裁定図、指図の該当箇所のリンクを示すようにしてください。」

**符牒を出すときは、同じ行に必ず3点を添える:**

| # | 添えるもの | 例 |
|---|---|---|
| ① | **一行の中身** | 「掘る水面の SW2 が、自分の合格条件『埋没0%』に2%落ちる件」 |
| ② | **行き先のリンク** | 裁定図の URL / `docs/Sashizu/sotobori_sashizu.html#U12` / `edo_board.py show EDO-0064` |
| ③ | **どこ**(規則の「付」) | 「其十三の埋没表 SW2 の行 / 世界座標 (410,402) 付近」 |

⛔ **悪い例**(実際に差し戻された):

> 残タスク: **U12**(SW2 の埋没2%)— 裁定待ち

⭕ **良い例**:

> **U12 — 掘る水面 SW2 の 2% が石垣の天端に埋まる件**(裁定待ち)
> ・どこ: 其十三の埋没表 SW2 の行、虎ノ門寄りの西端(世界座標 410,402 付近)
> ・中身: 検査の合格条件が「掘る水面の run は埋没 0%」なのに SW2 だけ 2%。掘削の不良ではなく、
>   その区間の現況の地面がもともと石垣の天端より高いため
> ・図: https://claude.ai/code/artifact/... / 指図 `sotobori_sashizu.html` 其十三

### リンクの出し方

⛔ **指図はローカルのパスで示さない。必ず Artifact の URL で示す。**
ユーザーは `docs/Sashizu/*.html` をその場では開けない。パスは**私たちの索引**であって、相手が見る手段ではない。

> 2026-08-31 ユーザー指示 — 「**指図はアーティファクトで示してください。**」

- **指図そのもの** → **Artifact の URL**。台帳は `docs/Sashizu/README.md` の Artifact 列にあり、
  **更新するときは必ずその URL を `url=` に渡して同じ Artifact を上書きする**(新規に公開しない)。
  ⭐ ユーザーに見せる前に**最新の html を再公開してから**リンクを出す — 古い版を指すのは示していないのと同じ。
- **掲示板の件** → 番号だけでなく**題**を書き、`python3 Tools/Session/edo_board.py show EDO-0064` を添える
- **指図の未解決(U◯)** → **Artifact の URL + 図版番号(其◯)**。⭐ 裁定図があるならその URL が最優先
- **図版(其◯)** → 何の図かを1語添える(「其十三 = 石垣の背面の表」)
- **部材・run(SW2 / NE3f …)** → **どこの何か**を添える(「00002 の郭外の石垣」)

⭐ **判定法**: その1行だけを他人に見せて、**相手が中身を言い当てられるか**。
言い当てられないなら、符牒を裸で出している。

## 書式のひな形(そのまま使う)

```markdown
裁定2件・報告2件・共有1件です。裁定だけお答えください
(報告・共有にも番号を振ってあります。何かあれば番号で指してください)。

## 【裁定1】<問いを疑問文か名詞句で。ここだけ読んで何を選ぶか分かること>
- **どこ**: 辺14 s76.50〜79.50(東小門・中心 −474.0,1223.0) / 其の十二 右図
- **行き先**: <裁定図の URL / 指図のパス+図版番号 / `edo_board.py show EDO-◯◯◯◯`>(規則9)
- **背景**: <2文以内>
- **A**: <1行>
- **B**: <1行>
- **推奨**: A — <理由1文>
- **影響**: <動くもの。他邸への波及>
- **裁定図**: <URL>

## 【裁定2】<題>
…

---

## 【報告1】<何をしたか。見出しだけで分かる題>
- ① <1行>
- ② <1行>

## 【報告2】<題>
…

## 【共有1】<他邸がこれから踏むこと>
…
```

⭐ 冒頭の宣言に「**報告・共有にも番号を振ってあるので、番号で指してください**」と
添えておくと、読み手は返事の要らない項目にもコメントしてよいと分かる。

## 掲示板(board)との対応

| 通の種別 | `edo_board.py --type` | status |
|---|---|---|
| 【裁定】 | `decision` | `awaiting-user` |
| 【質問】 | `decision`(選択肢の代わりに聞きたい事実を `--options` に) | `awaiting-user` |
| 【報告】 | 節目のみ `info`。**細かい報告は書かない — コミットが報告を兼ねる** | `open` |
| 【共有】 | `info --estate cross` | `open` |

`edo_board.py post` は**規則6と規則8を機械で弾く**(6点セット欠落・複数の裁定の詰め込み)。
弾かれたら書式を直す。回避しない。

---

## 付 — 「どこ」を必ず示す

裁定・質問・報告のすべてで、**相手が図の上で指させるもの**を最低1つ添える
(2026-08-29 ユーザー差し戻し「どこのことを指してるのか分からない」)。

| 種類 | 書き方の例 |
|---|---|
| 図版番号 | 「**其廿三**の左の図」「取り合い詳細図(御蔵門)」 |
| 外周の位置 | 「**辺14 の s6.8〜12.3**(東辺の北端・隅櫓のすぐ南)」 |
| グリッド | 「**u−18 v62**(長局の南辺の中ほど)」 |
| 世界座標 | 「(−555.5, 1295.6)」 |
| 名前 + 隣接物 | 「`Y_NE_Sode_E`(隅櫓 Y_NE と東小門のあいだ)」 |

⭐ 一番強いのは「**図版番号 + 一言の場所説明**」。図がまだ無いなら**先に図を出してから**求める。
